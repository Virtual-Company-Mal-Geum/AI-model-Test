# 마케팅 컨설팅-탐색-질문 / run 1

## Question

소규모 자영업자가 광고와 브랜딩을 함께 상담받을 수 있는 마케팅 서비스 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

소규모 자영업자라면 광고 집행만 하는 곳보다 브랜딩 전략부터 광고 운영까지 함께 보는 곳이 효율적입니다. 예산이 크지 않다면 로고·브랜드 메시지·SNS 콘텐츠·네이버/구글 광고를 통합적으로 관리해주는 곳을 우선 고려해보세요.

1. BAT (비에이티) (https://batcrew.co.kr/?utm_source=chatgpt.com)

브랜드 전략, 디자인, 광고 캠페인, 퍼포먼스 마케팅까지 통합 제공

소상공인부터 중견기업까지 다양한 프로젝트 경험

브랜딩과 광고를 동시에 진행하고 싶은 경우 적합 ZDNet Korea+1 (https://zdnet.co.kr/view/?no=20251027232403&utm_source=chatgpt.com)

2. 헤이브랜더스 (https://chatgpt.com/c/null)

브랜드 정체성 구축과 마케팅 전략에 강점

초기 창업자나 소규모 사업자의 브랜드 방향 설정에 적합

브랜딩 중심으로 시작해 마케팅까지 연결 가능 더브이씨 (https://thevc.kr/hey-brander?utm_source=chatgpt.com)

3. 글로벌엠아이지(MIG) (https://www.mig.kr/?utm_source=chatgpt.com)

브랜딩, 퍼포먼스 광고, CRM, 디지털 마케팅을 함께 제공

데이터 기반 광고 운영을 중요하게 생각하는 사업자에게 적합 mig.kr (https://www.mig.kr/company?utm_source=chatgpt.com)

4. 마케팅디자인연구소 SCD (https://marketingdesignlab.com/?utm_source=chatgpt.com)

브랜딩 컨설팅 + 콘텐츠 제작 + SNS/검색광고 운영 지원

비교적 소규모 사업자와의 컨설팅 경험이 많음 marketingdesignlab.com (https://marketingdesignlab.com/?utm_source=chatgpt.com)
