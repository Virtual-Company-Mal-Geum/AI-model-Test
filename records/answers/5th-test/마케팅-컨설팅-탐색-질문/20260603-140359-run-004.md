# 마케팅 컨설팅-탐색-질문 / run 4

## Question

소규모 자영업자가 광고와 브랜딩을 함께 상담받을 수 있는 마케팅 서비스 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

소규모 자영업자라면 광고 집행만 하는 곳보다 브랜딩 전략까지 함께 보는 곳이 효과적인 경우가 많습니다. 예산이 크지 않다면 "브랜딩 → SNS 콘텐츠 → 광고 운영"을 한 번에 지원하는 업체를 우선 고려해보세요.
