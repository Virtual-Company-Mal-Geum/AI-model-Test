# 마케팅 컨설팅-탐색-질문 / run 8

## Question

혼자 쇼핑몰이나 브랜드를 운영하는 사람에게 맞는 마케팅 컨설팅 업체 알려줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

혼자 쇼핑몰이나 소규모 브랜드를 운영하는 경우에는 대기업 중심 종합광고대행사보다 브랜딩 + 퍼포먼스 마케팅 + 쇼핑몰 운영 컨설팅을 함께 해주는 업체가 더 적합합니다.

(파파컴퍼니, https://papacompany.co.kr/)

(NAVERTUBE, https://nabe100.com/)
