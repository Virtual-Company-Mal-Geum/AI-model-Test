# 마케팅 컨설팅-탐색-질문 / run 2

## Question

개인 사업자가 온라인 홍보를 위해 상담받을 수 있는 마케팅 업체 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

소상공인·중소기업 대상 맞춤형 광고 전략 제공

광고를 외주 없이 직접 운영한다고 밝히고 있음

SNS 운영, 콘텐츠 제작, 인플루언서 마케팅까지 지원 원플랜 (https://oneplan.co.kr/?utm_source=chatgpt.com)
