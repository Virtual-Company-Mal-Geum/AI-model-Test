# 마케팅 컨설팅-탐색-질문 / run 6

## Question

1인 사업자가 광고 전략이나 SNS 운영을 상담받을 수 있는 곳 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

1인 사업자가 광고 전략, SNS 운영, 콘텐츠 기획 등을 상담받기 좋은 곳을 우선순위로 정리해봤습니다.

1. 소상공인시장진흥공단 컨설팅 (가장 추천)

정부 지원 사업이라 비용 부담이 매우 적음

마케팅, SNS 홍보, 브랜딩, 온라인 판매 전략 등을 전문가와 1:1 상담 가능

예비창업자와 기존 소상공인 모두 신청 가능

컨설팅 비용의 대부분을 정부가 지원 소상공인 컨설팅 시스템 (https://mgr.sbiz.or.kr/cm/intro.do?utm_source=chatgpt.com)

2. 소상공인 온라인 판로 지원사업

SNS 마케팅, 콘텐츠 제작, 광고 운영, 라이브커머스 등 온라인 마케팅 전반 지원

온라인 판매가 목적이라면 실무적인 도움을 받기 좋음

교육 → 컨설팅 → 실행 지원까지 연결 가능 감성채집가+1 (https://creativeflame.tistory.com/1033?utm_source=chatgpt.com)

3. SNS 활용패키지 사업

SNS 채널 진단

광고 전략 수립

타겟 광고 운영 및 성과 분석

전문기관이 직접 컨설팅 제공 기업마당 (https://www.bizinfo.go.kr/see/seeh/selectSmesPblancView.do?pblancId=PBLN_000000000104190&utm_source=chatgpt.com)

4. 지역 소상공인지원센터

경기도를 포함한 각 지역 센터에서 무료 또는 저비용 상담 제공

인스타그램, 블로그, 네이버 플레이스, 스마트스토어 운영 관련 상담 가능

오프라인 방문 상담도 가능

5. 중소기업유통센터(판판대로)

온라인 판로 개척 전문

SNS 마케팅, 상세페이지, 광고 콘텐츠 제작 지원

온라인 판매 중심 사업자에게 적합 감성채집가+1 (https://creativeflame.tistory.com/1033?utm_source=chatgpt.com)
