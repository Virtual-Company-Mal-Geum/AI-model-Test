# 마케팅 컨설팅-탐색-질문 / run 3

## Question

초기 창업자가 마케팅 방향을 잡기 위해 이용할 만한 컨설팅 서비스 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

시장 검증, 사업모델(BM), 투자 연계, 성장 전략 수립 지원

창업 초기 대표가 방향성을 잡기에 적합 kstartup.com (https://kstartup.com/?utm_source=chatgpt.com)
