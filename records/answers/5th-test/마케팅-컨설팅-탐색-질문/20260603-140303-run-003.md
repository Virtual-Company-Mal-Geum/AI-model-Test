# 마케팅 컨설팅-탐색-질문 / run 3

## Question

소규모 자영업자가 광고와 브랜딩을 함께 상담받을 수 있는 마케팅 서비스 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

소규모 자영업자가 광고 집행 + 브랜딩 전략을 함께 상담받으려면 단순 광고대행사보다 브랜드 컨설팅과 콘텐츠 제작까지 제공하는 곳이 더 적합합니다.

1. 토레아도르 에이전시

소상공인 대상 맞춤형 마케팅을 주력으로 함

SNS 마케팅, 인플루언서 마케팅, 브랜드 인지도 향상 전략 제공

비교적 적은 예산으로 시작 가능한 상품 보유 My Site (https://www.toreadoragency.com/?utm_source=chatgpt.com)

URL

(토레아도르 에이전시, https://www.toreadoragency.com/)

2. BAT

국내에서 브랜딩 역량이 강한 종합 브랜드 에이전시

브랜드 전략, 디자인, 마케팅 캠페인을 통합적으로 수행

소상공인 대상 브랜딩·마케팅 컨설팅 프로그램도 운영한 사례가 있음 한경매거진 (https://magazine.hankyung.com/job-joy/article/202510274863d?utm_source=chatgpt.com)

URL

(BAT, https://bat.xyz/ (https://chatgpt.com/c/null))

3. 빵컴퍼니 (카페·베이커리 특화)

소규모 식음료 브랜드에 강점

브랜드 진단, 네이밍, 로고, SNS 브랜딩, 콘텐츠 제작까지 지원

카페·디저트·베이커리 업종이라면 특히 적합 빵모닝 (https://www.bbangmorning.com/37?utm_source=chatgpt.com)

URL

(빵컴퍼니, https://www.bbangmorning.com/37)

4. 마케티

AI 기반 마케팅 플랫폼

광고 소재 제작, SNS 운영, 콘텐츠 생성 자동화에 강점

마케팅 담당자가 없는 1인 사업자에게 적합 markety.co.kr (https://markety.co.kr/?utm_source=chatgpt.com)

URL

(마케티, https://markety.co.kr/)

가장 추천하는 곳

월 예산 50~300만 원 수준의 일반 자영업자 → 토레아도르 에이전시

브랜드를 제대로 만들고 싶은 경우 → BAT

카페·베이커리·식음료 업종 → 빵컴퍼니

최소 비용으로 직접 운영하고 싶은 경우 → 마케티

업종(카페, 병원, 학원, 제조업, 온라인 쇼핑몰 등)을 알려주면 그 업종에 맞는 업체들로 더 구체적으로 추천해줄게.
