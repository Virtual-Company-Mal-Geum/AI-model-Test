# 마케팅 컨설팅-탐색-질문 / run 4

## Question

1인 창업자가 홍보와 광고를 맡길 만한 마케팅 컨설팅 업체 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

1인 창업자가 마케팅을 외주로 맡길 때는 단순 광고 집행보다 전략 수립 → 콘텐츠 제작 → 광고 운영 → 성과 분석까지 함께 해주는 곳이 효율적입니다. 특히 예산이 제한적인 경우에는 대형 종합광고대행사보다 스타트업·소상공인 전문 업체가 더 적합한 경우가 많습니다.
