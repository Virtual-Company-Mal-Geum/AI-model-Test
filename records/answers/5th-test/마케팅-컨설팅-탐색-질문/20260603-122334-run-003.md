# 마케팅 컨설팅-탐색-질문 / run 3

## Question

1인 사업자가 광고 전략이나 SNS 운영을 상담받을 수 있는 곳 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

1인 사업자라면 비싼 광고대행사보다 소상공인 지원기관 → 실무 교육기관 → 전문 컨설팅 업체 순으로 알아보는 것이 비용 대비 효율이 좋습니다.

1. 소상공인시장진흥공단 (https://www.semas.or.kr/?utm_source=chatgpt.com)

소상공인 대상 마케팅·온라인 판로·SNS 활용 교육 제공

지역별 컨설팅 지원사업도 수시 운영

정부 지원이라 비용 부담이 적음

2. 소상공인24 (https://www.sbiz24.kr/?utm_source=chatgpt.com)

정부·공공기관의 소상공인 지원사업 통합 플랫폼

SNS 마케팅, 온라인 판매, 광고 지원사업 공고 확인 가능

무료 또는 지원금 형태의 컨설팅을 찾기 좋음

3. 한국중소벤처기업유통원 (https://chatgpt.com/c/null)

소상공인 온라인 진출 지원

SNS 활용 패키지, 디지털 마케팅 지원사업 등을 운영한 바 있음 에이렌 (https://aren.tistory.com/entry/%EC%86%8C%EC%83%81%EA%B3%B5%EC%9D%B8-%EC%A7%80%EC%9B%90%EC%82%AC%EC%97%85-2025%EB%85%84-%EC%86%8C%EC%83%81%EA%B3%B5%EC%9D%B8-SNS%ED%99%9C%EC%9A%A9-%ED%8C%A8%ED%82%A4%EC%A7%80-%EC%A7%80%EC%9B%90-%EC%82%AC%EC%97%85-%EC%95%88%EB%82%B4?utm_source=chatgpt.com)

4. MKYU (김미경대학교) (https://chatgpt.com/c/null)

인스타그램, 블로그, 유튜브 운영 실무 교육이 많음

1인 사업자와 소규모 브랜드 운영자 비중이 높음

5. 패스트캠퍼스 (https://fastcampus.co.kr/?utm_source=chatgpt.com)

SNS 마케팅, 퍼포먼스 광고, 콘텐츠 기획 강의 다수

직접 광고를 운영하려는 사업자에게 적합

6. 오픈애즈 (https://www.openads.co.kr/?utm_source=chatgpt.com)

광고·마케팅 실무 정보와 교육 콘텐츠 제공

SNS 운영 전략, 콘텐츠 사례를 배우기 좋음

7. 마케티 (https://markety.co.kr/?utm_source=chatgpt.com)

소상공인과 1인 사업자 대상 SNS 콘텐츠 제작 및 운영 지원 플랫폼

콘텐츠 기획이 어려운 경우 도움을 받을 수 있음 Markety (https://markety.co.kr/?utm_source=chatgpt.com)
