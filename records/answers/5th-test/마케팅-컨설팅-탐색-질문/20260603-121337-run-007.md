# 마케팅 컨설팅-탐색-질문 / run 1

## Question

개인 사업자가 온라인 홍보를 위해 상담받을 수 있는 마케팅 업체 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

개인사업자가 온라인 홍보를 위해 상담받기 좋은 업체를 기준으로 소상공인 대응 경험, 온라인 광고 운영 범위, 상담 접근성, SEO/콘텐츠 역량을 중심으로 추려봤습니다.

1. 원플랜마케팅 (https://oneplan.co.kr/?utm_source=chatgpt.com)
네이버·구글·메타 광고를 중심으로 운영하며, 소상공인·중소기업 대상 마케팅 컨설팅을 별도로 제공하고 있습니다. 광고 집행뿐 아니라 SEO, 콘텐츠, SNS 운영까지 통합적으로 상담받을 수 있는 점이 장점입니다. 특히 예산이 크지 않은 개인사업자에게 맞춘 전략을 강조하고 있습니다. oneplan.co.kr+1 (https://oneplan.co.kr/?utm_source=chatgpt.com)

2. 엠노베이션(MNOVATION) (https://mnovation.co.kr/?utm_source=chatgpt.com)
콘텐츠 기반 온라인 마케팅을 주력으로 하며, 광고대행·인플루언서 마케팅·브랜딩까지 폭넓게 지원합니다. 처음 온라인 마케팅을 시작하는 사업자가 상담받기 좋은 종합형 대행사입니다. 엠노베이션 : 온라인마케팅 파트너 (https://mnovation.co.kr/?utm_source=chatgpt.com)

3. 마케티 (https://markety.co.kr/?utm_source=chatgpt.com)
전통적인 대행사라기보다는 AI 기반 마케팅 플랫폼에 가깝습니다. 광고 대행 비용이 부담되는 1인 사업자나 소규모 쇼핑몰 운영자에게 적합하며, SNS 콘텐츠 제작 자동화에 강점이 있습니다. markety.co.kr (https://markety.co.kr/?utm_source=chatgpt.com)
