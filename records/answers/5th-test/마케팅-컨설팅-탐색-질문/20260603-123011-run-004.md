# 마케팅 컨설팅-탐색-질문 / run 4

## Question

초기 창업자가 마케팅 방향을 잡기 위해 이용할 만한 컨설팅 서비스 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

초기 창업자가 마케팅 방향(포지셔닝, 고객 정의, GTM 전략, 브랜딩, 퍼포먼스 마케팅 등)을 잡기 위해 활용하기 좋은 곳들을 유형별로 추천할게요.

마케팅 전략뿐 아니라 투자유치, 사업개발까지 함께 점검 가능
