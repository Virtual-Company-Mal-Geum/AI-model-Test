# 온라인 강좌-탐색-질문 / run 9

## Question

프로그래밍 경험이 없는 사람이 입문용으로 듣기 좋은 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍이 처음이라면 “문법 암기”보다 재미있게 따라 만들 수 있는 강의가 훨씬 중요해요. 아래 순서대로 보면 부담이 적습니다.

생활코딩 → 가장 쉬운 입문

코드잇 / 인프런 → 한국어로 체계적으로 학습

CS50 → 제대로 기초 다지기

freeCodeCamp → 무료 실습 위주

추천 강좌들:

생활코딩 (완전 초보용, 무료)

HTML, CSS, JavaScript부터 차근차근 설명해줘서 “컴퓨터 잘 모르는 사람”도 많이 시작해요.

웹사이트 만드는 재미를 빨리 느낄 수 있음.

(생활코딩, https://opentutorials.org/course/1 (https://opentutorials.org/course/1?utm_source=chatgpt.com))

인프런 - 파이썬 입문 강의들 (한국어, 쉬운 편)

다양한 강사가 있어서 스타일 맞는 강의를 고를 수 있어요.

“파이썬 입문”, “코딩 왕초보” 검색 추천.

(인프런, https://www.inflearn.com/ (https://www.inflearn.com/?utm_source=chatgpt.com))

코드잇 (초보 친화적, 유료)

인터랙티브 방식이라 직접 코드를 치면서 배우기 쉬움.

디자인도 깔끔해서 공부 진입장벽이 낮아요.

(코드잇, https://codeit.kr/ (https://codeit.kr/?utm_source=chatgpt.com))

CS50 by Harvard (세계적으로 유명한 입문 강의)

난이도는 조금 있지만 “왜 이렇게 동작하는지”를 잘 알려줘요.

자막 지원됨.

(CS50, https://cs50.harvard.edu/x/ (https://cs50.harvard.edu/x/?utm_source=chatgpt.com))

freeCodeCamp (무료 + 실습 중심)

영어지만 실습이 많아서 따라 하다 보면 실력이 빨리 늘어요.

웹개발 입문에 특히 좋음.

(freeCodeCamp, https://www.freecodecamp.org/ (https://www.freecodecamp.org/?utm_source=chatgpt.com))

추천 루트도 간단히 말하면:

완전 처음 → 생활코딩

한국어로 체계적 → 코드잇 / 인프런

제대로 깊게 배우기 → CS50

무료 실습 많이 → freeCodeCamp

그리고 처음 언어는 보통 Python(파이썬) 을 가장 추천해요. 문법이 쉬워서 초보자가 좌절하기 덜합니다.
