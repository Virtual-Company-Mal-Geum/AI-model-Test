# 온라인 강좌-탐색-질문 / run 5

## Question

프로그래밍 경험이 없는 사람이 입문용으로 듣기 좋은 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 한 번도 해본 적 없다면, 처음에는 Python(파이썬) 이나 웹 개발 기초(HTML/CSS/JavaScript) 를 배우는 과정이 가장 진입장벽이 낮습니다. 아래 강의들은 초보자들이 많이 추천하는 입문용 강좌들입니다.

1. 생활코딩 (가장 추천)

완전 초보자를 대상으로 설명이 매우 친절함

프로그래밍이 무엇인지부터 웹, Python, JavaScript까지 단계별 학습 가능

대부분 무료

"코딩이 처음인데 어디서 시작해야 할지 모르겠다"는 사람에게 적합 Keep going+1 (https://keeeepgoing.tistory.com/1?utm_source=chatgpt.com)

2. Codecademy

브라우저에서 바로 코딩하면서 배우는 방식

설치 과정 없이 실습 가능

영어 강의지만 인터랙티브해서 입문자에게 좋음 Keep going (https://keeeepgoing.tistory.com/1?utm_source=chatgpt.com)

3. Coursera

해외 대학(스탠퍼드, 미시간대 등)의 입문 강좌 제공

체계적으로 배우고 싶은 사람에게 적합

일부 강좌는 무료 청강 가능 Reddit (https://www.reddit.com/r/chatgpt_newtech/comments/12p24g7?utm_source=chatgpt.com)

4. 인프런

한국어 강의가 매우 많음

"파이썬 입문", "웹 개발 입문" 등 검색하면 초보자용 강좌 다수

실무 중심 강의가 많음 인프런+1 (https://www.inflearn.com/course/%ED%81%B4%EB%A1%9C%EB%93%9C-%EC%BD%94%EB%93%9C-%EC%99%84%EB%B2%BD-%EB%A7%88%EC%8A%A4%ED%84%B0-ai-%EA%B0%9C%EB%B0%9C?utm_source=chatgpt.com)

5. CS50 (하버드대학교)

세계적으로 유명한 컴퓨터공학 입문 강의

난이도는 약간 있지만 기초를 탄탄하게 다질 수 있음

무료 제공

입문자 추천 학습 순서

생활코딩 → 웹 개발 기초 또는 Python

Codecademy로 실습

인프런 또는 Coursera로 관심 분야 심화

CS50로 컴퓨터공학 기초 학습

요청하신 형식으로 URL을 정리하면:

Coursera, https://www.coursera.org/
