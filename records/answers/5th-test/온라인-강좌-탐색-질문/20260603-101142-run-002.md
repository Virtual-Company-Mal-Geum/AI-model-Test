# 온라인 강좌-탐색-질문 / run 2

## Question

코딩 기초를 배우고 싶은 성인에게 알맞은 온라인 강의 플랫폼 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

코딩 기초를 처음 배우는 성인이라면, “설명이 쉬운가”, “실습 중심인가”, “한국어 지원이 되는가”, “꾸준히 따라가기 좋은 구조인가”를 기준으로 고르는 게 좋아요. 아래 플랫폼들은 입문자 만족도가 높은 편입니다.

한국어 중심으로 배우기 좋은 곳

인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 많고, 파이썬·웹개발·앱개발 입문 강의가 특히 다양해요. 실무형 강의도 많아서 기초 이후까지 이어가기 좋습니다.

생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

완전 초보에게 가장 많이 추천되는 무료 플랫폼 중 하나예요. HTML, CSS, JavaScript, Python 등을 아주 쉽게 설명합니다.

패스트캠퍼스 (https://fastcampus.co.kr/?utm_source=chatgpt.com)

체계적인 커리큘럼이 강점이에요. 부트캠프 스타일이나 프로젝트형 강의가 많습니다.

코드잇 (https://www.codeit.kr/?utm_source=chatgpt.com)

인터랙티브 학습 방식이라 처음 배우는 성인이 따라가기 편해요. 짧게 실습하며 배우는 스타일입니다.

해외 플랫폼 (영어 가능하면 추천)

Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코드를 작성하며 배우는 방식이라 입문 난도가 낮습니다.

freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

무료인데도 커리큘럼이 탄탄해요. 웹개발 입문에 특히 강합니다.

Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학·기업 강의를 들을 수 있어요. 기초 컴퓨터공학과 프로그래밍을 체계적으로 배우기 좋습니다.

Udemy (https://www.udemy.com/?utm_source=chatgpt.com)

할인 폭이 큰 편이라 저렴하게 원하는 기술을 골라 배우기 좋아요.

목적별 추천

완전 처음 + 한국어 → 생활코딩, 코드잇

취업/실무까지 생각 → 인프런, 패스트캠퍼스

영어 괜찮고 실습 선호 → Codecademy, freeCodeCamp

대학식 체계 학습 → Coursera
