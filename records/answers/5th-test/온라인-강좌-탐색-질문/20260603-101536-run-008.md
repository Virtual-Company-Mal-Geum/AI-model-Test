# 온라인 강좌-탐색-질문 / run 8

## Question

코딩 기초를 배우고 싶은 성인에게 알맞은 온라인 강의 플랫폼 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

코딩 기초를 처음 배우는 성인이라면, **“설명이 쉬운가 + 실습이 많은가 + 꾸준히 이어가기 좋은가”**를 기준으로 고르는 게 중요해요. 아래 플랫폼들은 입문자에게 특히 평가가 좋은 곳들입니다.

한국어로 배우기 좋은 플랫폼
1. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 매우 많고, 입문 강좌가 특히 강함

Python, 웹개발, 앱개발, AI까지 단계별 학습 가능

“따라 만들기” 스타일 강의가 많아서 초보자에게 편함

질문 답변 문화가 활발한 편

추천 대상:

완전 비전공자

한국어 설명 선호

실무 감각도 함께 배우고 싶은 사람

2. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

무료로 시작 가능

개념 설명을 정말 쉽게 해주는 것으로 유명

HTML/CSS/JavaScript 같은 웹 기초 학습에 최고 수준

추천 대상:

“코딩이 뭔지”부터 천천히 배우고 싶은 사람

부담 없이 입문하고 싶은 사람

3. 패스트캠퍼스 (https://fastcampus.co.kr/?utm_source=chatgpt.com)

커리어 전환용 강의가 많음

실무 프로젝트 중심 강의가 강점

데이터 분석, AI, 프론트엔드 등 트랙 다양

추천 대상:

취업/이직 목표가 있는 성인

체계적인 커리큘럼 선호

해외 플랫폼 (영어 가능하면 강력 추천)
4. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저 안에서 바로 코딩 가능

설치 없이 실습 중심 학습

인터랙티브 방식이라 초보자 만족도가 높음

추천 대상:

손으로 직접 해보며 배우는 스타일

짧게 자주 공부하고 싶은 사람

5. Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학/기업 강의를 온라인으로 제공

Google, University of Michigan 같은 기관 강의 인기

수료증 과정도 많음

추천 대상:

체계적인 학습 선호

장기적으로 전문성까지 키우고 싶은 사람

6. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

거의 전 과정 무료

실습 + 프로젝트 중심

웹개발 입문에 매우 유명

추천 대상:

비용 부담 없이 깊게 배우고 싶은 사람

꾸준히 프로젝트 해보고 싶은 사람

처음 시작한다면 추천 학습 순서

HTML/CSS → 웹페이지 만들기

JavaScript 또는 Python 선택

작은 프로젝트 만들기

Git/GitHub 익히기

관심 분야(웹/앱/데이터/AI) 확장

요청한 형식으로 URL 정리

(생활코딩, https://opentutorials.org/)

(패스트캠퍼스, https://fastcampus.co.kr/)

(Codecademy, https://www.codecademy.com/)

(Coursera, https://www.coursera.org/)
