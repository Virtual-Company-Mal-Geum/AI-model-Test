# 온라인 강좌-탐색-질문 / run 7

## Question

비전공 성인이 프로그래밍을 배우기 좋은 온라인 교육 사이트 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

비전공 성인이 시작하기 좋은 기준으로 골라봤어.

(한글 지원, 난이도, 실습 중심 여부, 취업/포트폴리오 연결 가능성 등을 기준으로 추천)

처음 시작하기 가장 쉬운 곳
1. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

한국어 입문 강의의 대표격

HTML/CSS, JavaScript, Python, 데이터베이스까지 기초를 아주 쉽게 설명

“프로그래밍이 뭔지 감 잡기”에 최고

무료 강의가 많아서 부담이 적음

추천 대상:

완전 처음 시작하는 사람

컴퓨터 용어도 낯선 사람

2. 프로그래머스 (https://programmers.co.kr/?utm_source=chatgpt.com)

한국 취업 준비와 연결성이 강함

코딩 테스트 + 강의 + 실습 환경이 잘 되어 있음

Python, JavaScript, SQL 입문 코스가 괜찮음

추천 대상:

나중에 취업/이직까지 생각하는 사람

실습 문제를 많이 풀고 싶은 사람

3. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 매우 많음

입문부터 실무까지 범위가 넓음

강사 스타일이 다양해서 자기한테 맞는 수업 찾기 좋음

추천 대상:

영상 강의 스타일을 좋아하는 사람

웹개발/앱개발/AI 등 방향을 아직 고민 중인 사람

해외 사이트 중 추천
4. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

전 세계 입문자들에게 가장 유명한 무료 플랫폼 중 하나

직접 코드를 치면서 배우는 방식

웹개발 중심으로 매우 강력함

추천 대상:

영어가 아주 어렵지만 않다면 최고의 무료 선택지

“손으로 많이 해보며 배우기” 원하는 사람

5. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

인터랙티브 학습이 매우 잘 되어 있음

설치 없이 브라우저에서 바로 코딩 가능

초보 친화적 UI

추천 대상:

게임 튜토리얼처럼 단계별 학습 좋아하는 사람

짧게 매일 공부하고 싶은 사람

6. CS50 (Harvard) (https://cs50.harvard.edu/?utm_source=chatgpt.com)

하버드의 유명한 컴퓨터과학 입문 강의

난이도는 조금 있지만 개념 이해가 매우 탄탄해짐

무료

추천 대상:

“제대로” 기초를 배우고 싶은 사람

장기적으로 개발자를 목표로 하는 사람

AI 시대 기준으로 특히 추천하는 학습 순서
비전공 성인이라면 보통 이 순서가 효율 좋아:

HTML/CSS + JavaScript 기초

Python 기초

Git/GitHub

간단한 프로젝트 만들기

AI 도구(ChatGPT, Copilot 등)와 함께 개발하기

추천 조합 (현실적으로 가장 많이 성공하는 루트)

완전 초보:

생활코딩 → 인프런 입문 강의

취업/이직 목표:

프로그래머스 → 인프런 → 포트폴리오 제작

영어 가능 + 무료 선호:

freeCodeCamp → CS50

요청한 형식으로 URL만 정리

(생활코딩, https://opentutorials.org/)

(프로그래머스, https://programmers.co.kr/)

(인프런, https://www.inflearn.com/)

(freeCodeCamp, https://www.freecodecamp.org/)

(Codecademy, https://www.codecademy.com/)

(CS50, https://cs50.harvard.edu/)
