# 온라인 강좌-탐색-질문 / run 3

## Question

코딩 기초를 배우고 싶은 성인에게 알맞은 온라인 강의 플랫폼 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

코딩 기초를 처음 배우는 성인이라면, 학습 스타일(영상 중심 / 실습 중심 / 체계적 커리큘럼 / 영어 가능 여부) 에 따라 잘 맞는 플랫폼이 달라져요. 아래는 입문자에게 특히 평이 좋은 온라인 강의 플랫폼들입니다.

한국어로 배우기 좋은 플랫폼
1. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 매우 많고, 입문자용 강좌가 풍부함

Python, 웹개발, 앱개발, AI 등 분야 다양

실무 개발자 강의가 많아서 현실적인 예제를 접하기 좋음

커뮤니티와 Q&A 활성화

추천 대상:

완전 초보

한국어 설명 선호

취업/실무까지 이어가고 싶은 사람

2. 패스트캠퍼스 (https://fastcampus.co.kr/?utm_source=chatgpt.com)

커리큘럼이 비교적 체계적

부트캠프 스타일 강의가 많음

데이터분석, 프론트엔드, 백엔드 등 직무별 학습 가능

추천 대상:

“무엇부터 해야 할지” 정리된 로드맵이 필요한 사람

장기적으로 커리어 전환을 고려하는 사람

3. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

무료

코딩 개념 설명이 아주 친절함

HTML/CSS/JavaScript/Python 입문에 특히 강함

추천 대상:

비용 부담 없이 시작하고 싶은 사람

“코딩이 뭔지” 감 잡고 싶은 완전 입문자

영어 가능하면 강력 추천
4. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코딩 실습 가능

따라 치면서 배우는 구조라 초보자 친화적

인터랙티브 학습 경험이 뛰어남

추천 대상:

이론보다 직접 해보며 배우는 스타일

영어 읽기에 큰 부담 없는 사람

5. Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학/기업(예: Google, Stanford) 강의 제공

수료증 과정도 많음

CS 기초를 체계적으로 배우기 좋음

추천 대상:

깊이 있게 배우고 싶은 사람

인증서나 체계적인 학습 선호

6. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

무료

웹개발 중심 실습형 학습

프로젝트 기반 학습이 강점

추천 대상:

직접 프로젝트 만들면서 배우고 싶은 사람

비용 없이 꾸준히 공부하고 싶은 사람

처음 시작한다면 추천 학습 순서
보통 아래 순서가 가장 무난합니다:

Python 기초 또는 웹기초(HTML/CSS)

간단한 프로젝트 만들기

Git/GitHub 배우기

관심 분야 선택

웹개발

앱개발

게임

데이터분석/AI 등

한 줄 추천

완전 초보 + 한국어 → 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com) 또는 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

실습형 → Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)
