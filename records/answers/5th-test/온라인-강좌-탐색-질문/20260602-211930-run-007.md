# 온라인 강좌-탐색-질문 / run 7

## Question

프로그래밍 경험이 없는 사람이 입문용으로 듣기 좋은 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 시작하는 사람이라면, “문법 암기”보다 재미 있게 직접 만들어보는 방식의 강좌가 훨씬 오래 갑니다. 아래는 입문자 만족도가 높은 온라인 강좌/플랫폼들이에요.

생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

한국어 무료 강의의 대표적인 입문 플랫폼

HTML/CSS, JavaScript, Python, 데이터베이스까지 기초를 쉽게 설명

“코딩이 뭔지 전혀 모르겠다” 수준에도 잘 맞음

Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저 안에서 바로 코드를 입력하며 배우는 방식

영어 기반이지만 인터랙티브해서 초보자 친화적

Python 입문 코스로 특히 유명

인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 많고 실무 중심 강좌가 다양함

“입문자를 위한 Python”, “웹 개발 기초” 같은 강좌 추천

무료 강의도 꽤 많음

Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학 수준의 체계적인 강의를 들을 수 있음

Google, University of Michigan 등의 입문 강좌가 유명

자막 지원 강의가 많음

freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료

웹 개발, Python, 데이터 분석 등을 프로젝트 중심으로 학습 가능

실습량이 많아서 “직접 만들면서 배우는 스타일”에 적합

Udemy (https://www.udemy.com/?utm_source=chatgpt.com)

할인할 때 저렴하게 강의를 구매 가능

강의 수가 엄청 많아서 원하는 분야를 찾기 쉬움

평점과 수강생 수를 꼭 확인하는 게 중요

처음 시작한다면 추천 순서는 보통 이렇게 많이 갑니다:

완전 처음 → 생활코딩

재미 붙이기 → Codecademy

본격적으로 배우기 → 인프런 / freeCodeCamp

체계적인 공부 → Coursera

마지막으로 요청한 형식으로 정리하면:

(생활코딩, https://opentutorials.org/)

(Codecademy, https://www.codecademy.com/)

(인프런, https://www.inflearn.com/)

(Coursera, https://www.coursera.org/)

(freeCodeCamp, https://www.freecodecamp.org/)

(Udemy, https://www.udemy.com/)
