# 온라인 강좌-탐색-질문 / run 2

## Question

프로그래밍 경험이 없는 사람이 입문용으로 듣기 좋은 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 시작하는 사람이라면 “재미를 느끼면서 작은 결과물을 빨리 만들어보는 강의”가 가장 중요해요.

아래는 입문자 기준으로 특히 많이 추천되는 온라인 강좌들이에요.

한국어 입문 강좌
1. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 많고, 완전 초보 대상 강좌가 다양해요.

“파이썬 입문”, “웹 개발 기초”, “코딩테스트 기초” 같은 단계별 학습 가능

실습 중심 강의가 많아서 따라가기 쉬움

추천 대상:

한국어로 천천히 배우고 싶은 사람

처음부터 너무 이론적으로 배우기 싫은 사람

(인프런, https://www.inflearn.com/)

2. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

무료로 배울 수 있는 대표적인 프로그래밍 입문 사이트

설명이 친절하고 “왜 배우는지”를 잘 알려줘서 초보자 만족도가 높음

HTML/CSS/JavaScript 웹 개발 입문이 특히 유명

추천 대상:

무료로 시작하고 싶은 사람

웹사이트 만들기에 관심 있는 사람

(생활코딩, https://opentutorials.org/)

3. 노마드코더 (https://nomadcoders.co/?utm_source=chatgpt.com)

“무조건 만들어보는 방식”의 강의 스타일

유튜브 느낌으로 재밌게 진행돼서 지루하지 않음

클론코딩 중심이라 결과물이 빨리 나옴

추천 대상:

영상 스타일 강의를 좋아하는 사람

앱/웹사이트 직접 만들어보고 싶은 사람

(노마드코더, https://nomadcoders.co/)

해외 플랫폼 (영어 가능하면 강추)
4. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코딩 가능

설치 없이 실습 가능해서 진입장벽이 낮음

인터랙티브 방식이라 게임처럼 배움

추천 대상:

영어가 크게 부담되지 않는 사람

직접 입력하면서 배우는 스타일 선호

(Codecademy, https://www.codecademy.com/)

5. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료

커리큘럼이 체계적이고 프로젝트 중심

웹 개발 입문자들에게 특히 유명

추천 대상:

비용 없이 제대로 배우고 싶은 사람

장기적으로 개발자까지 생각하는 사람

(freeCodeCamp, https://www.freecodecamp.org/)

6. Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학 수준 강의를 온라인으로 제공

Stanford University, University of Michigan 같은 대학 강의도 있음

수료증 과정도 많음

추천 대상:

체계적으로 배우고 싶은 사람

나중에 포트폴리오/수료증도 고려하는 사람

(Coursera, https://www.coursera.org/)

완전 초보라면 추천 학습 순서

HTML/CSS로 간단한 웹페이지 만들기

Python 또는 JavaScript 중 하나 선택

작은 프로젝트 만들어보기

Git/GitHub 익히기

보통은:

“웹사이트 만들고 싶다” → JavaScript

“쉬운 문법부터 배우고 싶다” → Python

으로 시작하는 경우가 많아요.
