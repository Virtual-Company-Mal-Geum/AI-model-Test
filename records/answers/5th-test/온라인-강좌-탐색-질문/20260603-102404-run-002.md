# 온라인 강좌-탐색-질문 / run 2

## Question

프로그래밍을 독학하려는 성인에게 적합한 온라인 강의 사이트를 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 독학하려는 성인이라면, **“어떤 스타일로 배우고 싶은지”**에 따라 좋은 사이트가 달라져요.

아래는 입문자부터 실무 지향까지 많이 추천되는 온라인 강의 플랫폼들입니다.

입문자에게 특히 좋은 곳
1. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코드를 실행하면서 배울 수 있어서 초보자에게 매우 편함

Python, JavaScript, 웹 개발, 데이터 분석 등 다양함

“직접 따라치며 배우는 방식”을 좋아하면 잘 맞음

2. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

무료 중심 플랫폼

웹 개발, Python, 데이터 분석, AI 기초까지 가능

프로젝트 기반이라 포트폴리오 만들기 좋음

영어 기반이지만 난이도 설명이 친절한 편

3. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 매우 많음

국내 개발 환경과 취업 흐름에 맞춘 강의가 많음

입문 강의부터 실무 강의까지 폭넓음

4. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

완전 초보에게 강력 추천

프로그래밍 개념을 쉽게 설명함

HTML/CSS/JS, Python 등 기초 공부에 좋음

무료 콘텐츠가 많음

체계적으로 배우기 좋은 곳
5. Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학/기업 강의를 온라인으로 제공

Google, Stanford University 같은 기관 강의도 있음

컴퓨터공학 기초를 체계적으로 배우기 좋음

수료증 과정도 있음

6. edX (https://www.edx.org/?utm_source=chatgpt.com)

대학 강의 스타일

CS50 같은 유명 컴퓨터공학 입문 강의 제공

이론 + 실습 균형이 좋음

7. Udemy (https://www.udemy.com/?utm_source=chatgpt.com)

강의 수가 엄청 많고 할인도 자주 함

특정 기술을 빠르게 배우기 좋음

강사 품질 차이가 있어서 평점 확인 중요

실무·취업 중심
8. The Odin Project (https://www.theodinproject.com/?utm_source=chatgpt.com)

웹 개발자를 목표로 할 때 유명

무료

실제 프로젝트를 만들며 배우는 스타일

자기주도 학습 능력을 키우기 좋음

9. CS50 by Harvard (https://cs50.harvard.edu/?utm_source=chatgpt.com)

컴퓨터공학 사고방식을 제대로 배우고 싶을 때 추천

난이도는 조금 있지만 매우 유명한 입문 강의

강의 퀄리티가 높음

10. LeetCode (https://leetcode.com/?utm_source=chatgpt.com)

코딩 테스트/알고리즘 연습용

어느 정도 기초를 배운 뒤 사용 추천

개발자 취업 준비에 많이 활용됨

처음 시작한다면 추천 조합

완전 초보 + 한국어 선호

→ 생활코딩 → 인프런

영어 가능 + 실습 중심

→ Codecademy → freeCodeCamp

취업 목표

→ The Odin Project + LeetCode

CS 기초까지 제대로

→ CS50 + Coursera
