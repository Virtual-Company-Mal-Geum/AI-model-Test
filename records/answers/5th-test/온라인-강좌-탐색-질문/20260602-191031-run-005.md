# 온라인 강좌-탐색-질문 / run 5

## Question

프로그래밍 입문자가 기초부터 배울 수 있는 온라인 강좌를 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍 입문자라면 “문법만 배우는 강의”보다 직접 만들어보는 방식의 강좌가 훨씬 오래 기억에 남아요. 아래는 초보자가 시작하기 좋은 온라인 강좌들을 난이도와 특징 기준으로 정리한 추천입니다.

한국어로 배우기 좋은 강좌
1. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

완전 입문자에게 가장 유명한 무료 강좌 중 하나

HTML, CSS, JavaScript, Python, 데이터베이스까지 기초를 천천히 설명

“왜 이걸 배우는지”를 이해하기 쉽게 알려줌

영상 길이가 짧아서 부담이 적음

추천 대상:

컴퓨터/코딩이 처음인 사람

무료로 시작하고 싶은 사람

(생활코딩, https://opentutorials.org/)

2. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 매우 많음

“파이썬 입문”, “웹 개발 입문”, “앱 만들기” 같은 실전형 강좌 다양

무료 강의도 많고 로드맵 기능이 좋아서 방향 잡기 쉬움

추천 대상:

체계적으로 배우고 싶은 사람

한국어 설명을 선호하는 사람

(인프런, https://www.inflearn.com/)

3. 프로그래머스 (https://programmers.co.kr/?utm_source=chatgpt.com)

코딩 테스트 플랫폼으로 유명하지만 입문 강좌도 괜찮음

문제를 직접 풀면서 배우는 스타일

취업 준비까지 연결하기 좋음

추천 대상:

나중에 개발자 취업도 관심 있는 사람

문제 풀이형 학습을 좋아하는 사람

(프로그래머스, https://programmers.co.kr/)

해외 강좌 (무료/고품질)
4. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

전 세계 입문자들이 많이 사용하는 무료 플랫폼

웹 개발, Python, 데이터 분석 등을 프로젝트 중심으로 배움

실제 포트폴리오를 만들 수 있음

추천 대상:

영어 읽기에 큰 거부감이 없는 사람

실습 위주 학습을 원하는 사람

(freeCodeCamp, https://www.freecodecamp.org/)

5. CS50 by Harvard (https://cs50.harvard.edu/x?utm_source=chatgpt.com)

하버드대의 유명한 컴퓨터공학 입문 강의

난이도는 조금 있지만 설명 퀄리티가 매우 높음

프로그래밍 사고력을 제대로 길러줌

추천 대상:

제대로 기초를 다지고 싶은 사람

천천히 깊게 배우고 싶은 사람

(CS50, https://cs50.harvard.edu/x/)

6. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코드를 작성하면서 배울 수 있음

인터랙티브 방식이라 재미있게 진행 가능

Python 입문 코스로 특히 유명

추천 대상:

실습형 인터페이스를 좋아하는 사람

설치 없이 바로 시작하고 싶은 사람

(Codecademy, https://www.codecademy.com/)

처음 시작한다면 추천 순서
완전 처음이라면 보통 이 순서가 가장 무난합니다:

HTML/CSS로 웹페이지 만들기

JavaScript 기초

Python 기초

간단한 프로젝트 만들기

Git/GitHub 배우기

입문 언어 추천

웹사이트 만들기 관심 → JavaScript

쉬운 문법부터 시작 → Python

앱/게임 관심 → JavaScript 또는 Python

진로로 개발자 생각 → Python + JavaScript 조합 추천

원하면 다음 단계로:

“하루 1시간 기준 3개월 공부 로드맵”

“중학생/고등학생에게 쉬운 강좌”

“무료 강좌만 모아서 추천”

“게임 만들기로 배우는 코딩”

“파이썬 입문 강의 TOP5 비교”

같은 것도 정리해줄 수 있어요.
