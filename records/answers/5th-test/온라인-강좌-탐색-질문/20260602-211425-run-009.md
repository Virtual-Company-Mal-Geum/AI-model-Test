# 온라인 강좌-탐색-질문 / run 8

## Question

성인 초보자가 따라가기 쉬운 프로그래밍 강좌 사이트를 알려줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

성인 초보자가 시작하기 쉬운 프로그래밍 강좌 사이트들을 난이도·설명 방식 기준으로 골라봤어.

특히 “처음 배우는 사람” 기준으로 추천했어.

Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

인터랙티브 방식이라 설치 없이 바로 코딩 가능

Python, JavaScript 입문이 특히 쉬움

영어 사이트지만 초보자 친화적

생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

한국어 무료 강의의 대표격

웹 개발, Python, 데이터베이스 등을 아주 천천히 설명

비전공 성인 입문자에게 특히 인기

프로그래머스 (https://programmers.co.kr/?utm_source=chatgpt.com)

한국어 강의 + 코딩 테스트 연습 가능

실습 중심이라 배운 내용을 바로 써볼 수 있음

취업 준비까지 연결하기 좋음

인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 매우 많음

“왕초보” 대상 강좌가 다양

웹 개발, 앱 개발, AI 등 분야 선택 폭이 넓음

freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료

단계별 프로젝트 방식

웹 개발 공부에 매우 강함

Khan Academy Computer Programming (https://www.khanacademy.org/computing/computer-programming?utm_source=chatgpt.com)

그림·애니메이션 활용 설명이 쉬움

완전 초보자용으로 적합

부담 없이 맛보기 가능

CS50 by Harvard (https://cs50.harvard.edu/x/?utm_source=chatgpt.com)

유명한 컴퓨터공학 입문 강의

난이도는 약간 있지만 설명 퀄리티가 매우 높음

“제대로 기초 다지기”에 좋음

요약하면:

완전 처음 → 생활코딩 / Codecademy

한국어 실습 중심 → 프로그래머스 / 인프런

무료 위주 → freeCodeCamp / 생활코딩

체계적 CS 기초 → CS50

원하면 내가:

“문과 성인 초보자용 추천 순서”

“Python부터 시작하는 가장 쉬운 루트”

“3개월 공부 계획”

“무료만으로 배우는 로드맵”

도 정리해줄게.
