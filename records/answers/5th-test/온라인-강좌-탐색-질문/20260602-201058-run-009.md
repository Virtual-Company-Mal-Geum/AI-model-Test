# 온라인 강좌-탐색-질문 / run 3

## Question

프로그래밍 입문자가 기초부터 배울 수 있는 온라인 강좌를 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍 입문자라면 “문법만” 배우기보다 작은 프로젝트를 직접 만들어보는 강의가 훨씬 오래 기억됩니다. 아래는 초보자가 시작하기 좋은 온라인 강좌/플랫폼들이에요.

한국어로 배우기 좋은 강좌
1. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 매우 많고 입문자용 콘텐츠가 풍부함

Python, 웹개발, Java, AI 등 분야별 로드맵이 잘 정리되어 있음

무료 강의도 많아서 부담 없이 시작 가능

추천 입문 강의:

“파이썬 입문”

“웹 개발 왕초보”

“생활코딩 연계 강의”

2. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

완전 초보자 기준으로 설명이 쉬움

HTML/CSS/JavaScript부터 서버, 데이터베이스까지 연결해서 배울 수 있음

“왜 배우는지”를 잘 설명해줘서 입문자 만족도가 높음

특히 추천:

WEB1 HTML & Internet

JavaScript 기초

Python 기초

3. 패스트캠퍼스 (https://fastcampus.co.kr/?utm_source=chatgpt.com)

실무 중심 강의가 많음

디자인, 데이터분석, 앱개발 등 분야가 다양함

할인 이벤트가 자주 있음

추천 대상:

“취업용 포트폴리오”까지 생각하는 입문자

해외 플랫폼 (영어 가능하면 강력 추천)
4. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료

실습 위주

웹개발 입문에 세계적으로 유명함

프로젝트를 만들면서 배우는 방식

추천 코스:

Responsive Web Design

JavaScript Algorithms and Data Structures

5. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저 안에서 바로 코딩 가능

인터랙티브 방식이라 초보자에게 매우 친절함

Python 입문 코스가 특히 유명

6. Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학 수준 강의를 들을 수 있음

스탠퍼드, 미시간대 등의 강좌 제공

체계적으로 공부하고 싶은 사람에게 좋음

추천 강좌:

Python for Everybody

어떤 언어부터 시작하면 좋을까?

Python → 가장 추천 (문법 쉬움, AI/자동화/데이터 활용 가능)

JavaScript → 웹사이트 만들고 싶다면 추천

Java → 앱/취업 대비용으로 많이 사용

C언어 → 컴퓨터 구조까지 깊게 배우고 싶을 때

처음이라면:

Python 기초

간단한 프로젝트

웹 or AI or 앱 중 관심 분야 선택
