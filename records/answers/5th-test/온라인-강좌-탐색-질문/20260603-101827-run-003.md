# 온라인 강좌-탐색-질문 / run 3

## Question

초보자가 프로그래밍 개념부터 차근차근 배울 수 있는 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 시작한다면, “문법 암기”보다 “컴퓨터가 어떻게 생각하는지”를 이해하는 강의부터 듣는 게 좋아요. 아래 순서대로 배우면 비교적 덜 막히면서 실력을 쌓을 수 있습니다.

생활코딩 — 완전 초보자용으로 가장 유명한 한국어 무료 강좌. 웹, Python, JavaScript 등 기초를 아주 쉽게 설명해줘요.

(생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com))

프로그래머스 — 코딩 테스트뿐 아니라 입문 강의도 잘 되어 있고, 실습 환경이 편해요.

(프로그래머스 (https://programmers.co.kr/?utm_source=chatgpt.com))

CS50 by Harvard — 세계적으로 유명한 컴퓨터공학 입문 강의. 조금 어렵지만 “진짜 프로그래밍 개념”을 배우기 좋아요.

(CS50 (https://cs50.harvard.edu/x/?utm_source=chatgpt.com))

freeCodeCamp — 영어 기반이지만 무료이고, 웹 개발을 단계별 실습으로 배울 수 있어요.

(freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com))

Codecademy — 브라우저에서 바로 코딩하면서 배우는 스타일이라 초보자 진입 장벽이 낮아요.

(Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com))

인프런 — 한국어 강의 플랫폼. Python, Java, 웹 개발 등 입문 강좌가 많아요.

(인프런 (https://www.inflearn.com/?utm_source=chatgpt.com))

추천 학습 순서는 보통 이렇게 많이 갑니다:

생활코딩 → Python 기초

간단한 프로젝트 만들기

자료구조/알고리즘 기초

웹 개발 또는 앱 개발 중 관심 분야 선택

그리고 초보자라면 첫 언어는 보통 Python을 가장 추천해요. 문법이 쉬워서 프로그래밍 개념 자체에 집중하기 좋습니다.
