# 온라인 강좌-탐색-질문 / run 9

## Question

코딩을 처음 시작하는 성인이 듣기 좋은 온라인 강의 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

코딩을 처음 시작하는 성인이라면, 너무 이론 중심보다는 “직접 만들어보는 방식”의 강의가 훨씬 오래 갑니다. 아래 순서대로 시작하면 부담이 적어요.

HTML/CSS → 웹페이지 만들기

Python → 쉬운 문법으로 프로그래밍 감각 익히기

JavaScript → 웹에 동작 추가하기

작은 프로젝트 만들기

추천 강의들을 난이도와 스타일 기준으로 정리해볼게요.

1. 생활코딩 — 한국어 입문용 최고 수준

완전 초보 기준 설명

무료 강의가 많음

“웹”, “HTML/CSS”, “JavaScript”, “Python” 입문이 특히 좋음

코딩이 처음인 성인이 가장 많이 추천하는 곳 중 하나

(생활코딩, https://opentutorials.org/ (https://opentutorials.org/?utm_source=chatgpt.com))

2. 인프런 — 한국어 실무형 강의 많음

입문부터 취업 준비까지 다양

강사 스타일 선택 가능

“파이썬 입문”, “웹 개발 입문” 강의 추천 많음

할인 자주 해서 가성비 좋음

(인프런, https://www.inflearn.com/ (https://www.inflearn.com/?utm_source=chatgpt.com))

3. Codecademy — 영어 괜찮으면 최고의 인터랙티브 입문

브라우저에서 바로 코딩 가능

“읽기”보다 “직접 따라하기” 중심

Python 입문이 특히 쉬움

게임처럼 진행돼서 지루하지 않음

(Codecademy, https://www.codecademy.com/ (https://www.codecademy.com/?utm_source=chatgpt.com))

4. freeCodeCamp — 무료인데 퀄리티 매우 높음

웹개발 입문에 강함

프로젝트 기반 학습

무료 인증서 제공

꾸준히 하면 포트폴리오까지 가능

(freeCodeCamp, https://www.freecodecamp.org/ (https://www.freecodecamp.org/?utm_source=chatgpt.com))

5. Udemy — 세일할 때 가성비 최고

강의 종류가 엄청 많음

“Python Bootcamp”, “웹개발 부트캠프” 유명

강의 하나 사두고 천천히 보기 좋음

(Udemy, https://www.udemy.com/ (https://www.udemy.com/?utm_source=chatgpt.com))

시작 조합 추천

한국어 + 완전 초보 → 생활코딩 → 인프런

영어 가능 + 실습 좋아함 → Codecademy → freeCodeCamp

빠르게 결과물 만들고 싶음 → Python 먼저 추천

처음이면 “Python 입문” 또는 “HTML/CSS 웹 만들기”부터 시작하는 걸 가장 추천해요.
