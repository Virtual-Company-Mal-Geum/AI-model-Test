# 온라인 강좌-탐색-질문 / run 10

## Question

코딩을 처음 시작하는 성인이 듣기 좋은 온라인 강의 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

코딩을 처음 시작하는 성인이라면, “재미를 잃지 않고 꾸준히 따라갈 수 있는 강의”가 가장 중요해요. 아래는 입문자 기준으로 특히 평이 좋은 온라인 강의 플랫폼들이에요.

Codecademy

영어 기반이지만 인터랙티브하게 직접 코드를 입력하면서 배울 수 있어서 완전 초보에게 좋아요.

Python, HTML/CSS, JavaScript 입문 코스가 특히 유명해요.

“설치 없이 브라우저에서 바로 코딩” 가능한 점이 장점.

(Codecademy, https://www.codecademy.com/ (https://www.codecademy.com/?utm_source=chatgpt.com))

Udemy

할인할 때 강의를 저렴하게 구매 가능하고, 한국어 강의도 많아요.

“왕초보 Python”, “웹개발 입문”, “앱 만들기” 같은 실전형 강의가 다양해요.

한 번 구매하면 평생 수강 가능한 경우가 많아요.

(Udemy, https://www.udemy.com/ (https://www.udemy.com/?utm_source=chatgpt.com))

인프런

한국어로 배우고 싶다면 가장 추천되는 플랫폼 중 하나예요.

국내 개발자들이 만든 입문 강의가 많고, 질의응답 문화가 활발해요.

특히 Python, Java, React 입문 강의가 인기 많아요.

(인프런, https://www.inflearn.com/ (https://www.inflearn.com/?utm_source=chatgpt.com))

Coursera

대학 수준 강의를 체계적으로 듣고 싶은 사람에게 좋아요.

University of Michigan, Stanford University 같은 학교 강의도 들을 수 있어요.

천천히 개념부터 배우고 싶은 성인 학습자에게 잘 맞아요.

(Coursera, https://www.coursera.org/ (https://www.coursera.org/?utm_source=chatgpt.com))

생활코딩

무료 강의 중심이고, 설명이 정말 쉬워서 국내 입문자들에게 유명해요.

웹 개발 입문(HTML/CSS/JavaScript) 시작용으로 특히 추천돼요.

“왜 배우는지”를 잘 설명해줘서 비전공 성인도 부담이 적어요.

(생활코딩, https://opentutorials.org/ (https://opentutorials.org/?utm_source=chatgpt.com))

처음 시작한다면 추천 순서는 보통 이렇게 많이 가요:

웹사이트 만들기 관심 → 생활코딩 / Codecademy

취업·실무 관심 → 인프런 / Udemy

체계적인 공부 → Coursera

가볍고 재밌게 시작 → Codecademy

그리고 첫 언어는 대부분:

Python → 가장 쉬운 편, 자동화·데이터·AI까지 연결 가능

JavaScript → 웹 개발 바로 가능

둘 중 하나로 시작하는 걸 추천해요.
