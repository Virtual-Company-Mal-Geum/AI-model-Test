# 온라인 강좌-탐색-질문 / run 6

## Question

프로그래밍 입문자가 기초부터 배울 수 있는 온라인 강좌를 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

처음 프로그래밍을 배우는 입문자라면 “재미를 느끼면서 작은 성공 경험을 자주 만드는 강의”가 중요해요.

아래는 난이도·설명 방식·실습 중심 여부를 고려해서 추천하는 온라인 강좌들입니다.

한국어로 배우기 좋은 강좌
1. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

완전 입문자에게 가장 많이 추천되는 무료 강의

설명이 쉽고 부담이 적음

HTML/CSS, JavaScript, Python, 데이터베이스까지 단계적으로 가능

“코딩이 뭔지” 감 잡기에 특히 좋음

추천 대상:

처음 시작하는 사람

무료 강의를 원하는 사람

천천히 개념 이해하고 싶은 사람

2. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 매우 많음

입문~실무까지 폭넓음

무료 입문 강좌도 많고, 질문 답변 문화가 좋은 편

추천 강좌 예시:

“파이썬 입문”

“웹 개발 입문”

“자바스크립트 기초”

추천 대상:

체계적으로 배우고 싶은 사람

한국어 설명 선호

3. 노마드코더 (https://nomadcoders.co/?utm_source=chatgpt.com)

실습 중심 강의가 강점

직접 앱/웹사이트를 만들면서 배움

초보자도 결과물을 빨리 만들 수 있음

추천 대상:

“만들면서 배우는 스타일”

웹/앱 개발에 관심 있는 사람

해외 유명 무료 플랫폼
4. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

세계적으로 유명한 무료 코딩 학습 사이트

웹 개발 입문에 특히 강함

단계별 실습 + 프로젝트 방식

추천 대상:

영어에 부담이 크지 않은 사람

웹 개발 목표

5. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저 안에서 바로 코딩 가능

인터랙티브 방식이라 지루하지 않음

Python, JavaScript 입문에 좋음

추천 대상:

게임처럼 배우고 싶은 사람

설치 없이 시작하고 싶은 사람

6. CS50 by Harvard (https://cs50.harvard.edu/?utm_source=chatgpt.com)

하버드의 유명 컴퓨터공학 입문 강의

난이도는 조금 있지만 매우 퀄리티 높음

프로그래밍 사고력을 키우기 좋음

추천 대상:

제대로 기초를 배우고 싶은 사람

장기적으로 개발자를 목표로 하는 사람

어떤 언어부터 시작하면 좋을까?

웹사이트 만들기 → JavaScript

자동화/AI/데이터 분석 → Python

앱 개발 → Java/Kotlin 또는 Swift

게임 개발 → C# + Unity

처음이라면 보통 Python 또는 JavaScript부터 많이 시작해요.
