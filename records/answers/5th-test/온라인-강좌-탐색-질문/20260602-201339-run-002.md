# 온라인 강좌-탐색-질문 / run 2

## Question

비전공 성인이 프로그래밍을 배우기 좋은 온라인 교육 사이트 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

비전공 성인이 처음부터 프로그래밍을 배우기 좋은 온라인 교육 사이트들을 난이도·학습 스타일 기준으로 정리해볼게요.

“코딩 입문 → 실습 → 프로젝트” 흐름이 잘 되어 있는 곳 위주로 골랐어요.

한국어로 배우기 좋은 사이트
1. 프로그래머스 (https://programmers.co.kr/?utm_source=chatgpt.com)

한국어 강의와 코딩 테스트 환경이 강점

웹 개발, Python, JavaScript, SQL 입문 강의가 잘 정리되어 있음

취업 준비용 알고리즘 연습도 가능

“실습하면서 배우는 스타일”에 적합

2. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

국내 최대 규모 개발 강의 플랫폼 중 하나

무료 입문 강의가 많음

웹 개발, 앱 개발, 데이터 분석, AI까지 범위가 넓음

강사 스타일이 다양해서 자기에게 맞는 수업 찾기 좋음

3. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

완전 초보자용으로 매우 유명

어려운 용어를 쉽게 설명함

HTML/CSS/JavaScript/Python 입문에 특히 좋음

“코딩이 뭔지 처음 접하는 사람”에게 추천

4. 패스트캠퍼스 (https://fastcampus.co.kr/?utm_source=chatgpt.com)

직무 중심 강의가 많음

프론트엔드·백엔드·데이터·AI 등 커리큘럼 체계적

장기적으로 실무 역량까지 연결하기 좋음

해외 사이트 (퀄리티 매우 높음)
5. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료

직접 코드를 작성하며 배우는 구조

웹 개발 입문에 세계적으로 유명

프로젝트 기반이라 실력이 빨리 늘어남

6. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

인터랙티브 방식이 매우 강함

브라우저 안에서 바로 코딩 가능

영어 부담만 괜찮다면 입문 난이도 최고 수준

7. CS50 by Harvard (https://cs50.harvard.edu/?utm_source=chatgpt.com)

하버드의 유명 컴퓨터과학 입문 강의

프로그래밍 원리 자체를 탄탄하게 배울 수 있음

난이도는 약간 높지만 매우 체계적

8. Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학 강의를 온라인으로 수강 가능

Stanford, Google, IBM 등의 과정 제공

인증서 과정도 많음

입문자에게 추천하는 학습 순서

HTML/CSS로 웹 구조 이해

JavaScript 또는 Python 중 하나 선택

간단한 프로젝트 만들기

Git/GitHub 배우기

원하는 분야 선택

웹 개발

앱 개발

데이터 분석

AI/머신러닝

게임 개발

개인적으로 가장 무난한 조합

완전 처음:

생활코딩 → 프로그래머스 → 인프런

영어 가능 + 실습 선호:

freeCodeCamp → Codecademy → CS50

요청한 형식으로 마지막에 다시 정리하면:

(프로그래머스, https://programmers.co.kr/)

(인프런, https://www.inflearn.com/)

(생활코딩, https://opentutorials.org/)

(패스트캠퍼스, https://fastcampus.co.kr/)

(freeCodeCamp, https://www.freecodecamp.org/)

(Codecademy, https://www.codecademy.com/)

(CS50 by Harvard, https://cs50.harvard.edu/)

(Coursera, https://www.coursera.org/)
