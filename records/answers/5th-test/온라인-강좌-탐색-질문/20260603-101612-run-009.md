# 온라인 강좌-탐색-질문 / run 9

## Question

코딩 기초를 배우고 싶은 성인에게 알맞은 온라인 강의 플랫폼 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

코딩 기초를 처음 배우는 성인이라면, 설명 방식이 친절하고, 실습 중심이며, 학습 동기 유지가 쉬운 플랫폼이 좋습니다. 목적(취업, 취미, 업무 자동화 등)에 따라 추천이 조금 달라지는데, 입문자 기준으로 많이 만족도가 높은 곳들을 정리해볼게요.

한국어로 배우기 좋은 플랫폼

인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 매우 많고, 입문용 무료 강의도 풍부함

Python, 웹개발, 앱개발, 데이터분석 등 분야 다양

국내 개발 문화에 맞는 설명이 장점

생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

완전 초보자에게 특히 추천

무료 강의 중심

“코딩이 왜 필요한지”부터 쉽게 설명해줌

웹 개발 입문은 거의 정석 수준

패스트캠퍼스 (https://fastcampus.co.kr/?utm_source=chatgpt.com)

체계적인 커리큘럼 강점

취업/실무 중심 강의 많음

장기적으로 개발 직무를 고려한다면 괜찮음

영어 괜찮다면 강력 추천

Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코딩 가능

“따라 치면서 배우는 방식”이라 입문자 친화적

Python, JavaScript 입문에 매우 좋음

freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료

프로젝트 기반 학습

웹개발 입문자에게 특히 유명

Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학 수준 강의를 온라인으로 제공

Google, University of Michigan 같은 기관 강의 수강 가능

기초부터 전문 과정까지 폭넓음

목적별 추천

진짜 완전 처음 → 생활코딩, Codecademy

한국어 + 실무 느낌 → 인프런

취업 목표 → 패스트캠퍼스, Coursera

무료 위주 → 생활코딩, freeCodeCamp

재미있게 인터랙티브하게 → Codecademy
