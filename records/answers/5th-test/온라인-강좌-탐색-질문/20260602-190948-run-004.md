# 온라인 강좌-탐색-질문 / run 4

## Question

프로그래밍 입문자가 기초부터 배울 수 있는 온라인 강좌를 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍 입문자라면 “언어 하나 + 실습 중심 + 꾸준한 작은 프로젝트” 방식으로 배우는 게 가장 효율적이에요.

처음 시작할 때는 보통 Python을 추천해요. 문법이 비교적 쉬워서 프로그래밍 개념(변수, 반복문, 함수 등)에 집중하기 좋습니다.

입문자에게 추천하는 온라인 강좌 플랫폼
1. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)
한국어 강의가 많고, 완전 초보 대상 강좌가 잘 되어 있어요.

특히 Python, 웹 개발, 앱 개발 입문 코스가 다양합니다.

추천 이유:

한국어 설명이라 진입장벽이 낮음

실습 위주 강의 많음

로드맵 기능 제공

2. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)
프로그래밍을 처음 배우는 사람들에게 정말 유명한 무료 강의 사이트예요.

웹 개발과 프로그래밍 기초를 아주 쉽게 설명합니다.

추천 이유:

무료

설명이 친절하고 쉬움

HTML/CSS/JavaScript 입문에 특히 강함

3. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)
브라우저에서 바로 코드를 작성하면서 배우는 인터랙티브 학습 플랫폼입니다.

추천 이유:

설치 없이 바로 실습 가능

단계별 진행 방식

영어지만 초보 친화적

4. Coursera (https://www.coursera.org/?utm_source=chatgpt.com)
대학 수준의 체계적인 강의를 들을 수 있는 플랫폼입니다.

Stanford University, University of Michigan 같은 학교 강의도 많아요.

추천 이유:

체계적인 커리큘럼

수료증 가능

컴퓨터공학 기초까지 확장 가능

5. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)
무료로 웹 개발과 Python 등을 프로젝트 중심으로 배울 수 있습니다.

추천 이유:

완전 무료

프로젝트 기반 학습

실제 포트폴리오 제작 가능

6. Udemy (https://www.udemy.com/?utm_source=chatgpt.com)
할인을 자주 해서 저렴하게 강의를 구매할 수 있어요.

추천 이유:

강의 수가 매우 많음

원하는 분야를 세부적으로 학습 가능

실무형 강의 많음

처음 시작한다면 추천 학습 순서

Python 기초 문법

간단한 콘솔 프로그램 만들기

자료구조/알고리즘 기초

웹 개발 또는 앱 개발 선택

작은 프로젝트 만들기

요청한 형식으로 URL 정리
