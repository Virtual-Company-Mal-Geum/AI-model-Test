# 온라인 강좌-탐색-질문 / run 8

## Question

코딩을 처음 시작하는 성인이 듣기 좋은 온라인 강의 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

코딩을 처음 시작하는 성인이라면, “문법 암기”보다 작은 프로젝트를 직접 만들어보는 방식의 강의가 훨씬 오래 갑니다.

아래는 입문자 기준으로 특히 많이 추천되는 온라인 강의 플랫폼들이에요.

한국어로 시작하기 좋은 강의
1. 인프런

한국어 강의가 매우 많고, 입문용 무료 강의도 풍부함

Python, 웹개발, 앱개발, AI까지 단계별 학습 가능

“파이썬 입문”, “웹 개발 입문”부터 시작하기 좋음

(인프런, https://www.inflearn.com (https://www.inflearn.com/?utm_source=chatgpt.com))

2. 생활코딩

완전 초보 친화적인 무료 강의

HTML/CSS/JavaScript 같은 웹개발 입문이 특히 유명

“코딩이 왜 필요한지”부터 쉽게 설명해줌

(생활코딩, https://opentutorials.org (https://opentutorials.org/?utm_source=chatgpt.com))

3. 패스트캠퍼스

실무 중심 커리큘럼이 많음

취업·이직 목적의 성인 학습자에게 인기

데이터분석, 프론트엔드, 백엔드 등 트랙형 강의 강점

(패스트캠퍼스, https://fastcampus.co.kr (https://fastcampus.co.kr/?utm_source=chatgpt.com))

영어 기반이지만 세계적으로 유명한 강의
4. Codecademy

브라우저에서 바로 코딩 가능

설치 없이 실습 중심으로 배움

영어 부담이 크지 않은 편

(Codecademy, https://www.codecademy.com (https://www.codecademy.com/?utm_source=chatgpt.com))

5. freeCodeCamp

완전 무료

웹개발 입문부터 프로젝트 제작까지 가능

해외에서 입문용으로 가장 많이 추천되는 플랫폼 중 하나

(freeCodeCamp, https://www.freecodecamp.org (https://www.freecodecamp.org/?utm_source=chatgpt.com))

6. Coursera

대학 수준 강의를 온라인으로 수강 가능

Google, IBM 등의 입문 코스가 유명

체계적으로 배우고 싶은 사람에게 추천

(Coursera, https://www.coursera.org (https://www.coursera.org/?utm_source=chatgpt.com))

처음 시작할 때 추천 순서

Python 기초 또는 HTML/CSS 시작

작은 프로젝트 따라 만들기

Git/GitHub 배우기

관심 분야 선택

웹개발

데이터분석

AI

앱개발

게임개발

만약 원하면 다음 단계로:

“비전공 성인 기준 3개월 학습 로드맵”

“취업까지 연결되는 강의 추천”

“무료만 골라서 추천”

“Python vs 웹개발 뭐부터 할지”

같은 것도 이어서 정리해줄게.
