# 온라인 강좌-탐색-질문 / run 8

## Question

처음 코딩을 배우는 사람에게 적합한 프로그래밍 온라인 강의 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

처음 코딩을 배우는 사람이라면 “문법 설명 + 직접 실습 + 쉬운 프로젝트”가 있는 강의를 추천해요. 아래 순서대로 시작하면 부담이 적습니다.

파이썬으로 프로그래밍 기초 익히기

문법이 쉬워서 입문자에게 가장 많이 추천됨

간단한 게임, 자동화, 데이터 분석까지 확장 가능

추천 강의 플랫폼

인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 많고 초보자용 무료 강의도 풍부함

생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

완전 초보 기준 설명으로 유명

Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코딩 가능

웹 개발 배우기 (HTML/CSS/JavaScript)

결과가 바로 화면에 보여서 재미를 느끼기 쉬움

웹사이트 만들기에 관심 있다면 추천

추천 플랫폼

freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

무료 + 실습 중심 + 프로젝트 많음

MDN Web Docs (https://developer.mozilla.org/?utm_source=chatgpt.com)

웹 개발 공식 문서 느낌의 최고급 자료

노마드 코더 (https://nomadcoders.co/?utm_source=chatgpt.com)

따라 만들기 프로젝트 스타일 강의

게임처럼 배우고 싶다면

재미 중심으로 시작 가능

중학생/고등학생 입문자도 많이 사용

추천 플랫폼

Scratch (https://scratch.mit.edu/?utm_source=chatgpt.com)

블록 코딩으로 프로그래밍 개념 학습

Code.org (https://code.org/?utm_source=chatgpt.com)

게임형 학습 콘텐츠 제공
