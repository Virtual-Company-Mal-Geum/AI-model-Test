# 온라인 강좌-탐색-질문 / run 10

## Question

비전공 성인이 프로그래밍을 배우기 좋은 온라인 교육 사이트 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

비전공 성인이 처음 프로그래밍을 배우기에는 **“설치 없이 시작 가능 + 커리큘럼이 체계적 + 실습이 많은 곳”**이 좋습니다.

1. Codeit(코드잇) (https://codeit.kr/?utm_source=chatgpt.com)

완전 초보자를 위한 입문 과정이 잘 구성되어 있음

Python, 웹 개발, 데이터 분석, AI 기초 등을 단계별로 학습 가능

브라우저에서 바로 실습할 수 있어 개발 환경 설정 부담이 적음

프로그래밍을 처음 접하는 성인에게 특히 추천

2. Inflearn(인프런) (https://www.inflearn.com/?utm_source=chatgpt.com)

국내 최대 규모의 온라인 IT 강의 플랫폼 중 하나

무료 강의가 많아 부담 없이 시작 가능

Python, Java, 웹 개발, 앱 개발, AI 등 거의 모든 분야를 다룸

원하는 기술만 골라서 배우기 좋음 seoulrendy (https://news.seoulrendy.com/?p=74&utm_source=chatgpt.com)

3. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

무료로 배울 수 있는 대표적인 프로그래밍 교육 사이트

비전공자를 위한 설명이 매우 친절함

HTML, CSS, JavaScript, Python 등의 기초 학습에 적합 라이프점퍼 블로그 (https://lifejumper.tistory.com/135?utm_source=chatgpt.com)

4. Udemy(유데미) (https://www.udemy.com/?utm_source=chatgpt.com)

전 세계적으로 가장 큰 온라인 강의 플랫폼 중 하나

할인 행사가 자주 있어 저렴하게 수강 가능

영어 강의가 많지만 한국어 강의도 꾸준히 늘어나는 중

특정 기술을 빠르게 배우고 싶을 때 유용

5. Fast Campus(패스트캠퍼스) (https://fastcampus.co.kr/?utm_source=chatgpt.com)

취업·이직·커리어 전환을 목표로 하는 사람에게 적합

실무 중심의 대형 패키지 강의가 많음

웹 개발, 데이터 사이언스, AI 분야 강의가 강점 패스트캠퍼스+1 (https://fastcampus.co.kr/instructor_apply?utm_source=chatgpt.com)

6. 프로그래머스 스쿨 (https://school.programmers.co.kr/?utm_source=chatgpt.com)

코딩테스트와 실습 중심 학습에 강함

개발자 취업을 목표로 할 때 유용

Python, Java, JavaScript 등을 실습하며 배울 수 있음 프로그래머스 캠퍼스 (https://campus.programmers.co.kr/?utm_source=chatgpt.com)
