# 온라인 강좌-탐색-질문 / run 10

## Question

프로그래밍을 독학하려는 성인에게 적합한 온라인 강의 사이트를 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

독학으로 프로그래밍을 시작하는 성인이라면, “언어 하나를 깊게 배우는 곳”보다 기초 → 실습 → 프로젝트 → 취업/응용까지 이어지는 플랫폼을 고르는 게 중요해요.

아래는 초보자부터 실무 입문까지 많이 추천되는 온라인 강의 사이트들입니다.

한국어 강의 중심
1. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 개발 강의가 가장 활발한 플랫폼 중 하나

Python, Java, 웹개발, AI, 앱개발 등 거의 모든 분야 커버

실무형 강의와 로드맵이 잘 되어 있음

초보자용 무료 강의도 많음

2. 패스트캠퍼스 (https://fastcampus.co.kr/?utm_source=chatgpt.com)

취업·실무 중심 커리큘럼이 강점

데이터 분석, AI, 프론트엔드, 백엔드 과정이 체계적

긴 부트캠프형 강의가 많아 꾸준히 공부하기 좋음

3. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

완전 초보자 입문용으로 매우 유명

프로그래밍 개념 설명이 친절함

HTML/CSS/JavaScript/Python 입문 추천

무료

4. 노마드코더 (https://nomadcoders.co/?utm_source=chatgpt.com)

“직접 만들어보는” 프로젝트형 학습

클론코딩 방식이라 재미있게 배우기 좋음

웹개발·React·React Native 강의 인기

해외 플랫폼 (영어 가능하면 추천)
5. Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

스탠퍼드, 미시간대 같은 대학 강의 제공

컴퓨터공학 기초를 체계적으로 배우기 좋음

수료증 과정도 있음

6. Udemy (https://www.udemy.com/?utm_source=chatgpt.com)

강의 수가 매우 많고 할인도 자주 함

특정 기술 빠르게 배우기에 좋음

“100일 Python”, “React Bootcamp” 같은 인기 강의 많음

7. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료

웹개발·JavaScript·Python·데이터분석 학습 가능

실습과 프로젝트 중심

해외에서 독학 입문용으로 매우 유명

8. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코딩 가능

인터랙티브 학습이라 초보자에게 편함

“따라 치면서 배우는 스타일”에 적합

목적별 추천

완전 초보 → 생활코딩, Codecademy

한국어 실무 강의 → 인프런, 패스트캠퍼스

재미있게 프로젝트 제작 → 노마드코더

컴퓨터공학 기초까지 탄탄하게 → Coursera

무료 위주 → freeCodeCamp, 생활코딩

빠르게 특정 기술 습득 → Udemy
