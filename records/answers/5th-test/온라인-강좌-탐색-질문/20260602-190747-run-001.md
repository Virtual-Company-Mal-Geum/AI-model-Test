# 온라인 강좌-탐색-질문 / run 1

## Question

프로그래밍 입문자가 기초부터 배울 수 있는 온라인 강좌를 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍 입문자라면 “문법만 배우는 강의”보다 직접 만들어보는 실습형 강의가 훨씬 도움이 됩니다. 아래는 초보자가 많이 시작하는 온라인 강좌들입니다.

생활코딩

한국어로 매우 쉽게 설명해서 완전 초보자에게 유명함

HTML, CSS, JavaScript, Python, 데이터베이스까지 기초 학습 가능

무료 강의가 많음

(생활코딩, https://opentutorials.org (https://opentutorials.org/?utm_source=chatgpt.com))

인프런

한국어 강의 플랫폼

“파이썬 입문”, “웹 개발 기초”, “Java 기초” 같은 강의가 다양함

무료 입문 강의도 많음

(인프런, https://www.inflearn.com (https://www.inflearn.com/?utm_source=chatgpt.com))

코드카데미(Codecademy)

영어 기반이지만 인터랙티브 방식이라 초보자에게 매우 좋음

브라우저에서 바로 코딩 가능

Python, JavaScript 입문 추천

(Codecademy, https://www.codecademy.com (https://www.codecademy.com/?utm_source=chatgpt.com))

freeCodeCamp

완전 무료

웹 개발, Python, 데이터 분석 등을 프로젝트 중심으로 배움

실습량이 많아서 실력 향상에 좋음

(freeCodeCamp, https://www.freecodecamp.org (https://www.freecodecamp.org/?utm_source=chatgpt.com))

Coursera

해외 대학 강의를 온라인으로 제공

Harvard University, Stanford University 같은 학교 강의도 있음

체계적으로 배우고 싶은 사람에게 추천

(Coursera, https://www.coursera.org (https://www.coursera.org/?utm_source=chatgpt.com))

Udemy

할인할 때 저렴하게 구매 가능

웹 개발, 게임 개발, 앱 개발 등 분야가 매우 다양함

“Python Bootcamp” 계열 강의가 특히 인기

(Udemy, https://www.udemy.com (https://www.udemy.com/?utm_source=chatgpt.com))

처음 시작한다면 추천 순서는 보통:

완전 처음 → 생활코딩 / Codecademy

Python 배우기 → 인프런 / freeCodeCamp

웹 개발 진지하게 → freeCodeCamp / Udemy

대학식 체계 학습 → Coursera

입니다.
