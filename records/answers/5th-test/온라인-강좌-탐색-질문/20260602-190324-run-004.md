# 온라인 강좌-탐색-질문 / run 4

## Question

코딩을 처음 시작하는 성인이 듣기 좋은 온라인 강의 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

코딩을 처음 시작하는 성인이라면 "재미 → 성취감 → 실무 연결" 순서로 배우는 것이 중요합니다. 처음부터 컴퓨터공학 이론에 깊게 들어가기보다 Python이나 웹 개발 기초를 배우면서 작은 프로젝트를 만들어보는 강의를 추천해요.

1. 인프런

국내에서 가장 인기 있는 개발 강의 플랫폼 중 하나

한국어 강의가 많고 초보자 친화적

Python, 웹 개발, 데이터 분석, AI 입문까지 단계별 학습 가능

추천 강의:

"파이썬 입문"

"웹 개발 왕초보"

"비전공자를 위한 프로그래밍"

(인프런, https://www.inflearn.com (https://www.inflearn.com/?utm_source=chatgpt.com))

2. 코드잇

비전공 성인 입문자에게 특히 추천

학습 순서가 잘 설계되어 있음

실습 중심이라 따라가기 쉬움

Python, JavaScript, SQL 등을 체계적으로 배울 수 있음

(코드잇, https://codeit.kr (https://codeit.kr/?utm_source=chatgpt.com))

3. 생활코딩

완전 초보자가 가장 많이 시작하는 무료 강의

프로그래밍이 무엇인지부터 설명

HTML, CSS, JavaScript, Python 입문 강의가 매우 유명

(생활코딩, https://opentutorials.org (https://opentutorials.org/?utm_source=chatgpt.com))

4. Coursera

해외 대학 강의를 들을 수 있음

체계적인 컴퓨터과학 기초 학습 가능

영어에 부담이 없다면 매우 좋은 선택

Python 및 컴퓨터과학 입문 과정이 꾸준히 추천됨 TechRadar (https://www.techradar.com/best/python-online-courses?utm_source=chatgpt.com)

(코세라, https://www.coursera.org (https://www.coursera.org/?utm_source=chatgpt.com))

5. Udemy

강의 수가 매우 많음

할인 기간이 잦아서 저렴하게 수강 가능

프로젝트 중심 강의가 많음

Python, 웹 개발, 앱 개발 입문 강의가 풍부함 TechRadar (https://www.techradar.com/best/python-online-courses?utm_source=chatgpt.com)

(유데미, https://www.udemy.com (https://www.udemy.com/?utm_source=chatgpt.com))

처음 시작한다면 추천 순서

생활코딩 (무료로 프로그래밍 감 잡기)

코드잇 또는 인프런 (체계적으로 학습)

Python 기초

Git/GitHub 기초

웹 개발 또는 AI·데이터 분야 중 관심 분야 선택

개인적으로는 완전 초보 성인이라면 "코드잇 → Python → 간단한 프로젝트" 코스가 가장 진입장벽이 낮고 중도 포기 확률도 적습니다.
