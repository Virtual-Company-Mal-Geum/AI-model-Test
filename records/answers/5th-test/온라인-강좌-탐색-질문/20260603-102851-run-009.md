# 온라인 강좌-탐색-질문 / run 9

## Question

프로그래밍을 독학하려는 성인에게 적합한 온라인 강의 사이트를 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

독학으로 프로그래밍을 시작하는 성인이라면, 입문 난이도, 실습 중심 여부, 한국어 지원, 커리큘럼 체계성을 기준으로 고르는 게 좋아요. 아래 사이트들은 초보자부터 실무 준비 단계까지 많이 추천되는 곳들입니다.

한국어로 배우기 좋은 사이트
1. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 매우 많고, 웹 개발·Python·앱 개발·AI까지 폭넓게 배울 수 있음

실무 개발자 강의가 많아서 취업 준비에도 유리

초보자용 무료 강의도 많음

형식:

(인프런, https://www.inflearn.com/)

2. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

완전 초보자에게 특히 유명

HTML/CSS/JavaScript/Python 같은 기초를 쉽게 설명

무료

“프로그래밍이 뭔지” 감 잡기에 최고 수준

형식:

(생활코딩, https://opentutorials.org/)

3. 패스트캠퍼스 (https://fastcampus.co.kr/?utm_source=chatgpt.com)

데이터 분석, AI, 백엔드, 프론트엔드 등 실무형 강의 강점

장기 로드맵 구성에 좋음

가격은 조금 있는 편

형식:

(패스트캠퍼스, https://fastcampus.co.kr/)

해외 사이트 (영어 가능하면 매우 추천)
4. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

무료로 웹 개발 전체 과정을 실습 가능

직접 코딩하면서 배우는 방식

포트폴리오 만들기 좋음

형식:

(freeCodeCamp, https://www.freecodecamp.org/)

5. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

초보자 친화적

브라우저 안에서 바로 코딩 가능

Python, JavaScript 입문에 특히 좋음

형식:

(Codecademy, https://www.codecademy.com/)

6. Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학 수준 강의를 온라인으로 제공

스탠퍼드, 미시간대 같은 대학 강의 수강 가능

컴퓨터공학 기초를 체계적으로 배우기 좋음

형식:

(Coursera, https://www.coursera.org/)

목적별 추천

완전 처음 시작 → 생활코딩 / Codecademy

취업 목표 → 인프런 / 패스트캠퍼스

영어 가능 + 체계적 공부 → freeCodeCamp / Coursera

Python 입문 → 인프런 + Codecademy

웹 개발 → freeCodeCamp + 생활코딩

처음이라면 보통:

HTML/CSS

JavaScript 또는 Python

간단한 프로젝트 제작

순서로 시작하는 걸 많이 추천해요.
