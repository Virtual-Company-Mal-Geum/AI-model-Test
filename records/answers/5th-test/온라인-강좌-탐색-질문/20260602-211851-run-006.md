# 온라인 강좌-탐색-질문 / run 6

## Question

프로그래밍 경험이 없는 사람이 입문용으로 듣기 좋은 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍 경험이 전혀 없다면, 처음에는 **“재미를 느끼면서 작은 결과물을 만들어보는 강의”**가 가장 중요해요. 아래 강의들은 초보자가 많이 추천하는 입문용 온라인 강좌들이에요.

1. 생활코딩 — 가장 유명한 한국어 입문 강의

완전 초보자 기준으로 설명이 쉬움

웹 개발(HTML/CSS/JavaScript), Python, 데이터베이스 등 기초를 단계적으로 배울 수 있음

무료 강의가 많아서 부담 없이 시작 가능

(생활코딩, https://opentutorials.org (https://opentutorials.org/?utm_source=chatgpt.com))

2. 인프런 — 한국어 강의가 많고 입문 강좌 다양

“코딩 왕초보”, “Python 입문”, “웹 개발 기초” 같은 강좌가 많음

실무형 강의도 많아서 나중에 이어서 배우기 좋음

무료 입문 강의도 꽤 많음

(인프런, https://www.inflearn.com (https://www.inflearn.com/?utm_source=chatgpt.com))

3. Codecademy — 영어지만 인터랙티브해서 배우기 쉬움

브라우저에서 바로 코딩 가능

직접 따라 치면서 배우는 방식이라 지루하지 않음

Python, JavaScript 입문 강좌가 특히 유명

(Codecademy, https://www.codecademy.com (https://www.codecademy.com/?utm_source=chatgpt.com))

4. Coursera — 대학 스타일의 체계적인 강의

해외 대학 강의를 온라인으로 들을 수 있음

“Python for Everybody” 같은 초보용 강의가 유명

자막 지원 강의도 많음

(Coursera, https://www.coursera.org (https://www.coursera.org/?utm_source=chatgpt.com))

5. freeCodeCamp — 완전 무료 + 실습 중심

웹 개발 입문에 특히 강함

단계별 미션 방식이라 게임처럼 진행 가능

프로젝트를 만들면서 배우는 스타일

(freeCodeCamp, https://www.freecodecamp.org (https://www.freecodecamp.org/?utm_source=chatgpt.com))

처음 시작한다면 추천 순서

생활코딩 → 프로그래밍 감 잡기

Python 입문 또는 웹 개발 입문 선택

인프런/freeCodeCamp로 실습 늘리기

Coursera로 체계적으로 정리하기

특히 처음에는:

“Python 입문” → 가장 쉬운 편

“웹 개발 입문(HTML/CSS/JS)” → 결과물이 눈에 보여서 재미있음

이 두 가지 중 하나로 시작하는 걸 추천해요.
