# 온라인 강좌-탐색-질문 / run 6

## Question

코딩을 처음 시작하는 성인이 듣기 좋은 온라인 강의 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

처음 코딩을 시작하는 성인이라면, “재미를 느끼면서 작은 결과물을 빨리 만들어보는 강의”가 가장 중요해요. 아래 강의들은 초보자 친화적이고, 한국어 지원이나 입문 커리큘럼이 잘 되어 있어서 시작하기 좋아요.

생활코딩

한국어로 가장 유명한 코딩 입문 플랫폼 중 하나예요.

HTML/CSS, JavaScript, Python, 데이터베이스까지 무료 강의가 매우 잘 정리되어 있어요.

“코딩이 뭔지”부터 차근차근 설명해줘서 완전 초보에게 특히 추천해요.

(생활코딩, https://opentutorials.org (https://opentutorials.org/?utm_source=chatgpt.com))

인프런 (Inflearn)

한국어 강의가 많고, 실무형 입문 강의가 다양해요.

“파이썬 입문”, “웹 개발 왕초보” 같은 강의들이 많아서 원하는 분야를 찾기 쉬워요.

강의 스타일이 비교적 친근하고 국내 학습자 기준으로 설명해줘요.

(인프런, https://www.inflearn.com (https://www.inflearn.com/?utm_source=chatgpt.com))

Codecademy

영어 기반이지만 인터랙티브 방식이라 따라 치면서 배우기 좋아요.

설치 없이 브라우저에서 바로 코딩 가능해서 입문 장벽이 낮아요.

특히 Python, JavaScript 입문에 강해요.

(Codecademy, https://www.codecademy.com (https://www.codecademy.com/?utm_source=chatgpt.com))

Coursera

대학 수준 강의를 온라인으로 들을 수 있어요.

Google, University of Michigan 같은 기관의 입문 강의가 유명해요.

체계적으로 배우고 싶은 성인 학습자에게 추천해요.

(Coursera, https://www.coursera.org (https://www.coursera.org/?utm_source=chatgpt.com))

Udemy

할인할 때 저렴하게 강의를 구매할 수 있어요.

“Python Bootcamp”, “웹 개발 부트캠프” 같은 긴 호흡의 입문 강의가 인기예요.

강의 수가 많아서 평점 높은 강의를 고르는 게 중요해요.

(Udemy, https://www.udemy.com (https://www.udemy.com/?utm_source=chatgpt.com))

freeCodeCamp

완전 무료이고 실습 중심이에요.

웹 개발, Python, 데이터 분석 등을 프로젝트 기반으로 배울 수 있어요.

영어지만 초보자용 설명이 깔끔해서 많이 추천돼요.

(freeCodeCamp, https://www.freecodecamp.org (https://www.freecodecamp.org/?utm_source=chatgpt.com))

처음 시작이라면 추천 순서는 보통:

한국어 선호 → 생활코딩 → 인프런

영어 가능 + 실습 좋아함 → Codecademy → freeCodeCamp

체계적 커리큘럼 선호 → Coursera

한 번에 깊게 배우기 → Udemy

그리고 처음 언어는 보통 Python이 가장 무난해요. 문법이 쉬워서 입문자가 좌절하기 덜하고, 웹/자동화/AI까지 확장 가능해요.
