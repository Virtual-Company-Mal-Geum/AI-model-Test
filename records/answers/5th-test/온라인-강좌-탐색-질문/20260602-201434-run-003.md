# 온라인 강좌-탐색-질문 / run 3

## Question

비전공 성인이 프로그래밍을 배우기 좋은 온라인 교육 사이트 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

비전공 성인이 프로그래밍을 처음 배우기에는

설명이 쉬운지

실습이 많은지

한국어 지원이 되는지

취업·프로젝트까지 이어지는지

가 중요해요. 아래 사이트들은 입문자 만족도가 높고, 독학하기 좋은 곳들입니다.

한국어로 배우기 좋은 사이트
1. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

국내 최대급 온라인 IT 강의 플랫폼

Python, 웹개발, 앱개발, 데이터분석, AI까지 폭넓음

입문 강의가 많고 한국어 설명이라 진입장벽이 낮음

실무 개발자 강의가 많아 취업 준비에도 연결하기 좋음

추천 대상:

“완전 처음인데 한국어로 차근차근 배우고 싶다”

“나중에 취업까지 생각한다”

2. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

비전공자 입문용으로 가장 유명한 무료 플랫폼 중 하나

HTML/CSS/JavaScript/Python 등을 매우 쉽게 설명

“왜 배우는지”까지 설명해줘서 초보자 친화적

추천 대상:

“프로그래밍이 뭔지 감 잡고 싶다”

“무료로 시작하고 싶다”

3. 노마드코더 (https://nomadcoders.co/?utm_source=chatgpt.com)

직접 프로젝트를 만들면서 배우는 스타일

클론코딩 방식이라 결과물이 빨리 나와 재미있음

웹개발·앱개발 입문자에게 인기

추천 대상:

“지루한 문법보다 만들어보면서 배우고 싶다”

4. 패스트캠퍼스 (https://fastcampus.co.kr/?utm_source=chatgpt.com)

취업/실무 중심 강의가 많음

AI, 데이터분석, 프론트엔드, 백엔드 등 커리큘럼 체계적

가격대는 있지만 강의 분량이 많음

추천 대상:

“진지하게 커리어 전환을 고려한다”

해외 사이트 (영어 가능하면 매우 추천)
5. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

세계적으로 유명한 무료 코딩 학습 사이트

웹개발 입문에 특히 강함

실습 기반 + 무료 인증서 제공

추천 대상:

“무료로 제대로 배우고 싶다”

“실습 위주가 좋다”

6. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코딩 가능

인터랙티브 학습이라 초보자가 따라가기 쉬움

Python 입문용으로 특히 유명

추천 대상:

“설치 같은 거 없이 바로 연습하고 싶다”

7. CS50 by Harvard (https://cs50.harvard.edu/?utm_source=chatgpt.com)

하버드대학교의 유명한 컴퓨터공학 입문 강의

난이도는 조금 있지만 기초를 탄탄하게 잡아줌

무료 제공

추천 대상:

“기초 원리를 제대로 배우고 싶다”

입문자에게 추천하는 학습 순서
가장 무난한 루트

생활코딩 → 프로그래밍 감 익히기

Python 기초 배우기

간단한 프로젝트 만들기

웹/앱/AI 중 관심 분야 선택

처음 배우는 사람에게 추천 언어

가장 추천: Python

문법이 쉬움

데이터분석·AI·자동화까지 활용 가능

웹사이트 만들고 싶다면:

HTML/CSS → JavaScript
