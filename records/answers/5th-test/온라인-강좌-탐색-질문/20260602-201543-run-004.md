# 온라인 강좌-탐색-질문 / run 4

## Question

비전공 성인이 프로그래밍을 배우기 좋은 온라인 교육 사이트 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

비전공 성인이 시작하기 좋은 기준으로 골랐어:

입문 친화적인 설명

실습 중심

한국어 지원 여부

취업/포트폴리오 연결 가능성

무료 또는 저렴한 시작 비용

한국어 기반으로 배우기 좋은 곳

인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 가장 많고, 입문 강좌가 풍부함

Python, 웹개발, 앱개발, AI까지 전부 가능

“따라 만들기” 스타일이 많아서 비전공자에게 편함

생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

완전 초보용으로 유명

프로그래밍 개념 설명이 매우 쉬움

무료 강의가 많음

HTML/CSS/JavaScript/Python 입문 추천

패스트캠퍼스 (https://fastcampus.co.kr/?utm_source=chatgpt.com)

실무형 강의가 강점

데이터분석, AI, 백엔드, 프론트엔드 등 커리어 중심

할인 기간이 많아서 패키지 구매 가성비가 좋음

코드잇 (https://codeit.kr/?utm_source=chatgpt.com)

인터랙티브 실습 방식이라 지루하지 않음

비전공 성인 학습자 만족도가 높음

Python, SQL, 데이터분석 입문 특히 괜찮음

해외 사이트 중 입문자에게 좋은 곳

freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

무료

웹개발 입문 최고 수준

프로젝트 중심 학습

영어지만 쉬운 편

Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코딩 가능

인터랙티브 학습 강점

“처음 코딩”인 사람에게 매우 적합

Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학/기업 강의 제공

Google, Stanford University 같은 기관 강의 많음

체계적으로 배우고 싶은 사람에게 좋음

CS50 by Harvard (https://cs50.harvard.edu/?utm_source=chatgpt.com)

세계적으로 유명한 컴퓨터공학 입문 강의

난이도는 조금 있지만 개념 이해에 최고 수준

무료

목적별 추천

“진짜 처음” → 생활코딩, Codecademy

“취업/이직 목표” → 인프런, 패스트캠퍼스

“재밌게 실습” → 코드잇

“돈 안 쓰고 제대로” → freeCodeCamp, CS50

“데이터분석/AI 입문” → 코드잇, Coursera
