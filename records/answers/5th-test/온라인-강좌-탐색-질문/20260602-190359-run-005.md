# 온라인 강좌-탐색-질문 / run 5

## Question

코딩을 처음 시작하는 성인이 듣기 좋은 온라인 강의 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

코딩을 처음 시작하는 성인이라면, “재미 + 실습 + 한국어 지원 + 꾸준히 이어가기 쉬운 구조”가 중요해요. 아래 순서대로 보면 진입 난이도가 비교적 편합니다.

웹 개발로 바로 결과물을 만들어보고 싶다

→ HTML/CSS/JavaScript 중심 추천

취업·실무까지 생각한다

→ Python + 자료구조 + 프로젝트형 추천

완전 비전공자라 용어부터 어렵다

→ 아주 기초적인 입문 강의부터 시작 추천

추천 강의 플랫폼 정리:

생활코딩 — 완전 초보 입문에 가장 유명한 무료 강의. 설명이 쉽고 부담이 적어요.

(생활코딩, https://opentutorials.org/)

인프런 — 한국어 강의가 많고, 입문부터 취업 과정까지 다양해요.

(인프런, https://www.inflearn.com/)

노마드코더 — “직접 만들면서 배우는 스타일”이라 재미있게 시작하기 좋아요.

(노마드코더, https://nomadcoders.co/)

패스트캠퍼스 — 체계적인 커리큘럼과 직무 중심 강의가 많아요.

(패스트캠퍼스, https://fastcampus.co.kr/)

코드잇 — 비전공자 친화적이고 인터랙티브 실습이 잘 되어 있어요.

(코드잇, https://www.codeit.kr/)

Coursera — 해외 대학 강의를 들을 수 있고, 영어 괜찮으면 정말 좋아요.

(Coursera, https://www.coursera.org/)

Udemy — 할인 자주 해서 가성비 좋고 강의 수가 엄청 많아요.

(Udemy, https://www.udemy.com/)

처음 시작이라면 추천 조합은 이렇게 많이 갑니다:

완전 처음 → 생활코딩 + 코드잇

재미있게 웹 만들기 → 노마드코더

취업 목표 → 인프런 + 패스트캠퍼스

영어 가능 + 깊이 있는 공부 → Coursera

추가로 원하면:

“비전공자 기준 3개월 로드맵”

“파이썬 vs 웹개발 뭐부터 할지”

“무료 강의만 모아서 추천”

“취업 목적 기준 추천”

도 정리해줄게요.
