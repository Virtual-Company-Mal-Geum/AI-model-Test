# 온라인 강좌-탐색-질문 / run 4

## Question

처음 코딩을 배우는 사람에게 적합한 프로그래밍 온라인 강의 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

처음 프로그래밍을 배우는 사람이라면 “문법 설명이 쉬운지”, “실습이 많은지”, “한글 지원이 되는지”를 기준으로 고르는 게 좋아요. 아래 강의들은 입문자들이 많이 추천하는 곳들이에요.

생활코딩

웹 개발, Python, JavaScript 등을 정말 쉽게 설명해줘서 완전 초보에게 가장 유명한 입문 강의 중 하나예요.

무료 강의가 많고 부담 없이 시작하기 좋아요.

(생활코딩, https://opentutorials.org/ (https://opentutorials.org/?utm_source=chatgpt.com))

인프런

한국어 강의가 많고, “코딩 입문”, “Python 기초”, “웹 개발 시작” 같은 초보용 강좌가 다양해요.

무료 강의도 꽤 많아서 처음 시작하기 좋습니다.

(인프런, https://www.inflearn.com/ (https://www.inflearn.com/?utm_source=chatgpt.com))

Codecademy

영어 기반이지만, 직접 코드를 입력하면서 배우는 방식이라 이해가 쉬워요.

Python, HTML/CSS, JavaScript 입문에 특히 좋아요.

(Codecademy, https://www.codecademy.com/ (https://www.codecademy.com/?utm_source=chatgpt.com))

Coursera

대학 수준의 강의를 들을 수 있는 플랫폼이에요.

처음에는 “Python for Everybody” 같은 입문 강의가 유명해요.

(Coursera, https://www.coursera.org/ (https://www.coursera.org/?utm_source=chatgpt.com))

Udemy

할인할 때 저렴하게 구매할 수 있고, 실무 중심 강의가 많아요.

“왕초보 Python”, “웹 개발 부트캠프” 같은 강의가 인기예요.

(Udemy, https://www.udemy.com/ (https://www.udemy.com/?utm_source=chatgpt.com))

freeCodeCamp

완전 무료이며, 웹 개발을 단계별로 실습하면서 배울 수 있어요.

프로젝트 중심이라 실력을 키우기 좋아요.

(freeCodeCamp, https://www.freecodecamp.org/ (https://www.freecodecamp.org/?utm_source=chatgpt.com))

처음 시작한다면 추천 순서는 보통:

한국어가 편하면 → 생활코딩 / 인프런

직접 따라 치면서 배우고 싶으면 → Codecademy

웹 개발 포트폴리오까지 만들고 싶으면 → freeCodeCamp

체계적인 대학식 강의를 원하면 → Coursera
