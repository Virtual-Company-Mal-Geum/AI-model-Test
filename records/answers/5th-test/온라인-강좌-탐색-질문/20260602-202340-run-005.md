# 온라인 강좌-탐색-질문 / run 5

## Question

처음 코딩을 배우는 사람에게 적합한 프로그래밍 온라인 강의 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

처음 코딩을 배우는 사람이라면 “문법만 설명하는 강의”보다 직접 따라 만들 수 있는 강의가 훨씬 도움이 됩니다. 아래는 입문자에게 특히 많이 추천되는 온라인 강의 플랫폼들이에요.

생활코딩

한국어로 매우 쉽게 설명해줘서 완전 초보자에게 인기 많음

HTML/CSS, JavaScript, Python, 데이터베이스 등 기초를 폭넓게 배울 수 있음

무료 강의가 많음

(생활코딩, https://opentutorials.org/)

인프런

한국어 강의 플랫폼

입문용 무료 강의가 많고, 실무 개발자 강의도 다양함

“파이썬 입문”, “웹 개발 기초” 같은 강의 추천

(인프런, https://www.inflearn.com/)

코드잇

인터랙티브 방식이라 직접 코드를 입력하면서 배울 수 있음

디자인이 깔끔하고 초보자 친화적

Python, 웹 개발, 데이터 분석 입문 추천

(코드잇, https://www.codeit.kr/)

Udemy

전 세계적으로 유명한 온라인 강의 플랫폼

할인할 때 저렴하게 구매 가능

영어 강의가 많지만 자막 지원되는 경우 많음

(Udemy, https://www.udemy.com/)

Codecademy

브라우저에서 바로 코딩 가능

설치 없이 연습 가능해서 입문자에게 편함

Python, JavaScript, 웹 개발 입문 추천

(Codecademy, https://www.codecademy.com/)

CS50 (하버드 대학교)

세계적으로 유명한 컴퓨터공학 입문 강의

난이도는 조금 있지만 “제대로 기초”를 배우기 좋음

무료 제공

(CS50, https://cs50.harvard.edu/)

처음 시작한다면 추천 순서는 보통 이렇게 많이 합니다:

완전 처음: 생활코딩 / 코드잇

재미있게 실습: Codecademy

제대로 기초 다지기: CS50

다양한 분야 탐색: 인프런 / Udemy
