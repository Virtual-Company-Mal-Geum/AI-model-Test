# 온라인 강좌-탐색-질문 / run 4

## Question

성인 초보자가 따라가기 쉬운 프로그래밍 강좌 사이트를 알려줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 배우는 성인이라면 “설명이 쉬운지”, “실습이 많은지”, “한글 지원이 되는지”, “무료로 시작 가능한지”를 기준으로 고르는 게 좋아요. 아래 사이트들은 초보자가 많이 시작하는 곳들이에요.

1. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

한국어로 아주 쉽게 설명해줘서 입문자에게 특히 유명해요.

HTML/CSS, JavaScript, Python, 데이터베이스 등 기초를 단계별로 배울 수 있어요.

“코딩이 뭔지도 모르겠다” 수준에서 시작하기 좋아요.

(생활코딩, https://opentutorials.org/)

2. 프로그래머스 (https://programmers.co.kr/?utm_source=chatgpt.com)

강의 + 코딩 테스트 연습을 같이 할 수 있어요.

실습 환경이 웹에 바로 있어서 설치 없이 시작 가능한 강좌도 많아요.

취업 준비용으로도 많이 사용해요.

(프로그래머스, https://programmers.co.kr/)

3. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 매우 많고, 입문 강좌 선택지가 풍부해요.

Python, 웹 개발, 앱 개발, AI 등 거의 모든 분야가 있어요.

무료 강의도 꽤 많아요.

(인프런, https://www.inflearn.com/)

4. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

해외 사이트지만 무료 퀄리티가 매우 높아요.

직접 코드를 작성하면서 배우는 방식이라 실력이 빨리 늘어요.

웹 개발 입문자에게 특히 추천돼요.

(freeCodeCamp, https://www.freecodecamp.org/)

5. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

화면에서 바로 코드를 입력하며 배우는 인터랙티브 방식이에요.

영어가 아주 어렵지는 않은 편이라 초보자도 접근 가능해요.

“게임처럼 배우는 느낌”이 있어서 지루하지 않아요.

(Codecademy, https://www.codecademy.com/)

6. Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학 수준 강의를 온라인으로 들을 수 있어요.

기초 컴퓨터 과학 과정도 많고, 일부는 무료 청강 가능해요.

조금 더 체계적으로 배우고 싶은 사람에게 좋아요.

(Coursera, https://www.coursera.org/)

처음 시작이라면 추천 순서는 보통:

생활코딩

인프런 무료 강의

프로그래머스 또는 freeCodeCamp

이 흐름이 가장 부담이 적어요.

원하면 제가 “완전 비전공 성인 기준”으로:

웹 개발 입문용

앱 만들기용

게임 개발용

AI/파이썬 입문용

처럼 목적별 추천도 정리해줄게요.
