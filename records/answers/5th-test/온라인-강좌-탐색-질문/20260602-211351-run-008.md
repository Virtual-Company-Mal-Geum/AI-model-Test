# 온라인 강좌-탐색-질문 / run 7

## Question

성인 초보자가 따라가기 쉬운 프로그래밍 강좌 사이트를 알려줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

성인 초보자가 시작하기 쉬운 프로그래밍 강좌 사이트들을 난이도·설명 방식·실습 중심 여부 기준으로 골라봤어.

한국어로 배우기 좋은 곳

인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 많고, 입문자를 위한 무료 강좌도 풍부함

Python, 웹개발, 앱개발, AI 등 거의 모든 분야 있음

“따라 만들기” 스타일 강의가 많아서 초보자에게 편함

(인프런, https://www.inflearn.com/)

생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

진짜 초보자용으로 유명

개념 설명을 쉽게 해주고 무료 콘텐츠가 많음

HTML/CSS/JavaScript/Python 입문 추천

(생활코딩, https://opentutorials.org/)

점프 투 파이썬 (https://wikidocs.net/book/1?utm_source=chatgpt.com)

Python 입문 교재 느낌으로 차근차근 설명

독학 초보자들이 많이 시작하는 사이트

(점프 투 파이썬, https://wikidocs.net/book/1)

해외지만 초보자에게 매우 좋은 곳

Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코딩 가능

“한 줄씩 따라치는” 방식이라 입문 난이도가 낮음

영어이긴 하지만 인터랙티브해서 이해하기 쉬움

(Codecademy, https://www.codecademy.com/)

freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료

웹개발 입문 코스가 특히 유명

실습 중심 + 프로젝트 제작 방식

(freeCodeCamp, https://www.freecodecamp.org/)

CS50 by Harvard (https://cs50.harvard.edu/?utm_source=chatgpt.com)

유명한 하버드 컴퓨터공학 입문 강의

난이도는 약간 있지만 설명력이 뛰어남

프로그래밍을 제대로 이해하고 싶은 사람에게 추천

(CS50, https://cs50.harvard.edu/)

처음 시작한다면 추천 순서는:

완전 처음 → 생활코딩

Python 배우고 싶음 → 점프 투 파이썬

직접 많이 코딩해보고 싶음 → Codecademy / freeCodeCamp

제대로 기초를 다지고 싶음 → CS50

원하면 내가:

“게임 만들기로 배우는 입문”

“Python만 집중”

“웹개발 취업용”

“중학생/고등학생도 이해 가능한 강의”

같은 식으로 더 좁혀서 추천해줄 수도 있어.
