# 온라인 강좌-탐색-질문 / run 9

## Question

성인 초보자가 따라가기 쉬운 프로그래밍 강좌 사이트를 알려줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

성인 초보자가 시작하기 좋은 프로그래밍 강좌 사이트들을 난이도, 설명 방식, 한글 지원 여부 기준으로 골라봤어.

처음에는 “문법 완벽 이해”보다 직접 따라 만들기 위주 강의를 추천해.

한국어로 배우기 좋은 사이트
1. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 매우 많음

입문자 대상 무료 강의도 풍부

Python, 웹개발, 앱개발, AI까지 전부 가능

“따라 만들기” 스타일 강의가 많아서 성인 초보자에게 특히 편함

추천 입문 분야:

Python

HTML/CSS

JavaScript

2. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

진짜 초보자용 설명으로 유명

컴퓨터를 잘 몰라도 이해하기 쉽게 설명

무료

웹 개발 입문에 매우 강함

특히 추천:

WEB1

JavaScript

Python

3. 패스트캠퍼스 (https://fastcampus.co.kr/?utm_source=chatgpt.com)

실무 중심 강의 많음

디자인/UI가 깔끔해서 보기 편함

다만 완전 입문보다는 “입문~취업 준비” 느낌

추천 대상:

목표가 취업/이직인 사람

프로젝트 중심 학습 원하는 사람

해외 사이트 (초보자 친화적)
4. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코딩 가능

설치 없이 연습 가능

영어지만 인터랙티브 방식이라 따라가기 쉬움

추천 언어:

Python

JavaScript

SQL

5. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료

단계별 실습 중심

웹개발 공부에 특히 강력

장점:

직접 문제 풀면서 학습

포트폴리오 프로젝트 제공

6. Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학 강의 스타일

체계적으로 배우기 좋음

자막 지원 강의 많음

추천:

Python for Everybody

Google IT 과정

완전 초보자라면 추천 순서

생활코딩

인프런 무료 Python 강의

Codecademy 실습

freeCodeCamp 프로젝트
