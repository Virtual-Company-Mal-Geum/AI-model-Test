# 온라인 강좌-탐색-질문 / run 1

## Question

비전공 성인이 프로그래밍을 배우기 좋은 온라인 교육 사이트 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

비전공 성인이 시작하기 좋은 기준으로 골라봤어.

특히 “입문 난이도”, “실습 중심”, “한국어 지원”, “취업/실무 연결”을 기준으로 추천할게.

완전 입문용 (프로그래밍 처음이라면)
1. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코딩 가능

설치 없이 시작 가능해서 진입장벽이 낮음

Python, JavaScript, 웹개발 입문 강의가 특히 유명

영어 기반이지만 인터랙티브 학습이 매우 강점

추천 대상:

“코딩이 뭔지부터 모르겠다”

게임 튜토리얼처럼 배우고 싶다

2. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

한국어 무료 강의의 대표격

설명이 친절하고 비전공자 눈높이에 맞음

웹개발, Python, 데이터베이스 등 기초 학습에 좋음

추천 대상:

한국어로 차근차근 배우고 싶은 사람

비용 없이 시작하고 싶은 사람

3. CS50 (Harvard) (https://cs50.harvard.edu/x/?utm_source=chatgpt.com)

하버드의 유명 컴퓨터과학 입문 강의

단순 문법보다 “컴퓨터적 사고”를 잘 가르침

난도는 조금 있지만 매우 탄탄함

추천 대상:

제대로 기초를 다지고 싶은 사람

장기적으로 개발자를 고려하는 사람

실무/취업 중심
4. 프로그래머스 (https://programmers.co.kr/?utm_source=chatgpt.com)

한국 개발자 취업 준비에 강함

코딩 테스트 연습 환경 제공

강의 + 실습 + 채용 연결 구조

추천 대상:

취업 또는 이직 목표

알고리즘/코딩테스트 준비

5. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국 최대 규모 개발 강의 플랫폼 중 하나

실무 강의가 매우 다양

프론트엔드, 백엔드, AI, 앱개발 등 폭넓음

추천 대상:

특정 기술을 실무적으로 배우고 싶은 사람

한국어 강의를 선호하는 사람

6. Udemy (https://www.udemy.com/?utm_source=chatgpt.com)

글로벌 최대 온라인 강의 플랫폼

세일 때 가격이 매우 저렴

실무 프로젝트형 강의가 많음

추천 대상:

가성비 중요

프로젝트 중심으로 배우고 싶은 사람

무료 + 프로젝트 중심
7. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

무료인데 커리큘럼 완성도가 높음

웹개발/JavaScript 학습에 강력

프로젝트 만들면서 배움

추천 대상:

“만들면서 배우는 스타일”

웹개발 입문

8. Khan Academy Computer Programming (https://www.khanacademy.org/computing/computer-programming?utm_source=chatgpt.com)

아주 기초적인 개념 설명이 뛰어남

시각적으로 배우기 좋음

부담 없이 입문 가능

추천 대상:

수학/논리형 설명을 좋아하는 사람

초등 개념 수준부터 시작하고 싶은 사람

어떤 사이트부터 시작하면 좋은지 추천 루트
가장 쉬운 루트
생활코딩 → Codecademy → 인프런/프로그래머스

웹개발 목표
freeCodeCamp → Codecademy → 인프런

진지하게 개발자 목표
CS50 → 프로그래머스 → 인프런
