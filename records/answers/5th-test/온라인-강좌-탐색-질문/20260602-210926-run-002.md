# 온라인 강좌-탐색-질문 / run 1

## Question

성인 초보자가 따라가기 쉬운 프로그래밍 강좌 사이트를 알려줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

성인 초보자가 시작하기 쉬운 프로그래밍 강좌 사이트들을 “설명 친절함 + 입문 난이도 + 실습 중심” 기준으로 골라봤어.

특히 처음이면 Python → 웹 개발 → 자료구조/알고리즘 순서로 배우는 게 부담이 적어.

한국어 강의 중심
1. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 많고 초보자용 강좌가 매우 풍부함

“입문”, “왕초보”, “비전공자” 강의가 잘 정리돼 있음

Python, 웹 개발, 앱 개발, AI까지 이어서 배우기 좋음

무료 강의도 꽤 많음

추천 대상:

완전 처음 시작하는 사람

한국어 설명이 편한 사람

2. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

가장 유명한 한국어 무료 프로그래밍 입문 사이트 중 하나

설명이 차분하고 부담이 적음

HTML/CSS/JavaScript 입문이 특히 좋음

추천 대상:

“코딩이 뭔지도 잘 모르겠다” 수준의 완전 초보

웹 개발을 가볍게 시작하고 싶은 사람

3. 프로그래머스 (https://programmers.co.kr/?utm_source=chatgpt.com)

강의 + 코딩 테스트 연습을 같이 할 수 있음

실습 환경이 잘 되어 있어서 설치 스트레스가 적음

취업 준비 단계까지 연결 가능

추천 대상:

배우면서 문제도 같이 풀고 싶은 사람

나중에 개발 취업도 고려하는 사람

해외 사이트 (초보 친화적)
4. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료

단계별 실습 방식이라 따라가기 쉬움

웹 개발 입문에 특히 강함

추천 대상:

영어에 거부감이 크지 않은 사람

실습 위주로 배우고 싶은 사람

5. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코딩 가능

인터랙티브 방식이라 게임처럼 배우기 쉬움

초보자 UX가 매우 좋음

추천 대상:

지루한 강의보다 직접 입력하면서 배우고 싶은 사람

6. CS50 by Harvard (https://cs50.harvard.edu/?utm_source=chatgpt.com)

세계적으로 유명한 컴퓨터공학 입문 강좌

난이도는 조금 있지만 설명 퀄리티가 뛰어남

무료

추천 대상:

“제대로 기초를 배우고 싶다”는 사람

장기적으로 개발 공부를 할 사람

개인적으로 가장 추천하는 시작 조합
완전 처음이라면:

생활코딩으로 웹 기초 맛보기

인프런에서 Python 입문 강의 듣기

프로그래머스에서 간단한 문제 풀이 시작

이 흐름이 부담이 가장 적어.

마지막에 요청한 형식으로 다시 정리하면:

(생활코딩, https://opentutorials.org/)

(프로그래머스, https://programmers.co.kr/)

(freeCodeCamp, https://www.freecodecamp.org/)

(Codecademy, https://www.codecademy.com/)

(CS50, https://cs50.harvard.edu/)
