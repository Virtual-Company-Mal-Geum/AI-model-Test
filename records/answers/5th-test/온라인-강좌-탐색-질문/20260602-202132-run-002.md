# 온라인 강좌-탐색-질문 / run 2

## Question

처음 코딩을 배우는 사람에게 적합한 프로그래밍 온라인 강의 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

처음 코딩을 배우는 사람이라면, “재미를 느끼면서 작은 결과물을 빨리 만들어보는 강의”가 가장 중요해요. 아래 강의들은 입문자들이 많이 추천하는 온라인 강의들이고, 한국어/영어 여부도 같이 적어둘게요.

생활코딩

완전 초보자에게 가장 많이 추천되는 무료 강의

HTML, CSS, JavaScript, Python, 데이터베이스까지 차근차근 설명

코딩을 처음 접하는 학생도 따라가기 쉬움

한국어 강의

(생활코딩, https://opentutorials.org/ (https://opentutorials.org/?utm_source=chatgpt.com))

인프런

한국어 강의가 매우 많고, 입문 강의 선택 폭이 넓음

“파이썬 입문”, “웹 개발 기초” 같은 강의가 인기

무료 강의도 꽤 많음

(인프런, https://www.inflearn.com/ (https://www.inflearn.com/?utm_source=chatgpt.com))

코드잇(Codeit)

인터랙티브 방식이라 직접 코드를 입력하며 배우기 좋음

디자인과 설명이 깔끔해서 독학 난이도가 낮음

Python, 웹 개발, 데이터 분석 입문 추천

(코드잇, https://www.codeit.kr/ (https://www.codeit.kr/?utm_source=chatgpt.com))

프로그래머스

코딩 테스트로 유명하지만 입문 강의도 잘 되어 있음

실습 중심이라 “직접 해보며 배우는 스타일”에 적합

(프로그래머스, https://programmers.co.kr/ (https://programmers.co.kr/?utm_source=chatgpt.com))

Codecademy

영어 기반이지만 세계적으로 유명한 코딩 입문 사이트

설치 없이 브라우저에서 바로 실습 가능

영어가 괜찮다면 가장 직관적인 편

(Codecademy, https://www.codecademy.com/ (https://www.codecademy.com/?utm_source=chatgpt.com))

CS50 (하버드 무료 강의)

유명한 컴퓨터공학 입문 강의

난이도는 조금 있지만 “진짜 기초 체력”을 만들기 좋음

무료 + 자막 지원

(CS50, https://cs50.harvard.edu/ (https://cs50.harvard.edu/?utm_source=chatgpt.com))

추천 순서를 정하면:

완전 처음 → 생활코딩 / 코드잇

재미있게 실습 → Codecademy

진지하게 컴퓨터공학 기초 → CS50

한국어로 다양하게 → 인프런

처음 시작한다면 개인적으로는 Python + 작은 프로젝트 만들기 조합을 가장 추천해요.
