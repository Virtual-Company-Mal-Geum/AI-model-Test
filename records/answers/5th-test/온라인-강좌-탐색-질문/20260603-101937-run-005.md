# 온라인 강좌-탐색-질문 / run 5

## Question

초보자가 프로그래밍 개념부터 차근차근 배울 수 있는 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 배우는 단계라면, “문법 암기”보다 개념 → 실습 → 작은 프로젝트 순서로 배우는 강좌가 훨씬 오래 갑니다. 아래는 초보자에게 특히 많이 추천되는 입문 강좌들이에요.

한국어 강좌

생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

완전 초보자용으로 가장 유명한 입문 사이트 중 하나

컴퓨터, 인터넷, 웹, Python, JavaScript까지 단계적으로 설명

“왜 이걸 배우는지”를 쉽게 알려줘서 입문 난도가 낮음

인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 프로그래밍 강의 플랫폼

무료 입문 강좌가 많고, 웹 개발·앱 개발·AI 등 분야별 선택 가능

추천 입문 키워드:

“파이썬 입문”

“웹 개발 입문”

“JavaScript 기초”

점프 투 파이썬 (https://wikidocs.net/book/1?utm_source=chatgpt.com)

Python 초보자용 무료 온라인 책

문법 설명 + 예제가 잘 정리돼 있음

처음 프로그래밍 언어 하나를 배우기에 좋음

노마드코더 (https://nomadcoders.co/?utm_source=chatgpt.com)

직접 무언가 만들어보는 스타일의 강의가 많음

웹사이트, 앱, 클론코딩 중심

기초를 조금 익힌 뒤 프로젝트 경험 쌓기 좋음

해외 강좌 (영어지만 매우 유명)

freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

무료로 체계적인 커리큘럼 제공

HTML/CSS → JavaScript → 백엔드 → 데이터 분석까지 가능

실습 위주라 손으로 직접 익히기 좋음

CS50 by Harvard (https://cs50.harvard.edu/x/?utm_source=chatgpt.com)

하버드의 대표 컴퓨터공학 입문 강좌

프로그래밍 개념(변수, 조건문, 알고리즘 등)을 깊이 있게 설명

난이도는 약간 있지만 개념 이해에 매우 좋음

Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코딩 가능

따라 치면서 배우는 인터랙티브 방식

초보자가 “코딩 감각” 익히기 좋음

처음 시작할 때 추천 루트
웹사이트 만들기에 관심 있다면

생활코딩 HTML/CSS

JavaScript 기초

노마드코더 또는 freeCodeCamp 프로젝트

앱/자동화/AI에 관심 있다면

점프 투 파이썬

인프런 Python 입문

작은 프로그램 직접 만들어보기

컴퓨터공학 개념까지 제대로 배우고 싶다면

생활코딩

CS50

자료구조/알고리즘 기초

개인적으로 초보자에게 가장 무난한 조합

개념 이해: 생활코딩

첫 언어: 점프 투 파이썬

실습: freeCodeCamp

CS 기초: CS50

이 순서로 가면 “코딩은 처음인데 어디서부터 해야 할지 모르겠다” 상태에서 꽤 안정적으로 올라갈 수 있어요.
