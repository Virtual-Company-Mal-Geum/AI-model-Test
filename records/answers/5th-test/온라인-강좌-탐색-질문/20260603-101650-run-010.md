# 온라인 강좌-탐색-질문 / run 10

## Question

코딩 기초를 배우고 싶은 성인에게 알맞은 온라인 강의 플랫폼 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

코딩 기초를 처음 배우는 성인이라면, **“설명이 쉬운지 + 실습이 많은지 + 꾸준히 이어가기 쉬운지”**를 기준으로 고르는 게 좋아요. 아래 플랫폼들은 입문자들에게 특히 평가가 좋은 곳들입니다.

한국어 중심으로 배우기 좋은 플랫폼
1. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 매우 많고, 입문자용 강의가 다양함

Python, 웹개발, 앱개발, 데이터분석 등 분야 선택 가능

실무 개발자 강의가 많아 “현업 느낌”을 익히기 좋음

할인 이벤트가 자주 있음

추천 대상:

한국어로 편하게 시작하고 싶은 사람

영상 강의 스타일을 선호하는 사람

2. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

무료로 코딩 개념을 정말 쉽게 설명해줌

HTML/CSS/JavaScript 같은 웹 기초 입문에 특히 강함

부담 없이 시작하기 좋음

추천 대상:

“코딩이 처음”인 완전 입문자

무료로 먼저 체험해보고 싶은 사람

3. 패스트캠퍼스 (https://fastcampus.co.kr/?utm_source=chatgpt.com)

체계적인 커리큘럼이 강점

데이터분석, AI, 프론트엔드 등 전문 과정이 많음

취업/이직 준비용 로드맵 제공

추천 대상:

장기적으로 진로까지 고민하는 사람

프로젝트 중심 학습을 원하는 사람

해외 플랫폼 (영어 가능하면 매우 추천)
4. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코딩 실습 가능

“읽고 → 바로 실행” 구조라 초보자 친화적

인터랙티브 학습이 강점

추천 대상:

손으로 직접 해보면서 배우는 스타일

영어에 거부감이 크지 않은 사람

5. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료

웹개발 입문 커리큘럼이 매우 탄탄

프로젝트 기반 학습 가능

추천 대상:

비용 부담 없이 깊게 배우고 싶은 사람

웹개발에 관심 있는 사람

6. Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학/기업 강의를 온라인으로 제공

Google, IBM 같은 기관의 입문 강의도 많음

수료증 과정 제공

추천 대상:

체계적인 강의를 선호하는 사람

이력서용 인증서도 고려하는 사람

처음 시작한다면 추천 학습 순서

Python 기초 또는 웹개발 입문 선택

변수 → 조건문 → 반복문 → 함수 익히기

작은 프로젝트 만들어보기

Git/GitHub 익히기

관심 분야 선택

웹개발

앱개발

게임

데이터분석

AI

빠르게 고르기

완전 초보 + 무료 → 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

한국어 + 실무형 → 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

영어 가능 + 인터랙티브 → Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

무료로 깊게 → freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)
