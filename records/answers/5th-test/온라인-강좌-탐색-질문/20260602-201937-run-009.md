# 온라인 강좌-탐색-질문 / run 9

## Question

비전공 성인이 프로그래밍을 배우기 좋은 온라인 교육 사이트 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

비전공 성인이 처음 프로그래밍을 배우기엔 “설명이 친절한지”, “실습 중심인지”, “커리큘럼이 체계적인지”, “한국어 지원이 되는지”가 중요해요. 아래는 입문자 기준으로 특히 평가가 좋은 온라인 학습 사이트들입니다.

한국어로 배우기 좋은 사이트
1. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국에서 가장 많이 쓰이는 개발 학습 플랫폼 중 하나

웹개발, Python, Java, AI, 앱개발 등 강의가 매우 다양함

입문 강의가 많고 실무 개발자 강의 비중이 큼

“무료 강의 → 유료 심화” 흐름으로 시작하기 좋음

추천 대상:

완전 초보

한국어 설명 선호

실무 중심 학습 원하는 사람

2. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

비전공 입문자에게 거의 교과서처럼 추천되는 사이트

HTML/CSS/JavaScript/Python 기초 설명이 정말 쉬움

무료

“왜 배우는지”까지 설명해줘서 초보가 덜 막힘

추천 대상:

코딩 처음 접하는 사람

컴퓨터 개념부터 차근차근 배우고 싶은 사람

3. 프로그래머스 (https://programmers.co.kr/?utm_source=chatgpt.com)

코딩 테스트와 실습 중심 플랫폼

강의 + 문제풀이 같이 가능

취업 준비와 연결하기 좋음

추천 대상:

어느 정도 기초 후 실력 키우고 싶은 사람

문제풀이 연습하고 싶은 사람

4. 패스트캠퍼스 (https://fastcampus.co.kr/?utm_source=chatgpt.com)

직무/실무 중심 강의가 강함

데이터분석, AI, 프론트엔드, 백엔드 등 분야 다양

장기 로드맵형 강의가 많음

추천 대상:

진로 변경/취업 목표

체계적인 커리큘럼 선호

해외 사이트 (영어 가능하면 강력 추천)
5. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료

웹개발 입문 최강급으로 유명

직접 코드를 작성하며 배우는 구조

수료 인증도 있음

추천 대상:

웹개발 입문

영어 읽기 가능

돈 안 들이고 배우고 싶은 사람

6. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

인터랙티브 실습이 매우 강력함

브라우저 안에서 바로 코딩 가능

초보 친화적 UI

추천 대상:

“읽는 것보다 직접 해보며 배우는 스타일”

짧게 짧게 학습하는 사람

7. Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학/기업 강의를 온라인으로 제공

Google, Stanford University 등 유명 기관 강의 많음

컴퓨터공학 기초를 체계적으로 배우기 좋음

추천 대상:

깊이 있게 배우고 싶은 사람

학문적 기초도 같이 배우고 싶은 사람

처음 시작한다면 추천 루트
완전 처음이라면

생활코딩

인프런 Python/웹개발 입문

freeCodeCamp 실습

이 순서가 가장 무난해요.

어떤 언어부터 배우면 좋을까?

웹사이트 만들기 → JavaScript

자동화/데이터/AI → Python

앱 개발 → Kotlin / Swift

취업 범용성 → Python + JavaScript 조합 추천
