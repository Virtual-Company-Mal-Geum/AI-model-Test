# 온라인 강좌-탐색-질문 / run 7

## Question

코딩을 처음 시작하는 성인이 듣기 좋은 온라인 강의 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

코딩을 처음 시작하는 성인이라면, “문법 암기”보다 작은 결과물을 빨리 만들어보는 강의가 훨씬 오래 갑니다. 아래는 입문자 만족도가 높고, 한국어/영어 기준으로 접근하기 좋은 온라인 강의들입니다.

한국어 강의

인프런

한국어 강의가 가장 많고, 입문자용 무료 강의도 풍부함

Python, 웹개발, 앱개발, AI까지 단계별 학습 가능

“파이썬 입문”, “웹 개발 왕초보” 같은 실전형 강의가 많음

(인프런, https://inflearn.com/ (https://chatgpt.com/c/null))

생활코딩

완전 초보 기준으로 설명을 정말 쉽게 해주는 무료 강의

HTML/CSS/JavaScript부터 서버, 데이터베이스까지 연결 가능

“코딩이 뭔지 감 잡기”에 특히 좋음

(생활코딩, https://opentutorials.org/)

패스트캠퍼스

취업·실무 중심 커리큘럼이 강점

비전공 성인 학습자 대상 강의가 많음

한 번에 여러 분야를 배우는 패키지가 인기

(패스트캠퍼스, https://fastcampus.co.kr/)

노마드코더

결과물을 직접 만들면서 배우는 스타일

웹사이트, 앱, 클론코딩 강의가 유명

“재미 붙이기”에 강함

(노마드코더, https://nomadcoders.co/)

영어 강의 (기초 영어 가능하면 추천)

Codecademy

설치 없이 브라우저에서 바로 코딩 가능

손으로 직접 따라치는 인터랙티브 방식

진짜 완전 초보에게 매우 친절함

(Codecademy, https://www.codecademy.com/)

CS50 by Harvard

세계적으로 유명한 컴퓨터공학 입문 강의

난이도는 조금 있지만, 코딩 사고방식을 제대로 잡아줌

무료로 수강 가능

(CS50, https://cs50.harvard.edu/x/)

Coursera

대학 강의를 온라인으로 들을 수 있음

Google, IBM 등의 입문 코스가 인기

수료증 과정도 많음

(Coursera, https://www.coursera.org/)

처음 시작할 때 추천 루트

“코딩이 뭔지 감 잡기” → 생활코딩

“재미있게 결과물 만들기” → 노마드코더

“체계적으로 배우기” → 인프런 / 패스트캠퍼스

“영어 괜찮고 깊게 배우기” → CS50

그리고 첫 언어는 대부분 아래 둘 중 하나 추천합니다:

Python: 쉽고 AI/자동화까지 확장 가능

JavaScript: 웹사이트 만들기 바로 가능

원하면 다음 단계로:

“완전 비전공자 기준 3개월 공부 로드맵”

“직장인 기준 하루 1시간 커리큘럼”

“웹개발 / 앱개발 / AI 중 뭐가 맞는지”

도 같이 정리해줄게.
