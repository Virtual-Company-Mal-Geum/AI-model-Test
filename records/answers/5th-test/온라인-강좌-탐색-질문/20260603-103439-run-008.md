# 온라인 강좌-탐색-질문 / run 8

## Question

코딩을 처음 배우는 직장인이나 성인 학습자가 듣기 좋은 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

직장인이나 성인 학습자가 코딩을 처음 시작할 때는 “이론 → 실습 → 작은 프로젝트” 순서로 배울 수 있는 강의가 좋습니다. 특히 비전공자라면 Python(파이썬)으로 시작하는 것을 추천합니다.

1. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

국내 최대 규모의 개발 강의 플랫폼

한국어 강의가 매우 많고, 입문 강의 선택지가 풍부함

"파이썬 입문", "웹 개발 입문", "업무 자동화" 같은 직장인 대상 강의가 많음

완전 초보자에게 추천 애플위키+1 (https://applewiki.tistory.com/entry/%EB%AC%B4%EB%A3%8C-%ED%8C%8C%EC%9D%B4%EC%8D%AC-%EA%B0%95%EC%9D%98-%EC%B6%94%EC%B2%9C-%EC%99%95%EC%B4%88%EB%B3%B4%EB%8F%84-%EC%9D%B4%ED%95%B4%ED%95%98%EB%8A%94-%EC%BD%94%EB%94%A9-%EC%9E%85%EB%AC%B8?utm_source=chatgpt.com)

URL 형식:

(인프런, https://www.inflearn.com/)

2. 코드잇 (https://www.codeit.kr/?utm_source=chatgpt.com)

비전공자와 성인 학습자를 대상으로 설계된 커리큘럼

설명이 친절하고 단계별 학습이 체계적

실습 환경이 잘 갖춰져 있어 설치 과정에서 덜 헤맴

꾸준히 공부할 수 있는 학습 경로 제공 버섯돌이의 인사이드 소셜웹 (https://mushman.co.kr/2692154?utm_source=chatgpt.com)

URL 형식:

(코드잇, https://www.codeit.kr/)

3. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

무료로 시작 가능

HTML, CSS, JavaScript, Python 등 기초 개념 설명이 매우 쉬움

"코딩이 뭔지" 감을 잡기에 최고 수준의 입문 자료 실용-잡식주의자+1 (https://devyeop.tistory.com/entry/%EB%AC%B4%EB%A3%8C%EB%A1%9C-%EC%BD%94%EB%94%A9-%EB%B0%B0%EC%9A%B0%EB%8A%94-%EB%B0%A9%EB%B2%95-5%EA%B0%80%EC%A7%80-2025%EB%85%84-%EA%B8%B0%EC%A4%80?utm_source=chatgpt.com)

URL 형식:

(생활코딩, https://opentutorials.org/)

4. 패스트캠퍼스 (https://fastcampus.co.kr/?utm_source=chatgpt.com)

직장인 대상 강의가 많음

데이터 분석, AI, 웹 개발, 업무 자동화 등 실무 중심

어느 정도 진로가 정해진 후 수강하면 효과적 오늘도 좋은 날 (https://mrscho.com/entry/%EB%B9%84%EC%A0%84%EA%B3%B5%EC%9E%90%EB%8F%84-%EB%94%B0%EB%9D%BC%ED%95%A0-%EC%88%98-%EC%9E%88%EB%8A%94-%EC%BD%94%EB%94%A9-%EA%B0%95%EC%9D%98-%EC%B6%94%EC%B2%9C-%EC%9E%85%EB%AC%B8%EC%9E%90-%EA%B0%95%EC%9D%98-%EB%A6%AC%EC%8A%A4%ED%8A%B8-%EB%B3%B4%EA%B8%B0?utm_source=chatgpt.com)

URL 형식:

(패스트캠퍼스, https://fastcampus.co.kr/)

5. Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

해외 대학 및 기업 강의 제공

영어가 가능하다면 매우 훌륭한 선택

Google, University of Michigan 등의 입문 강의를 들을 수 있음

URL 형식:

(Coursera, https://www.coursera.org/)

처음 시작하는 사람에게 추천하는 학습 순서

생활코딩 → 코딩 개념 익히기

인프런 또는 코드잇 → 파이썬 입문 완강

간단한 자동화 프로그램 만들기

웹 개발, 데이터 분석, AI 중 관심 분야 선택

패스트캠퍼스·Coursera 등으로 심화

시간이 부족한 직장인이라면 생활코딩 → 코드잇(파이썬) → 작은 프로젝트 순서가 가장 부담 없이 시작하기 좋습니다.
