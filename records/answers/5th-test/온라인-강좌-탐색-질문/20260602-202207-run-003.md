# 온라인 강좌-탐색-질문 / run 3

## Question

처음 코딩을 배우는 사람에게 적합한 프로그래밍 온라인 강의 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

처음 코딩을 배우는 사람이라면 **“재미를 느끼면서 작은 성공 경험을 빨리 만드는 강의”**가 가장 중요해요.

특히 처음에는 너무 어려운 컴퓨터공학 이론보다, 파이썬·웹 개발·실습 중심 강의를 추천합니다.

한국어로 배우기 좋은 입문 강의
1. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 매우 많고, 입문자용 무료 강의도 풍부함

“파이썬 입문”, “웹 개발”, “HTML/CSS”, “게임 만들기” 같은 실습형 강의가 많음

강사 스타일이 다양해서 자기랑 맞는 강의를 찾기 쉬움

추천 대상:

완전 처음 시작하는 사람

한국어 설명이 편한 사람

2. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

무료로 코딩 기초를 배우기 가장 유명한 사이트 중 하나

설명이 쉽고 친절해서 “코딩이 뭔지” 감 잡기에 좋음

HTML/CSS/JavaScript, Python, 데이터베이스까지 기초를 탄탄히 배울 수 있음

추천 대상:

부담 없이 무료로 시작하고 싶은 사람

코딩 원리를 쉽게 이해하고 싶은 사람

3. 노마드코더 (https://nomadcoders.co/?utm_source=chatgpt.com)

“무언가 직접 만들어보는 방식”이 강점

클론코딩 스타일이라 결과물이 빨리 나와서 재미를 느끼기 쉬움

웹사이트·앱 만들기 입문에 좋음

추천 대상:

지루한 이론보다 실습을 좋아하는 사람

웹 개발에 관심 있는 사람

4. 코드잇 (https://www.codeit.kr/?utm_source=chatgpt.com)

커리큘럼이 체계적이고 디자인이 깔끔함

인터랙티브 실습이 많아서 혼자 공부하기 편함

Python, 데이터 분석, 웹 개발 등 다양함

추천 대상:

단계별로 차근차근 배우고 싶은 사람

독학이 막막한 사람

5. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

세계적으로 유명한 영어권 코딩 학습 플랫폼

브라우저에서 바로 코딩 가능

실습 중심이라 손으로 직접 익히기 좋음

추천 대상:

영어에 거부감이 없는 사람

인터랙티브 학습을 좋아하는 사람

처음 시작할 때 추천 공부 순서

Python 또는 HTML/CSS 중 하나 선택

작은 프로젝트 따라 만들기

Git/GitHub 익히기

관심 분야 선택

웹 개발

게임

앱 개발

AI/데이터 분석 등

가장 무난한 시작 추천

“코딩이 완전 처음” → 생활코딩 + 인프런 무료 강의

“재미있게 만들면서 배우고 싶음” → 노마드코더

“체계적으로 오래 공부할 계획” → 코드잇

마지막으로 요청한 형식으로 정리하면:

(인프런, https://www.inflearn.com/)

(생활코딩, https://opentutorials.org/)

(노마드코더, https://nomadcoders.co/)

(코드잇, https://www.codeit.kr/)

(Codecademy, https://www.codecademy.com/)
