# 온라인 강좌-탐색-질문 / run 3

## Question

프로그래밍 입문자가 기초부터 배울 수 있는 온라인 강좌를 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 시작한다면, “문법 → 간단한 프로젝트 → 실전 응용” 순서로 배우는 강좌가 가장 좋아요. 아래 강의들은 입문자 기준으로 이해하기 쉽고, 한국어/영어 모두 포함해서 추천할 만한 곳들이에요.

Python 기초를 가장 쉽게 시작하고 싶다면

Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

인터랙티브 방식이라 설치 없이 바로 코딩 가능

초보자에게 특히 친절함

Python, HTML/CSS, JavaScript 입문 추천

형식: (Codecademy, https://www.codecademy.com/)

체계적으로 대학 강의 느낌으로 배우고 싶다면

Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

해외 대학 강의를 온라인으로 수강 가능

“Python for Everybody”가 입문자에게 유명

무료 청강 가능한 강좌도 많음

형식: (Coursera, https://www.coursera.org/)

한국어 강의를 선호한다면

인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 입문 강의가 매우 많음

Python, 웹개발, 앱개발까지 이어서 배우기 좋음

“왕초보 프로그래밍” 계열 강좌 추천

형식: (인프런, https://www.inflearn.com/)

게임처럼 재미있게 배우고 싶다면

freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료

웹 개발 입문에 특히 강함

실습 위주라 포트폴리오 만들기 좋음

형식: (freeCodeCamp, https://www.freecodecamp.org/)

영상으로 천천히 따라 배우고 싶다면

생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

한국에서 가장 유명한 무료 코딩 입문 사이트 중 하나

HTML/CSS/JavaScript/Python 기초 설명이 매우 쉬움

형식: (생활코딩, https://opentutorials.org/)

코딩 테스트나 알고리즘까지 이어서 배우고 싶다면

프로그래머스 (https://programmers.co.kr/?utm_source=chatgpt.com)

기초 문법 + 문제풀이를 같이 연습 가능

취업 준비 단계까지 연결하기 좋음

형식: (프로그래머스, https://programmers.co.kr/)

입문자 기준 추천 순서는 보통 이렇게 많이 가요:

완전 처음 → 생활코딩 / Codecademy

Python 배우기 → Coursera / 인프런

웹개발 배우기 → freeCodeCamp

실력 키우기 → 프로그래머스

처음 시작한다면 언어는 Python을 가장 추천해요. 문법이 쉬워서 프로그래밍 사고방식을 배우기에 좋아요.
