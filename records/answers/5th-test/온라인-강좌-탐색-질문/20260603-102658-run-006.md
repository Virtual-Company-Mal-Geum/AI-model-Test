# 온라인 강좌-탐색-질문 / run 6

## Question

프로그래밍을 독학하려는 성인에게 적합한 온라인 강의 사이트를 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 독학하려는 성인이라면, **“실습 중심 + 커리큘럼 체계 + 꾸준히 이어가기 쉬운 구조”**가 중요합니다. 아래는 목적별로 추천하기 좋은 온라인 강의 사이트들이에요.

입문자에게 특히 좋은 사이트
1. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

완전 초보자에게 가장 유명한 인터랙티브 학습 플랫폼 중 하나

브라우저 안에서 바로 코드를 실행할 수 있어서 설치 스트레스가 적음

Python, JavaScript, 웹개발, 데이터 분석 등 기초 학습에 강함

“한 줄씩 따라 하며 배우는 방식”이라 독학 지속성이 높음

추천 대상:

코딩을 처음 시작하는 사람

실습형 학습을 좋아하는 사람

2. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

무료인데도 커리큘럼 퀄리티가 매우 높음

웹개발 중심으로 단계별 프로젝트 수행 가능

실제 포트폴리오를 만들면서 학습 가능

해외 개발자 커뮤니티에서 평판이 매우 좋음

추천 대상:

비용 부담 없이 시작하고 싶은 사람

웹개발 취업/포트폴리오를 목표로 하는 사람

3. Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학·기업 수준 강의를 온라인으로 제공

Stanford University, University of Michigan, Google 등의 강의 수강 가능

컴퓨터공학 기초를 체계적으로 배우기 좋음

수료증 과정도 다양함

추천 대상:

이론까지 제대로 배우고 싶은 사람

진지하게 커리어 전환을 고려하는 사람

4. Udemy (https://www.udemy.com/?utm_source=chatgpt.com)

강의 수가 매우 많고 할인도 자주 함

한국어 강의도 풍부

실무형 강의가 많아서 빠르게 결과물을 만들기 좋음

강사별 품질 차이가 있으므로 리뷰 확인이 중요

추천 대상:

특정 기술을 빠르게 배우고 싶은 사람

저렴하게 여러 강의를 듣고 싶은 사람

5. Inflearn(인프런) (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 기반 플랫폼 중 가장 인기 있는 편

웹개발, 앱개발, AI, 백엔드, CS 등 범위가 넓음

국내 취업 시장에 맞춘 강의가 많음

질의응답이 비교적 활발함

추천 대상:

한국어 강의를 선호하는 사람

국내 개발 취업을 목표로 하는 사람

6. edX (https://www.edx.org/?utm_source=chatgpt.com)

대학 수준 CS 강의가 강점

Harvard University, MIT 강의 제공

컴퓨터 구조, 알고리즘, CS 기초를 깊게 배우기 좋음

추천 대상:

“왜 이렇게 동작하는지”까지 이해하고 싶은 사람

컴퓨터공학 기반을 탄탄히 하고 싶은 사람
