# 온라인 강좌-탐색-질문 / run 4

## Question

프로그래밍 경험이 없는 사람이 입문용으로 듣기 좋은 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍이 처음이라면 “문법”보다도 재미있게 따라갈 수 있는 구성, 실습 환경, 한글 지원 여부가 중요해요. 아래 강의들은 입문자가 많이 시작하는 대표적인 온라인 강좌들이에요.

완전 처음이라면 추천

생활코딩 (무료)

한국어로 설명이 정말 쉬운 편이라 입문자 만족도가 높아요.

웹 개발(HTML/CSS/JS), Python, 데이터베이스 등 기초를 단계별로 배울 수 있어요.

“프로그래밍이 뭔지” 감 잡기 좋습니다.

(생활코딩, https://opentutorials.org (https://opentutorials.org/?utm_source=chatgpt.com))

Codecademy

설치 없이 브라우저에서 바로 코딩 가능

영어 기반이지만 인터랙티브해서 초보자도 따라가기 쉬워요.

Python, JavaScript 입문 코스가 특히 유명합니다.

(Codecademy, https://www.codecademy.com (https://www.codecademy.com/?utm_source=chatgpt.com))

CS50x by Harvard

세계적으로 유명한 컴퓨터공학 입문 강의

난이도는 살짝 있는 편이지만, “제대로 기초”를 배우고 싶다면 강력 추천

무료 + 한글 자막 지원

(CS50x, https://cs50.harvard.edu/x/ (https://cs50.harvard.edu/x/?utm_source=chatgpt.com))

Python 입문용 추천

점프 투 파이썬

한국에서 가장 유명한 Python 입문 교재/강좌 중 하나

문법 설명이 친절하고 예제가 많아요.

처음 프로그래밍 배우는 사람도 많이 시작합니다.

(점프 투 파이썬, https://wikidocs.net/book/1 (https://wikidocs.net/book/1?utm_source=chatgpt.com))

Coursera – Python for Everybody

진짜 초보자를 대상으로 만든 Python 강좌

천천히 설명해줘서 부담이 적어요.

대학 강의 스타일 좋아하면 추천

(Python for Everybody, https://www.coursera.org/specializations/python (https://www.coursera.org/specializations/python?utm_source=chatgpt.com))

게임처럼 배우고 싶다면

Scratch

블록을 조립하면서 코딩 개념을 익히는 방식

청소년이나 완전 비전공자 입문용으로 매우 좋음

(Scratch, https://scratch.mit.edu (https://scratch.mit.edu/?utm_source=chatgpt.com))

추천 순서를 하나만 정하면:

완전 처음 → 생활코딩 / Scratch

Python 배우고 싶음 → 점프 투 파이썬

제대로 CS 기초까지 → CS50x

영어 괜찮고 실습 선호 → Codecademy

원하면 다음 단계로:

“웹 개발 입문용”

“게임 만들기용”

“AI/데이터 분석 입문용”

“중학생/고등학생에게 좋은 강의”

같이 목적별로도 추천해줄게.
