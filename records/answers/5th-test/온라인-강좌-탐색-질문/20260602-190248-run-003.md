# 온라인 강좌-탐색-질문 / run 3

## Question

코딩을 처음 시작하는 성인이 듣기 좋은 온라인 강의 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

처음 코딩을 시작하는 성인이라면, “문법만 설명하는 강의”보다 실습 중심 + 커뮤니티가 활성화된 플랫폼이 훨씬 오래 갑니다. 아래 순서대로 보면 진입이 편해요.

파이썬 기초 → 작은 프로젝트

웹 개발 또는 데이터 분석 중 관심 분야 선택

깃허브·배포·협업 익히기

추천 강의 플랫폼과 특징은 아래와 같아요.

1. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 가장 많고 입문자 친화적

“파이썬 입문”, “웹 개발”, “자바스크립트”, “앱 개발”까지 이어서 듣기 좋음

질문 답변 문화가 좋아서 독학 난이도가 낮음

추천 대상:

완전 처음 시작하는 사람

한국어 설명이 편한 사람

(인프런, https://www.inflearn.com/)

2. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

무료로 시작 가능

코딩 원리를 정말 쉽게 설명함

HTML/CSS/JavaScript 입문은 특히 강력

추천 대상:

“코딩이 뭔지 감부터 잡고 싶은” 사람

부담 없이 체험해보고 싶은 사람

(생활코딩, https://opentutorials.org/)

3. 패스트캠퍼스 (https://fastcampus.co.kr/?utm_source=chatgpt.com)

커리어 중심 강의가 많음

데이터 분석, AI, 프론트엔드 같은 실무 트랙 강함

강의 길이는 긴 편이지만 체계적

추천 대상:

취업·이직 목표가 있는 사람

한 번에 깊게 배우고 싶은 사람

(패스트캠퍼스, https://fastcampus.co.kr/)

4. Udemy (https://www.udemy.com/?utm_source=chatgpt.com)

전 세계 최대급 온라인 강의 플랫폼

할인 때 가격이 매우 저렴

영어 강의가 많지만 퀄리티 높은 입문 강의가 많음

추천 대상:

영어 자막 괜찮은 사람

특정 기술을 빠르게 배우고 싶은 사람

(Udemy, https://www.udemy.com/)

5. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저 안에서 바로 코딩 가능

“읽기 → 바로 실행” 구조라 입문 난이도가 낮음

게임처럼 단계별 진행

추천 대상:

책보다 직접 눌러보며 배우는 스타일

설치 환경 세팅이 귀찮은 사람

(Codecademy, https://www.codecademy.com/)

시작 조합 추천

완전 초보: 생활코딩 → 인프런

취업 목표: 인프런 → 패스트캠퍼스

영어 가능: Codecademy → Udemy

처음 언어는 보통 파이썬(Python) 추천해요. 문법이 쉬워서 코딩 사고방식을 익히기에 가장 편한 편입니다.
