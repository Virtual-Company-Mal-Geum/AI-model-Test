# 온라인 강좌-탐색-질문 / run 7

## Question

코딩 기초를 배우고 싶은 성인에게 알맞은 온라인 강의 플랫폼 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

코딩을 처음 배우는 성인이라면 “설명이 쉬운지”, “실습이 많은지”, “한국어 지원 여부”, “목표(취업/취미/업무 자동화)”에 따라 플랫폼 선택이 달라집니다. 아래는 입문자에게 특히 많이 추천되는 온라인 강의 플랫폼들이에요.

한국어로 배우기 좋은 플랫폼
1. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 매우 많고 입문 강의가 풍부함

웹개발, Python, AI, 앱개발 등 분야 다양

실무 개발자 강의가 많아 취업 준비에도 유리

“따라 만들기” 스타일 강의가 많아 초보자 친화적

추천 대상:

완전 초보

한국어 설명 선호

취업/실무까지 이어서 배우고 싶은 사람

2. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

무료 중심

개념 설명이 매우 쉽고 친절함

HTML/CSS/JavaScript/Python 입문에 강함

코딩이 처음인 성인 입문자에게 특히 유명

추천 대상:

“코딩이 뭔지도 잘 모르겠다” 수준의 완전 입문자

부담 없이 시작하고 싶은 사람

3. 패스트캠퍼스 (https://fastcampus.co.kr/?utm_source=chatgpt.com)

실무 중심 강의가 많음

데이터분석, AI, 프론트엔드 등 커리큘럼 체계적

장기 로드맵형 강의 제공

추천 대상:

커리어 전환

직무 역량 강화

체계적인 커리큘럼 선호

해외 플랫폼 (영어 가능하면 매우 추천)
4. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코딩 가능

인터랙티브 실습이 강력함

“읽고 바로 실행” 구조라 초보자에게 좋음

추천 대상:

실습 위주 학습 선호

영어에 거부감이 없는 사람

5. Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학/기업 연계 강의 제공

Google, Stanford 같은 기관 강의 수강 가능

체계적인 커리큘럼과 수료증 제공

추천 대상:

깊이 있게 배우고 싶은 사람

이력서용 인증서도 고려하는 사람

6. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료

웹개발 입문에 매우 유명

프로젝트 기반 학습 제공

실습량이 많음

추천 대상:

비용 없이 제대로 배우고 싶은 사람

웹개발 입문

어떤 플랫폼을 고르면 좋을까?

완전 초보 + 한국어 → 생활코딩, 인프런

취업 목표 → 인프런, 패스트캠퍼스, Coursera

재미있게 실습 → Codecademy

무료 우선 → 생활코딩, freeCodeCamp

영어 괜찮고 체계적 학습 원함 → Coursera

마지막으로 요청한 형식으로 정리하면:

(인프런, https://www.inflearn.com/)

(생활코딩, https://opentutorials.org/)

(패스트캠퍼스, https://fastcampus.co.kr/)

(Codecademy, https://www.codecademy.com/)

(Coursera, https://www.coursera.org/)

(freeCodeCamp, https://www.freecodecamp.org/)
