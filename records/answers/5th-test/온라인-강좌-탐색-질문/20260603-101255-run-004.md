# 온라인 강좌-탐색-질문 / run 4

## Question

코딩 기초를 배우고 싶은 성인에게 알맞은 온라인 강의 플랫폼 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

코딩을 처음 배우는 성인이라면 “설명이 친절한지”, “실습이 많은지”, “한국어 지원 여부”, “취업/실무 연결성”을 기준으로 고르는 게 좋아요. 목적별로 추천하면 아래 플랫폼들이 특히 입문자에게 잘 맞습니다.

한국어로 쉽게 시작하고 싶다면

인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

국내 최대급 온라인 IT 강의 플랫폼이에요. 파이썬, 웹 개발, 앱 개발, 데이터 분석 등 입문 강의가 많고 한국어 설명이라 진입장벽이 낮아요.

특히 “비전공자용”, “왕초보용” 강의가 잘 정리되어 있습니다.

패스트캠퍼스 (https://fastcampus.co.kr/?utm_source=chatgpt.com)

실무 중심 강의가 많고 커리큘럼이 체계적이에요. 웹 개발이나 AI 쪽 관심 있으면 좋습니다. 다만 강의 분량이 긴 편이라 꾸준히 듣는 스타일에 더 잘 맞아요.

생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

완전 초보에게 정말 유명한 무료 플랫폼이에요. HTML/CSS/JavaScript 같은 웹 기초를 부담 없이 시작하기 좋습니다.

“코딩이 뭔지도 모르겠다” 단계라면 여기부터 추천해요.

해외 플랫폼이지만 퀄리티 좋은 곳

Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코딩하면서 배우는 방식이라 초보자에게 매우 직관적이에요. 영어 기반이지만 인터랙티브 학습이 강점입니다.

Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

Stanford University, University of Michigan 같은 대학 강의를 들을 수 있어요.

이론 + 프로젝트형 학습을 원하면 좋고, 일부 강의는 무료 청강 가능합니다.

freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료인데도 퀄리티가 높아요. 웹 개발 입문부터 프로젝트 제작까지 이어집니다. 영어가 아주 어렵지는 않은 편입니다.

어떤 플랫폼을 고르면 좋을까?

완전 처음 → 생활코딩, 인프런

재밌게 실습 위주 → Codecademy

취업/포트폴리오 목표 → 패스트캠퍼스, Coursera

무료로 오래 공부 → freeCodeCamp
