# 온라인 강좌-탐색-질문 / run 1

## Question

프로그래밍을 독학하려는 성인에게 적합한 온라인 강의 사이트를 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

독학으로 프로그래밍을 배우려면 “어떤 스타일로 공부하느냐”가 중요해요.

아래는 성인 학습자가 많이 활용하는 온라인 강의 사이트들을 입문 난이도, 실무성, 한국어 지원 여부 기준으로 골라봤어요.

한국어로 배우기 좋은 사이트
1. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국 개발자 강의가 매우 많음

웹 개발, 앱 개발, 데이터 분석, AI까지 폭넓음

실무 중심 강의가 많고 Q&A 활성화

처음 시작한다면:

Python

Java

웹 프론트엔드(HTML/CSS/JavaScript)

추천

형식:

(인프런, https://www.inflearn.com/)

2. 프로그래머스 (https://programmers.co.kr/?utm_source=chatgpt.com)

코딩 테스트와 실습 환경이 강점

개발자 취업 준비에도 많이 사용

강의 + 문제 풀이를 같이 하기 좋음

형식:

(프로그래머스, https://programmers.co.kr/)

3. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

완전 초보에게 특히 추천

무료

설명이 매우 친절하고 부담이 적음

웹 개발 입문으로 유명

형식:

(생활코딩, https://opentutorials.org/)

해외 사이트 (퀄리티 높은 무료/실무 강의 많음)
4. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

무료로 웹 개발 전체 커리큘럼 제공

직접 코드를 작성하며 학습

영어이지만 쉬운 편

포트폴리오 만들기 좋음

형식:

(freeCodeCamp, https://www.freecodecamp.org/)

5. Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학 수준 강의 제공

스탠퍼드, 미시간대 같은 대학 강의 수강 가능

컴퓨터공학 기초를 체계적으로 배우기 좋음

형식:

(Coursera, https://www.coursera.org/)

6. Udemy (https://www.udemy.com/?utm_source=chatgpt.com)

실무형 강의가 많음

할인할 때 가격이 매우 저렴

웹 개발, 앱 개발, AI 분야 강세

형식:

(Udemy, https://www.udemy.com/)

7. CS50 by Harvard (https://cs50.harvard.edu/?utm_source=chatgpt.com)

세계적으로 유명한 컴퓨터공학 입문 강의

프로그래밍 사고력을 키우기 좋음

난이도는 약간 있는 편

형식:

(CS50, https://cs50.harvard.edu/)

처음 시작하는 사람에게 추천 조합
완전 초보

생활코딩

인프런 Python 입문

간단한 개인 프로젝트

취업/실무 목표

인프런 or Udemy

프로그래머스 코딩 테스트

포트폴리오 제작

영어 괜찮고 깊게 배우고 싶다면

CS50

freeCodeCamp

Coursera

개인적으로는 성인 독학 기준으로:

“쉽게 시작” → 생활코딩

“실무 중심” → 인프런

“무료 + 꾸준한 실습” → freeCodeCamp
