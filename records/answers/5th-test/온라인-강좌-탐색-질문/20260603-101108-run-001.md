# 온라인 강좌-탐색-질문 / run 1

## Question

코딩 기초를 배우고 싶은 성인에게 알맞은 온라인 강의 플랫폼 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

코딩을 처음 배우는 성인이라면 “설명이 쉬운지”, “실습이 많은지”, “한국어 지원 여부”, “커뮤니티/질문 환경”을 기준으로 고르는 게 좋아요. 목적별로 추천하면 아래 플랫폼들이 특히 입문자에게 잘 맞습니다.

한국어로 쉽게 시작하고 싶다면

인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

국내 최대급 개발 강의 플랫폼이에요.

Python, 웹개발, 앱개발, 데이터분석 등 입문 강의가 많고 한국어 설명이 친절한 편입니다.

“파이썬 입문”, “웹 개발 기초” 같은 로드맵도 잘 되어 있어요.

패스트캠퍼스 (https://fastcampus.co.kr/?utm_source=chatgpt.com)

실무 중심 강의가 강점이에요.

초보용 부트캠프 스타일 강의도 많아서 체계적으로 배우기 좋습니다.

생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

완전 초보자에게 특히 추천돼요.

무료이고 설명이 정말 쉬운 편이라 “코딩이 처음”인 사람도 부담이 적습니다.

영어 괜찮고 체계적인 해외 플랫폼을 원한다면

Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코딩하면서 배우는 방식이라 입문 난도가 낮아요.

Python, JavaScript, SQL 시작용으로 유명합니다.

Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학·기업 강의를 들을 수 있어요.

예: Google, Stanford 같은 기관의 입문 코스.

이론과 체계를 함께 배우고 싶은 사람에게 추천합니다.

Udemy (https://www.udemy.com/?utm_source=chatgpt.com)

강의 수가 매우 많고 할인도 자주 합니다.

“Python bootcamp”, “웹개발 풀코스” 같은 강의가 인기예요.

무료 중심으로 연습 많이 하고 싶다면

freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

무료로 웹개발·Python·데이터분석을 실습 중심으로 배울 수 있어요.

프로젝트 기반이라 포트폴리오 만들기에도 좋습니다.

CS50 by Harvard (https://cs50.harvard.edu/?utm_source=chatgpt.com)

세계적으로 유명한 컴퓨터공학 입문 강의예요.

난도는 약간 있지만 “제대로 기초를 배우고 싶다”면 매우 좋습니다.

목적별 추천 한 줄 정리

완전 초보 + 한국어 → 생활코딩, 인프런

취업/실무 목표 → 패스트캠퍼스, Udemy

영어 가능 + 인터랙티브 학습 → Codecademy

무료 + 프로젝트 중심 → freeCodeCamp

컴공 기초까지 탄탄하게 → CS50
