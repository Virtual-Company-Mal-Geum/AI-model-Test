# 온라인 강좌-탐색-질문 / run 6

## Question

처음 코딩을 배우는 사람에게 적합한 프로그래밍 온라인 강의 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

처음 코딩을 배우는 사람이라면 "설명이 쉬운지", "실습이 많은지", "무료로 시작 가능한지"를 기준으로 고르는 것이 좋습니다.

1. 생활코딩

한국어로 제공되어 입문자에게 가장 친절한 편

HTML, CSS, JavaScript, Python 등 기초부터 배울 수 있음

짧은 강의 위주라 부담이 적음

완전 초보자에게 가장 추천 에듀로그 (https://nyangbanggu.tistory.com/entry/%EB%AC%B4%EB%A3%8C%EB%A1%9C-%EC%BD%94%EB%94%A9-%EB%8F%85%ED%95%99%ED%95%98%EB%8A%94-%EB%B0%A9%EB%B2%95-%E2%80%93-%EC%98%A8%EB%9D%BC%EC%9D%B8-%EA%B0%95%EC%9D%98-%EC%B6%94%EC%B2%9C-TOP-5?utm_source=chatgpt.com)

2. Codecademy

브라우저에서 직접 코드를 입력하며 학습

즉시 피드백을 받을 수 있어 이해가 빠름

Python, JavaScript, Java 등 다양한 언어 지원

"읽기보다 직접 해보며 배우는 사람"에게 추천 우주뉴스+1 (https://maya2025.co.kr/entry/%EA%B5%AC%EA%B8%80%EC%9D%B4-%EC%B6%94%EC%B2%9C%ED%95%98%EB%8A%94-%EB%AC%B4%EB%A3%8C-%EC%BD%94%EB%94%A9-%EA%B0%95%EC%9D%98-%EC%82%AC%EC%9D%B4%ED%8A%B8-5%EA%B3%B3-%E2%80%93-%ED%94%84%EB%A1%9C%EA%B7%B8%EB%9E%98%EB%B0%8D-%EB%8F%85%ED%95%99-%EA%B0%80%EC%9D%B4%EB%93%9C?utm_source=chatgpt.com)

3. freeCodeCamp

완전 무료

프로젝트를 만들면서 배우는 실습 중심 커리큘럼

수료 인증서도 제공

웹 개발을 목표로 하는 입문자에게 특히 좋음 freecodingcourses.com+1 (https://freecodingcourses.com/best-for/on-a-budget?utm_source=chatgpt.com)

4. CS50 (하버드 컴퓨터과학 입문)

프로그래밍뿐 아니라 컴퓨터과학의 기초 개념까지 배움

강의 품질이 매우 높음

다만 난이도는 위 3개보다 조금 높은 편

제대로 기초를 다지고 싶은 사람에게 추천 우주뉴스+1 (https://maya2025.co.kr/entry/%EA%B5%AC%EA%B8%80%EC%9D%B4-%EC%B6%94%EC%B2%9C%ED%95%98%EB%8A%94-%EB%AC%B4%EB%A3%8C-%EC%BD%94%EB%94%A9-%EA%B0%95%EC%9D%98-%EC%82%AC%EC%9D%B4%ED%8A%B8-5%EA%B3%B3-%E2%80%93-%ED%94%84%EB%A1%9C%EA%B7%B8%EB%9E%98%EB%B0%8D-%EB%8F%85%ED%95%99-%EA%B0%80%EC%9D%B4%EB%93%9C?utm_source=chatgpt.com)

5. The Odin Project

웹 개발자를 목표로 한다면 좋은 선택

프로젝트 기반 학습

실무에 가까운 경험을 쌓을 수 있음

초반에는 다소 어렵게 느껴질 수 있음 careercoders.academy+1 (https://www.careercoders.academy/blog/best-beginner-coding-platforms-in-daegu-south-korea?utm_source=chatgpt.com)
