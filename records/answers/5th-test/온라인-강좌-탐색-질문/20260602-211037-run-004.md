# 온라인 강좌-탐색-질문 / run 3

## Question

성인 초보자가 따라가기 쉬운 프로그래밍 강좌 사이트를 알려줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

처음 프로그래밍을 배우는 성인이라면 “문법 설명이 쉬운지”, “실습이 많은지”, “한국어 지원이 되는지”가 중요해요. 아래 사이트들은 초보자 기준으로 따라가기 편한 곳들이에요.

한국어로 배우기 좋은 곳

생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

진짜 입문자용으로 유명해요.

웹, Python, JavaScript 등 기초를 아주 천천히 설명해줘요.

영상 + 글 강의 조합이라 부담이 적어요.

인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 많고 무료 입문 강좌도 많아요.

“파이썬 입문”, “웹 개발 입문” 같은 초보용 코스가 잘 정리돼 있어요.

강사 스타일이 다양해서 본인에게 맞는 수업 찾기 쉬워요.

프로그래머스 (https://programmers.co.kr/?utm_source=chatgpt.com)

코딩 연습 문제와 입문 강의가 함께 있어요.

기초 문법 배우고 바로 문제 풀어볼 수 있어서 실력 늘기 좋아요.

해외 사이트지만 초보자에게 매우 좋은 곳

freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료.

단계별 실습 중심이라 “따라 하면서 배우기”에 최고 수준이에요.

웹 개발 입문에 특히 강해요.

Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저 안에서 바로 코딩 가능.

설치 없이 실습 가능해서 초보자가 편해요.

영어지만 인터페이스가 직관적이에요.

CS50 by Harvard (https://cs50.harvard.edu/?utm_source=chatgpt.com)

하버드 입문 컴퓨터공학 강의.

난이도는 조금 있지만 설명력이 뛰어나요.

“제대로 기초를 배우고 싶다”면 추천해요.

처음 시작한다면 보통은:

웹/앱 관심 → JavaScript

업무 자동화/AI 관심 → Python

으로 시작하는 경우가 많아요.

원하면 내가 “완전 비전공 성인 기준”으로

가장 쉬운 언어 추천

1개월 공부 루트

무료 강의 조합

까지 이어서 짜줄 수도 있어요.
