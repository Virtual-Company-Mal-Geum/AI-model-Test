# 온라인 강좌-탐색-질문 / run 1

## Question

처음 코딩을 배우는 사람에게 적합한 프로그래밍 온라인 강의 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

처음 코딩을 배우는 사람이라면, **“재미를 느끼면서 작은 성공 경험을 빨리 만드는 강의”**가 중요해요.

아래는 입문자에게 특히 많이 추천되는 온라인 강의 플랫폼과 특징이에요.

한국어로 배우기 좋은 강의
1. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 매우 많고 입문 강의가 풍부함

웹 개발, Python, AI, 앱 개발까지 단계별 학습 가능

무료 강의도 꽤 많음

“입문 → 실전” 흐름으로 이어가기 쉬움

추천 대상:

완전 처음 시작하는 사람

한국어 설명을 선호하는 사람

2. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

무료 중심

프로그래밍 개념을 정말 쉽게 설명함

HTML/CSS/JavaScript/Python 입문에 특히 강함

부담 없이 시작하기 좋음

추천 대상:

“코딩이 뭔지부터 알고 싶다”

천천히 이해하며 배우고 싶은 사람

3. 노마드코더 (https://nomadcoders.co/?utm_source=chatgpt.com)

직접 결과물을 만드는 스타일

유튜브 감성의 비교적 가벼운 진행

웹사이트/앱 만들기를 빠르게 체험 가능

추천 대상:

만들면서 배우는 걸 좋아하는 사람

지루한 이론보다 실습 중심을 원하는 사람

해외 플랫폼 (영어 가능하면 강력 추천)
4. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코딩 가능

설치 없이 시작 가능

인터랙티브 방식이라 초보자 친화적

추천 대상:

영어가 크게 부담되지 않는 사람

게임처럼 따라 하며 배우고 싶은 사람

5. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료

웹 개발 입문에 매우 유명

프로젝트 기반 학습

수료 인증도 제공

추천 대상:

무료로 깊게 배우고 싶은 사람

웹 개발에 관심 있는 사람

6. Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학 수준 강의 제공

Stanford University, University of Michigan 같은 학교 강의 수강 가능

체계적인 커리큘럼

추천 대상:

진지하게 CS 기초까지 배우고 싶은 사람

장기적으로 개발자를 목표로 하는 사람

처음 시작할 때 추천하는 언어
입문자 기준으로는 보통 이렇게 추천돼요:

Python → 가장 배우기 쉬운 편

JavaScript → 웹사이트를 직접 만들 수 있음

HTML/CSS → 웹페이지 디자인 기초

처음이라면:

HTML/CSS

JavaScript 또는 Python

순서가 가장 무난해요.

가장 무난한 추천 조합

완전 초보 + 한국어 → 생활코딩 → 인프런

실습 중심 → 노마드코더

영어 가능 + 인터랙티브 → Codecademy

무료 장기 학습 → freeCodeCamp

마지막으로 요청한 형식으로 정리하면:

(인프런, https://www.inflearn.com/)

(생활코딩, https://opentutorials.org/)

(노마드코더, https://nomadcoders.co/)

(Codecademy, https://www.codecademy.com/)

(freeCodeCamp, https://www.freecodecamp.org/)

(Coursera, https://www.coursera.org/)
