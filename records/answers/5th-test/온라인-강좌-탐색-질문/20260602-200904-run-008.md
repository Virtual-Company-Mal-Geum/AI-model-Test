# 온라인 강좌-탐색-질문 / run 2

## Question

프로그래밍 입문자가 기초부터 배울 수 있는 온라인 강좌를 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍 입문자라면 “문법만 배우는 강의”보다 직접 만들어보면서 배우는 강의가 훨씬 오래 기억에 남아요.

아래는 초보자가 시작하기 좋은 온라인 강좌들을 난이도와 스타일별로 정리한 추천입니다.

한국어로 배우기 좋은 강좌
1. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 매우 많고 입문자 친화적

Python, Java, 웹개발, 게임개발 등 분야 다양

실습 중심 강의가 많아서 처음 배우기 좋음

무료 강의도 꽤 많음

추천 입문 과정:

Python 기초

HTML/CSS/JavaScript 웹개발 입문

2. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

완전 초보자용으로 유명

설명이 친절하고 부담이 적음

웹개발 입문에 특히 강함

무료

추천 대상:

“코딩이 처음인데 뭐부터 해야 할지 모르겠다”는 사람

3. 패스트캠퍼스 (https://fastcampus.co.kr/?utm_source=chatgpt.com)

체계적인 커리큘럼

실무 느낌의 프로젝트 강의 많음

웹개발·데이터분석·AI 분야 강함

추천 대상:

기초 이후 취업/포트폴리오까지 생각하는 경우

해외 플랫폼 (영어 가능하면 강력 추천)
4. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코딩 가능

설치 없이 연습 가능

인터랙티브 방식이라 초보자가 배우기 쉬움

추천 언어:

Python

JavaScript

5. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료

웹개발 입문부터 프로젝트까지 가능

실습 중심

유명한 무료 플랫폼

추천 대상:

웹개발을 제대로 시작하고 싶은 사람

6. Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학 스타일 강의

스탠퍼드·미시간대 등 유명 대학 강좌 제공

이론 + 실습 균형 좋음

추천 과정:

Python for Everybody

처음 시작한다면 추천 순서

Python 기초 배우기

간단한 프로젝트 만들기

웹개발(HTML/CSS/JS) 또는 데이터분석 방향 선택

Git/GitHub 익히기

포트폴리오 만들기

개인적으로 가장 무난한 조합

완전 처음 → 생활코딩

실습 많이 → Codecademy

한국어 + 체계적 → 인프런

무료로 깊게 → freeCodeCamp

마지막으로 요청한 형식으로 정리하면:

(생활코딩, https://opentutorials.org/)

(패스트캠퍼스, https://fastcampus.co.kr/)

(Codecademy, https://www.codecademy.com/)

(freeCodeCamp, https://www.freecodecamp.org/)
