# 온라인 강좌-탐색-질문 / run 8

## Question

프로그래밍 경험이 없는 사람이 입문용으로 듣기 좋은 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍 경험이 전혀 없다면, 처음에는 “재미를 느끼면서 작은 결과물을 빨리 만드는 강의”가 가장 중요해요. 아래 강좌들은 초보자들이 많이 추천하는 입문용 온라인 강의들입니다.

생활코딩 (무료, 한국어)

완전 초보자에게 가장 많이 추천되는 입문 강의

HTML, CSS, JavaScript, Python 등 기초를 쉽게 설명

“왜 배우는지”를 이해하기 좋음

(생활코딩, https://opentutorials.org (https://opentutorials.org/?utm_source=chatgpt.com))

인프런

한국어 강의가 많고, 입문 강좌 선택 폭이 넓음

“파이썬 입문”, “웹 개발 입문” 같은 강의가 특히 인기

실습 중심 강의가 많음

(인프런, https://www.inflearn.com (https://www.inflearn.com/?utm_source=chatgpt.com))

코드잇

인터랙티브 실습 방식이라 초보자가 따라가기 쉬움

Python, 데이터 분석, 웹 개발 입문 강좌가 체계적

숙제·퀴즈 형태라 독학 유지에 도움

(코드잇, https://www.codeit.kr (https://www.codeit.kr/?utm_source=chatgpt.com))

Udemy

전 세계적으로 유명한 온라인 강의 플랫폼

“Python for Beginners” 같은 강의가 매우 많음

할인할 때 저렴하게 구매 가능

(Udemy, https://www.udemy.com (https://www.udemy.com/?utm_source=chatgpt.com))

CS50 (하버드대학교, 무료)

세계적으로 유명한 컴퓨터공학 입문 강의

난이도는 약간 있지만 설명이 뛰어남

프로그래밍을 제대로 이해하고 싶은 사람에게 추천

(CS50, https://cs50.harvard.edu/x/ (https://cs50.harvard.edu/x/?utm_source=chatgpt.com))

Codecademy

브라우저에서 바로 코딩 가능

설치 없이 실습 가능해서 입문 장벽이 낮음

영어가 괜찮다면 매우 추천

(Codecademy, https://www.codecademy.com (https://www.codecademy.com/?utm_source=chatgpt.com))

처음 시작한다면 추천 순서는 보통:

한국어 선호 → 생활코딩 → 인프런/코드잇

영어 가능 → Codecademy → CS50

그리고 입문 언어는 보통 Python부터 시작하는 게 가장 쉬운 편입니다.
