# 온라인 강좌-탐색-질문 / run 1

## Question

프로그래밍 경험이 없는 사람이 입문용으로 듣기 좋은 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 시작하는 사람이라면, “문법”보다도 재미 있게 따라갈 수 있는지, 실습이 많은지, 한국어 지원이 되는지가 중요해요. 아래 강좌들은 완전 입문자 기준으로 많이 추천되는 곳들이에요.

생활코딩

한국어로 설명이 정말 쉬운 편이라 입문자에게 가장 많이 추천돼요.

HTML, CSS, JavaScript, Python 같은 기초를 부담 없이 시작할 수 있어요.

무료 강의가 많고, “프로그래밍이 뭔지” 감 잡기에 좋아요.

(생활코딩, https://opentutorials.org/ (https://opentutorials.org/?utm_source=chatgpt.com))

인프런

한국어 강의 플랫폼이라 접근성이 좋아요.

“파이썬 입문”, “코딩 처음 시작하기” 같은 초보자 강의가 다양해요.

무료 강의도 꽤 많고, 강사 스타일 선택 폭이 넓어요.

(인프런, https://www.inflearn.com/ (https://www.inflearn.com/?utm_source=chatgpt.com))

Codecademy

영어 기반이지만, 직접 코드를 입력하면서 배우는 방식이라 초보자에게 매우 직관적이에요.

설치 없이 브라우저에서 바로 실습 가능해요.

특히 Python 입문 코스가 유명해요.

(Codecademy, https://www.codecademy.com/ (https://www.codecademy.com/?utm_source=chatgpt.com))

CS50 (하버드대)

세계적으로 유명한 컴퓨터공학 입문 강의예요.

난이도는 약간 있는 편이지만, 프로그래밍 사고방식을 정말 잘 알려줘요.

한글 자막 지원 영상도 많아요.

(CS50, https://cs50.harvard.edu/x/ (https://cs50.harvard.edu/x/?utm_source=chatgpt.com))

노마드 코더

“작은 프로젝트를 직접 만들면서 배우는 스타일”이라 지루하지 않아요.

웹 개발 입문자들이 많이 시작하는 곳이에요.

강의 분위기가 편하고 실습 중심이에요.

(노마드 코더, https://nomadcoders.co/ (https://nomadcoders.co/?utm_source=chatgpt.com))

처음이라면 추천 순서는 보통 이렇게 많이 가요:

정말 아무것도 모름 → 생활코딩

한국어 + 체계적인 강의 원함 → 인프런

직접 코딩하면서 배우고 싶음 → Codecademy

제대로 CS 기초까지 배우고 싶음 → CS50

결과물을 만들며 배우고 싶음 → 노마드 코더
