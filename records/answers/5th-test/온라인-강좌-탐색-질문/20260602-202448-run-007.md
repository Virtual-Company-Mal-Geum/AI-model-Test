# 온라인 강좌-탐색-질문 / run 7

## Question

처음 코딩을 배우는 사람에게 적합한 프로그래밍 온라인 강의 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

처음 코딩을 배우는 사람이라면, “문법만 설명하는 강의”보다 직접 만들면서 배우는 강의가 훨씬 오래 기억에 남아요.

아래는 입문자가 많이 시작하는 온라인 강의 플랫폼과 특징이에요.

한국어 강의 추천
1. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 많고 입문자 친화적

Python, 웹 개발, 앱 개발, AI까지 분야 다양

무료 입문 강의도 꽤 많음

실습 중심 강의가 많아서 처음 배우기 좋음

추천 대상:

“완전 처음인데 한국어로 차근차근 배우고 싶다”

2. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

무료로 배우기 좋은 대표 사이트

프로그래밍 개념 설명을 정말 쉽게 함

HTML/CSS/JavaScript, Python 입문에 강함

추천 대상:

“코딩이 뭔지도 잘 모르는데 부담 없이 시작하고 싶다”

3. 노마드코더 (https://nomadcoders.co/?utm_source=chatgpt.com)

직접 프로젝트를 만들면서 배우는 스타일

유튜브/클론코딩 기반 강의가 유명

웹 개발 입문자에게 특히 인기

추천 대상:

“재밌게 결과물을 만들면서 배우고 싶다”

해외 강의 추천
4. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코딩 가능

설치 없이 시작 가능해서 편함

인터랙티브 방식이라 초보자 만족도가 높음

추천 대상:

“설치 과정 없이 바로 연습하고 싶다”

5. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료

웹 개발 입문 코스로 유명

단계별 프로젝트가 잘 구성됨

추천 대상:

“무료로 제대로 배우고 싶다”

6. Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학 수준 강의 제공

Stanford University, University of Michigan 같은 대학 강의 수강 가능

이론 + 실습 균형이 좋음

추천 대상:

“체계적으로 공부하고 싶다”

입문자에게 추천하는 시작 언어

Python: 가장 배우기 쉬운 편, AI/자동화에도 활용 가능

JavaScript: 웹사이트 만들기에 좋음

HTML/CSS: 웹페이지 디자인 입문용

처음이라면 보통:

Python → 간단한 프로젝트 → 웹/앱/AI 중 관심 분야 선택

이 흐름이 가장 무난해요.
