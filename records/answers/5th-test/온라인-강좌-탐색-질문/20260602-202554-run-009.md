# 온라인 강좌-탐색-질문 / run 9

## Question

처음 코딩을 배우는 사람에게 적합한 프로그래밍 온라인 강의 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

처음 코딩을 배우는 사람이라면 무료 강의로 기초를 익히고, 흥미가 생기면 체계적인 유료 강의로 넘어가는 것을 추천합니다.

1. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

국내 코딩 입문자들에게 가장 많이 추천되는 무료 강의

HTML, CSS, JavaScript, Python 등 기초부터 설명

비전공자도 이해하기 쉬운 강의 스타일

무료

2. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 직접 코드를 작성하며 배우는 방식

영어로 제공되지만 초보자 친화적

Python, JavaScript, 웹 개발 입문 과정이 특히 좋음

3. Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

세계 대학 및 기업의 온라인 강의 제공

입문용 프로그래밍, Python, 컴퓨터 과학 기초 강의 다수

일부 강의는 무료 청강 가능 My 스토리 님의 블로그 (https://dnflstmxhfl.tistory.com/entry/AI-%EC%99%95%EC%B4%88%EB%B3%B4%EA%B0%80-%EB%AC%B4%EB%A3%8C%EB%A1%9C-%EB%B0%B0%EC%9A%B0%EB%8A%94-%EC%8B%A4%EC%A0%84-%EA%B0%95%EC%9D%98-%EC%B6%94%EC%B2%9C?utm_source=chatgpt.com)

4. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 매우 많음

"파이썬 입문", "웹 개발 입문" 같은 초급 강의가 풍부

무료 강의와 유료 강의 모두 제공

5. CS50 (Harvard) (https://cs50.harvard.edu/x?utm_source=chatgpt.com)

하버드대학교의 유명한 컴퓨터 과학 입문 강의

프로그래밍뿐 아니라 컴퓨터가 어떻게 동작하는지 이해 가능

무료

추천 순서

생활코딩

Python 기초 (생활코딩 또는 Codecademy)

인프런 입문 강의

CS50
