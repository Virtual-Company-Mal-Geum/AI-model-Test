# 온라인 강좌-탐색-질문 / run 7

## Question

초보자가 프로그래밍 개념부터 차근차근 배울 수 있는 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 배우는 사람이라면 “언어 문법”보다도 컴퓨터 사고방식, 변수·조건문·반복문 같은 기본 개념을 잘 설명해주는 강좌가 중요해요. 아래는 입문자 기준으로 특히 배우기 쉬운 강좌들입니다.

한국어로 배우기 좋은 강좌
1. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

완전 초보자용으로 가장 유명한 무료 강의 중 하나

프로그래밍 개념 → 웹 → Python → 데이터베이스까지 단계적으로 가능

설명이 쉽고 부담이 적음

“코딩이 뭔지”부터 시작하고 싶다면 가장 추천

(생활코딩, https://opentutorials.org/)

2. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

국내 개발 강의 플랫폼

무료 입문 강좌가 많고, 영상 퀄리티가 좋은 편

Python, Java, 웹개발, 앱개발 등 다양함

입문 추천 검색:

“파이썬 입문”

“웹 개발 왕초보”

(인프런, https://www.inflearn.com/)

3. 노마드 코더 (https://nomadcoders.co/?utm_source=chatgpt.com)

직접 무언가 만들어보는 스타일

웹사이트·앱을 따라 만들며 배우기 좋음

초반엔 약간 빠를 수 있지만 재미있게 배울 수 있음

(노마드 코더, https://nomadcoders.co/)

해외 사이트 (기초 개념 이해에 강함)
4. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코딩 가능

“한 줄 배우고 바로 실행” 방식이라 초보자에게 매우 좋음

영어지만 인터랙티브해서 이해하기 쉬움

(Codecademy, https://www.codecademy.com/)

5. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료

웹개발 입문 과정이 체계적

실습 중심이라 포트폴리오 만들기 좋음

(freeCodeCamp, https://www.freecodecamp.org/)

6. CS50 by Harvard (https://cs50.harvard.edu/x?utm_source=chatgpt.com)

세계적으로 유명한 컴퓨터공학 입문 강의

단순 문법이 아니라 “컴퓨터가 어떻게 동작하는지”까지 알려줌

난이도는 조금 있는 편이지만 정말 탄탄함

(CS50, https://cs50.harvard.edu/x/)

처음 시작할 때 추천 순서

생활코딩으로 프로그래밍 감 잡기

Python 기초 배우기

작은 프로젝트 따라 만들기

웹/앱/게임 등 관심 분야 선택하기

처음 언어는 보통 Python을 가장 많이 추천해요. 문법이 비교적 쉬워서 개념 이해에 집중하기 좋습니다.
