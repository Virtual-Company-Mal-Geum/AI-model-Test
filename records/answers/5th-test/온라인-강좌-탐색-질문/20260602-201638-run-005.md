# 온라인 강좌-탐색-질문 / run 5

## Question

비전공 성인이 프로그래밍을 배우기 좋은 온라인 교육 사이트 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

비전공 성인이 처음 프로그래밍을 배우기에는

“설명이 쉬운가”

“실습이 많은가”

“한국어 지원이 되는가”

“포기하지 않게 커리큘럼이 잘 짜여 있는가”

가 정말 중요해요.

아래는 입문자 기준으로 특히 평가가 좋은 온라인 교육 사이트들입니다.

한국어로 배우기 좋은 사이트
1. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국에서 가장 많이 쓰는 개발 강의 플랫폼 중 하나

파이썬, 웹개발, 앱개발, AI까지 전부 있음

“입문자용 로드맵”이 잘 되어 있어서 방향 잡기 쉬움

실무 개발자 강의가 많아 현실적인 공부 가능

추천 대상:

완전 초보

한국어 강의를 선호하는 사람

취업/이직까지 생각하는 사람

2. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

프로그래밍 입문자에게 거의 교과서 같은 사이트

무료

개념 설명이 매우 쉽고 부담이 적음

HTML/CSS/JavaScript 입문이 특히 유명

추천 대상:

“코딩이 뭔지도 잘 모르겠다” 수준의 완전 초보

부담 없이 시작하고 싶은 사람

3. 프로그래머스 (https://programmers.co.kr/?utm_source=chatgpt.com)

코딩 테스트 플랫폼으로 유명하지만 강의도 좋음

실습 중심

취업 준비와 연결하기 좋음

추천 대상:

어느 정도 기초 후 문제풀이까지 하고 싶은 사람

개발자 취업 관심 있는 사람

해외 사이트 (퀄리티 매우 높음)
4. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

인터랙티브 방식이라 직접 코드를 치면서 배움

입문자 친화도가 매우 높음

영어지만 쉬운 편

추천 대상:

“읽기보다 직접 해보는 스타일”

게임처럼 배우고 싶은 사람

5. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료

웹개발/파이썬/데이터분석 과정 훌륭

프로젝트 기반 학습 가능

해외에서 입문 추천 1순위로 자주 언급됨

추천 대상:

돈 많이 쓰고 싶지 않은 사람

프로젝트 중심으로 배우고 싶은 사람

6. Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학 수준 강의를 온라인으로 제공

스탠퍼드, 미시간대 같은 학교 강의 수강 가능

체계적이고 깊이 있음

추천 대상:

제대로 기초 CS까지 배우고 싶은 사람

장기적으로 전문성 키우고 싶은 사람

어떤 언어부터 시작하면 좋은가?
대부분의 비전공 성인에게는:

파이썬(Python)

문법 쉬움

AI/자동화/데이터분석까지 연결 가능

또는

웹 개발(HTML/CSS/JavaScript)

결과물이 눈에 보여서 재미 붙이기 쉬움

포트폴리오 만들기 좋음

을 추천해요.

가장 추천하는 조합 (초보 기준)

완전 처음 → 생활코딩

기초 익힘 → 인프런

실습/취업 준비 → 프로그래머스

영어 가능하면 → freeCodeCamp 병행

마지막에 요청한 형식으로 정리하면:

(인프런, https://www.inflearn.com/)

(생활코딩, https://opentutorials.org/)

(프로그래머스, https://programmers.co.kr/)

(Codecademy, https://www.codecademy.com/)

(freeCodeCamp, https://www.freecodecamp.org/)

(Coursera, https://www.coursera.org/)
