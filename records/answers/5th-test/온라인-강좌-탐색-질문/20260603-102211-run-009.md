# 온라인 강좌-탐색-질문 / run 9

## Question

초보자가 프로그래밍 개념부터 차근차근 배울 수 있는 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 배우는 사람이라면, “문법”보다도 컴퓨터가 어떻게 생각하는지를 이해할 수 있는 강좌부터 시작하는 게 좋아요. 아래 순서대로 보면 부담이 적습니다.

블록 코딩/기초 사고력

파이썬 같은 쉬운 언어 입문

작은 프로젝트 만들기

자료구조·알고리즘 기초

1. 엔트리(완전 입문용)

블록을 조립하면서 프로그래밍 사고방식을 익힐 수 있어서 초등~중학생 입문자에게 특히 좋아요.

웹 개발, Python, JavaScript 등을 차근차근 배울 수 있습니다.
