# 온라인 강좌-탐색-질문 / run 4

## Question

프로그래밍 입문자가 기초부터 배울 수 있는 온라인 강좌를 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍 입문자라면 “언어 하나만 배우기”보다 기초 개념 → 간단한 프로젝트 → 실습 반복 흐름으로 배우는 게 가장 오래 갑니다.

특히 처음에는 Python 기반 강의가 진입장벽이 낮아서 추천돼요.

가장 추천하는 온라인 강좌
1. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

인터랙티브 방식이라 설치 없이 바로 코딩 가능

완전 초보에게 특히 쉬움

Python, 웹개발, 데이터 분석 입문 코스가 강점

“손으로 따라치면서 배우는 스타일” 좋아하면 추천

2. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

한국어 무료 강의의 대표격

프로그래밍 개념을 정말 쉽게 설명함

웹개발(HTML/CSS/JavaScript) 입문에 최고 수준

“왜 배우는지”를 이해시키는 스타일

3. CS50 by Harvard (https://cs50.harvard.edu/x/?utm_source=chatgpt.com)

세계적으로 유명한 컴퓨터공학 입문 강좌

난이도는 조금 있지만 기초 체력을 탄탄하게 만들어줌

단순 문법보다 사고방식과 문제 해결 능력을 키워줌

영어 강의지만 자막 지원

4. Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학 강의를 온라인으로 들을 수 있음

“Python for Everybody” 같은 입문 강의가 유명

체계적으로 배우고 싶은 사람에게 추천

수료증 과정도 많음

5. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료

웹개발 중심 실습형 플랫폼

프로젝트를 직접 만들면서 배움

포트폴리오 만들기 좋음

6. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의 다양함

실무형 강의가 많고 초보용 강좌도 많음

웹개발, 앱개발, 게임개발 등 분야별 선택 가능

입문자에게 추천하는 학습 순서

Python 또는 웹개발(HTML/CSS/JS) 중 하나 선택

문법 30%

작은 프로젝트 70%

계산기

간단한 게임

할 일 관리 앱

개인 웹페이지

모르는 건 검색하면서 반복

빠르게 시작하려면

“코딩 자체가 처음” → 생활코딩 + Codecademy

“제대로 기초 다지고 싶음” → CS50

“취업/실무 목표” → freeCodeCamp + 인프런

“대학 강의 스타일 선호” → Coursera

요청한 형식으로 정리하면:

(Codecademy, https://www.codecademy.com/)

(생활코딩, https://opentutorials.org/)

(CS50, https://cs50.harvard.edu/x/)

(Coursera, https://www.coursera.org/)

(freeCodeCamp, https://www.freecodecamp.org/)

(인프런, https://www.inflearn.com/)
