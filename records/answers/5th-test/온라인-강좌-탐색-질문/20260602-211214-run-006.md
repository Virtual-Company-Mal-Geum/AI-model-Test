# 온라인 강좌-탐색-질문 / run 5

## Question

성인 초보자가 따라가기 쉬운 프로그래밍 강좌 사이트를 알려줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

성인 초보자가 시작하기 쉬운 프로그래밍 강좌 사이트들을 “입문 난이도”, “한글 지원”, “실습 중심” 기준으로 골라봤어.

Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

가장 유명한 입문용 사이트 중 하나

설치 없이 브라우저에서 바로 코딩 가능

Python, JavaScript, 웹개발 입문이 특히 쉬움

영어 기반이지만 인터랙티브해서 따라가기 편함

생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

한국 초보자에게 가장 많이 추천되는 무료 강의

설명이 정말 천천히 진행됨

웹개발, Python, 데이터베이스 입문 강의가 좋음

“코딩이 뭔지도 모르겠다” 수준에도 적합

프로그래머스 (https://programmers.co.kr/?utm_source=chatgpt.com)

한국어 강의 + 실습 환경 제공

기초 문법부터 코딩테스트까지 연결 가능

초보용 Python/JavaScript 강좌가 깔끔함

Inflearn (인프런) (https://www.inflearn.com/?utm_source=chatgpt.com)

국내 최대 개발 강의 플랫폼 중 하나

무료 입문 강좌가 많음

원하는 분야(웹, 앱, AI 등) 찾기 쉬움

freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

무료로 체계적인 커리큘럼 제공

웹개발 입문에 특히 강함

실습 중심이라 “보는 공부”보다 직접 만드는 느낌이 큼

CS50 by Harvard (https://cs50.harvard.edu/?utm_source=chatgpt.com)

하버드의 유명한 컴퓨터공학 입문 강의

난이도는 조금 있지만 설명력이 뛰어남

“제대로 기초를 배우고 싶다”면 추천

마지막에 요청한 형식으로 다시 정리하면:

(Codecademy, https://www.codecademy.com/)

(생활코딩, https://opentutorials.org/)

(프로그래머스, https://programmers.co.kr/)

(인프런, https://www.inflearn.com/)

(freeCodeCamp, https://www.freecodecamp.org/)

(CS50, https://cs50.harvard.edu/)
