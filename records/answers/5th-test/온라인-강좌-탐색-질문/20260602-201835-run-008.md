# 온라인 강좌-탐색-질문 / run 8

## Question

비전공 성인이 프로그래밍을 배우기 좋은 온라인 교육 사이트 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

비전공 성인이 처음 프로그래밍을 배우기엔 “설명이 쉬운지”, “실습이 많은지”, “한국어 지원이 되는지”, “포트폴리오까지 연결되는지”가 중요해요. 아래는 입문자 기준으로 특히 많이 추천되는 온라인 교육 사이트들이에요.

한국어 중심으로 배우기 좋은 곳
1. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 매우 많고, 비전공자 입문 강의가 강함

웹 개발, Python, AI, 앱 개발 등 분야별 로드맵이 잘 되어 있음

실무 개발자 강의가 많아 취업 준비까지 이어가기 좋음

“무료 강의 → 유료 심화” 흐름으로 시작하기 편함

추천 대상:

한국어로 차근차근 배우고 싶은 사람

개발 진로를 탐색 중인 사람

2. 프로그래머스 (https://programmers.co.kr/?utm_source=chatgpt.com)

코딩 테스트와 실습 환경이 강점

입문 강의 + 실습 문제를 함께 진행 가능

취업 연계 콘텐츠도 많음

추천 대상:

실습 위주로 배우고 싶은 사람

나중에 개발자 취업도 고려하는 사람

3. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

완전 초보자용 설명으로 유명

무료

웹 개발, HTML/CSS/JavaScript, Python 입문에 특히 좋음

“왜 배우는지”까지 쉽게 설명해줌

추천 대상:

프로그래밍이 처음인 사람

무료로 부담 없이 시작하고 싶은 사람

해외 플랫폼 (퀄리티 높은 입문 강의 많음)
4. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코딩 가능

인터랙티브 실습이 강력함

Python 입문 코스로 특히 유명

추천 대상:

영어에 거부감이 적은 사람

직접 따라 치며 배우는 스타일

5. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료

웹 개발 커리큘럼이 체계적

프로젝트 중심 학습 가능

수료 인증도 제공

추천 대상:

비용 없이 깊게 배우고 싶은 사람

웹 개발 포트폴리오를 만들고 싶은 사람

6. Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학/기업 강의를 온라인으로 제공

Google, Stanford University 등의 강의 수강 가능

체계적인 커리큘럼이 장점

추천 대상:

이론과 체계를 함께 배우고 싶은 사람

자격증/수료증도 고려하는 사람

가장 추천하는 시작 조합
비전공 성인 기준으로는 보통 이렇게 시작하면 실패 확률이 낮아요:

생활코딩 → 프로그래밍 감 잡기

인프런 Python 또는 웹개발 입문 강의

프로그래머스에서 실습 문제 풀기

freeCodeCamp로 프로젝트 만들기

요청한 형식으로 URL 정리

(인프런, https://www.inflearn.com/)

(프로그래머스, https://programmers.co.kr/)

(생활코딩, https://opentutorials.org/)

(Codecademy, https://www.codecademy.com/)

(freeCodeCamp, https://www.freecodecamp.org/)

(Coursera, https://www.coursera.org/)
