# 온라인 강좌-탐색-질문 / run 10

## Question

처음 코딩을 배우는 사람에게 적합한 프로그래밍 온라인 강의 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

처음 코딩을 배우는 사람이라면 "재미있게 시작 → 작은 프로젝트 만들기 → 기초 문법 익히기" 순서로 배우는 것이 가장 좋습니다. 특히 처음에는 Python(파이썬)이나 웹 개발(HTML/CSS/JavaScript) 입문 강의를 추천합니다.

1. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

국내에서 가장 인기 있는 개발 학습 플랫폼 중 하나

한국어 강의가 많고 초보자용 무료 강의도 풍부

파이썬, 웹 개발, 앱 개발, AI 등 다양한 분야 제공

입문자에게 특히 좋은 무료 강의가 많음 구남이의 투자로 FIRE하기+1 (https://bh3kks.tistory.com/entry/%EC%9D%B8%ED%94%84%EB%9F%B0-vs-%ED%94%84%EB%A1%9C%EA%B7%B8%EB%9E%98%EB%A8%B8%EC%8A%A4-%EC%96%B4%EB%96%A4-%EC%BD%94%EB%94%A9-%EA%B0%95%EC%9D%98%EA%B0%80-%EB%8D%94-%EC%A2%8B%EC%9D%8C-%EB%B9%84%EA%B5%90%EB%B6%84%EC%84%9D%ED%95%98%EA%B8%B0?utm_source=chatgpt.com)

2. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

완전 초보자를 위한 무료 프로그래밍 교육 사이트

프로그래밍 개념을 매우 쉽게 설명

HTML, CSS, JavaScript, Python 등 입문 과정이 유명

"코딩이 무엇인지"부터 배우기에 적합

취업 준비 단계까지 이어서 공부하기 좋음 구남이의 투자로 FIRE하기 (https://bh3kks.tistory.com/entry/%EC%9D%B8%ED%94%84%EB%9F%B0-vs-%ED%94%84%EB%A1%9C%EA%B7%B8%EB%9E%98%EB%A8%B8%EC%8A%A4-%EC%96%B4%EB%96%A4-%EC%BD%94%EB%94%A9-%EA%B0%95%EC%9D%98%EA%B0%80-%EB%8D%94-%EC%A2%8B%EC%9D%8C-%EB%B9%84%EA%B5%90%EB%B6%84%EC%84%9D%ED%95%98%EA%B8%B0?utm_source=chatgpt.com)

4. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

"읽기만 하는 강의"보다 직접 실습하는 것을 좋아하는 사람에게 추천 리핏해빗 님의 블로그 (https://inform-insight.com/12?utm_source=chatgpt.com)
