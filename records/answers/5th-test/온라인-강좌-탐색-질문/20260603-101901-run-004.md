# 온라인 강좌-탐색-질문 / run 4

## Question

초보자가 프로그래밍 개념부터 차근차근 배울 수 있는 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 개념부터 차근차근 배우고 싶은 완전 초보자라면, 언어 문법부터 시작하기보다 컴퓨터 사고방식 → 기본 문법 → 작은 프로젝트 순서로 배우는 것이 좋습니다.

1. 생활코딩

한국어로 설명이 매우 쉽고 친절함

"코딩이 무엇인가?"부터 시작

HTML, CSS, JavaScript, Python, 데이터베이스 등 단계별 학습 가능

비전공자와 학생에게 특히 추천 에듀로그+1 (https://nyangbanggu.tistory.com/entry/%EB%AC%B4%EB%A3%8C%EB%A1%9C-%EC%BD%94%EB%94%A9-%EB%8F%85%ED%95%99%ED%95%98%EB%8A%94-%EB%B0%A9%EB%B2%95-%E2%80%93-%EC%98%A8%EB%9D%BC%EC%9D%B8-%EA%B0%95%EC%9D%98-%EC%B6%94%EC%B2%9C-TOP-5?utm_source=chatgpt.com)

(생활코딩, https://opentutorials.org/)

2. CS50

하버드의 대표적인 컴퓨터 과학 입문 강의

프로그래밍뿐 아니라 컴퓨터가 어떻게 동작하는지 배움

알고리즘, 자료구조, 문제 해결 능력을 함께 익힘

난이도는 약간 있지만 가장 탄탄한 기초를 만들어 줌 Eduhub21+1 (https://eduhub21.com/en/top-10-free-programming-courses-for-beginners/?utm_source=chatgpt.com)

URL

(CS50, https://cs50.harvard.edu/x/)

3. freeCodeCamp

실습과 프로젝트 중심

웹 개발을 배우고 싶다면 매우 좋은 선택

무료이며 단계별 커리큘럼 제공 Eduhub21+2우주뉴스+2 (https://eduhub21.com/en/top-10-free-programming-courses-for-beginners/?utm_source=chatgpt.com)

URL

(freeCodeCamp, https://www.freecodecamp.org/)

4. Codecademy

코드를 직접 입력하면서 배우는 인터랙티브 방식

즉시 피드백을 받을 수 있어 초보자가 따라가기 쉬움

Python, JavaScript 등 입문 과정 제공 위키백과+1 (https://en.wikipedia.org/wiki/Codecademy?utm_source=chatgpt.com)

URL

(Codecademy, https://www.codecademy.com/)

웹 개발 입문자에게 매우 유용

HTML, CSS, JavaScript, Python 등을 브라우저에서 바로 실습 가능
