# 온라인 강좌-탐색-질문 / run 2

## Question

성인 초보자가 따라가기 쉬운 프로그래밍 강좌 사이트를 알려줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍이 처음인 성인이라면 “설명이 쉬운지”, “실습이 많은지”, “한국어 지원이 되는지”가 중요해요. 아래 사이트들은 초보자가 시작하기 좋은 곳들입니다.

한국어로 배우기 좋은 곳

생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

웹 개발, Python, 데이터베이스 등을 아주 쉽게 설명해줘서 입문자에게 가장 많이 추천돼요.

인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 많고, 무료 입문 강좌도 많아요. Python, Java, 웹 개발 입문에 좋습니다.

노마드 코더 (https://nomadcoders.co/?utm_source=chatgpt.com)

“직접 만들어보는 방식”이라 지루하지 않고 실습 중심이에요.

패스트캠퍼스 (https://fastcampus.co.kr/?utm_source=chatgpt.com)

비교적 체계적인 커리큘럼이 많고, 직무 연결형 강의가 강점입니다.

영어지만 초보자에게 쉬운 곳

Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코딩하면서 배울 수 있어서 완전 초보자에게 좋아요.

freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

무료이고 실습 중심이에요. 웹 개발 입문자들에게 특히 유명합니다.

CS50 (하버드) (https://cs50.harvard.edu/?utm_source=chatgpt.com)

난이도는 조금 있지만 설명이 뛰어나고 재미있어요. 기초 컴퓨터 사고력을 키우기 좋습니다.

Khan Academy Computer Programming (https://www.khanacademy.org/computing/computer-programming?utm_source=chatgpt.com)

아주 기초부터 천천히 설명해줘서 부담이 적어요.

처음 시작한다면 추천 순서는 보통 이렇게 많이 해요:

생활코딩 또는 Codecademy로 기초 감 잡기

Python 또는 웹 개발 하나 선택

인프런/노마드 코더로 작은 프로젝트 만들기

freeCodeCamp로 실습 반복하기

마지막으로 요청한 형식으로 정리하면:

(생활코딩, https://opentutorials.org/)

(인프런, https://www.inflearn.com/)

(노마드 코더, https://nomadcoders.co/)

(Codecademy, https://www.codecademy.com/)

(freeCodeCamp, https://www.freecodecamp.org/)
