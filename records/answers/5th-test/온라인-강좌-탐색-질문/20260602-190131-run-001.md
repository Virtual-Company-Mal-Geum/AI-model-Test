# 온라인 강좌-탐색-질문 / run 1

## Question

코딩을 처음 시작하는 성인이 듣기 좋은 온라인 강의 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

처음 코딩을 시작하는 성인이라면 “문법 암기”보다 재미 있게 작은 결과물을 만들어보는 강의가 훨씬 오래 갑니다. 아래 순서대로 보면 부담이 적어요.

입문자에게 특히 추천하는 온라인 강의 플랫폼

생활코딩

한국어로 가장 유명한 코딩 입문 강의 중 하나예요.

HTML/CSS, JavaScript, Python, 데이터베이스까지 아주 쉽게 설명해줘서 완전 초보에게 잘 맞습니다.

무료 강의가 많다는 것도 장점이에요.

(생활코딩, https://opentutorials.org (https://opentutorials.org/?utm_source=chatgpt.com))

인프런

한국어 강의 플랫폼이라 접근성이 좋고, “왕초보용” 강의가 정말 많아요.

Python, 웹개발, 앱개발, AI까지 단계별로 들을 수 있습니다.

(인프런, https://www.inflearn.com (https://www.inflearn.com/?utm_source=chatgpt.com))

Codecademy

영어 기반이지만, 직접 코드를 입력하면서 배우는 방식이라 초보가 이해하기 쉬워요.

“코딩이 어떤 느낌인지” 체험하기 좋습니다.

(Codecademy, https://www.codecademy.com (https://www.codecademy.com/?utm_source=chatgpt.com))

Coursera

해외 대학 강의를 온라인으로 들을 수 있는 플랫폼이에요.

특히 Python, 컴퓨터공학 기초 강의 퀄리티가 높습니다.

(Coursera, https://www.coursera.org (https://www.coursera.org/?utm_source=chatgpt.com))

노마드코더

“실제로 만들면서 배우기” 스타일이라 동기부여가 잘 됩니다.

웹사이트나 앱을 직접 만들어보는 프로젝트 중심 강의가 많아요.

(노마드코더, https://nomadcoders.co (https://nomadcoders.co/?utm_source=chatgpt.com))

Udemy

강의 수가 매우 많고 할인도 자주 합니다.

해외 강의지만 좋은 입문 강의가 많고, 실무형 프로젝트 강의도 강점이에요.

(Udemy, https://www.udemy.com (https://www.udemy.com/?utm_source=chatgpt.com))

처음 시작한다면 추천 순서

완전 처음 → 생활코딩 / Codecademy

한국어로 차근차근 → 인프런

프로젝트 중심 → 노마드코더

체계적인 대학 스타일 → Coursera

다양한 실전 강의 → Udemy

그리고 첫 언어는 대부분:

웹 만들기 관심 → JavaScript

자동화/AI/데이터 관심 → Python

으로 시작하면 무난합니다.
