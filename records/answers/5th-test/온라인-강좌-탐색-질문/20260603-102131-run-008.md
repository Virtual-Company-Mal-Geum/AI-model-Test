# 온라인 강좌-탐색-질문 / run 8

## Question

초보자가 프로그래밍 개념부터 차근차근 배울 수 있는 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 완전 처음 시작한다면 "개념 → 간단한 실습 → 프로젝트" 순서로 배우는 것이 가장 좋습니다.

HTML, CSS, JavaScript, Python 등 기초 강의가 매우 친절함

비전공자와 학생에게 특히 추천 에듀로그+1 (https://nyangbanggu.tistory.com/entry/%EB%AC%B4%EB%A3%8C%EB%A1%9C-%EC%BD%94%EB%94%A9-%EB%8F%85%ED%95%99%ED%95%98%EB%8A%94-%EB%B0%A9%EB%B2%95-%E2%80%93-%EC%98%A8%EB%9D%BC%EC%9D%B8-%EA%B0%95%EC%9D%98-%EC%B6%94%EC%B2%9C-TOP-5?utm_source=chatgpt.com)
