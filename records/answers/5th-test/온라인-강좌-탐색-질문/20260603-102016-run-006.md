# 온라인 강좌-탐색-질문 / run 6

## Question

초보자가 프로그래밍 개념부터 차근차근 배울 수 있는 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 배우는 사람이라면, “문법 암기”보다 개념 → 작은 실습 → 프로젝트 흐름으로 배우는 게 훨씬 오래 갑니다.

아래는 초보자가 따라가기 좋은 강좌/플랫폼들을 난이도와 스타일별로 정리한 추천입니다.

완전 입문용 (프로그래밍 사고방식부터)
1. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

한국어 입문 강의의 대표격

“웹이 뭔지”, “프로그래밍이 왜 필요한지”부터 설명

HTML/CSS → JavaScript → Python까지 연결해서 배우기 좋음

영상이 짧고 부담이 적어서 초보자 유지력이 높음

추천 대상:

“코드 한 줄도 처음”

한국어로 천천히 배우고 싶은 사람

형식:

(생활코딩, https://opentutorials.org/)

2. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코딩 가능

설명 → 바로 실습 구조라 초보자 친화적

Python 입문 코스가 특히 유명

추천 대상:

직접 따라치면서 배우는 스타일 선호

설치 과정 없이 시작하고 싶은 사람

형식:

(Codecademy, https://www.codecademy.com/)

개념을 탄탄하게 배우기 좋은 곳
3. CS50 by Harvard (https://cs50.harvard.edu/x?utm_source=chatgpt.com)

세계적으로 유명한 컴퓨터공학 입문 강의

단순 문법이 아니라:

알고리즘

메모리

자료구조

문제 해결 방식

등을 이해하게 해줌

난이도는 조금 있지만 “진짜 기초 체력”이 생김

추천 대상:

제대로 배우고 싶은 사람

나중에 개발자로 가보고 싶은 사람

형식:

(CS50, https://cs50.harvard.edu/x/)

4. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

무료인데 커리큘럼이 매우 체계적

웹 개발 중심

프로젝트 기반 학습이 강점

수료 인증도 제공

추천 대상:

무료로 길게 공부하고 싶은 사람

포트폴리오까지 만들고 싶은 사람

형식:

(freeCodeCamp, https://www.freecodecamp.org/)

Python 입문에 특히 좋은 곳
5. 점프 투 파이썬 (https://wikidocs.net/book/1?utm_source=chatgpt.com)

한국어 Python 입문서의 고전

설명이 쉬운 편

문법 + 실전 예제 균형이 좋음

추천 대상:

Python으로 시작하고 싶은 사람

책 스타일 학습 선호

형식:

(점프 투 파이썬, https://wikidocs.net/book/1)

6. Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학 강의를 온라인으로 듣는 느낌

Python for Everybody 과정이 특히 유명

기초 개념 설명이 차분함

추천 대상:

체계적인 강의 스타일 선호

영어 강의 괜찮은 사람

형식:

(Coursera, https://www.coursera.org/)

게임처럼 배우고 싶다면
7. 프로그래머스 (https://programmers.co.kr/?utm_source=chatgpt.com)

한국어 기반

알고리즘 문제 풀이 + 실습 환경 제공

입문 강의도 꽤 잘 되어 있음

추천 대상:

코딩테스트도 같이 준비하고 싶은 사람

실습 위주 선호

형식:

(프로그래머스, https://programmers.co.kr/)

추천 학습 순서
완전 초보 기준이면 보통 이렇게 많이 갑니다:

생활코딩으로 개념 익히기

Python 또는 웹개발 하나 선택

Codecademy/freeCodeCamp로 실습

CS50로 컴퓨터공학 기초 강화

작은 프로젝트 만들기

처음 시작할 때 언어 추천

가장 무난: Python Programming

앱/게임 만들고 싶음: Python 또는 JavaScript부터
