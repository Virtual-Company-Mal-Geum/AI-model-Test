# 온라인 강좌-탐색-질문 / run 3

## Question

프로그래밍을 독학하려는 성인에게 적합한 온라인 강의 사이트를 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

독학으로 프로그래밍을 배우려는 성인이라면, “기초 설명이 친절한지”, “실습 환경이 잘 되어 있는지”, “꾸준히 학습하기 쉬운지”를 기준으로 고르는 게 중요해요. 목적별로 추천할 만한 사이트들을 정리해볼게요.

입문자에게 특히 좋은 사이트
1. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 매우 많고, 입문자 대상 강의가 풍부함

웹 개발, Python, 앱 개발, 데이터 분석 등 분야 다양

실무 개발자 강의가 많아서 “현업 감각” 익히기 좋음

질문 답변 문화가 비교적 활발함

추천 대상:

영어 강의가 부담되는 사람

한국어로 차근차근 배우고 싶은 사람

2. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

무료 중심의 대표적인 프로그래밍 입문 사이트

설명이 아주 친절하고 부담이 적음

HTML/CSS/JavaScript, Python 같은 기초 시작하기 좋음

추천 대상:

“프로그래밍이 처음”인 사람

돈 들이기 전에 적성 확인하고 싶은 사람

3. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코딩 가능

직접 입력하면서 배우는 인터랙티브 방식

초보자가 “손으로 익히기” 좋음

추천 대상:

읽는 것보다 직접 실습하며 배우는 스타일

영어에 큰 거부감이 없는 사람

4. Udemy (https://www.udemy.com/?utm_source=chatgpt.com)

강의 수가 매우 많고 할인 자주 함

웹 개발, AI, 게임 개발 등 거의 모든 분야 존재

유명 강사는 커리큘럼 품질이 높음

추천 대상:

특정 기술을 깊게 배우고 싶은 사람

저렴하게 강의를 여러 개 듣고 싶은 사람

5. Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학/기업 연계 강의 많음

스탠퍼드, 구글 같은 기관 강의 수강 가능

체계적인 커리큘럼이 강점

추천 대상:

이론까지 제대로 배우고 싶은 사람

인증서나 체계적 학습을 원하는 사람

6. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료

웹 개발과 JavaScript 학습에 매우 강함

프로젝트 기반 학습 가능

추천 대상:

비용 없이 실력을 키우고 싶은 사람

포트폴리오까지 만들고 싶은 사람

목적별 추천

웹 개발 취업 목표 → 인프런 + freeCodeCamp

취미/교양 수준 입문 → 생활코딩

영어 가능 + 실습 선호 → Codecademy

AI/데이터 분석 관심 → Coursera, Udemy

가장 무난한 시작 → 인프런

요청한 형식으로 URL 정리

(인프런, https://www.inflearn.com/)

(생활코딩, https://opentutorials.org/)

(Codecademy, https://www.codecademy.com/)

(Udemy, https://www.udemy.com/)

(Coursera, https://www.coursera.org/)

(freeCodeCamp, https://www.freecodecamp.org/)
