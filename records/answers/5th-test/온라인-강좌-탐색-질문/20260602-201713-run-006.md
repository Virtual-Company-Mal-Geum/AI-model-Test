# 온라인 강좌-탐색-질문 / run 6

## Question

비전공 성인이 프로그래밍을 배우기 좋은 온라인 교육 사이트 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

비전공 성인이 처음 프로그래밍을 배우기에는 “설명이 쉬운지”, “실습이 많은지”, “한국어 지원이 되는지”, “커리큘럼이 체계적인지”가 중요해요. 목적별로 추천해볼게요.

한국어로 쉽고 체계적으로 배우기
1. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국에서 가장 많이 쓰이는 개발 강의 플랫폼 중 하나

입문 강의가 많고, 실무 개발자 강의도 풍부

웹 개발, Python, 앱 개발, AI, 데이터 분석까지 다양

무료 강의도 꽤 많음

추천 대상:

완전 초보

한국어 설명 선호

취업/이직까지 생각하는 사람

2. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

프로그래밍 입문자에게 특히 유명

설명이 정말 쉬운 편

웹 개발(HTML/CSS/JavaScript), Python 기초 학습에 좋음

무료

추천 대상:

“코딩이 뭔지도 잘 모르겠다” 수준의 입문자

부담 없이 시작하고 싶은 사람

3. 프로그래머스 (https://programmers.co.kr/?utm_source=chatgpt.com)

강의 + 코딩 테스트 연습을 함께 할 수 있음

실습 환경이 잘 되어 있음

취업 준비용으로도 많이 사용

추천 대상:

어느 정도 배우고 실전 문제도 풀고 싶은 사람

개발자 취업 관심 있는 사람

해외 사이트 (퀄리티 높고 무료 자료 많음)
4. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

세계적으로 유명한 무료 코딩 학습 사이트

웹 개발, Python, 데이터 분석, 머신러닝 등 가능

단계별 실습 중심

영어지만 쉬운 편

추천 대상:

무료로 제대로 배우고 싶은 사람

프로젝트 중심 학습 선호

5. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

인터랙티브 방식이라 직접 코드를 치면서 배움

초보 친화적 UI

Python 입문이 특히 괜찮음

추천 대상:

책보다 “직접 해보는 스타일”이 맞는 사람

6. CS50 by Harvard (https://cs50.harvard.edu/?utm_source=chatgpt.com)

하버드의 유명한 컴퓨터공학 입문 강의

논리적 사고와 컴퓨터 원리를 탄탄하게 배울 수 있음

난이도는 조금 있는 편

추천 대상:

제대로 컴퓨터공학 기초를 배우고 싶은 사람

장기적으로 개발자를 목표로 하는 사람

어떤 언어부터 배우면 좋을까?

웹사이트 만들기 관심 → HTML/CSS → JavaScript

업무 자동화/AI/데이터 분석 → Python

앱 만들기 → Kotlin(Android) / Swift(iPhone)

아직 모르겠음 → Python 추천

처음 시작하는 사람에게 추천 루트

생활코딩으로 개념 익히기

인프런이나 Codecademy로 실습

프로그래머스에서 문제 풀이

프로젝트 하나 만들어보기

요청한 형식으로 URL 정리

(인프런, https://www.inflearn.com/)

(생활코딩, https://opentutorials.org/)

(프로그래머스, https://programmers.co.kr/)

(freeCodeCamp, https://www.freecodecamp.org/)

(Codecademy, https://www.codecademy.com/)

(CS50 Harvard, https://cs50.harvard.edu/)
