# 온라인 강좌-탐색-질문 / run 5

## Question

코딩 기초를 배우고 싶은 성인에게 알맞은 온라인 강의 플랫폼 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

코딩을 처음 배우는 성인이라면 “설명이 친절한지”, “실습 중심인지”, “한국어 지원이 되는지”, “취업·포트폴리오까지 연결되는지”를 기준으로 고르는 게 좋아요. 목적별로 추천해볼게요.

입문자에게 특히 좋은 플랫폼

생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

한국어 무료 강의로 가장 유명한 입문 플랫폼 중 하나예요.

HTML, CSS, JavaScript, Python 같은 기초를 부담 없이 시작하기 좋아요.

“코딩이 뭔지”부터 설명해줘서 완전 초보에게 특히 추천.

인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 매우 많고, 웹개발·앱개발·데이터분석 등 분야별 선택 폭이 넓어요.

입문 → 실전 프로젝트 → 취업 준비까지 이어가기 좋음.

할인도 자주 해서 가성비가 괜찮아요.

프로그래머스 (https://programmers.co.kr/?utm_source=chatgpt.com)

코딩 테스트와 실습 환경이 강점.

“배우고 바로 문제 풀기” 스타일이라 실력 향상 체감이 빠른 편.

개발자 취업 준비와 연결하기 좋음.

Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

영어 기반이지만 인터랙티브 학습이 정말 잘 되어 있어요.

브라우저 안에서 바로 코딩 가능해서 설치 스트레스가 적음.

혼자 게임처럼 배우는 느낌을 선호하면 추천.

Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학·기업 연계 강의가 많아요.

Google, IBM 같은 기관의 입문 코스도 유명.

체계적으로 배우고 수료증까지 받고 싶을 때 좋음.

Udemy (https://www.udemy.com/?utm_source=chatgpt.com)

실무형 강의가 많고 할인 폭이 큼.

웹개발, Python, 게임개발 등 원하는 분야를 빠르게 시작하기 좋아요.

다만 강의 품질 차이가 있어서 평점 확인 필수.

freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료.

웹개발 중심으로 프로젝트를 만들면서 배우는 스타일.

영어에 거부감이 없으면 최고의 무료 선택지 중 하나.

목적별 추천

완전 처음 → 생활코딩, Codecademy

한국어 + 체계적 → 인프런

취업/코딩테스트 → 프로그래머스

무료 위주 → 생활코딩, freeCodeCamp

대학 강의 느낌 → Coursera

빠른 실무 입문 → Udemy
