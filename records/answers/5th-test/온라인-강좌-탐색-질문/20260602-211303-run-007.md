# 온라인 강좌-탐색-질문 / run 6

## Question

성인 초보자가 따라가기 쉬운 프로그래밍 강좌 사이트를 알려줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 배우는 성인이라면 “설명이 친절한지”, “실습이 많은지”, “한국어 지원이 되는지”가 중요해요. 아래 사이트들은 초보자 기준으로 특히 따라가기 쉬운 곳들이에요.

한국어로 배우기 좋은 곳

인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 많고 입문용 강좌가 풍부해요.

웹 개발, Python, 앱 개발, AI까지 다양하게 배울 수 있어요.

“왕초보”, “비전공자” 대상 강의가 많아서 성인 입문자에게 인기예요.

생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

무료 강의 중심이고 설명이 정말 쉬운 편이에요.

HTML/CSS/JavaScript/Python 입문에 특히 좋아요.

부담 없이 시작하기 좋은 대표 사이트예요.

점프 투 파이썬 (https://wikidocs.net/book/1?utm_source=chatgpt.com)

Python 입문서로 유명해요.

문법 설명과 예제가 잘 정리되어 있어 독학하기 좋아요.

해외 사이트지만 초보자에게 매우 좋은 곳

Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

직접 코드를 입력하면서 배우는 방식이라 재미있어요.

영어가 아주 어렵지는 않은 편이고 인터랙티브 학습이 강점이에요.

freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료에 실습 중심이에요.

웹 개발 입문자들에게 특히 유명해요.

프로젝트를 만들면서 배우는 스타일이에요.

CS50 by Harvard (https://cs50.harvard.edu/x/?utm_source=chatgpt.com)

세계적으로 유명한 컴퓨터공학 입문 강좌예요.

난이도는 조금 있지만 설명이 뛰어나고 동기부여가 잘 돼요.

프로그래밍을 제대로 이해하고 싶은 사람에게 추천해요.

처음 시작한다면 보통은:

웹 개발 → 생활코딩 → 인프런

Python → 점프 투 파이썬 → 인프런

영어 가능 → Codecademy / freeCodeCamp

순서로 많이 시작해요.

마지막에 요청한 형식으로 다시 정리하면:

(인프런, https://www.inflearn.com/)

(생활코딩, https://opentutorials.org/)

(점프 투 파이썬, https://wikidocs.net/book/1)

(Codecademy, https://www.codecademy.com/)

(freeCodeCamp, https://www.freecodecamp.org/)

(CS50, https://cs50.harvard.edu/x/)
