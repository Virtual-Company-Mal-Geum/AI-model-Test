# 온라인 강좌-탐색-질문 / run 1

## Question

초보자가 프로그래밍 개념부터 차근차근 배울 수 있는 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 배우는 초보자라면, “문법 암기”보다 컴퓨터 사고방식 + 작은 프로젝트 경험을 같이 배우는 강좌가 훨씬 오래 갑니다. 아래 순서대로 보면 부담이 적어요.

웹으로 눈에 보이는 결과를 빨리 만들기

Python 같은 쉬운 언어로 기초 문법 익히기

자료구조·알고리즘·객체지향 같은 CS 기초 배우기

작은 프로젝트 직접 만들어보기

추천 강좌들을 난이도 순으로 정리하면:

입문용 (완전 초보 추천)
1. 생활코딩 (https://opentutorials.org/course/1?utm_source=chatgpt.com)

한국어 초보자 입문으로 가장 유명한 편

HTML/CSS/JavaScript/Python 등을 아주 쉽게 설명

“왜 배우는지”를 같이 알려줘서 처음 시작하기 좋음

형식:

(생활코딩, https://opentutorials.org/course/1)

2. CS50 by Harvard (https://cs50.harvard.edu/x/?utm_source=chatgpt.com)

세계적으로 유명한 컴퓨터공학 입문 강의

프로그래밍 개념 자체를 탄탄하게 알려줌

처음엔 조금 어렵지만 설명 퀄리티가 매우 좋음

형식:

(CS50 by Harvard, https://cs50.harvard.edu/x/)

3. 점프 투 파이썬 (https://wikidocs.net/book/1?utm_source=chatgpt.com)

Python 입문 교재/강좌

문법 설명이 친절하고 예제가 많음

코딩 테스트나 자동화에도 이어지기 좋음

형식:

(점프 투 파이썬, https://wikidocs.net/book/1)

실습 중심 강좌
4. 프로그래머스 (https://programmers.co.kr/learn?utm_source=chatgpt.com)

직접 문제를 풀면서 배우는 스타일

기초 문법 → 알고리즘 → 실전 문제까지 가능

취업 준비용으로도 많이 사용

형식:

(프로그래머스, https://programmers.co.kr/learn)

5. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 많고 분야 다양함

웹개발, 앱개발, 게임개발 등 선택 가능

무료 입문 강의도 꽤 많음

형식:

(인프런, https://www.inflearn.com/)

영어 괜찮으면 강력 추천
6. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

무료로 웹개발 전체 과정을 배울 수 있음

실습량이 많아서 손에 익기 좋음

프로젝트 중심 학습 가능

형식:

(freeCodeCamp, https://www.freecodecamp.org/)

7. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저 안에서 바로 코딩 가능

인터랙티브 방식이라 초보자 친화적

게임처럼 단계별 진행

형식:

(Codecademy, https://www.codecademy.com/)

처음 시작한다면 추천 순서는:

생활코딩

점프 투 파이썬

CS50
