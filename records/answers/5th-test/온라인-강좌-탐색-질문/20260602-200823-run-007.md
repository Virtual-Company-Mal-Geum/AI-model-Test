# 온라인 강좌-탐색-질문 / run 1

## Question

프로그래밍 입문자가 기초부터 배울 수 있는 온라인 강좌를 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍 입문자라면 “쉬운 설명 + 실습 중심 + 커뮤니티 활성화”가 중요한데, 아래 강의들이 특히 많이 추천돼요.

인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 많아서 처음 시작하기 좋아요.

Python, 웹 개발, 앱 개발, 게임 개발까지 다양하게 배울 수 있어요.

무료 입문 강의도 많습니다.

형식: (인프런, https://www.inflearn.com/ (https://www.inflearn.com/?utm_source=chatgpt.com))

생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

완전 초보자용으로 유명한 무료 강의 사이트예요.

HTML/CSS/JavaScript/Python 등을 아주 쉽게 설명해줘요.

“코딩이 처음인 사람”에게 특히 추천됩니다.

형식: (생활코딩, https://opentutorials.org/ (https://opentutorials.org/?utm_source=chatgpt.com))

Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

영어 사이트지만 실습형이라 따라 하면서 배우기 좋아요.

브라우저에서 바로 코드를 실행할 수 있습니다.

Python 입문용으로 인기가 많아요.

형식: (Codecademy, https://www.codecademy.com/ (https://www.codecademy.com/?utm_source=chatgpt.com))

Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학 수준의 강의를 들을 수 있어요.

Google, Stanford University 같은 기관 강의도 많습니다.

기초 컴퓨터공학을 체계적으로 배우고 싶다면 추천해요.

형식: (Coursera, https://www.coursera.org/ (https://www.coursera.org/?utm_source=chatgpt.com))

freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

무료로 웹 개발을 깊게 배울 수 있어요.

프로젝트 중심이라 포트폴리오 만들기에도 좋습니다.

유튜브 강의도 매우 유명해요.

형식: (freeCodeCamp, https://www.freecodecamp.org/ (https://www.freecodecamp.org/?utm_source=chatgpt.com))

처음 시작한다면 추천 순서는:

완전 처음 → 생활코딩

Python 배우기 → 인프런 + Codecademy

웹 개발 → freeCodeCamp

체계적인 CS 공부 → Coursera

원하면 다음으로:

“중학생/고등학생에게 쉬운 강의”

“게임 만들기 입문”

“Python만 집중”

“무료 강의만”

“한국어 강의 위주”

같이 목적별로도 추천해줄게.
