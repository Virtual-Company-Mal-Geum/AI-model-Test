# 온라인 강좌-탐색-질문 / run 6

## Question

코딩을 처음 배우는 직장인이나 성인 학습자가 듣기 좋은 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)
