# 온라인 강좌-탐색-질문 / run 6

## Question

코딩 기초를 배우고 싶은 성인에게 알맞은 온라인 강의 플랫폼 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

코딩을 처음 배우는 성인이라면 “설명이 쉬운지”, “실습이 많은지”, “한국어 지원 여부”, “목표(취업·취미·업무 자동화 등)”에 따라 플랫폼 선택이 달라져요. 아래는 입문자에게 특히 평가가 좋은 온라인 강의 플랫폼들이에요.

한국어 중심으로 배우기 좋은 곳

인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 매우 많고, 입문 강좌가 친절한 편

Python, 웹개발, 앱개발, 데이터분석 등 분야 다양

한국 개발자 커뮤니티 느낌이라 질문 답변도 활발

패스트캠퍼스 (https://fastcampus.co.kr/?utm_source=chatgpt.com)

커리어·취업 중심 커리큘럼이 강함

실무 프로젝트형 강의가 많음

초보자용 국비·부트캠프 스타일 과정도 있음

생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

완전 초보자에게 특히 추천

무료 강의가 많고 설명이 아주 쉬움

HTML/CSS/JavaScript 입문용으로 유명

해외 플랫폼 (영어 가능하면 강력 추천)

Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코딩 가능

인터랙티브 실습 중심이라 입문 난이도가 낮음

Python, JavaScript 입문에 특히 좋음

Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학·기업(구글, IBM 등) 연계 강의 제공

체계적인 커리큘럼 강점

수료증 과정도 많음

Udemy (https://www.udemy.com/?utm_source=chatgpt.com)

강의 수가 매우 많고 할인 자주 함

원하는 기술 하나를 빠르게 배우기 좋음

강사별 퀄리티 차이는 있어서 평점 확인 필요

freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

무료로 웹개발·Python·데이터분석 학습 가능

실습과 프로젝트 중심

영어지만 입문 난이도는 낮은 편

목적별 추천

“진짜 처음” → 생활코딩, Codecademy

“한국어로 차근차근” → 인프런

“취업·포트폴리오” → 패스트캠퍼스, Coursera

“가성비” → Udemy

“무료 위주” → freeCodeCamp, 생활코딩

(생활코딩, https://opentutorials.org/)

(Codecademy, https://www.codecademy.com/)

(Coursera, https://www.coursera.org/)
