# 온라인 강좌-탐색-질문 / run 10

## Question

초보자가 프로그래밍 개념부터 차근차근 배울 수 있는 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 배우는 사람이라면 “문법만” 배우기보다,

컴퓨터 사고방식 → 2) 간단한 코드 작성 → 3) 작은 프로젝트 제작 순서로 가는 강좌가 훨씬 오래 기억에 남습니다.

아래는 초보자 기준으로 난이도와 설명력이 좋은 강좌들입니다.

한국어로 시작하기 좋은 강좌
1. 생활코딩 — 가장 추천
생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

진짜 입문자 기준으로 설명이 매우 쉬움

“인터넷이 뭔가요?” 수준부터 시작 가능

HTML/CSS → JavaScript → Python → 데이터베이스까지 연결해서 배울 수 있음

무료 강좌가 많음

특히 추천 코스:

WEB1 (웹 기초)

JavaScript 입문

Python 입문

2. 인프런
인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의 플랫폼

무료 입문 강의가 많고 실습 중심

개발자 커뮤니티에서도 많이 사용

추천 검색 키워드:

“파이썬 입문”

“웹 개발 입문”

“프로그래밍 처음 시작”

3. 노마드 코더
노마드 코더 (https://nomadcoders.co/?utm_source=chatgpt.com)

직접 결과물을 만드는 스타일

“클론코딩” 방식이라 재미있게 배우기 좋음

유튜브보다 체계적

추천:

Python 챌린지

React 입문

코코아톡 클론

영어 괜찮으면 강력 추천
4. freeCodeCamp
freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

전 세계에서 가장 유명한 무료 코딩 학습 사이트 중 하나

단계별 실습 + 프로젝트 방식

웹개발, Python, 데이터 분석까지 가능

장점:

완전 무료

실습량 많음

포트폴리오 만들기 좋음

5. CS50 (하버드)
CS50 (https://cs50.harvard.edu/x/?utm_source=chatgpt.com)

컴퓨터공학 사고방식을 정말 잘 가르침

초보자도 들을 수 있지만 약간 난이도 있음

“왜 이렇게 동작하는지” 이해하기 좋음

추천 대상:

제대로 기초부터 배우고 싶은 사람

장기적으로 개발자 생각이 있는 사람

어떤 언어부터 시작하면 좋은가?
대부분의 초보자에게는:

Python → 가장 쉬움

JavaScript → 웹 만들기 가능

이후 Java / C++ 등 확장

순서 추천:

Python으로 프로그래밍 개념 익히기

HTML/CSS/JavaScript로 웹 만들어보기

프로젝트 해보기

완전 초보자용 추천 루트
1개월 기준 예시:

1주차

생활코딩 WEB1

변수, 조건문 이해

2주차

Python 기초

간단한 계산기 만들기

3주차

HTML/CSS로 자기소개 페이지 만들기

4주차

JavaScript로 버튼/게임 만들기

이렇게 하면 “코드 읽기”에서 “직접 만들기” 단계까지 갈 수 있습니다.
