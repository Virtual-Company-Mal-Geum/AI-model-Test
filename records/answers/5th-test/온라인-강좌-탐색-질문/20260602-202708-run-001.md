# 온라인 강좌-탐색-질문 / run 1

## Question

성인 초보자가 따라가기 쉬운 프로그래밍 강좌 사이트를 알려줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

성인 초보자가 시작하기 쉬운 프로그래밍 강좌 사이트들을 난이도·설명 방식 기준으로 골라봤어.

처음엔 “문법 암기”보다 직접 따라 만들기 + 짧은 실습 위주 사이트가 훨씬 덜 어렵게 느껴져.

한국어 중심으로 배우기 좋은 곳
1. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

한국 초보자 입문용으로 가장 유명한 편

설명이 쉬운 편이고 “왜 배우는지”를 같이 알려줌

HTML/CSS → JavaScript → Python 순으로 가기 좋음

무료 강의가 많음

추천 대상:

완전 비전공자

컴퓨터 지식이 거의 없는 사람

2. 점프 투 파이썬 (https://wikidocs.net/book/1?utm_source=chatgpt.com)

Python 입문 책/강의 느낌

예제가 많고 단계별 설명이 깔끔함

웹 개발이나 자동화 입문 전 기초 다지기 좋음

추천 대상:

Python부터 시작하고 싶은 사람

차근차근 읽는 스타일 선호

3. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의 플랫폼

무료 입문 강의도 꽤 많음

실무형 강좌가 많아서 목표 잡기 좋음

추천 대상:

영상 강의 선호

앱/웹/게임 등 목표가 있는 사람

해외 사이트지만 초보자 친화적인 곳
4. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

실습 중심

웹 개발 입문에 특히 강함

무료 + 단계별 프로젝트 제공

추천 대상:

직접 만들어보면서 배우는 스타일

영어 괜찮은 편

5. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코딩 가능

“한 줄 배우고 바로 실행” 방식

인터랙티브해서 지루하지 않음

추천 대상:

게임처럼 배우고 싶은 사람

설치 과정 귀찮은 사람

6. CS50 by Harvard (https://cs50.harvard.edu/x/?utm_source=chatgpt.com)

유명한 하버드 컴공 입문 강의

난이도는 약간 있지만 설명력이 뛰어남

프로그래밍 사고방식 배우기 좋음

추천 대상:

제대로 기초를 배우고 싶은 사람

장기적으로 개발 공부할 생각 있는 사람

처음 시작한다면 추천 순서

생활코딩

점프 투 파이썬 또는 Codecademy

freeCodeCamp

인프런 실전 프로젝트

CS50
