# 온라인 강좌-탐색-질문 / run 5

## Question

프로그래밍을 독학하려는 성인에게 적합한 온라인 강의 사이트를 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

독학으로 프로그래밍을 시작하는 성인이라면, “기초를 체계적으로 설명해주는지”, “실습이 많은지”, “한국어 지원 여부”, “가격”을 기준으로 고르는 게 좋아요. 아래 사이트들은 입문자부터 취업 준비 단계까지 많이 추천되는 곳들입니다.

freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료

웹 개발, Python, 데이터 분석, 알고리즘 등을 실습 중심으로 배울 수 있음

프로젝트 기반이라 “직접 만들면서 배우는 스타일”에 적합

Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저 안에서 바로 코딩 가능

초보자 UI가 매우 친절함

Python, JavaScript, SQL 입문에 특히 강함

Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학·기업 강의를 온라인으로 제공

Google, Stanford University 등의 강의를 들을 수 있음

체계적으로 공부하고 싶은 사람에게 추천

Udemy (https://www.udemy.com/?utm_source=chatgpt.com)

실무형 강의가 많음

할인 기간이 많아서 저렴하게 구매 가능

“웹 개발 부트캠프”, “Python 완전 정복” 같은 장기 강의가 유명

인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의 중심

국내 개발자 취업 준비에 적합

Spring, React, Java, CS 기초 강의가 강함

생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

한국어 무료 강의

프로그래밍을 처음 접하는 사람도 이해하기 쉽게 설명

HTML/CSS/JavaScript 입문용으로 특히 유명
