# 온라인 강좌-탐색-질문 / run 2

## Question

코딩을 처음 시작하는 성인이 듣기 좋은 온라인 강의 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

처음 코딩을 배우는 성인이라면 “문법 설명”보다도 작은 프로젝트를 직접 만들어보는 방식이 훨씬 오래 기억에 남아요.

아래 강의들은 비전공자·입문자 기준으로 특히 많이 추천되는 곳들이에요.

한국어로 배우기 좋은 강의
1. 생활코딩

완전 초보자용으로 가장 유명한 무료 강의 중 하나

HTML/CSS, JavaScript, Python, 데이터베이스까지 기초를 쉽게 설명

“코딩이 뭔지” 감 잡기에 최고

(생활코딩, https://opentutorials.org/)

2. 인프런

한국어 강의가 매우 많고 입문 강의도 풍부

Python, 웹개발, 앱개발, AI까지 분야별 선택 가능

할인 이벤트가 자주 있음

(인프런, https://www.inflearn.com/)

3. 코드잇

인터랙티브 방식이라 직접 입력하면서 배우기 좋음

디자인이 깔끔하고 초보 친화적

“하루 20~30분” 느낌으로 꾸준히 하기 좋음

(코드잇, https://www.codeit.kr/)

영어 괜찮다면 정말 추천하는 곳
4. freeCodeCamp

완전 무료

웹개발 입문부터 실전 프로젝트까지 가능

해외에서 초보자 추천 1순위로 자주 언급됨

(freeCodeCamp, https://www.freecodecamp.org/)

5. CS50 (하버드)

세계적으로 유명한 컴퓨터공학 입문 강의

난이도는 조금 있지만 “재미있게 깊게” 배울 수 있음

프로그래밍 사고력을 키우기에 좋음

(CS50, https://cs50.harvard.edu/)

6. Udemy

입문 강의 종류가 엄청 많음

“Python Bootcamp”, “웹개발 Bootcamp” 류 강의가 유명

세일 때 저렴하게 구매 가능

(Udemy, https://www.udemy.com/)

처음 시작한다면 추천 루트

생활코딩 또는 코드잇으로 감 잡기

Python 기초 배우기

작은 프로젝트 만들어보기

이후 웹개발 / 앱개발 / AI 중 관심 분야 선택

특히 처음에는 Python으로 시작하는 걸 추천해요. 문법이 비교적 쉽고 활용 분야도 넓어요.
