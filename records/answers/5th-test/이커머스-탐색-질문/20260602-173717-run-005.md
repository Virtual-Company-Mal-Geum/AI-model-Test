# 이커머스-탐색-질문 / run 5

## Question

노트북, 스마트폰, 패션 상품을 살 때 많이 이용하는 신뢰도 높은 쇼핑몰 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

노트북·스마트폰·패션 상품을 살 때 많이 이용하는, 비교적 신뢰도가 높은 대표 쇼핑몰들을 분야별로 정리해볼게요.

전자제품(노트북·스마트폰)

쿠팡 (https://www.coupang.com/?utm_source=chatgpt.com)

로켓배송이 강점이고, 전자제품 할인도 자주 열려요.

11번가 (https://www.11st.co.kr/?utm_source=chatgpt.com)

SK 계열 할인과 카드 프로모션이 강한 편이에요.

G마켓 (https://www.gmarket.co.kr/?utm_source=chatgpt.com)

브랜드 공식 판매처가 많고 해외직구도 활발해요.

옥션 (https://www.auction.co.kr/?utm_source=chatgpt.com)

G마켓과 비슷한 구조로 할인 이벤트가 자주 있어요.

네이버 쇼핑 (https://shopping.naver.com/?utm_source=chatgpt.com)

가격 비교용으로 가장 많이 쓰이고 리뷰 확인하기 좋아요.

삼성닷컴 (https://chatgpt.com/c/null)

갤럭시·노트북 구매 시 공식 혜택과 사전예약 보상이 좋은 편이에요.

애플 공식 스토어 코리아 (https://www.apple.com/kr/store/?utm_source=chatgpt.com)

아이폰·맥북 정품 구매와 학생 할인 이용하기 좋아요.

패션 쇼핑몰

무신사 (https://www.musinsa.com/?utm_source=chatgpt.com)

국내 스트릿·캐주얼 브랜드가 가장 강한 대표 플랫폼이에요.

29CM (https://www.29cm.co.kr/?utm_source=chatgpt.com)

감성 브랜드·디자이너 브랜드 큐레이션이 강점이에요.

W컨셉 (https://www.wconcept.co.kr/?utm_source=chatgpt.com)

여성 패션·디자이너 브랜드 비중이 높아요.

지그재그 (https://zigzag.kr/?utm_source=chatgpt.com)

여성 쇼핑몰 모아서 보기 좋고 가격 비교가 편해요.

에이블리 (https://a-bly.com/?utm_source=chatgpt.com)

트렌디한 패션과 빠른 배송으로 많이 이용해요.

SSF샵 (https://www.ssfshop.com/?utm_source=chatgpt.com)

삼성물산 패션 브랜드(빈폴·구호 등) 공식몰이에요.

해외 직구까지 고려하면

아마존 (https://www.amazon.com/?utm_source=chatgpt.com)

전자제품·액세서리 직구 대표 사이트예요.

알리익스프레스 (https://chatgpt.com/c/null)

전자제품 → 쿠팡, 네이버쇼핑, 삼성닷컴
