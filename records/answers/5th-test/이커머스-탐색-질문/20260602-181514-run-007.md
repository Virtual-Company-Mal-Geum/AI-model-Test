# 이커머스-탐색-질문 / run 7

## Question

온라인으로 상품을 구매할 때 신뢰할 수 있고 후기가 많은 쇼핑몰을 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

어떤 종류의 상품을 주로 구매하느냐에 따라 가장 좋은 쇼핑몰이 조금 달라져.

그래도 한국에서 전반적으로 후기 수가 많고, 배송·환불·신뢰도 측면에서 많이 이용되는 대표 쇼핑몰들을 정리해볼게.

종합 쇼핑몰

쿠팡 (https://www.coupang.com/?utm_source=chatgpt.com)

로켓배송이 강점이고 상품 후기 수가 매우 많아서 비교하기 편해.

네이버 스마트스토어 (https://smartstore.naver.com/?utm_source=chatgpt.com)

실제 구매자 리뷰와 평점 확인이 쉬워서 상품 비교에 좋음.

11번가 (https://www.11st.co.kr/?utm_source=chatgpt.com)

오래된 오픈마켓이라 판매자 수와 후기 데이터가 많음.

G마켓 (https://www.gmarket.co.kr/?utm_source=chatgpt.com)

할인 행사와 해외직구 상품 종류가 다양함.

옥션 (https://www.auction.co.kr/?utm_source=chatgpt.com)

G마켓과 비슷하게 오래 운영되어 신뢰도가 높은 편.

전자제품·IT

다나와 (https://www.danawa.com/?utm_source=chatgpt.com)

가격 비교와 실사용 후기 확인에 매우 유용함.

컴퓨존 (https://www.compuzone.co.kr/?utm_source=chatgpt.com)

PC·부품 쪽에서 신뢰도가 높은 쇼핑몰.

패션·의류

무신사 (https://www.musinsa.com/?utm_source=chatgpt.com)

스트리트·캐주얼 패션 후기와 착용 사진이 많음.

29CM (https://www.29cm.co.kr/?utm_source=chatgpt.com)

감성 브랜드와 라이프스타일 제품이 강점.

해외직구

아마존 (https://www.amazon.com/?utm_source=chatgpt.com)

글로벌 최대 규모라 후기 수가 압도적으로 많음.

알리익스프레스 (https://chatgpt.com/c/null)

저렴한 제품이 많지만 판매자 평점·리뷰를 꼭 확인하는 게 중요함.
