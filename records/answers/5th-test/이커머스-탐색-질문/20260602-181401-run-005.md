# 이커머스-탐색-질문 / run 5

## Question

온라인으로 상품을 구매할 때 신뢰할 수 있고 후기가 많은 쇼핑몰을 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

온라인 쇼핑몰은 “무엇을 사는지”에 따라 신뢰도와 만족도가 꽤 달라져요. 한국에서 이용자가 많고 후기·배송·고객응대 측면에서 비교적 안정적이라는 평가를 받는 곳들을 카테고리별로 정리해볼게요.

종합 쇼핑몰

쿠팡 (https://www.coupang.com/?utm_source=chatgpt.com)

로켓배송이 강점이고 상품 후기 수가 매우 많아서 비교하기 편해요.

네이버 쇼핑 (https://shopping.naver.com/?utm_source=chatgpt.com)

여러 쇼핑몰 가격과 리뷰를 한 번에 비교하기 좋아요.

11번가 (https://www.11st.co.kr/?utm_source=chatgpt.com)

브랜드 공식 스토어가 많고 할인 행사도 자주 열려요.

G마켓 (https://www.gmarket.co.kr/?utm_source=chatgpt.com)

오래된 오픈마켓이라 판매자와 후기 데이터가 풍부해요.

옥션 (https://www.auction.co.kr/?utm_source=chatgpt.com)

G마켓 계열로 특가 상품이나 중소 판매자 상품이 다양해요.

패션·의류

무신사 (https://www.musinsa.com/?utm_source=chatgpt.com)

스트리트·캐주얼 브랜드가 강하고 착용 후기 문화가 잘 되어 있어요.

29CM (https://www.29cm.co.kr/?utm_source=chatgpt.com)

감성 브랜드와 라이프스타일 제품 추천이 강점이에요.

지그재그 (https://www.zigzag.kr/?utm_source=chatgpt.com)

여성 쇼핑몰 통합 플랫폼이라 후기 비교가 쉬워요.

전자제품

다나와 (https://www.danawa.com/?utm_source=chatgpt.com)

가격 비교와 스펙 비교에 매우 유용해요.

하이마트 (https://www.e-himart.co.kr/?utm_source=chatgpt.com)

대형 가전 구매 시 설치·AS 측면에서 안정적인 편이에요.

해외직구

아마존 (https://www.amazon.com/?utm_source=chatgpt.com)

글로벌 후기 수가 압도적으로 많고 상품 선택 폭이 넓어요.

알리익스프레스 (https://chatgpt.com/c/null)

저렴한 제품이 많지만 판매자 평점과 후기 확인은 꼭 필요해요.
