# 이커머스-탐색-질문 / run 9

## Question

전자기기와 패션 상품을 온라인으로 살 때 이용하기 좋은 쇼핑몰 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

전자기기와 패션은 “무엇을 중시하느냐”에 따라 좋은 쇼핑몰이 조금 달라져.

가격, 정품 신뢰도, 배송 속도, 해외 브랜드 접근성 기준으로 나눠서 추천할게.

전자기기 쇼핑몰 추천
국내

쿠팡 (https://www.coupang.com/?utm_source=chatgpt.com)

로켓배송이 강점이고, 이어폰·키보드·태블릿 같은 IT 소형기기 구매가 편해.

11번가 (https://www.11st.co.kr/?utm_source=chatgpt.com)

할인 행사와 카드 혜택이 자주 있어서 가격 비교용으로 좋아.

G마켓 (https://www.gmarket.co.kr/?utm_source=chatgpt.com)

브랜드 공식 판매처가 많고 중저가 전자기기 찾기 편함.

네이버 쇼핑 (https://shopping.naver.com/?utm_source=chatgpt.com)

최저가 비교와 후기 확인이 매우 편리함.

삼성스토어 (https://chatgpt.com/c/null)

삼성 제품은 공식몰 혜택·AS 신뢰도가 좋음.

애플 코리아 (https://www.apple.com/kr?utm_source=chatgpt.com)

아이폰·아이패드·맥북은 공식몰 구매가 가장 안전한 편.

패션 쇼핑몰 추천

지그재그 (https://www.zigzag.kr/?utm_source=chatgpt.com)

다양한 쇼핑몰 상품을 한 번에 비교 가능.
