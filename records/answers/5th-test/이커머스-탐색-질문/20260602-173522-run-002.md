# 이커머스-탐색-질문 / run 2

## Question

노트북, 스마트폰, 패션 상품을 살 때 많이 이용하는 신뢰도 높은 쇼핑몰 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

노트북, 스마트폰, 패션 상품은 가격·정품 여부·AS 정책이 중요해서, 오래 운영됐고 사용자 평판이 좋은 곳 위주로 고르는 게 좋아요. 국내 기준으로 많이 쓰이고 신뢰도가 높은 쇼핑몰들을 카테고리별로 정리해볼게요.

노트북/스마트폰 구매 추천 쇼핑몰

쿠팡 (https://www.coupang.com/?utm_source=chatgpt.com)

로켓배송이 강점이고 전자제품 할인 빈도가 높음. 판매자 평점 확인 필수.

11번가 (https://www.11st.co.kr/?utm_source=chatgpt.com)

삼성·애플 공식 스토어 입점이 많고 카드 할인 자주 진행.

G마켓 (https://www.gmarket.co.kr/?utm_source=chatgpt.com)

전자제품 특가가 자주 뜨고 해외직구 옵션도 다양함.

옥션 (https://www.auction.co.kr/?utm_source=chatgpt.com)

G마켓과 비슷한 계열로 가격 비교용으로 좋음.

네이버 쇼핑 (https://shopping.naver.com/?utm_source=chatgpt.com)

여러 쇼핑몰 가격 비교에 최적. 리뷰 수가 많아서 판단하기 좋음.

삼성닷컴 (https://chatgpt.com/c/null)

갤럭시·노트북 공식 구매 시 가장 안전한 선택.

Apple Korea (https://www.apple.com/kr/?utm_source=chatgpt.com)

아이폰·맥북 정품 구매와 학생 할인 이용 가능.

패션 상품 구매 추천 쇼핑몰

무신사 (https://www.musinsa.com/?utm_source=chatgpt.com)

국내 스트릿·캐주얼 브랜드가 가장 강한 편. 리뷰 신뢰도가 높음.

29CM (https://www.29cm.co.kr/?utm_source=chatgpt.com)

감성 브랜드·디자이너 브랜드 큐레이션이 강점.

W Concept (https://www.wconcept.co.kr/?utm_source=chatgpt.com)

여성 패션·디자이너 브랜드 쪽에서 인기 많음.

SSF SHOP (https://www.ssfshop.com/?utm_source=chatgpt.com)

삼성물산 계열이라 품질·정품 신뢰도가 높은 편.

지그재그 (https://www.zigzag.kr/?utm_source=chatgpt.com)

여성 쇼핑몰 통합 플랫폼 느낌으로 사용하기 편함.

에이블리 (https://chatgpt.com/c/null)

트렌디한 저가 패션 찾기 좋음.

해외 직구까지 고려하면 많이 쓰는 곳

Amazon (https://www.amazon.com/?utm_source=chatgpt.com)

전자제품·패션 모두 강력. 해외배송과 리뷰 시스템이 장점.
