# 이커머스-탐색-질문 / run 3

## Question

스마트폰이나 노트북을 온라인으로 구매할 때 믿고 이용할 수 있는 사이트 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

스마트폰이나 노트북을 온라인으로 살 때는 정품 보장, AS 대응, 배송 안정성, 리뷰 신뢰도가 중요해요. 한국에서 많이 이용하고 비교적 신뢰도가 높은 곳들을 용도별로 정리해볼게요.
