# 이커머스-탐색-질문 / run 8

## Question

전자기기와 패션 상품을 온라인으로 살 때 이용하기 좋은 쇼핑몰 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

전자기기랑 패션 상품을 온라인으로 살 때는 “가격 경쟁력”, “정품 신뢰도”, “배송 속도”, “브랜드 다양성” 기준으로 나눠서 보는 게 좋아요. 한국에서 많이 쓰이고 이용하기 편한 곳들 위주로 추천할게요.

전자기기 쇼핑몰 추천

쿠팡 (https://www.coupang.com/?utm_source=chatgpt.com)

로켓배송이 강점이고, 이어폰·노트북·모니터 같은 IT 기기 가격이 자주 저렴해요.

11번가 (https://www.11st.co.kr/?utm_source=chatgpt.com)

SK 계열 할인이나 카드 프로모션이 자주 있어서 전자기기 특가가 괜찮아요.

G마켓 (https://www.gmarket.co.kr/?utm_source=chatgpt.com)

해외직구와 국내 판매를 같이 보기 좋고 브랜드 선택 폭이 넓어요.

다나와 (https://www.danawa.com/?utm_source=chatgpt.com)

직접 판매몰이라기보다 가격 비교 사이트에 가까운데, PC 부품·노트북·모니터 살 때 거의 필수예요.

컴퓨존 (https://www.compuzone.co.kr/?utm_source=chatgpt.com)

PC 부품이나 게이밍 장비 구매할 때 신뢰도가 높은 편이에요.

애플 코리아 (https://www.apple.com/kr?utm_source=chatgpt.com)

아이폰·아이패드·맥북은 공식몰 구매 시 각인이나 학생 할인 이용하기 좋아요.

패션 쇼핑몰 추천

무신사 (https://www.musinsa.com/?utm_source=chatgpt.com)

국내 스트릿·캐주얼 브랜드가 많고 패션 입문용으로 가장 대중적이에요.

29CM (https://www.29cm.co.kr/?utm_source=chatgpt.com)

감성적인 브랜드 큐레이션이 강점이고 의류·라이프스타일 제품 퀄리티가 좋아요.

W컨셉 (https://www.wconcept.co.kr/?utm_source=chatgpt.com)

디자이너 브랜드나 트렌디한 여성/유니섹스 패션 찾기 좋아요.

SSF샵 (https://www.ssfshop.com/?utm_source=chatgpt.com)

삼성물산 계열이라 빈폴·준지 같은 브랜드 구매하기 편해요.

지그재그 (https://www.zigzag.kr/?utm_source=chatgpt.com)

다양한 쇼핑몰을 한 번에 비교하기 좋아서 가성비 패션 찾을 때 편해요.

에이블리 (https://chatgpt.com/c/null)

빠른 트렌드 상품과 저렴한 가격대가 강점이에요.
