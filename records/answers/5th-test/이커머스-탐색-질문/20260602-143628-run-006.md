# 이커머스-탐색-질문 / run 6

## Question

온라인에서 스마트폰이나 노트북을 구매하려고 하는데 믿을 수 있는 쇼핑몰 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

스마트폰이나 노트북을 온라인으로 살 때는 정품 보장, AS 대응, 환불 정책, 후기 신뢰도가 중요해요. 한국에서 비교적 신뢰도가 높은 곳들을 목적별로 정리해볼게요.
