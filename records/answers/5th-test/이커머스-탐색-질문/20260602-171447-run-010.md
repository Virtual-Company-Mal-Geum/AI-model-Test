# 이커머스-탐색-질문 / run 10

## Question

전자기기와 패션 상품을 온라인으로 살 때 이용하기 좋은 쇼핑몰 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

전자기기와 패션은 쇼핑몰마다 강점이 꽤 달라서, “가격”, “정품 신뢰도”, “배송 속도”, “해외 브랜드”, “중고/리셀” 중 어디를 중요하게 보느냐에 따라 선택이 달라져요. 아래처럼 나눠서 보면 편합니다.
