# 이커머스-탐색-질문 / run 7

## Question

온라인 쇼핑을 하려고 하는데 전자제품과 의류를 구매하기 좋은 사이트를 알려줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

전자제품과 의류를 온라인으로 구매할 때는 가격, 정품 여부, 배송 속도, 교환/환불 정책을 함께 보는 게 좋아요. 한국에서 많이 사용하는 믿을 만한 사이트들을 카테고리별로 정리해볼게요.

전자제품 구매 추천 사이트

쿠팡 (https://www.coupang.com/?utm_source=chatgpt.com)

로켓배송이 빠르고 전자기기 할인도 자주 열려요. 휴대폰, 노트북, 게이밍 기기까지 다양합니다.

11번가 (https://www.11st.co.kr/?utm_source=chatgpt.com)

삼성·LG 공식 스토어가 많고 카드 할인 이벤트가 자주 있습니다.

G마켓 (https://www.gmarket.co.kr/?utm_source=chatgpt.com)

해외직구와 국내 전자제품을 함께 비교하기 좋아요.

다나와 (https://www.danawa.com/?utm_source=chatgpt.com)

직접 판매 사이트라기보다 가격 비교에 강점이 있어요. 부품·노트북 비교할 때 특히 유용합니다.

애플 코리아 (https://www.apple.com/kr/?utm_source=chatgpt.com)

아이폰, 아이패드, 맥북 같은 애플 제품은 공식몰 구매가 안전합니다.

삼성닷컴 (https://www.samsung.com/sec/?utm_source=chatgpt.com)

갤럭시, TV, 가전제품 공식 할인과 학생 할인 등이 있습니다.

의류 구매 추천 사이트

무신사 (https://www.musinsa.com/?utm_source=chatgpt.com)

국내 스트리트·캐주얼 브랜드가 매우 많고 리뷰가 자세합니다.

29CM (https://www.29cm.co.kr/?utm_source=chatgpt.com)

감성 브랜드와 디자이너 의류를 찾기 좋아요.

지그재그 (https://zigzag.kr/?utm_source=chatgpt.com)

여성 의류 쇼핑몰을 한 번에 비교하기 편합니다.

W컨셉 (https://www.wconcept.co.kr/?utm_source=chatgpt.com)

디자이너 브랜드와 트렌디한 패션 아이템이 많아요.

SSF샵 (https://www.ssfshop.com/?utm_source=chatgpt.com)

빈폴·에잇세컨즈 같은 삼성물산 브랜드를 구매할 수 있습니다.

유니클로 코리아 (https://www.uniqlo.com/kr/ko/?utm_source=chatgpt.com)

기본템이나 기능성 의류 구매에 무난합니다.
