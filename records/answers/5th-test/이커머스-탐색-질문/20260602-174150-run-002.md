# 이커머스-탐색-질문 / run 2

## Question

온라인에서 전자기기와 의류를 구매하려는 사람에게 추천할 만한 쇼핑몰을 알려줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

전자기기와 의류를 함께 혹은 각각 잘 구매할 수 있는 온라인 쇼핑몰들을 정리해봤어. 국내 기준으로 접근성과 상품 수, 가격 비교 편의성을 중심으로 골랐어.

전자기기 쇼핑몰

쿠팡 (https://www.coupang.com/?utm_source=chatgpt.com)

로켓배송이 강점이고, 스마트폰·노트북·주변기기 종류가 매우 많아.

11번가 (https://www.11st.co.kr/?utm_source=chatgpt.com)

할인 행사와 카드 혜택이 자주 있어서 가성비 구매에 좋아.

G마켓 (https://www.gmarket.co.kr/?utm_source=chatgpt.com)

컴퓨터 부품, 가전, 해외직구 상품까지 폭넓게 찾을 수 있어.

다나와 (https://www.danawa.com/?utm_source=chatgpt.com)

직접 판매보다는 가격 비교에 특화되어 있어서 최저가 찾기에 유용해.

네이버쇼핑 (https://shopping.naver.com/?utm_source=chatgpt.com)

여러 쇼핑몰 가격과 리뷰를 한 번에 비교하기 편리해.

의류 쇼핑몰

무신사 (https://www.musinsa.com/?utm_source=chatgpt.com)

스트릿·캐주얼 브랜드가 강하고 10~20대에게 특히 인기 많아.

29CM (https://www.29cm.co.kr/?utm_source=chatgpt.com)

감성적인 브랜드와 디자이너 의류가 많아.

지그재그 (https://www.zigzag.kr/?utm_source=chatgpt.com)

여성 의류 쇼핑몰들을 한 번에 모아보기 좋아.

에이블리 (https://chatgpt.com/c/null)

트렌디한 패션과 빠른 배송이 장점이야.

W컨셉 (https://www.wconcept.co.kr/?utm_source=chatgpt.com)

디자이너 브랜드와 깔끔한 스타일 의류가 많아.

전자기기 + 의류 둘 다 구매하기 좋은 곳
