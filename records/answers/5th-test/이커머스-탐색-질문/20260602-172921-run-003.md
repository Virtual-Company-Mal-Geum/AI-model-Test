# 이커머스-탐색-질문 / run 3

## Question

온라인 쇼핑을 하려고 하는데 전자제품과 의류를 구매하기 좋은 사이트를 알려줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

전자제품과 의류를 온라인으로 구매할 때는 가격, 정품 여부, 배송 속도, 리뷰 신뢰도를 같이 보는 게 좋아요. 한국에서 많이 사용하는 곳 기준으로 추천해볼게요.

전자제품 구매 추천 사이트

쿠팡 (https://www.coupang.com/?utm_source=chatgpt.com)

로켓배송이 강점이고, 가전·IT 제품 종류가 매우 많아요.

11번가 (https://www.11st.co.kr/?utm_source=chatgpt.com)

삼성·LG 공식스토어 할인 행사와 카드 혜택이 자주 있어요.

G마켓 (https://www.gmarket.co.kr/?utm_source=chatgpt.com)

가격 비교가 쉬운 편이고 병행수입 제품도 다양해요.

하이마트몰 (https://www.e-himart.co.kr/?utm_source=chatgpt.com)

대형 가전 구매나 설치 서비스가 필요한 경우 좋아요.

전자랜드 쇼핑몰 (https://www.etlandmall.co.kr/?utm_source=chatgpt.com)

노트북·TV·생활가전 특가가 자주 올라와요.

의류 구매 추천 사이트

무신사 (https://www.musinsa.com/?utm_source=chatgpt.com)

스트릿·캐주얼 브랜드가 강하고 리뷰가 자세해요.

29CM (https://www.29cm.co.kr/?utm_source=chatgpt.com)

감성 브랜드와 디자이너 의류를 찾기 좋아요.

지그재그 (https://www.zigzag.kr/?utm_source=chatgpt.com)

여성 의류 쇼핑몰을 한 번에 비교하기 편해요.

W컨셉 (https://www.wconcept.co.kr/?utm_source=chatgpt.com)

디자이너 브랜드와 트렌디한 패션이 많아요.

SSF샵 (https://www.ssfshop.com/?utm_source=chatgpt.com)

삼성물산 계열 브랜드(빈폴·에잇세컨즈 등)를 구매하기 좋아요.
