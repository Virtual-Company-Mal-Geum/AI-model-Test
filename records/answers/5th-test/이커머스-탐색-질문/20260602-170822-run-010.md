# 이커머스-탐색-질문 / run 3

## Question

온라인에서 스마트폰이나 노트북을 구매하려고 하는데 믿을 수 있는 쇼핑몰 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

스마트폰이나 노트북 구매할 때는 정품 보장, AS 대응, 배송 안정성, 후기 신뢰도가 중요한데, 아래 쇼핑몰들이 국내에서 비교적 믿고 많이 사용하는 곳들이에요.

국내 종합 쇼핑몰

쿠팡 (https://www.coupang.com/?utm_source=chatgpt.com)

로켓배송이 강점이고 전자제품 할인도 자주 합니다. 다만 판매자가 다양하니 “공식 판매처” 여부 확인 추천.

11번가 (https://www.11st.co.kr/?utm_source=chatgpt.com)

SK 계열 오픈마켓. 삼성/LG/애플 공식관 할인 이벤트가 자주 있습니다.

G마켓 (https://www.gmarket.co.kr/?utm_source=chatgpt.com)

오래된 대형 오픈마켓이라 후기 데이터가 많고 가격 비교하기 좋습니다.

옥션 (https://www.auction.co.kr/?utm_source=chatgpt.com)

G마켓과 비슷한 계열로 특가 행사 자주 진행합니다.

전자제품 전문 쇼핑몰

하이마트 (https://www.e-himart.co.kr/?utm_source=chatgpt.com)

오프라인 매장 연계가 강점이라 초기 불량 대응이 편한 편입니다.

전자랜드 (https://www.etlandmall.co.kr/?utm_source=chatgpt.com)

가전·노트북 할인 행사 자주 하고 카드 할인도 괜찮습니다.

브랜드 공식 스토어

삼성닷컴 (https://chatgpt.com/c/null)

갤럭시/갤럭시북 구매 시 교육 할인·사전예약 혜택이 강합니다.

Apple Korea (https://www.apple.com/kr/?utm_source=chatgpt.com)

아이폰·맥북 공식 구매처. 학생 할인과 정품 보장이 장점입니다.

LG전자 온라인몰 (https://www.lge.co.kr/?utm_source=chatgpt.com)

LG 그램이나 모니터 구매 시 공식 혜택과 AS가 안정적입니다.

해외 직구도 고려한다면

Amazon (https://www.amazon.com/?utm_source=chatgpt.com)

가격 경쟁력이 좋을 때가 있지만 전압·키보드 배열·AS 조건 확인 필요.

Newegg (https://www.newegg.com/?utm_source=chatgpt.com)

노트북·PC 부품 쪽으로 유명한 미국 쇼핑몰입니다.

팁:

너무 싼 가격은 병행수입/리퍼일 수 있으니 확인하기

“공식 인증 판매점” 여부 체크

카드 할인 + 쿠폰 + 포인트까지 같이 비교

노트북은 특히 AS 정책과 초기 불량 교환 기간 확인 추천
