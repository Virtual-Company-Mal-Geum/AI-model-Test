# 이커머스-탐색-질문 / run 4

## Question

전자기기와 패션 상품을 온라인으로 살 때 이용하기 좋은 쇼핑몰 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

전자기기와 패션은 각각 강점이 다른 쇼핑몰을 쓰는 게 좋아요. 한국 기준으로 많이 쓰이고, 가격·정품 신뢰도·배송·상품 다양성까지 고려해서 추천해볼게요.

전자기기 쇼핑몰

쿠팡 (https://www.coupang.com/?utm_source=chatgpt.com)

로켓배송이 강점이고, 이어폰·노트북·모니터 같은 IT 기기 할인도 자주 열려요. 빠른 배송을 중요하게 생각하면 가장 편한 편입니다.

11번가 (https://www.11st.co.kr/?utm_source=chatgpt.com)

삼성·LG·애플 공식 판매처가 많고 카드 할인 행사도 자주 있습니다.

G마켓 (https://www.gmarket.co.kr/?utm_source=chatgpt.com)

가격 비교하기 좋고 해외직구 전자기기도 다양합니다.

다나와 (https://www.danawa.com/?utm_source=chatgpt.com)

직접 판매보다는 가격 비교 플랫폼에 가까워요. PC 부품·노트북·모니터 최저가 찾을 때 특히 유용합니다.

컴퓨존 (https://www.compuzone.co.kr/?utm_source=chatgpt.com)

PC 부품이나 게이밍 장비 쪽 신뢰도가 높고 조립 PC 구매도 많이 합니다.

애플 공식 스토어 (https://www.apple.com/kr/store?utm_source=chatgpt.com)

아이폰·아이패드·맥북은 공식 스토어가 학생 할인이나 AS 측면에서 안정적입니다.

패션 쇼핑몰

무신사 (https://www.musinsa.com/?utm_source=chatgpt.com)

국내 스트리트·캐주얼 브랜드가 가장 다양하고 리뷰가 많아서 실패 확률이 낮아요.

29CM (https://www.29cm.co.kr/?utm_source=chatgpt.com)

감성 브랜드·디자이너 브랜드 찾기 좋고 사진/큐레이션이 깔끔합니다.

W컨셉 (https://www.wconcept.co.kr/?utm_source=chatgpt.com)

여성 패션과 디자이너 브랜드 쪽이 강합니다.

지그재그 (https://www.zigzag.kr/?utm_source=chatgpt.com)

여러 쇼핑몰을 한 번에 비교하기 좋아요. 트렌디한 옷 찾을 때 편합니다.

에이블리 (https://chatgpt.com/c/null)

저렴하고 트렌드 빠른 상품이 많고 스타일 추천 기능이 강한 편입니다.

SSF SHOP (https://www.ssfshop.com/?utm_source=chatgpt.com)

삼성물산 계열 브랜드(빈폴, 준지 등) 구매하기 좋습니다.
