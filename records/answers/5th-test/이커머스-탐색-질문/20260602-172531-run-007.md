# 이커머스-탐색-질문 / run 7

## Question

스마트폰과 패션 아이템을 안전하게 구매할 수 있는 온라인 쇼핑몰을 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

스마트폰이나 패션 아이템을 살 때는 정품 보장, 환불 정책, 리뷰 시스템, 고객센터 대응이 잘 되어 있는 쇼핑몰을 이용하는 게 좋아요. 아래는 한국에서 비교적 안전하게 많이 사용하는 곳들이에요.

(Samsung, https://www.samsung.com/sec/)
