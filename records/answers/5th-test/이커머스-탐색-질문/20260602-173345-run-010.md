# 이커머스-탐색-질문 / run 10

## Question

온라인 쇼핑을 하려고 하는데 전자제품과 의류를 구매하기 좋은 사이트를 알려줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

전자제품과 의류는 가격 비교, 정품 보장, 배송 속도, 할인 행사 여부를 기준으로 사이트를 나눠서 이용하면 좋아요.

전자제품 구매 추천 사이트

쿠팡 (https://www.coupang.com/?utm_source=chatgpt.com)

로켓배송이 강점이고 전자제품 할인 행사도 자주 열려요.

11번가 (https://www.11st.co.kr/?utm_source=chatgpt.com)

삼성·LG 같은 브랜드 공식 스토어가 많고 카드 할인도 자주 있습니다.

G마켓 (https://www.gmarket.co.kr/?utm_source=chatgpt.com)

다양한 판매자가 있어 가격 비교하기 좋아요.

네이버 쇼핑 (https://shopping.naver.com/?utm_source=chatgpt.com)

여러 쇼핑몰 가격을 한 번에 비교할 수 있어서 최저가 찾기 편합니다.

다나와 (https://www.danawa.com/?utm_source=chatgpt.com)

PC 부품·노트북·가전 비교에 특히 강한 사이트예요.

의류 구매 추천 사이트

무신사 (https://www.musinsa.com/?utm_source=chatgpt.com)

국내 스트릿·캐주얼 브랜드가 많고 후기 시스템이 잘 되어 있어요.

29CM (https://www.29cm.co.kr/?utm_source=chatgpt.com)

감성 브랜드와 디자이너 브랜드를 찾기 좋습니다.

지그재그 (https://www.zigzag.kr/?utm_source=chatgpt.com)

여성 의류 쇼핑몰을 한 번에 비교하기 편해요.

에이블리 (https://chatgpt.com/c/null)

트렌디한 스타일과 저렴한 가격대 제품이 많습니다.

SSF SHOP (https://www.ssfshop.com/?utm_source=chatgpt.com)

삼성물산 패션 브랜드들을 공식으로 구매할 수 있어요.
