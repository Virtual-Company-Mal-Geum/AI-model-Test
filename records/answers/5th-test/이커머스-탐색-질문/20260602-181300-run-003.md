# 이커머스-탐색-질문 / run 3

## Question

온라인으로 상품을 구매할 때 신뢰할 수 있고 후기가 많은 쇼핑몰을 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

한국에서 온라인으로 상품을 살 때는 “후기 수 + 운영 안정성 + 고객센터/반품 체계”를 같이 보는 게 좋아. 아래 쇼핑몰들은 사용자 수가 많고 리뷰가 풍부해서 비교적 신뢰도가 높은 편이야.

쿠팡 (https://www.coupang.com/?utm_source=chatgpt.com)

로켓배송이 강점이고 후기 수가 매우 많아. 생활용품, 전자기기, 식품까지 전반적으로 강함.

네이버 스마트스토어 (https://smartstore.naver.com/?utm_source=chatgpt.com)

판매자별 후기와 구매 인증 리뷰가 많고, 가격 비교가 편리해.

11번가 (https://www.11st.co.kr/?utm_source=chatgpt.com)

전자제품·생활용품 할인 행사가 자주 있음. 리뷰 시스템도 잘 되어 있는 편.

G마켓 (https://www.gmarket.co.kr/?utm_source=chatgpt.com)

오래된 오픈마켓이라 판매자와 후기 데이터가 많음.

옥션 (https://www.auction.co.kr/?utm_source=chatgpt.com)

G마켓과 비슷한 계열로 상품 수가 많고 리뷰 참고하기 좋음.

SSG.COM (https://www.ssg.com/?utm_source=chatgpt.com)

신세계 계열이라 식품·브랜드 제품 신뢰도가 높은 편.

오늘의집 (https://ohou.se/?utm_source=chatgpt.com)

가구·인테리어 제품 리뷰 사진이 많아서 실제 사용 느낌 보기 좋음.

무신사 스토어 (https://store.musinsa.com/?utm_source=chatgpt.com)

의류·패션 분야에서 후기와 사이즈 리뷰가 매우 자세함.

29CM (https://www.29cm.co.kr/?utm_source=chatgpt.com)

감성 브랜드·디자인 제품 위주. 리뷰 품질이 좋은 편.

알리익스프레스 코리아 (https://chatgpt.com/c/null)

해외직구용. 후기 수는 압도적으로 많지만 판매자 평점과 리뷰 사진을 꼭 확인하는 게 중요함.
