# 이커머스-탐색-질문 / run 8

## Question

온라인으로 상품을 구매할 때 신뢰할 수 있고 후기가 많은 쇼핑몰을 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

카테고리별로 많이 쓰이고 후기·구매량이 풍부한 온라인 쇼핑몰들을 정리해볼게.

한국 기준으로 접근성과 신뢰도를 우선해서 골랐어.

종합 쇼핑몰

쿠팡 (https://www.coupang.com/?utm_source=chatgpt.com)

배송 속도가 빠르고 리뷰 수가 매우 많아서 제품 비교가 쉬움.

네이버 스마트스토어 (https://shopping.naver.com/?utm_source=chatgpt.com)

실사용 후기와 사진 리뷰가 많고 가격 비교가 편리함.

11번가 (https://www.11st.co.kr/?utm_source=chatgpt.com)

오래된 대형 오픈마켓이라 판매자 수와 후기 데이터가 풍부함.

G마켓 (https://www.gmarket.co.kr/?utm_source=chatgpt.com)

다양한 브랜드와 해외직구 상품까지 폭넓게 구매 가능.

옥션 (https://www.auction.co.kr/?utm_source=chatgpt.com)

할인 행사와 중소 판매자 상품이 많은 편.

전자제품/IT

다나와 (https://www.danawa.com/?utm_source=chatgpt.com)

최저가 비교와 사용자 리뷰 확인에 강함.

컴퓨존 (https://www.compuzone.co.kr/?utm_source=chatgpt.com)

PC 부품·노트북 구매 시 신뢰도가 높은 편.

하이마트 (https://www.e-himart.co.kr/?utm_source=chatgpt.com)

가전제품 공식 유통과 AS 측면에서 안정적임.

패션/라이프스타일

무신사 (https://www.musinsa.com/?utm_source=chatgpt.com)

국내 패션 플랫폼 중 후기와 착용 사진이 매우 많음.

29CM (https://www.29cm.co.kr/?utm_source=chatgpt.com)

디자인·라이프스타일 브랜드 큐레이션이 강점.

W컨셉 (https://www.wconcept.co.kr/?utm_source=chatgpt.com)

여성 패션과 디자이너 브랜드 비중이 큼.

해외직구

아마존 (https://www.amazon.com/?utm_source=chatgpt.com)

글로벌 최대 규모라 리뷰 수와 신뢰성이 높음.

알리익스프레스 (https://chatgpt.com/c/null)

저렴한 제품이 많지만 판매자 평점 확인이 중요함.

아이허브 (https://kr.iherb.com/?utm_source=chatgpt.com)

건강식품·영양제 직구에서 인기 많음.
