# beginner-marketing-practical-course / run 2

## Question

초보자가 들을 만한 마케팅 실무 강의 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://github.com/)

## Answer

초보자가 “마케팅 실무”를 배우기 좋은 강의는 크게 국내 실무형 플랫폼 + 글로벌 입문형 강의로 나눠서 보는 게 좋아. 아래는 실제로 입문자들이 많이 시작하는 곳 위주로 정리했어.

1. 인프런 (국내 실무 마케팅 입문 1순위)

실무 마케터, 창업자 강의가 많아서 “바로 써먹는 구조”로 배울 수 있음

네이버 블로그, 인스타그램, 퍼포먼스 마케팅 기초까지 다양

(인프런, https://www.inflearn.com/)

2. 패스트캠퍼스 (체계적인 커리큘럼형)

“마케팅 전반 로드맵”처럼 단계별로 배우기 좋음

브랜드 마케팅 / 퍼포먼스 마케팅 / 콘텐츠 전략까지 포함된 과정 많음

(패스트캠퍼스, https://fastcampus.co.kr/)

3. 클래스101 (입문 + 크리에이터/콘텐츠 마케팅 강점)

초보자가 이해하기 쉽게 설명하는 강의가 많음

개인 브랜드, SNS 운영, 콘텐츠 제작 쪽에 특히 강함

(클래스101, https://class101.net/)

4. 유데미 Udemy (가성비 + 글로벌 실무)

해외 실무 마케터들이 만든 강의 많음

SEO, 구글 광고, 디지털 마케팅 기초 배우기 좋음 (할인 자주 있음)

(Udemy, https://www.udemy.com/)

5. 구글 디지털 마케팅 기초 (무료 + 공신력)

완전 초보용 “마케팅 개념 잡기”에 좋음

광고, 데이터, 디지털 전략 기본 구조 이해 가능

(Google Digital Garage, https://learndigital.withgoogle.com/)

추천 정리 (빠른 선택 가이드)

완전 초보 → 클래스101 / 구글 디지털 기초

실무 취업 준비 → 인프런 / 패스트캠퍼스

해외 스킬까지 → Udemy

원하면

👉 “SNS 마케팅만 집중해서 배우는 코스”

👉 “취업용 마케팅 포트폴리오 만드는 법”

이렇게도 딱 맞춰서 커리큘럼 짜줄게.
