# beginner-marketing-practical-course / run 4

## Question

초보자가 들을 만한 마케팅 실무 강의 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

초보자가 마케팅 실무를 배우기 좋은 강의/플랫폼을 난이도 낮은 순서 + 실무 활용도 기준으로 추천해볼게.

1. Google Digital Garage (기초 마케팅 무료)
디지털 마케팅 전반(SEO, 광고, 분석)을 가장 기초부터 설명해주는 무료 강의야.

실무 입문 전에 개념 잡기 좋음.

(Google Digital Garage, )

2. Meta Blueprint (SNS 광고 실무)
인스타그램/페이스북 광고를 직접 세팅하는 방법을 배우는 실무형 강의.

(Meta Blueprint, )

3. Inflearn (인프런 – 국내 실무 강의 많음)
한국형 마케팅 실무 강의가 가장 다양하게 있는 플랫폼.

콘텐츠 마케팅, 퍼포먼스 마케팅, 브랜드 마케팅까지 초보자용 강의 많음.

(Inflearn, )

4. FastCampus (패스트캠퍼스 – 실무 집중 코스)
취업/이직용으로 많이 듣는 실전 중심 강의.

퍼포먼스 마케팅, 데이터 기반 광고 운영 과정이 강점.

(FastCampus, )

5. CLASS101 (클래스101 – 콘텐츠/브랜딩 입문)
SNS 콘텐츠 제작, 개인 브랜딩, 소규모 브랜드 마케팅 입문에 좋음.

(CLASS101, )

원하면

👉 “취업용 / 프리랜서용 / 쇼핑몰 마케팅용” 이렇게 목적에 맞춰서 강의만 따로 추려서도 추천해줄게.
