# beginner-marketing-practical-course / run 5

## Question

초보자가 들을 만한 마케팅 실무 강의 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

초보자가 “실무 중심”으로 시작하기 좋은 마케팅 강의/플랫폼을 난이도 낮은 순서 + 활용도 기준으로 정리해볼게.

1) Google 디지털 마케팅 기초 과정
(Google)

(Google 디지털 장인 인증 과정 포함)

SEO, 광고, 데이터 분석 기초까지 무료로 학습 가능

(Google Digital Garage, https://learndigital.withgoogle.com/digitalgarage/)

2) HubSpot 아카데미 (인바운드 마케팅 실무)
(HubSpot)

콘텐츠 마케팅 / 이메일 마케팅 / 퍼널 구조 이해에 좋음

실무용 프레임워크를 무료로 배울 수 있음

(HubSpot Academy, https://academy.hubspot.com/)

3) Meta Blueprint (SNS 광고 실무)
(Meta)

인스타그램/페이스북 광고 집행 구조 학습

광고 운영 실무 입문용으로 좋음

(Meta Blueprint, https://www.facebook.com/business/learn)

4) Coursera 마케팅 과정 (전반 기초 + 데이터 포함)
(Coursera)

대학/기업 연계 강의 (기초~중급까지 다양)

디지털 마케팅 전체 구조 잡기 좋음

(Coursera, https://www.coursera.org/)

5) Udemy 실무형 마케팅 강의 (가성비)
(Udemy)

SEO, 퍼포먼스 마케팅, 광고 세팅 실무 강의 다양

가격 할인 자주 있어서 입문용으로 접근 쉬움

(Udemy, https://www.udemy.com/)

6) 인프런 (한국 실무 마케팅 강의)
(Inflearn)

국내 마케터들이 만든 실전형 강의 많음

네이버/쿠팡/스타트업 기반 실무 내용 있음

(Inflearn, https://www.inflearn.com/)

7) 패스트캠퍼스 (실무 부트캠프형)
(Fast Campus)

퍼포먼스 마케팅, 브랜드 마케팅 집중 과정

취업/이직 목적이면 가장 실무적

(Fast Campus, https://fastcampus.co.kr/)

8) 클래스101 (콘텐츠/브랜딩 감각용)
(Class101)

SNS 콘텐츠 제작, 브랜딩 감각 쌓기 좋음

마케팅 “감” 잡는 용도

(Class101, https://class101.net/)

원하면

👉 “취업용 마케팅 로드맵 (3개월/6개월)”

👉 “퍼포먼스 마케팅 vs 브랜드 마케팅 차이”

👉 “지금 바로 시작할 강의 1개만 추천”

이렇게도 딱 맞춰서 정리해줄게.
