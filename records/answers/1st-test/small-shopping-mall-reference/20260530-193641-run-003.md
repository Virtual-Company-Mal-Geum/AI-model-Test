# small-shopping-mall-reference / run 3

## Question

소규모 쇼핑몰이 참고할 만한 자사몰 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://github.com/)

## Answer

소규모 브랜드가 참고하기 좋은 자사몰(D2C) 성공 사례를 “브랜딩 / UX / 콘텐츠 / 전환 구조” 기준으로 골라서 정리해줄게. 각 사이트는 실제 운영 중인 대표 자사몰이야.

1) 마르디 메크르디 (Mardi Mercredi)

(마르디 메크르디, https://mardimercredi.com (https://mardimercredi.com/))

감성 브랜드 자사몰의 대표 사례 (꽃 프린팅 + 미니멀 UX)

핵심 포인트: 브랜드 무드 + 단순한 구매 흐름 + 강한 시그니처 디자인

2) 무신사 스탠다드

(무신사 스탠다드, https://musinsa.com/brands/musinsa_standard (https://chatgpt.com/c/null))

패션 기반 자사몰 + 플랫폼형 커머스

핵심 포인트: 상품 페이지 구조, 리뷰 시스템, 필터 UX

3) 29CM (큐레이션형 자사몰)

(29CM, https://www.29cm.co.kr (https://www.29cm.co.kr/))

“취향 큐레이션” 중심의 콘텐츠 커머스

핵심 포인트: 스토리 기반 상품 소개 + 매거진형 상세페이지

4) 아비브 (ABIB)

(ABIB, https://abib.com (https://abib.com/))

스킨케어 브랜드 자사몰 (클린 디자인)

핵심 포인트: 제품 신뢰감 UX + 성분 중심 정보 구조

5) 락피쉬 웨더웨어

(락피쉬 웨더웨어, https://rockfish-weatherwear.com (https://chatgpt.com/c/null))

시즌감 + 룩북 중심 패션 자사몰

핵심 포인트: 비주얼 중심 전환 구조 (Lookbook → 구매)

6) 조말론 런던 (D2C 글로벌 자사몰 예시)

(Jo Malone London, https://www.jomalone.com (https://www.jomalone.com/))

럭셔리 브랜드 자사몰 UX 표준

핵심 포인트: 제품 탐색 경험 + 향/감성 스토리텔링

공통적으로 참고할 포인트 (핵심만)
소규모 쇼핑몰 기준으로 보면 이 3개가 가장 중요해:

첫 화면 = 브랜드 느낌 (사진/무드)

상품 페이지 = 정보보다 “구매 확신 구조”

리뷰/후기 = 전환율 핵심 요소

카테고리 구조 = 3~5개로 단순화

원하면

👉 “카페24/아임웹 기준으로 이렇게 따라 만들면 되는 구조”

👉 “월 100~1000만원 자사몰 구조 템플릿”

이런 식으로 더 실전용으로도 정리해줄게.
