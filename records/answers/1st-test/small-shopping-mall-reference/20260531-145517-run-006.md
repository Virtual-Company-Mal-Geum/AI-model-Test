# small-shopping-mall-reference / run 6

## Question

소규모 쇼핑몰이 참고할 만한 자사몰 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

패션/라이프스타일 기준으로, 규모는 크지 않지만 브랜딩·디자인·상세페이지·콘텐츠 구성이 잘 되어 있어서 참고하기 좋은 자사몰들이야.

KHIHO (https://en.khiho.com/?utm_source=chatgpt.com) — 미니멀한 UI, 룩북 중심 구성, 브랜드 무드 연출 참고용

SOLEW (https://solewofficial.com/?utm_source=chatgpt.com) — 감도 높은 브랜딩과 제품 상세페이지 구성이 깔끔함

JKND (https://jknd.com/?utm_source=chatgpt.com) — 브랜드 스토리텔링과 콘텐츠 아카이빙 참고용

Everlane (https://www.everlane.com/?utm_source=chatgpt.com) — 제품 정보 전달, 투명한 브랜드 메시지 구성 참고용

Allbirds (https://www.allbirds.com/?utm_source=chatgpt.com) — 친환경 브랜딩과 제품 페이지 UX가 강점

Glossier (https://www.glossier.com/?utm_source=chatgpt.com) — 커뮤니티 기반 D2C 브랜딩 참고용

Away (https://www.awaytravel.com/?utm_source=chatgpt.com) — 라이프스타일 콘텐츠와 제품 스토리텔링이 뛰어남

Modern Citizen (https://www.moderncitizen.com/?utm_source=chatgpt.com) — 깔끔한 여성 패션몰 레이아웃 참고용

Ridge Wallet (https://ridge.com/?utm_source=chatgpt.com) — 단일 카테고리 제품을 강하게 브랜딩하는 방식 참고용

Ader Error (https://adererror.com/?utm_source=chatgpt.com) — 감각적인 비주얼 중심 쇼핑 경험 참고용

특히 소규모 쇼핑몰이라면 아래 4가지는 꼭 분석해보는 걸 추천해:

KHIHO → 미니멀 브랜드 운영 방식

SOLEW → 국내 디자이너 브랜드 구조

Everlane → 상품 상세페이지 설계

Glossier → SNS와 자사몰 연결 방식

어떤 카테고리(의류, 여성의류, 스트릿, 액세서리, 라이프스타일, 뷰티 등) 쇼핑몰을 만들 예정인지 알려주면 그 분야에 맞춰 더 구체적으로 추천해줄게.
