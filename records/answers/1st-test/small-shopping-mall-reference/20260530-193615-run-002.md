# small-shopping-mall-reference / run 2

## Question

소규모 쇼핑몰이 참고할 만한 자사몰 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://github.com/)

## Answer

소규모 쇼핑몰이 참고하기 좋은 국내/해외 자사몰(D2C) 사례를 “운영 구조나 UX, 브랜드 경험” 중심으로 골라서 정리해볼게. 요청한 형식대로 (이름, URL)도 같이 적어줄게.

🛍️ 소규모 쇼핑몰 참고용 자사몰 추천
1. Nike (나이키 D2C)

https://www.nike.com/kr

글로벌 대표 D2C 사례.

브랜드 중심 UI, 개인화 추천, 멤버십 구조가 매우 강력해서 “브랜드 쇼핑몰이 어떻게 팬을 만드는지” 보기 좋음. 모비인사이드 MOBIINSIDE (https://www.mobiinside.co.kr/2023/04/21/d2c-business/?utm_source=chatgpt.com)

2. MUSINSA (무신사 스토어)

https://www.musinsa.com (https://www.musinsa.com/)

패션 기반 커머스지만 사실상 “브랜드+커뮤니티+콘텐츠”가 합쳐진 자사몰 구조.

상품보다 스타일/콘텐츠 중심 UX 참고용으로 좋음.

3. 29CM

https://www.29cm.co.kr (https://www.29cm.co.kr/)

감성 큐레이션형 자사몰.

“왜 이 제품을 사야 하는지” 스토리텔링을 잘하는 대표 사례.

4. Olive Young (올리브영 온라인몰)

https://www.oliveyoung.co.kr (https://www.oliveyoung.co.kr/)

뷰티 카테고리 UX 참고용 최고 사례 중 하나.

랭킹/리뷰/추천 흐름이 매우 잘 설계됨.

5. Market Kurly (마켓컬리)

https://www.kurly.com (https://www.kurly.com/)

식품 자사몰 UX 대표 사례.

배송 경험 + 큐레이션 + 재구매 구조 참고하기 좋음.

6. Apple Store (애플 공식몰)

https://www.apple.com/kr/store

가장 “깔끔한 D2C UX”의 정석.

제품 집중형 디자인 + 옵션 구성 방식 참고 가치 높음.

7. LEGO Shop (레고 공식몰)

https://www.lego.com/ko-kr

굿즈/팬덤 기반 자사몰 구조 참고하기 좋음.

회원제 + 추천 + 테마 판매 방식이 강점.

8. Nike SNKRS (스니커즈 전용 D2C)

https://www.nike.com/kr/launch

한정판 판매 UX, 드롭(drop) 구조, 팬덤 기반 구매 설계 참고용.

💡 한 줄 정리

브랜드 경험 → Nike / Apple

콘텐츠형 커머스 → 29CM / 무신사

구매 UX 최적화 → 올리브영 / 마켓컬리

팬덤/한정판 구조 → LEGO / SNKRS

원하면

👉 “쇼핑몰 기획 관점에서 꼭 따라야 할 구조 (홈/상품/상세/결제 흐름)”

👉 “카페24/쇼피파이 기준으로 비슷하게 만드는 방법”

이것도 같이 정리해줄게.
