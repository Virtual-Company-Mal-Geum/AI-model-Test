# small-shopping-mall-reference / run 1

## Question

소규모 쇼핑몰이 참고할 만한 자사몰 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://github.com/)

## Answer

소규모 쇼핑몰이 참고하기 좋은 “자사몰(D2C) 잘 만든 사례”들을 몇 개 유형별로 정리해볼게. 실제로 UI/브랜딩/구매 흐름이 잘 설계된 곳들 위주야.

패션/라이프스타일 (브랜딩 중심 자사몰)

(Musinsa, https://www.musinsa.com (https://www.musinsa.com/))

→ 상품 큐레이션 + 콘텐츠형 상세페이지 구조가 강점

(29CM, https://www.29cm.co.kr (https://www.29cm.co.kr/))

→ “감성 콘텐츠 + 스토리텔링 중심” 자사몰 UX 대표 사례

(Ohouse (오늘의집), https://ohou.se (https://ohou.se/))

→ 커뮤니티 + 상품 구매가 자연스럽게 연결되는 구조

식품/리빙 (신뢰 + 재구매 구조)

(Market Kurly, https://www.kurly.com (https://www.kurly.com/))

→ 새벽배송 UX + 상세페이지 품질 + 반복 구매 설계

뷰티 (D2C 글로벌 확장형)

(COSRX, https://www.cosrx.com (https://www.cosrx.com/))

→ 글로벌 자사몰 + 단순한 구매 구조 + 성분 중심 설득

(Beauty of Joseon, https://beautyofjoseon.com (https://beautyofjoseon.com/))

→ 브랜드 스토리 + 한방 컨셉 + 해외 D2C 전환 잘된 사례

글로벌 D2C 표준형

(Nike, https://www.nike.com (https://www.nike.com/))

→ 개인화 추천, 멤버십 기반 락인 구조

(Apple, https://www.apple.com (https://www.apple.com/))

→ 제품 설명 단순화 + 구매 흐름 최소 단계화

한 줄 정리 (핵심만)
소규모 자사몰이 참고할 포인트는 딱 3개야:

“스토리형 상세페이지 (29CM 스타일)”

“반복구매 구조 (컬리 스타일)”

“콘텐츠+커뮤니티 결합 (오늘의집 스타일)”

원하면

👉 “초보 쇼핑몰이 그대로 따라 만들 수 있는 구조(섹션/페이지 구성)”도 같이 정리해줄게.
