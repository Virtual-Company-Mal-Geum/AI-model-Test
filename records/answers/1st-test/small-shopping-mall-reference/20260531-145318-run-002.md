# small-shopping-mall-reference / run 2

## Question

소규모 쇼핑몰이 참고할 만한 자사몰 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

소규모 쇼핑몰이라면 단순히 “예쁜 디자인”보다 브랜딩, 상품 상세페이지, 커뮤니티 운영, 콘텐츠 구성을 참고하는 게 더 도움이 됩니다.

국내 패션/라이프스타일 자사몰 기준으로 추천할 만한 곳들입니다.

PREVAIL (https://prevail.kr/?utm_source=chatgpt.com) — 스트릿·캐주얼 브랜드. 깔끔한 카테고리 구성과 브랜드 아이덴티티 표현이 좋음. PREVAIL 프리베일 | OFFICIAL STORE (https://prevail.kr/?utm_source=chatgpt.com)

threetimes (https://threetimes.kr/?utm_source=chatgpt.com) — 강한 브랜드 감성과 비주얼 중심의 쇼핑 경험 참고하기 좋음. 60%（SIXTYPERCENT） (https://global.sixty-percent.com/shops/threetimes?utm_source=chatgpt.com)

Et demain (https://etdemain.co.kr/?utm_source=chatgpt.com) — 룩북, 매거진, 팝업 소식 등 콘텐츠 운영 방식이 인상적임. 엣드맹(Et demain) (https://etdemain.co.kr/?utm_source=chatgpt.com)

bcurve (https://bcurve.kr/?utm_source=chatgpt.com) — 비교적 작은 규모에서도 브랜드 스토리와 상품을 자연스럽게 연결하는 구조. bcurve(비커브) (https://bcurve.kr/brand.html?utm_source=chatgpt.com)

COME INTO STYLE (https://comeintostyle.co.kr/?utm_source=chatgpt.com) — 미니멀한 여성복 쇼핑몰로 상세페이지와 이벤트 구성이 참고할 만함. COME INTO STYLE (https://comeintostyle.co.kr/?utm_source=chatgpt.com)

JKND (https://jknd.com/?utm_source=chatgpt.com) — 브랜드 세계관과 콘텐츠를 어떻게 보여주는지 참고하기 좋은 사례. JKND │ 제이케이앤디 (https://jknd.com/?utm_source=chatgpt.com)

Wanderlust Atelier (https://www.wanderlustatelier.com/?utm_source=chatgpt.com) — 고급스러운 비주얼과 큐레이션 중심의 메인 페이지 구성이 특징. wanderlustatelier.com (https://www.wanderlustatelier.com/?utm_source=chatgpt.com)

해외 자사몰도 참고하면 좋은데요.

Glossier (https://www.glossier.com/?utm_source=chatgpt.com) — D2C 브랜딩의 대표 사례. 제품보다 브랜드 경험을 먼저 판매함. Solo Blog (https://blog.soloist.ai/ecommerce-website-examples/?utm_source=chatgpt.com)

KITH (https://kith.com/?utm_source=chatgpt.com) — 룩북, 매거진, 협업 콘텐츠 활용이 뛰어남. Reddit (https://www.reddit.com/r/ChinaDropship/comments/1fwjy93?utm_source=chatgpt.com)

Paloma Wool (https://palomawool.com/?utm_source=chatgpt.com) — 감성 브랜딩과 커뮤니티 구축 방식 참고하기 좋음. Vogue (https://www.voguebusiness.com/story/fashion/inside-palomas-world?utm_source=chatgpt.com)

Miista (https://www.miista.com/?utm_source=chatgpt.com) — 프리미엄 브랜드가 자사몰 경험을 어떻게 설계하는지 볼 수 있음. Vogue (https://www.vogue.com/article/why-miista-is-thriving-in-fashions-most-punishing-era?utm_source=chatgpt.com)

특히 이제 막 자사몰을 만드는 단계라면 PREVAIL, threetimes, Et demain, Glossier 이 4곳은 꼭 살펴보는 걸 추천합니다. 각각 브랜드 스토리텔링, 비주얼, 상품 상세페이지, 회원 전환 구조를 배우기에 좋은 사례입니다.
