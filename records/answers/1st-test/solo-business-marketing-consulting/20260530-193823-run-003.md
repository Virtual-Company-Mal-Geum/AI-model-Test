# solo-business-marketing-consulting / run 3

## Question

1인 사업자가 쓸 만한 마케팅 컨설팅 서비스 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://github.com/)

## Answer

1인 사업자가 마케팅을 직접 하거나 외주로 맡길 때 많이 쓰는 “마케팅 컨설팅/실행 지원 서비스”들을 현실적으로 쓸 만한 것들 위주로 정리해줄게. (특히 한국에서 1인 사업자가 많이 쓰는 곳 기준)

1. 크몽 (프리랜서 마케팅 컨설팅 마켓)

(크몽, https://kmong.com/)

👉 특징

마케팅 전략, 광고 세팅, SNS 운영, 상세페이지 제작까지 1:1로 외주 가능

“1인 사업자 맞춤 컨설팅” 판매자가 많음

가격대가 5만~100만원대까지 다양해서 초기 사업자에게 현실적

👉 추천 이유

“컨설팅 + 실행(광고 세팅)”까지 한 번에 맡기기 좋음

2. 숨고 (Soomgo)

(숨고, https://soomgo.com/)

👉 특징

마케팅 전문가에게 견적 요청 → 여러 전문가가 제안

광고운영, 인스타 마케팅, 브랜딩, 블로그 SEO 가능

1인 사업자/소상공인 의뢰가 매우 많음

👉 추천 이유

비교 견적 구조라서 초보자가 가격/실력 비교하기 좋음

3. 오투잡 (Otwojob)

(오투잡, https://otwojob.com/ (https://chatgpt.com/c/null))

👉 특징

간단한 작업 중심 (배너, 상세페이지, SNS 콘텐츠)

소규모 마케팅 실행 외주에 강점

빠르게 작업 맡기기 좋음

👉 추천 이유

“컨설팅보다는 실행형 작업”이 필요할 때 좋음

4. 위시켓 (Wishket, 기업형 프리랜서 플랫폼)

(위시켓, https://www.wishket.com/)

👉 특징

마케팅 전략 + 웹/앱 제작 + 광고 캠페인까지 가능

검증된 프리랜서/에이전시 중심

조금 더 “사업 구조 설계” 수준까지 가능

👉 추천 이유

매출이 어느 정도 있는 1인 사업자에게 적합

5. 프립 (F-Lab 계열이 아니라 “프리랜서/클래스 기반 마케팅 컨설팅”)

(프립, https://www.frip.co.kr/)

👉 특징

실제 마케팅 전문가들이 “1:1 코칭/강의” 형태 제공

브랜드 성장, SNS 운영 전략, 콘텐츠 기획 중심

👉 추천 이유

단순 외주보다 “직접 배우면서 성장”하고 싶을 때 좋음

한줄 정리 (선택 기준)

빠르게 외주 + 저렴 → 크몽 / 오투잡

비교 견적 받고 싶다 → 숨고

사업 구조까지 설계 → 위시켓

직접 배우고 성장 → 프립

원하면

👉 “월 100만원 이하 마케팅 전략”

👉 “1인 쇼핑몰 기준 실제 광고 세팅 방법”

👉 “인스타 vs 네이버 뭐부터 해야 하는지”

이런 식으로 더 현실적인 실행 플랜도 같이 만들어줄게.
