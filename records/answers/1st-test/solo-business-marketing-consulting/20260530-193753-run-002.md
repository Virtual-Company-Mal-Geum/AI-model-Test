# solo-business-marketing-consulting / run 2

## Question

1인 사업자가 쓸 만한 마케팅 컨설팅 서비스 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://github.com/)

## Answer

1인 사업자(프리랜서, 온라인 쇼핑몰, 로컬 비즈니스 포함)가 많이 쓰는 마케팅 컨설팅/실행 서비스를 실사용 기준으로 정리해볼게. (전략 컨설팅 + 실무 대행 + 교육형으로 나눴어)

1. 크몽 (Kmong) – 1:1 마케팅 컨설팅 & 실행 대행
개인 사업자가 가장 많이 쓰는 플랫폼 중 하나야.

브랜딩, 광고, 스마트스토어, SNS 마케팅까지 전부 분야별 전문가를 선택해서 받을 수 있음.

특징: 단건 컨설팅 / 패키지 실행 / 가격 다양

추천 대상: “당장 매출 만들고 싶은 1인 사업자”

(크몽, https://kmong.com (https://kmong.com/)) 크몽 (https://kmong.com/gig/374384?utm_source=chatgpt.com)

2. 탈잉 (Taling) – 마케팅 수업 + 1:1 코칭
컨설팅보다는 “실행 가능한 교육 + 코칭” 스타일이 강함.

SNS 마케팅, 콘텐츠 제작, 퍼포먼스 마케팅 강의가 많음.

특징: 클래스 + 과외형 코칭

추천 대상: “직접 배우면서 운영하고 싶은 사람”

(탈잉, https://taling.me (https://taling.me/))

3. 위시켓 (Wishket) – 마케팅 외주 & 전략 프로젝트
디자인/광고/마케팅 캠페인까지 프로젝트 단위로 맡길 수 있음.

브랜딩이나 광고 세팅 같이 “조금 큰 작업”에 적합.

특징: 기업/프리랜서 매칭 플랫폼

추천 대상: “쇼핑몰 브랜딩, 광고 세팅 외주 맡기고 싶은 경우”

(위시켓, https://wishket.com (https://chatgpt.com/c/null))

4. 숨고 (Soomgo) – 지역/개인 맞춤 마케팅 전문가 매칭
로컬 기반 서비스(카페, 학원, 운동시설 등)에서 특히 많이 씀.

광고 대행, SNS 운영, 상세페이지 제작 등 가능.

특징: 빠른 견적 비교 / 개인 전문가 매칭

추천 대상: “가볍게 테스트로 마케팅 맡겨보고 싶은 경우”

(숨고, https://soomgo.com (https://soomgo.com/))

5. 오픈애즈 (OpenAds) – 광고/마케팅 전략 자료 + 컨설턴트 연결
실무 마케팅 정보 + 광고 플랫폼 활용법 + 전문가 연결까지 있음.

특징: 데이터 기반 마케팅 정보 강점

추천 대상: “광고 운영 자체를 배우고 싶은 사람”

(오픈애즈, https://www.openads.co.kr (https://www.openads.co.kr/))

6. 프립 / 클래스101 (콘텐츠형 마케팅 교육)
직접 컨설팅보다는 콘텐츠 기반으로 브랜딩, 콘텐츠 마케팅 배우는 용도.

특징: 브랜딩/콘텐츠 중심 교육

추천 대상: “장기적으로 브랜드 키우고 싶은 1인 사업자”

(클래스101, https://class101.net (https://class101.net/))

한 줄 정리

빠르게 매출 개선 → 크몽 / 숨고

배우면서 운영 → 탈잉 / 클래스101

외주 프로젝트 → 위시켓

데이터/광고 전략 → 오픈애즈

원하면

👉 “1인 쇼핑몰 기준으로 실제 매출 나는 마케팅 구조”

👉 “월 100~300 만드는 SNS 마케팅 전략”

이런 식으로 더 실전형으로도 정리해줄게.
