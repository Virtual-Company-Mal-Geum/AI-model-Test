# solo-business-marketing-consulting / run 1

## Question

1인 사업자가 쓸 만한 마케팅 컨설팅 서비스 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://github.com/)

## Answer

1인 사업자가 활용하기 좋은 마케팅 컨설팅 서비스는 “전략 수립 + 실행 지원 + 저비용/온라인 대응”이 가능한 곳을 고르는 게 핵심입니다. 아래는 실제로 1인 사업자/소상공인들이 많이 쓰는 서비스들입니다.

1. 크몽 (프리랜서 마케팅 컨설팅 플랫폼)
(크몽, https://kmong.com (https://kmong.com/))

1:1 마케팅 컨설턴트를 바로 구매해서 이용

SNS 광고, 브랜딩, 상세페이지, 스마트스토어 운영 등 세분화

예산에 맞춰 5~50만원대 소액 컨설팅도 가능

1인 사업자가 “가장 현실적으로 접근하기 쉬운 플랫폼”

👉 특징: “필요할 때만 전문가를 쓰는 구조”

2. 숨고 (전문가 매칭 서비스)
(숨고, https://soomgo.com (https://soomgo.com/))

마케팅 전문가 요청하면 여러 견적이 들어오는 구조

네이버 플레이스, 인스타그램, 광고운영, 브랜딩 등 다양

비교 후 선택 가능해서 비용 효율 좋음

초보 1인 사업자가 테스트하기 좋음

👉 특징: “여러 전문가 견적 비교 가능”

3. 프립 (소상공인/개인 브랜딩 클래스 + 컨설팅)
(프립, https://www.frip.co.kr (https://www.frip.co.kr/))

단순 컨설팅이 아니라 실전형 교육 + 코칭 형태

SNS 마케팅, 브랜딩, 콘텐츠 제작 교육 중심

1인 브랜드 구축 단계에서 도움됨

👉 특징: “직접 배우면서 사업 구조 잡기 좋음”

4. 위시켓 (외주형 마케팅/디지털 프로젝트)
(위시켓, https://www.wishket.com (https://www.wishket.com/))

마케팅 대행 + 웹사이트 + 광고 운영 외주 가능

규모 있는 프로젝트도 가능하지만 소규모도 대응

쇼핑몰 운영자, 스타트업이 많이 사용

👉 특징: “실행까지 맡기는 외주형 플랫폼”

5. 1인 창업/컨설팅 전문 크리에이터 (온라인 컨설팅)
(예: https://kmong.com (https://kmong.com/) / https://soomgo.com (https://soomgo.com/) 기반 개별 전문가)

“1인 사업 맞춤 컨설팅” 전문 판매자 존재

브랜드 전략, 고객 확보, 퍼널 설계 등 제공

단순 광고보다 “수익 구조 설계” 중심

👉 특징: “실행보다 방향 잡는 데 강함”

한줄 정리

실행형(바로 도움 필요) → 크몽, 숨고

배우면서 성장 → 프립

외주/운영 대행 → 위시켓

전략 설계 중심 → 1:1 컨설턴트 (크몽/숨고)

원하면

👉 “월 0~100만원 1인 사업자 기준 추천 컨설팅 조합”

👉 “스마트스토어 / 인스타 / 로컬 비즈니스별로 어떤 컨설팅이 맞는지”

이렇게 더 구체적으로도 정리해줄게.
