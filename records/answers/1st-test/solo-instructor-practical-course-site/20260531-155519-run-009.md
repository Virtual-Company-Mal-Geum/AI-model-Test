# solo-instructor-practical-course-site / run 9

## Question

1인 강사가 운영하는 실무 강의 사이트 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

1인 강사가 실무 강의(=VOD/라이브/코칭형 콘텐츠)를 운영하기 좋은 플랫폼은 “강사 등록이 열려 있고, 실제 수익화 구조가 잡혀 있는 곳”이 핵심입니다. 아래는 국내·글로벌 기준으로 많이 쓰이는 곳들입니다.

1. 인프런 (Inflearn)
개인 강사가 가장 많이 시작하는 실무형 강의 플랫폼입니다. IT, 마케팅, 데이터, AI 같은 실무 강의에 특히 강합니다.

(인프런, https://www.inflearn.com/)

2. 클래스101 (CLASS101)
디자인·영상·브랜딩·부업·창업 등 “콘텐츠 크리에이터형 강의”에 강한 플랫폼입니다. 제작·촬영 지원도 있어 초보 강사 진입이 쉬운 편입니다.

(클래스101, https://class101.net/)

3. 탈잉 (Taling)
실무 중심 1:1 코칭 + 소규모 클래스 운영에 강점이 있는 플랫폼입니다. 온라인/오프라인 혼합 강의도 가능해서 코치형 강사에게 적합합니다.

(탈잉, https://taling.me/)

4. 유데미 (Udemy)
글로벌 시장까지 판매 가능한 대표적인 오픈 강의 플랫폼입니다. 영어/한국어 모두 가능하고, 한 번 만든 강의로 장기 판매가 가능합니다.

(유데미, https://www.udemy.com/)

5. 패스트캠퍼스 (FastCampus)
실무 직무 교육(개발, 데이터, AI, 비즈니스)에 특화된 고급형 플랫폼입니다. 커리큘럼 기반으로 전문 강사 형태로 입점하는 구조입니다.

(패스트캠퍼스, https://fastcampus.co.kr/)

6. 클래스유 (ClassU)
지식 기반 1인 크리에이터가 강의 + 커뮤니티 형태로 운영하기 좋은 플랫폼입니다. 비교적 가볍게 시작할 수 있는 구조입니다.

(클래스유, https://classu.co.kr/ (https://chatgpt.com/c/null))

간단 정리

빠르게 시작: 인프런 / 클래스101

코칭·1:1 중심: 탈잉

글로벌 판매: 유데미

전문가 커리큘럼: 패스트캠퍼스

커뮤니티형: 클래스유

원하면 “수익 잘 나는 강의 주제 TOP 10”이나 “초보 강사 첫 강의 기획 방법”도 같이 정리해줄게요.
