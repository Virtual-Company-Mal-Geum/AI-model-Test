# solo-instructor-practical-course-site / run 10

## Question

1인 강사가 운영하는 실무 강의 사이트 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

아래는 1인 강사가 직접 강의 사이트를 만들거나 운영하면서 실무 강의를 올리기 좋은 플랫폼들입니다. (각각 “자체 사이트형 / 마켓형 / 혼합형”으로 나눴어요)

🧑‍🏫 1. 인프런 (마켓형 + 강사 수익화 최강)
(인프런, https://www.inflearn.com/)

IT·실무 강의 중심 (개발, 데이터, 마케팅, AI 등)

1인 강사 입장에서 가장 진입이 쉬운 대표 플랫폼

강의 올리면 바로 판매 가능

수익 정산 구조가 비교적 높은 편 (강사 친화적)

👉 추천 대상:

실무 IT / 비즈니스 / 자동화 / 마케팅 강사

🧑‍💻 2. 탈잉 (실무·오프라인/온라인 혼합형)
(탈잉, https://taling.me/)

1:1, 그룹, VOD 강의 모두 가능

실무형 강의(엑셀, 엑셀 자동화, 디자인, 부업)에 강함

“실전 경험 기반 강의” 판매에 유리

👉 추천 대상:

프리랜서, 실무 스킬 강사, 코칭형 강의

🎓 3. 클래스101 (브랜딩 중심 크리에이터형)
(클래스101, https://class101.net/)

강의 + 브랜딩 + 콘텐츠 판매 구조

구독형(Class101+)으로 지속 수익 가능

영상·디자인·창작 계열 강의 강세

👉 추천 대상:

크리에이터, 콘텐츠 제작자, 취미+실무 혼합 강사

🧩 4. 패스트캠퍼스 (고급 실무/부트캠프형)
(패스트캠퍼스, https://fastcampus.co.kr/)

기업/직무 전환/부트캠프 중심

강사 입점은 비교적 까다로운 편

대신 단가 높고 기업 교육 연계 가능

👉 추천 대상:

경력 있는 전문가, 기업 교육 강사

🏗️ 5. Teachable (자체 강의 사이트 구축형)
(Teachable, https://teachable.com/)

“내 사이트” 형태로 강의 운영 가능

결제, 수강, 이메일 마케팅까지 자체 운영

해외 강의 판매에도 적합

👉 추천 대상:

브랜드 강의 사이트 만들고 싶은 1인 사업자

🧠 6. Thinkific (노코드 강의 사이트)
(Thinkific, https://www.thinkific.com/)

코딩 없이 강의 사이트 제작 가능

수강 관리 + 결제 + 인증서 발급 기능

Teachable과 비슷한 구조

👉 추천 대상:

완전 독립형 “내 강의 플랫폼” 운영자

🔥 한줄 정리

빠르게 시작 → 인프런

실무 코칭 → 탈잉

브랜딩+콘텐츠 → 클래스101

고급 커리어 → 패스트캠퍼스

내 사이트 운영 → Teachable / Thinkific

원하면

👉 “1인 강사가 실제로 월 100~500만원 만드는 구조”

👉 “어떤 플랫폼이 수익화에 제일 유리한지 현실 비교”

이것도 바로 정리해줄게.
