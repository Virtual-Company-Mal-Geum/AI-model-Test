# solo-instructor-practical-course-site / run 3

## Question

1인 강사가 운영하는 실무 강의 사이트 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://github.com/)

## Answer

1인 강사가 직접 운영하거나, 개인 크리에이터가 실무 중심 강의를 올리는 플랫폼들을 중심으로 추천해줄게. (요청한 형식 그대로 정리했어)

1. (인프런, https://www.inflearn.com/)
실무 IT·마케팅·디자인 등 “현업 강사”들이 직접 강의를 제작해서 올리는 국내 대표 플랫폼이야.

특히 1인 개발자, 프리랜서, 현업 마케터들이 강의 많이 운영함.

2. (유데미, https://www.udemy.com/)
전 세계 개인 강사들이 강의를 직접 만들어 판매하는 구조라서

1인 강사 기반 실무 강의가 매우 많은 글로벌 플랫폼이야.

3. (탈잉, https://taling.me/)
한국형 1:1 클래스 + 실무 강의 플랫폼.

개인 강사, 프리랜서, 현업 실무자가 소규모 강의 많이 운영함.

4. (클래스101, https://class101.net/)
크리에이터, 1인 창업자, 디자이너, 마케터 등이

자기 콘텐츠 기반으로 강의 + 구독형 클래스 운영하는 플랫폼.

5. (탈잉 비즈/기업 강의형도 포함)
기업 교육이나 실무 컨설팅형 강의도 많아서

“실무 중심 1인 강사 브랜드” 구축 사례가 많음.

6. (크로노젠, https://learn.cronozen.com/lms (https://learn.cronozen.com/lms?utm_source=chatgpt.com))
1인 강사가 자기 브랜드로 “강의 사이트 자체를 개설”할 수 있는 LMS 플랫폼.

수수료 없이 개인 강의 플랫폼 운영하는 형태로 많이 사용됨.

원하면

👉 “마케팅 실무만 모은 플랫폼”

👉 “1인 강사들이 잘 버는 구조 분석”

👉 “강사 시작하는 방법 (플랫폼 선택 기준)”

이런 식으로도 더 구체적으로 정리해줄게.
