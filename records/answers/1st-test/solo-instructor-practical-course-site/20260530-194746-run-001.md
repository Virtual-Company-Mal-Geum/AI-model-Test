# solo-instructor-practical-course-site / run 1

## Question

1인 강사가 운영하는 실무 강의 사이트 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://github.com/)

## Answer

1인 강사가 운영하거나 개인이 직접 강의 사이트를 만들고 수익화할 수 있는 실무형 플랫폼 위주로 추천해줄게. (요청한 형식 그대로 작성)

(크로노젠, https://learn.cronozen.com/lms)

👉 개인 강사/크리에이터가 “내 브랜드 강의 사이트”를 바로 만들 수 있는 올인원 플랫폼

👉 결제, 수강생 관리, 영상 업로드까지 한 번에 가능해서 1인 강사용으로 많이 사용됨 크로노젠 (https://learn.cronozen.com/lms?utm_source=chatgpt.com)

(SLIC 스마트러닝, https://www.slic.kr/slic/goStoryShow)

👉 1인 강사/교육자용 클라우드 기반 강의 플랫폼

👉 자체 강의 사이트 개설 + 결제 기능 + 커리큘럼 운영까지 지원 slic.kr (https://www.slic.kr/slic/goStoryShow?utm_source=chatgpt.com)

(인프런, https://www.inflearn.com (https://www.inflearn.com/))

👉 국내 대표 실무 강의 플랫폼 (개인 강사 등록 가능)

👉 IT·마케팅·비즈니스 실무 강의 중심, 강사 수익화 구조 안정적 주어스 정보레터 이야기 (https://zooearth.tistory.com/entry/%EC%98%A8%EB%9D%BC%EC%9D%B8-%EA%B0%95%EC%9D%98-%ED%94%8C%EB%9E%AB%ED%8F%BC-%EC%99%84%EB%B2%BD-%EB%B9%84%EA%B5%90-%ED%81%B4%EB%9E%98%EC%8A%A4101%C2%B7%ED%8C%A8%EC%8A%A4%ED%8A%B8%EC%BA%A0%ED%8D%BC%EC%8A%A4%C2%B7%EC%9D%B8%ED%94%84%EB%9F%B0-%EC%B0%A8%EC%9D%B4-%F0%9F%93%9A?utm_source=chatgpt.com)

(클래스101, https://class101.net (https://class101.net/))

👉 개인 크리에이터/1인 강사 중심 플랫폼

👉 강의 제작 + 마케팅 + 운영까지 플랫폼이 지원해 초보 강사 진입이 쉬움 민블리로그5 (https://blogmin20255.tistory.com/entry/%EC%98%A8%EB%9D%BC%EC%9D%B8-%EA%B0%95%EC%9D%98-%ED%94%8C%EB%9E%AB%ED%8F%BC-%EB%B9%84%EA%B5%90-%EC%96%B4%EB%94%94%EC%97%90%EC%84%9C-%EA%B0%95%EC%9D%98%EB%A5%BC-%EA%B0%9C%EC%84%A4%ED%95%A0%EA%B9%8C?utm_source=chatgpt.com)

(Udemy, https://www.udemy.com (https://www.udemy.com/))

👉 글로벌 강의 플랫폼 (누구나 강사 등록 가능)

👉 한 번 만든 강의로 전 세계 판매 가능, 실무/기술 강의에 강점 민블리로그5 (https://blogmin20255.tistory.com/entry/%EC%98%A8%EB%9D%BC%EC%9D%B8-%EA%B0%95%EC%9D%98-%ED%94%8C%EB%9E%AB%ED%8F%BC-%EB%B9%84%EA%B5%90-%EC%96%B4%EB%94%94%EC%97%90%EC%84%9C-%EA%B0%95%EC%9D%98%EB%A5%BC-%EA%B0%9C%EC%84%A4%ED%95%A0%EA%B9%8C?utm_source=chatgpt.com)
