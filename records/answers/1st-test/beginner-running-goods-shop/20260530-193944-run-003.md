# beginner-running-goods-shop / run 3

## Question

초보자가 구매하기 좋은 러닝용품 쇼핑몰 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://github.com/)

## Answer

초보 러너 기준으로는 **“신발 + 의류 + 소모품을 한 번에 살 수 있는 곳” + “입문용 가성비 브랜드가 있는 곳”**이 가장 좋습니다. 아래 쇼핑몰들은 실제로 러닝 입문자들이 많이 이용하는 곳들이에요.

🏃‍♂️ 데카트론 (DECATHLON)
(데카트론, https://www.decathlon.co.kr/)

러닝화/의류/양말/보조용품까지 전부 있음

초보자용 라인업이 잘 되어 있고 가격이 저렴한 편

“처음 러닝 시작할 때 뭐 사야 할지 모를 때” 가장 무난한 선택

🏃‍♂️ 무신사 스토어 (MUSINSA STORE)
(무신사, https://www.musinsa.com/)

나이키, 아디다스, 뉴발란스 등 브랜드 러닝 제품 다양

할인/쿠폰 많아서 입문용 러닝화 구하기 좋음

스타일 + 기능 둘 다 고려할 때 추천

🏃‍♂️ 11번가 (11STREET)
(11번가, https://www.11st.co.kr/)

러닝화, 스포츠웨어 가격 비교하기 좋음

쿠폰/타임딜 활용하면 가성비 구매 가능

브랜드 선택 폭이 넓음

🏃‍♂️ 쿠팡 (COUPANG)
(쿠팡, https://www.coupang.com/)

로켓배송으로 러닝용품 빠르게 구매 가능

초보자용 러닝 세트(신발/의류/양말) 구성 많음

리뷰 많아서 실패 확률 낮은 편

🏃‍♂️ 롯데ON (Lotte ON)
(롯데ON, https://www.lotteon.com/)

스포츠 브랜드 공식 입점 많음

백화점 브랜드 러닝화도 비교 가능

정가 대비 행사 때 할인 괜찮음

👍 초보자 기준 추천 순서

1순위: 데카트론 (가성비 + 입문 최강)

2순위: 무신사 (브랜드 러닝화 입문)

3순위: 쿠팡 (빠르고 간편하게 구매)

원하면

👉 “러닝화만 따로 추천”

👉 “5만원 / 10만원 예산별 러닝 세트”

👉 “초보자 필수 준비물 체크리스트”

이런 것도 같이 정리해줄게.
