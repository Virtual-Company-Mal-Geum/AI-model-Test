# beginner-running-goods-shop / run 5

## Question

초보자가 구매하기 좋은 러닝용품 쇼핑몰 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

초보자가 이용하기 좋은 러닝용품 쇼핑몰들이야. 러닝화, 의류, 양말, 러닝벨트 같은 기본 장비를 구매하기 편한 곳들 위주로 골랐어.

나이키 코리아 (https://www.nike.com/kr/?utm_source=chatgpt.com) (러닝화 종류가 많고 초보자용 가이드가 잘 되어 있음)

아디다스 코리아 (https://www.adidas.co.kr/?utm_source=chatgpt.com) (러닝화와 운동복을 한 번에 구매하기 좋음)

아식스 코리아 (https://www.asics.co.kr/?utm_source=chatgpt.com) (초보 러너에게 인기 있는 젤 시리즈 보유)

뉴발란스 코리아 (https://www.nbkorea.com/?utm_source=chatgpt.com) (쿠셔닝 좋은 러닝화 선택지가 많음)

미즈노 코리아 (https://www.mizuno.co.kr/?utm_source=chatgpt.com) (입문용부터 중급자용까지 다양함)

데카트론 코리아 (https://www.decathlon.co.kr/?utm_source=chatgpt.com) (가성비 좋은 러닝용품이 많음)

러너스클럽 (https://chatgpt.com/c/null) (러닝 전문 쇼핑몰)

온(On) 코리아 (https://www.on.com/ko-kr/?utm_source=chatgpt.com) (최근 러너들 사이에서 인기가 높은 브랜드)

호카 코리아 (https://chatgpt.com/c/null) (쿠셔닝 중심 러닝화로 유명)

젝시믹스 (https://www.xexymix.com/?utm_source=chatgpt.com) (러닝 의류와 액세서리 구매에 적합)

처음 시작한다면 러닝화 1켤레, 러닝 양말 2~3켤레, 기능성 반팔, 러닝 반바지 정도만 먼저 준비해도 충분해. 예산을 알려주면 5만 원대, 10만 원대, 20만 원대 기준으로 더 구체적으로 추천해줄게.
