# beginner-running-goods-shop / run 6

## Question

초보자가 구매하기 좋은 러닝용품 쇼핑몰 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

초보자가 러닝을 시작할 때는 신발뿐 아니라 러닝복, 양말, 러닝벨트 같은 기본 장비를 한 번에 보기 쉬운 쇼핑몰이 편합니다.

나이키 코리아 (https://www.nike.com/kr/?utm_source=chatgpt.com) — 러닝화(페가수스, 보메로 등)와 의류를 함께 구매하기 좋음.

Running Warehouse (https://www.runningwarehouse.com/?utm_source=chatgpt.com) — 러닝 전문 쇼핑몰. 다양한 브랜드 비교가 쉽고 제품 정보가 자세함.

Garmin 코리아 (https://www.garmin.co.kr/?utm_source=chatgpt.com) — 러닝 워치와 GPS 장비를 찾을 때 유용함.

아식스 코리아 (https://www.asics.co.kr/?utm_source=chatgpt.com) — 쿠션이 좋은 입문용 러닝화 라인업이 많음.

브룩스 러닝 (https://www.brooksrunning.com/?utm_source=chatgpt.com) — 러너들 사이에서 입문용·장거리용 신발로 인기가 많음.

호카(HOKA) 코리아 (https://chatgpt.com/c/null) — 쿠션감이 뛰어난 러닝화로 유명함.

뉴발란스 코리아 (https://www.nbkorea.com/?utm_source=chatgpt.com) — 초보자용 러닝화부터 일상 겸용 제품까지 선택 폭이 넓음.

러닝 입문자라면 보통 러닝화 + 기능성 양말 + 가벼운 러닝복 정도만 먼저 구매해도 충분합니다. 이후에 러닝이 습관이 되면 GPS 워치나 러닝벨트를 추가하는 편이 좋아요.
