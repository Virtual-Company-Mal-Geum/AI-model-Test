## Question

초보자가 구매하기 좋은 러닝용품 쇼핑몰 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

가성비 → ABC마트 (https://www.abcmart.co.kr/?utm_source=chatgpt.com), 데카트론 코리아 (https://www.decathlon.co.kr/?utm_source=chatgpt.com)

러닝 시계/GPS 워치 → 가민 코리아 (https://www.garmin.co.kr/?utm_source=chatgpt.com)
