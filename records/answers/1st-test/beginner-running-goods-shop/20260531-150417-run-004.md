# beginner-running-goods-shop / run 4

## Question

초보자가 구매하기 좋은 러닝용품 쇼핑몰 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

초보자가 시작하기에 괜찮은 러닝용품 쇼핑몰들이에요. 신발, 러닝웨어, 양말, 러닝벨트 같은 기본 장비를 한 번에 보기 좋습니다.

러너스하이 (https://runnershigh.co.kr/?utm_source=chatgpt.com) (러닝화와 입문용 장비 종류가 다양함)

온코리아 (On Running) (https://www.on.com/ko-kr?utm_source=chatgpt.com) (쿠셔닝 좋은 러닝화로 유명)

나이키 코리아 (https://www.nike.com/kr?utm_source=chatgpt.com) (입문용 러닝화와 의류 선택 폭이 넓음)

아식스 코리아 (https://www.asics.com/kr/ko-kr?utm_source=chatgpt.com) (초보 러너들에게 인기 있는 젤 시리즈 보유)

호카 코리아 (https://chatgpt.com/c/null) (푹신한 쿠셔닝을 선호하면 추천)

브룩스 러닝 (https://www.brooksrunning.com/?utm_source=chatgpt.com) (러닝 전문 브랜드, 발 유형별 선택 가능)

데카트론 코리아 (https://www.decathlon.co.kr/?utm_source=chatgpt.com) (가성비 좋은 입문용 러닝용품 다수)

룰루레몬 코리아 (https://www.lululemon.co.kr/?utm_source=chatgpt.com) (러닝웨어 품질이 좋은 편) Lululemon Korea (https://www.lululemon.co.kr/ko-kr/c/mens-running-clothes/luxtreme?utm_source=chatgpt.com)

초보자라면 처음에는 러닝화 + 기능성 양말 + 러닝 반바지/티셔츠 정도만 구매해도 충분합니다. 예산을 알려주면 5만 원, 10만 원, 20만 원대 등으로 맞춰서 입문용 장비 조합도 추천해줄게요.
