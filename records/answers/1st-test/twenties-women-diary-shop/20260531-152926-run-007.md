# twenties-women-diary-shop / run 7

## Question

20대 여성이 좋아할 만한 다이어리 쇼핑몰 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

20대 여성들이 선호하는 감성/디자인 중심 다이어리를 기준으로, 디자인 종류가 다양하고 꾸준히 인기 있는 쇼핑몰들을 골라봤어.

텐바이텐

(10x10 (https://www.10x10.co.kr/?utm_source=chatgpt.com))

→ 감성 문구, 브랜드 다이어리, 스티커까지 한 번에 고를 수 있는 대표 디자인 플랫폼

1300K

(1300K (https://www.1300k.com/?utm_source=chatgpt.com))

→ 심플/미니멀 다이어리부터 브랜드형 플래너까지 다양하게 구성

아트박스

(ARTBOX (https://www.artbox.co.kr/?utm_source=chatgpt.com))

→ 귀엽고 캐릭터 중심 다이어리 많아서 20대 초중반 인기 높음

오늘의집

(Ohouse (https://ohou.se/?utm_source=chatgpt.com))

→ 문구 전문은 아니지만 감성 브랜드 다이어리/플래너 큐레이션이 강점

교보문고

(Kyobo Bookstore (https://www.kyobobook.co.kr/?utm_source=chatgpt.com))

→ 고급 다이어리, 플래너 브랜드 다양하고 오프라인/온라인 모두 안정적

모닝글로리

(Morning Glory (https://www.morningglory.co.kr/?utm_source=chatgpt.com))

→ 가성비 좋은 기본 다이어리 + 학생~20대 초반까지 넓게 인기

원하면 “감성/미니멀/귀여운/자기계발용”처럼 스타일별로 더 딱 맞게 골라서 추천해줄게.
