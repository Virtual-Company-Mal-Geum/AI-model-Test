# twenties-women-diary-shop / run 1

## Question

20대 여성이 좋아할 만한 다이어리 쇼핑몰 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://github.com/)

## Answer

20대 여성들이 많이 선호하는 다이어리는 “디자인 감성, 컬러톤(파스텔/미니멀), 구성(월간·주간·데일리), 꾸미기 쉬움” 이 4가지 기준으로 많이 고릅니다. 아래는 실제로 국내에서 많이 쓰는 다이어리 쇼핑몰/브랜드들이에요.

감성 다이어리 쇼핑몰 추천

(텐바이텐, https://github.com/)

→ 감성 문구/디자인 다이어리 종류가 가장 다양하고 시즌별 한정판이 많음

(1300K, https://github.com/)

→ 깔끔한 디자인 + 실용적인 플래너 위주, 직장인/대학생 20대에게 인기

(아트박스, https://github.com/)

→ 가성비 좋고 귀여운 캐릭터/컬러 다이어리 많아서 입문용으로 좋음

(데일리라이크, https://github.com/)

→ 파스텔 감성, 미니멀 디자인 다이어리로 “예쁜 감성” 쪽 대표 브랜드

(모트모트, https://github.com/)

→ 공부 플래너/루틴 관리용 다이어리로 유명 (목표관리형)

(인디고 / 교보문고 문구, https://github.com/)

→ 종이 질 좋고 정석 다이어리 느낌, 기록용으로 선호 많음

원하면

👉 “꾸미기용 감성 다이어리 TOP 5”

👉 “공부/자기계발용 플래너 추천”

👉 “다꾸 스티커까지 같이 사기 좋은 곳”

이렇게 더 세분화해서도 골라줄게.
