# twenties-women-diary-shop / run 8

## Question

20대 여성이 좋아할 만한 다이어리 쇼핑몰 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

20대 여성이 좋아할 만한 다이어리는 디자인 취향이 다양해서 “문구 편집샵 + 감성 브랜드” 위주로 보면 실패 확률이 적어요. 아래는 국내에서 많이 찾는 곳들입니다.

(텐바이텐, 텐바이텐 (https://www.10x10.co.kr/?utm_source=chatgpt.com)) — 감성 다이어리, 스티커, 플래너 디자인 종류가 가장 다양해서 취향 찾기 좋음

(아트박스, 아트박스 (https://www.artbox.co.kr/?utm_source=chatgpt.com)) — 무난하고 귀여운 스타일부터 실용형까지 폭넓게 있음

(1300K, 1300K (https://www.1300k.com/?utm_source=chatgpt.com)) — 디자인 다이어리, 브랜드 문구류 큐레이션이 잘 되어 있음

(모닝글로리, 모닝글로리 (https://www.morningglory.co.kr/?utm_source=chatgpt.com)) — 가격 부담 적고 기본형/학생·직장인용 다이어리 다양

(인디고, url인디고, ) — 감성적인 표지 디자인과 심플한 구성으로 20대 선호도 높음

원하면 “더 감성적인 브랜드(인스타 감성)”, “직장인용 플래너”, “꾸미기용 스티커 많은 곳”처럼 스타일별로 더 좁혀서도 추천해줄게.
