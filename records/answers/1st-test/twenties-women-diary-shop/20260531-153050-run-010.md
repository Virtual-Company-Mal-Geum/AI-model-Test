# twenties-women-diary-shop / run 10

## Question

20대 여성이 좋아할 만한 다이어리 쇼핑몰 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

20대 여성에게 인기 많은 감성 다이어리·문구 쇼핑몰들을 중심으로 추천해볼게. 디자인, 스티커, 플래너 구성까지 다양해서 취향 맞추기 좋다.

텐바이텐 (10x10, https://www.10x10.co.kr/)

모찌띵스 (MochiThings, https://www.mochithings.com/ (https://chatgpt.com/c/null))

아이코닉 (ICONIC, https://iconic.co.kr/ (https://chatgpt.com/c/null))

오브젝트 (Object, https://object.co.kr/ (https://chatgpt.com/c/null))

핫트랙스 (Hottracks, https://hottracks.kyobobook.co.kr/)

천삼백케이 (1300K, https://www.1300k.com/)

아트박스 (ARTBOX, https://www.artboxmall.com/ (https://chatgpt.com/c/null))

원하면 “미니멀 다이어리”, “꾸미기용 스티커 많은 곳”, “가성비 좋은 곳”처럼 스타일 기준으로도 더 좁혀서 추천해줄게.
