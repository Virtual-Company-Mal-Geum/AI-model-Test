# twenties-women-diary-shop / run 3

## Question

20대 여성이 좋아할 만한 다이어리 쇼핑몰 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

20대 여성이 선호하는 스타일 기준으로 “디자인 감성 + 실용성 + 다이어리/문구 큐레이션”이 잘 되어 있는 곳들 위주로 골라봤어.

(텐바이텐, 텐바이텐 (https://www.10x10.co.kr/?utm_source=chatgpt.com))

감성 다이어리, 스티커, 플래너 종류가 가장 다양해서 “꾸미기용 다이어리” 찾는 사람들한테 가장 인기 있는 편.

(1300K, 1300K (https://www.1300k.com/?utm_source=chatgpt.com))

심플~감성 디자인까지 폭이 넓고 브랜드 다이어리(몰스킨류 포함)도 잘 모여 있음.

(교보문고 핫트랙스, 핫트랙스 (https://hottracks.kyobobook.co.kr/?utm_source=chatgpt.com))

문구 전문이라 퀄리티 좋은 다이어리, 업무용/학업용 플래너 찾을 때 안정적.

(무인양품, MUJI (https://www.muji.com/kr?utm_source=chatgpt.com))

미니멀 다이어리 좋아하면 거의 정석. 군더더기 없이 깔끔한 구성.

(오브젝트, 오브젝트 (https://chatgpt.com/c/null))

작가/브랜드 감성 다이어리 많고 “조금 독특한 디자인” 찾을 때 좋음.

원하면 “꾸미기용 / 미니멀 / 일정관리용 / 선물용” 중 어떤 스타일인지 말해주면 더 정확하게 골라줄게.
