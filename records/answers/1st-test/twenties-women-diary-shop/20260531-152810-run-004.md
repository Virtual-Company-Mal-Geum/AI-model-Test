# twenties-women-diary-shop / run 4

## Question

20대 여성이 좋아할 만한 다이어리 쇼핑몰 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

20대 여성들이 좋아하는 감성·디자인 다이어리 많이 모여 있는 쇼핑몰들 추천해줄게.

(텐바이텐, 텐바이텐 (https://10x10.co.kr/?utm_source=chatgpt.com)) — 감성 디자인 다이어리, 스티커, 문구류까지 트렌디한 제품이 가장 다양함

(아트박스 ARTBOX, ARTBOX (https://www.artbox.co.kr/?utm_source=chatgpt.com)) — 귀엽고 실용적인 다이어리부터 캐릭터 제품까지 폭넓게 있음

(핫트랙스, 핫트랙스 (https://chatgpt.com/c/null)) — 교보문고 계열이라 브랜드 문구/프리미엄 다이어리 선택지가 좋음

(1300K, 1300K (https://www.1300k.com/?utm_source=chatgpt.com)) — 디자인 문구 전문몰이라 감성 다이어리, 플래너 종류가 많음

(오브젝트 OBJECT, OBJECT (https://chatgpt.com/c/null)) — 소규모 디자이너 브랜드 다이어리, 독특한 감성 제품 많음

(페이퍼리안 PAPERIAN, PAPERIAN (https://paperian.co.kr/?utm_source=chatgpt.com)) — 미니멀하고 감각적인 다이어리/스티커 중심으로 인기 있음

원하면 “미니멀 스타일 / 귀여운 스타일 / 직장인용 플래너”처럼 취향에 맞춰 더 좁혀서 추천해줄게.
