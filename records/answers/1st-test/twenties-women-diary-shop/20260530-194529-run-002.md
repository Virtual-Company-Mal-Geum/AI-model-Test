# twenties-women-diary-shop / run 2

## Question

20대 여성이 좋아할 만한 다이어리 쇼핑몰 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://github.com/)

## Answer

20대 여성이 좋아할 만한 다이어리 쇼핑몰은 디자인 감성(미니멀/빈티지/컬러감) + 커스터마이징(스티커, 날짜, 속지 구성) + 선물용 패키지를 잘 갖춘 곳이 인기가 많아요. 아래는 실제로 많이 찾는 대표 쇼핑몰/브랜드들이야.

📓 감성 다이어리 쇼핑몰 추천
1. 텐바이텐 (10x10)

(텐바이텐, https://www.10x10.co.kr/)

→ 국내에서 가장 유명한 감성 문구 편집샵

→ 다이어리 종류가 압도적으로 많고 브랜드 다양 (로이텀 느낌부터 캐릭터까지)

2. 모노폴리 스토어

(모노폴리, https://monopoly.co.kr/)

→ 심플 + 미니멀 감성 다이어리로 유명

→ 직장인/대학생용 플래너 디자인 깔끔

3. 위글위글 (Wiggle Wiggle)

(위글위글, https://wiggle-wiggle.com/)

→ 컬러풀하고 귀여운 스타일

→ 20대 여성 취향 “키치 감성” 다이어리 강세

4. 아트박스 (ARTBOX)

(아트박스, https://www.artbox.co.kr/)

→ 접근성 최고, 가격대 다양

→ 캐릭터/심플/실용형 다이어리 다 있음

5. 교보문고 핫트랙스

(핫트랙스, https://hottracks.kyobobook.co.kr/)

→ 문구 덕후들이 많이 찾는 곳

→ 해외 감성 브랜드(몰스킨, 르흐트룸1917 등) 구매 가능

💡 고를 때 팁

“감성 사진 + 여백 많은 다이어리” → 모노폴리 / 핫트랙스

“귀엽고 꾸미기용” → 위글위글 / 아트박스

“선물용 + 다양성” → 텐바이텐

원하면 **“선물용 TOP 5 다이어리”**나 **“인스타 감성 다이어리만 따로”**도 골라서 더 좁혀줄게.
