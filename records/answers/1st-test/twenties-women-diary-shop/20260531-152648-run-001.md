# twenties-women-diary-shop / run 1

## Question

20대 여성이 좋아할 만한 다이어리 쇼핑몰 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

20대 여성에게 선물용/취향용으로 많이 선택되는 감성 다이어리 쇼핑몰들을 추천해볼게요.

(무인양품 MUJI, https://www.muji.com/kr/)

(아트박스 ARTBOX, https://www.artbox.co.kr/)

(텐바이텐 10x10, https://www.10x10.co.kr/)

(호보니치 Hobonichi, https://www.1101.com/store/techo/)

(미도리 MIDORI, https://www.midori-japan.co.jp/)

(아처앤올리브 Archer & Olive, https://www.archerandolive.com/)

원하면 “가성비 / 감성 / 꾸미기용 / 플래너형”처럼 스타일별로 더 세분화해서도 추천해줄게.
