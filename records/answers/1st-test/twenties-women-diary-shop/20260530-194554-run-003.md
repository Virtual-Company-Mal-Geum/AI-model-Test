# twenties-women-diary-shop / run 3

## Question

20대 여성이 좋아할 만한 다이어리 쇼핑몰 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://github.com/)

## Answer

20대 여성들이 많이 사용하는 다이어리/플래너 쇼핑몰은 “감성 디자인 + 실용성 + 커스터마이징” 중심 브랜드들이 인기가 많아요. 아래는 실제로 많이 찾는 대표 쇼핑몰/브랜드들이야.

📒 1. 위드오트 (withOT)
감성적인 커버 디자인과 미니멀한 플래너로 유명한 브랜드야.

학생/직장인 둘 다 많이 사용함.

(위드오트, https://withot.com (https://chatgpt.com/c/null))

📒 2. 모트모트 (MOTEMOTE)
공부 플래너로 시작했지만 20대 직장인도 많이 쓰는 스케줄 관리형 다이어리 브랜드.

(모트모트, https://motemote.kr (https://motemote.kr/))

📒 3. 오롤리데이 (OHLOLLYDAY)
감성 문구 + 다이어리 + 라이프스타일 굿즈로 인기 많은 브랜드. 선물용으로도 좋음.

(오롤리데이, https://oh-lolly-day.com (https://oh-lolly-day.com/))

📒 4. 아날로그키퍼 (Analog Keeper)
손글씨 감성 + 기록용 다이어리로 유명. “기록하는 습관” 컨셉이 강함.

(아날로그키퍼, https://analogkeeper.com (https://chatgpt.com/c/null))

📒 5. 텐바이텐 (10x10)
여러 브랜드 다이어리를 한 번에 볼 수 있는 국내 대표 디자인 문구 쇼핑몰.

(텐바이텐, https://10x10.co.kr (https://10x10.co.kr/))

📒 6. 아이디어스 (idus)
핸드메이드 다이어리/커버/속지까지 다양하게 구매 가능한 플랫폼.

(아이디어스, https://www.idus.com (https://www.idus.com/))
