# suwon-small-meeting-space / run 2

## Question

수원에서 소규모 모임 가능한 공간 대여 장소 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://github.com/)

## Answer

수원에서 소규모 모임(스터디, 회의, 파티, 원데이 클래스 등)으로 많이 쓰이는 공간들을 유형별로 추천해줄게. 실제 예약/이용 가능한 곳 위주로 골랐어.

📍 1. 공유오피스 / 회의·스터디 공간
써니웍스 수원
자연광 있는 오피스 + 회의실/라운지/카페테리아까지 갖춘 공유오피스라 2~10명 정도 소규모 모임에 적합해.

(써니웍스 수원, https://sunnyworks.kr/) 써니웍스 (https://sunnyworks.kr/?utm_source=chatgpt.com)

👉 장점: 조용한 분위기, 회의실 이용 가능, 장기/단기 모두 적합

👉 추천 용도: 스터디, 창업모임, 팀 회의

📍 2. 프라이빗 파티 / 행사형 공간
파티움하우스 수원
웨딩홀 기반이지만 기업 행사, 세미나, 소규모 파티 공간 대여도 가능한 대형 연회 공간이야.

(파티움하우스 수원, https://www.partyumhouse.com/) Partyum House (https://www.partyumhouse.com/?utm_source=chatgpt.com)

👉 장점: 넓은 공간, 행사/모임/파티까지 가능

👉 추천 용도: 동아리 행사, 브랜드 모임, 대규모 소모임

📍 3. 루프탑 / 감성 파티룸
너울다락 (영통)
루프탑 + 실내 공간이 있는 프라이빗 파티룸이라 소규모 모임, 생일파티에 좋아.

(너울다락, https://www.neoul.team/darak) 너울 NEOUL (https://www.neoul.team/darak?utm_source=chatgpt.com)

👉 장점: 감성 인테리어, 프라이빗, 분위기 좋음

👉 추천 용도: 친구 모임, 생일파티, 브라이덜샤워

📍 4. 키즈/액티비티형 소규모 공간
점핑파크 정자점
실내 놀이공간 + 파티룸이 있어 아이들 모임이나 가족 단위 소규모 행사에 적합.

(점핑파크 정자점, https://www.mytripkorea.com/leisure/3081940?local=ko) WhatMyTrip (https://www.mytripkorea.com/leisure/3081940?local=ko&utm_source=chatgpt.com)

👉 장점: 파티룸 별도, 실내 활동 가능

👉 추천 용도: 키즈 모임, 가족 행사
