# suwon-small-meeting-space / run 5

## Question

수원에서 소규모 모임 가능한 공간 대여 장소 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

수원에서 소규모 모임(4~12명 정도) 하기 좋은 공간들을 골라봤어. 스터디, 보드게임, 친목 모임, 회의 용도로 많이 이용하는 곳들이야.

스페이스클라우드, https://www.spacecloud.kr (https://www.spacecloud.kr/?utm_source=chatgpt.com)

파티룸 여기, https://www.partyhere.kr (https://chatgpt.com/c/null)

아워플레이스, https://www.ourplace.co.kr (https://chatgpt.com/c/null)

모아모임공간, https://www.moamoim.com (https://chatgpt.com/c/null)

다함께공간, https://www.dahamgge.com (https://chatgpt.com/c/null)

또한 수원에서는 보드게임 모임, 독서 모임, 스터디 모임 등이 활발하게 운영되고 있어서 공간 대여와 함께 모임 장소를 찾는 경우 참고하기 좋아. 소모임+2소모임+2 (https://www.somoim.co.kr/%EC%88%98%EC%9B%90-%EB%B3%B4%EB%93%9C%EA%B2%8C%EC%9E%84-%EB%AA%A8%EC%9E%84?utm_source=chatgpt.com)

용도별로 추천하면:

보드게임·친목 모임 → 스페이스클라우드, 파티룸 여기

스터디·회의 → 아워플레이스

생일파티·소규모 행사 → 파티룸 여기, 모아모임공간

독서모임·소규모 클래스 → 아워플레이스, 다함께공간

원하면 수원역 근처, 광교, 인계동, 행궁동처럼 지역을 좁혀서 실제 예약 가능한 공간 위주로 더 자세히 추천해줄게.
