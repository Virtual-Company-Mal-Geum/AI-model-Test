## Question

수원에서 소규모 모임 가능한 공간 대여 장소 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://github.com/)

## Answer

수원에서 소규모 모임(스터디, 회의, 생일파티, 원데이클래스 등)으로 많이 쓰이는 공간들을 유형별로 추천해줄게. 각 장소 이름 + URL도 같이 적었어.

1. 행궁동 감성 파티룸 / 모임 공간

(PLACE BOOTER, https://shareit.kr/store/7104)

소규모 독립 파티룸 형태로, 2~10명 정도 모임에 적합해. 프로젝터가 있어서 영화 감상이나 스터디에도 좋고, 행궁동 분위기 자체가 좋아서 감성 모임에 많이 쓰이는 곳이야. 쉐어잇 (https://shareit.kr/store/7104?utm_source=chatgpt.com)

2. 수원시청역 인근 대형 컨벤션·모임 공간

(파티움하우스 수원, https://www.partyumhouse.com/)

원래 웨딩/연회장인데, 세미나·기업 모임·중대형 스터디·행사 대관도 가능한 공간. 소규모 모임이라도 프라이빗 룸을 활용할 수 있어 확장성이 큼. Partyum House (https://www.partyumhouse.com/?utm_source=chatgpt.com)

3. 수원 스터디/모임 플랫폼 (공간 포함 모임 탐색용)

(소모임 수원 스터디 리스트, https://www.somoim.co.kr/%EC%88%98%EC%9B%90-%EC%8A%A4%ED%84%B0%EB%94%94-%EB%AA%A8%EC%9E%84)

실제 공간 대여보다는 “모임 + 공간”을 같이 찾을 때 유용한 플랫폼. 수원에서 운영 중인 스터디/취미 모임을 확인하고 공간도 연결되는 경우가 많아. 소모임 (https://www.somoim.co.kr/%EC%88%98%EC%9B%90-%EC%8A%A4%ED%84%B0%EB%94%94-%EB%AA%A8%EC%9E%84?utm_source=chatgpt.com)

4. 프라이빗 예약형 룸 (소규모 회의/모임용)

(수원 인계동 프라이빗 룸 안내, https://suwon-shirtroom.isweb.co.kr/)

기본적으로 예약 기반의 독립 룸 구조라서 소규모 모임 공간으로도 활용되는 경우가 있음 (스터디/회의 용도로는 사전 확인 필요). 수원셔츠룸 인계동셔츠룸 예약사이트 (https://suwon-shirtroom.isweb.co.kr/?utm_source=chatgpt.com)

원하면

👉 “스터디용 (조용한 카페형)”

👉 “생일파티용 (감성/조명/빔 있는 곳)”

👉 “회의용 (화이트보드/회의실)”
