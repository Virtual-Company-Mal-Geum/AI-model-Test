# handmade-leather-wallet-gift / run 3

## Question

선물용으로 좋은 수제 가죽 지갑 브랜드 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

선물용으로 퀄리티 좋은 “수제 가죽 지갑” 브랜드들만 추려서 추천해볼게. 전통적인 핸드크래프트 계열 + 선물 만족도 높은 곳 위주야.

(GANZO, GANZO (https://www.ganzo.ne.jp/?utm_source=chatgpt.com))

→ 일본 대표 가죽 장인 브랜드. 깔끔한 클래식 지갑이 많고, 선물용으로 가장 무난하게 고급스럽다는 평가가 많음.

(HERZ, HERZ (https://www.herz-bag.jp/?utm_source=chatgpt.com))

→ “손맛” 강한 브랜드. 투박하지만 오래 쓸수록 멋이 올라오는 에이징 가죽 지갑 스타일.

(IL BISONTE, Il Bisonte (https://www.ilbisonte.com/?utm_source=chatgpt.com))

→ 이탈리아 감성 브랜드. 자연스러운 가죽 질감 + 감각적인 컬러가 강점이라 선물용 인기 높음.

(Saddleback Leather Co, Saddleback Leather Co (https://saddlebackleather.com/?utm_source=chatgpt.com))

→ “100년 쓰는 가죽 제품” 컨셉. 굉장히 튼튼하고 남성 선물용으로 특히 많이 선택됨.

(Tanner Goods, Tanner Goods (https://www.tannergoods.com/?utm_source=chatgpt.com))

→ 미니멀하고 현대적인 디자인 + 수제 가죽 느낌 균형이 좋아서 데일리 지갑으로 좋음.

(Ashland Leather, Ashland Leather (https://ashlandleather.com/?utm_source=chatgpt.com))

→ 최고급 소재(쉘 코도반) 중심. 가격은 높지만 “진짜 고급 선물” 느낌 원할 때 적합.

(Bellroy, Bellroy (https://bellroy.com/?utm_source=chatgpt.com))

→ 완전 수제 장인 느낌보다는 “실용+슬림 디자인” 쪽. 카드 많이 쓰는 사람 선물에 잘 맞음.

원하면 “남성/여성”, “예산(5만/10만/30만 이상)”, “미니멀 vs 클래식” 기준으로 딱 맞게 3개로 좁혀줄게.
