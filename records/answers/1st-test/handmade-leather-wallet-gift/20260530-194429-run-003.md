# handmade-leather-wallet-gift / run 3

## Question

선물용으로 좋은 수제 가죽 지갑 브랜드 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://github.com/)

## Answer

선물용으로 좋은 수제 가죽 지갑 브랜드들 몇 가지 깔끔하게 추천해줄게. 전반적으로 핸드스티치/이탈리아·미국 장인 제작/풀그레인 가죽/에이징(태닝) 품질 좋은 곳 위주야.

🧵 고급 수제·하이엔드 라인

(Maxwell-Scott, https://kr.maxwellscottbags.com (https://kr.maxwellscottbags.com/))

이탈리아 장인 제작 + 클래식한 비즈니스 스타일, 각인 커스터마이징 가능

(Saddleback Leather, https://saddlebackleather.com (https://saddlebackleather.com/))

미국 브랜드, “평생 쓰는 지갑” 컨셉으로 유명한 풀그레인 가죽 수제 브랜드

(Ashland Leather, https://ashlandleather.com (https://ashlandleather.com/))

시카고 기반 핸드메이드, 가죽 퀄리티와 에이징 변화가 매우 뛰어남

🪡 감성·디자인 중심 수제 브랜드

(Popov Leather, https://www.popovleather.com (https://www.popovleather.com/))

캐나다 브랜드, 전통적인 핸드스티치 방식 + 미니멀 디자인

(Il Bisonte, https://www.ilbisonte.com (https://www.ilbisonte.com/))

이탈리아 피렌체 수제 감성 브랜드, 자연스러운 태닝 가죽이 특징

(The Bridge, https://www.thebridge.it (https://www.thebridge.it/))

이탈리아 클래식 스타일, 선물용으로 고급스럽게 포장 퀄리티도 좋음

🎁 선물용으로 고를 때 팁

이니셜 각인 가능 여부 → 선물 만족도 크게 올라감

가죽 종류 (풀그레인 추천) → 오래 쓸수록 멋있게 변함

스타일 선택

포멀/직장인 → Maxwell-Scott, The Bridge

빈티지 감성 → Saddleback, Popov

감성+패션 → Il Bisonte

원하면 “가격대 10만/20만/30만 원대”로 딱 나눠서 선물용 베스트도 따로 골라줄게.
