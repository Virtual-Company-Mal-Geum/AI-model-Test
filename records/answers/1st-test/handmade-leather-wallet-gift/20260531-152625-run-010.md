# handmade-leather-wallet-gift / run 10

## Question

선물용으로 좋은 수제 가죽 지갑 브랜드 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

선물용으로 만족도 높은 “수제/장인 가죽 지갑” 브랜드들을 몇 가지 추려서 추천해볼게. 내구성, 에이징(가죽 태닝), 마감 퀄리티 기준으로 많이 선택되는 곳들이야.

1) Saddleback Leather
(미국식 풀그레인 가죽 + 평생 내구성 스타일)

(Saddleback Leather, Saddleback Leather (https://saddlebackleather.com/?utm_source=chatgpt.com))

2) Popov Leather
(캐나다 기반, 수작업 스티칭 감성 + 커스텀 가능)

(Popov Leather, Popov Leather (https://www.popovleather.com/?utm_source=chatgpt.com))

3) Ashland Leather
(시카고 기반, 쉘코드반 중심의 하이엔드 수제 지갑)

(Ashland Leather, Ashland Leather (https://ashlandleather.com/?utm_source=chatgpt.com))

4) Il Bussetto
(이탈리아 전통 베지터블 레더 + 클래식한 디자인)

(Il Bussetto, Il Bussetto (https://chatgpt.com/c/null))

5) Tanner Goods
(포틀랜드 기반, 미니멀 + 장인 가죽 작업)

(Tanner Goods, Tanner Goods (https://www.tannergoods.com/?utm_source=chatgpt.com))

6) Montblanc (가죽 라인)
(고급 선물용으로 가장 무난한 럭셔리 선택)

(Montblanc, Montblanc (https://www.montblanc.com/?utm_source=chatgpt.com))

7) Bellroy
(완전 수제 느낌보단 정교한 설계형 프리미엄 슬림 지갑)

(Bellroy, Bellroy (https://bellroy.com/?utm_source=chatgpt.com))

원하면 “30대 남자 선물용 / 10만~30만 원대 / 카드 많이 넣는 타입 / 미니멀 슬림형”처럼 조건 알려주면 그 기준으로 더 정확하게 좁혀줄게.
