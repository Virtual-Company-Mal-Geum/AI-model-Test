# handmade-leather-wallet-gift / run 2

## Question

선물용으로 좋은 수제 가죽 지갑 브랜드 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://github.com/)

## Answer

선물용 수제 가죽 지갑은 “가죽 등급(풀그레인/베지터블)” + “핸드메이드 여부” + “에이징(시간 지날수록 멋)” + “디자인 완성도” 이 4가지를 보면 실패 확률이 거의 없습니다.

아래는 실제로 선물용으로 많이 추천되는 수제/핸드메이드 가죽 지갑 브랜드들입니다.

🇰🇷 국내 수제 가죽 브랜드
1) 소로움 (Soroum)
미니멀한 디자인 + 프랑스 가죽 기반 제품으로 감성 선물용으로 많이 선택됩니다.

(소로움, https://soroum.kr/) 소로움 (https://soroum.kr/?utm_source=chatgpt.com)

2) GENTCREATE (젠트크리에이트)
풀그레인/맞춤형 중심의 핸드메이드 가죽 지갑 브랜드, 고급 선물용으로 인기

(GENTCREATE, https://gentcreate.com/ko/collections/handmade-leather-wallets) GENTCREATE (https://gentcreate.com/ko/collections/handmade-leather-wallets?utm_source=chatgpt.com)

3) VIVI ART LEATHER
공방 기반 수제 제작 브랜드 (카드지갑, 악어가죽 등 커스터마이징 가능)

(VIVI ART, https://viviart.store/) VIVI ART (https://viviart.store/?utm_source=chatgpt.com)

4) 루체인알티스 (Lucein Altis)
각인/선물포장 지원 + 실용적인 카드지갑/여권지갑 라인

(루체인알티스, https://luceinaltis.co.kr/) 루체인알티스 (https://luceinaltis.co.kr/?utm_source=chatgpt.com)

5) ASTULA (아스툴라)
가죽 공방 기반 오더메이드 브랜드 (맞춤 제작 가능, 고급 선물용)

(ASTULA, https://www.astula.co.kr/) astula.co.kr (https://www.astula.co.kr/?utm_source=chatgpt.com)

🌍 해외 감성/프리미엄 수제 브랜드
6) Saddleback Leather
미국 브랜드, “평생 보증”으로 유명한 두꺼운 풀그레인 가죽 지갑

(Saddleback Leather, https://saddlebackleather.com/)

7) Il Bisonte
이탈리아 핸드메이드 가죽 브랜드 (빈티지 에이징 감성 강함)

(Il Bisonte, https://www.ilbisonte.com/)

8) Bellroy
수제 느낌은 덜하지만 “미니멀+실용성”으로 선물 만족도 높음

(Bellroy, https://bellroy.com/)

🎁 현실적인 추천 (선물 기준)

감성/핸드메이드 느낌 최우선 → ASTULA / VIVI ART

무난 + 실패 없는 선물 → Bellroy / Il Bisonte

고급+특별한 선물 느낌 → GENTCREATE / Saddleback

가성비 수제 + 국내 감성 → 루체인알티스 / 소로움

원하면

👉 “남자/여자 선물용 TOP 3만 압축”

👉 “3~10만원 / 10~30만원 가격대별 추천”

👉 “20대 / 30대 취향별 추천”
