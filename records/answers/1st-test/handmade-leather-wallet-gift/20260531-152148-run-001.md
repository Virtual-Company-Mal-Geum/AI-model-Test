# handmade-leather-wallet-gift / run 1

## Question

선물용으로 좋은 수제 가죽 지갑 브랜드 추천해줘. 추천한 곳의 url을 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

선물용으로 “수제 감성 + 퀄리티” 좋은 가죽 지갑 브랜드들만 추려서 추천해줄게.

🧵 수제 가죽 지갑 브랜드 추천

(Ashland Leather, https://ashlandleather.com/)

→ 미국 시카고 기반, 코도반(고급 말가죽) 지갑으로 유명. 클래식 선물용으로 최상급.

(Popov Leather, https://popovleather.com/ (https://chatgpt.com/c/null))

→ 캐나다 수제 가죽 브랜드. 손바느질 느낌 강하고 커스텀 선물용으로 좋음.

(Saddleback Leather, https://saddlebackleather.com/)

→ 매우 튼튼하고 남성적인 스타일. “100년 가는 지갑” 콘셉트로 선물용 인기.

(Il Bussetto, https://ilbussetto.it/)

→ 이탈리아 브랜드. 염색/광택 마감이 예쁘고 고급스러운 선물용 느낌 강함.

(Corter Leather, https://corterleather.com/)

→ 미국 수제 브랜드. 미니멀한 디자인 + 빈티지 감성 균형 좋음.

(Bellroy, https://bellroy.com/)

→ 완전 수제는 아니지만, 슬림 지갑 + 실용성 때문에 선물용 실패 확률 낮음.

(Hender Scheme, https://henderscheme.com/)

→ 일본 하이엔드 수제 감성 브랜드. 디자인 자체가 패션 아이템 느낌.

원하면

👉 “20대 남자 선물용 / 30대 직장인용 / 10만원 이하”

이렇게 가격대랑 대상 말해주면 더 정확하게 좁혀서 추천해줄게.
