# 교육-탐색-질문 / run 19

## Question

프로그래밍을 처음 배우는 성인 학습자에게 적합한 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 배우는 성인 학습자라면, **“재미를 잃지 않고 꾸준히 따라갈 수 있는 구조”**가 가장 중요해요. 아래 강의들은 초보자 친화적이고, 실제로 많이 추천되는 곳들이에요.

무료로 기초를 차근차근 배우고 싶다면 — freeCodeCamp

HTML, CSS, JavaScript, Python까지 무료로 학습 가능

실습 중심이라 “직접 만들어보면서” 배우기 좋음

영어 기반이지만 쉬운 편

(freeCodeCamp, https://www.freecodecamp.org/ (https://www.freecodecamp.org/?utm_source=chatgpt.com))

인터랙티브하게 배우고 싶다면 — Codecademy

브라우저 안에서 바로 코드를 작성하면서 학습

“한 줄 배우고 바로 실행” 방식이라 입문자 만족도가 높음

초보자용 Python/JavaScript 코스 추천

(Codecademy, https://www.codecademy.com/ (https://www.codecademy.com/?utm_source=chatgpt.com))

대학교 스타일의 체계적인 강의를 원한다면 — Coursera

유명 대학/기업 강의를 온라인으로 수강 가능

특히 Python for Everybody 과정이 입문용으로 유명

일정 관리가 가능한 성인 학습자에게 잘 맞음

(Coursera, https://www.coursera.org/ (https://www.coursera.org/?utm_source=chatgpt.com))

한국어 강의를 선호한다면 — 인프런

한국어로 된 개발 강의가 매우 많음

입문자 대상 강의가 다양하고 실무 연결도 쉬움

“파이썬 입문”, “웹 개발 입문” 추천

(인프런, https://www.inflearn.com/ (https://www.inflearn.com/?utm_source=chatgpt.com))

짧고 재미있게 배우고 싶다면 — 노마드 코더

프로젝트 중심이라 결과물이 빨리 나옴

“클론 코딩” 방식이라 동기 유지가 쉬움

영상 스타일이 가볍고 성인 초보자에게 인기 많음

(노마드 코더, https://nomadcoders.co/ (https://nomadcoders.co/?utm_source=chatgpt.com))

처음 시작한다면 보통은:

파이썬 배우기 → 작은 프로젝트 만들기 → 웹/앱 분야 선택

순서가 가장 부담이 적어요.

원하면 제가:

“완전 비전공자용 3개월 학습 로드맵”

“30~40대 직장인 기준 추천 순서”

“파이썬 vs 웹개발 뭐부터 해야 하는지”

같은 것도 이어서 정리해줄게요.
