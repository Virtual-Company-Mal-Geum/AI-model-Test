# 교육-탐색-질문 / run 36

## Question

프로그래밍을 처음 배우는 성인 학습자에게 적합한 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 배우는 성인 학습자라면, 설명이 친절하고 실습 중심이며 학습 흐름이 체계적인 강좌를 고르는 게 중요해요. 아래는 입문자에게 특히 많이 추천되는 온라인 학습 플랫폼들이에요.

Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

완전 초보자용 인터랙티브 학습에 강함

브라우저에서 바로 코딩 가능

Python, JavaScript, 웹개발 입문 추천

Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학·기업 기반 강의 제공

“Python for Everybody” 같은 유명 입문 강좌가 있음

이론 + 실습 균형이 좋음

생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

한국어 무료 강의 중 입문자 만족도가 매우 높음

웹개발, Python, 데이터베이스 등을 쉽게 설명

성인 비전공자에게 특히 추천

Inflearn (인프런) (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 매우 다양함

실무형 강좌가 많고 가격도 비교적 부담이 적음

“파이썬 입문”, “웹개발 기초” 강좌 추천

Udemy (https://www.udemy.com/?utm_source=chatgpt.com)

할인 시 저렴하게 구매 가능

프로젝트 중심 강의가 많음

영어 강의가 많지만 한글 자막 지원도 많음

freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료

웹개발 중심의 단계별 커리큘럼 제공

실습량이 많아서 꾸준히 하기 좋음

CS50 by Harvard (https://cs50.harvard.edu/x/?utm_source=chatgpt.com)

세계적으로 유명한 컴퓨터공학 입문 강좌

난이도는 약간 있지만 설명 퀄리티가 매우 뛰어남

“제대로 배우고 싶다”는 사람에게 추천

처음 시작이라면 보통 이렇게 많이 추천해요:

“정말 아무것도 모른다” → 생활코딩 / Codecademy

“취업이나 실무까지 생각한다” → 인프런 / Coursera

“웹개발 프로젝트 만들어보고 싶다” → freeCodeCamp / Udemy

“컴퓨터공학 기초까지 탄탄하게” → CS50

원하면 다음 단계로:

“비전공자용 3개월 학습 로드맵”

“Python vs JavaScript 뭐부터 배울지”

“무료 강좌만 추려서 추천”

“40대·직장인에게 맞는 학습 방식”

같은 것도 이어서 정리해줄게.
