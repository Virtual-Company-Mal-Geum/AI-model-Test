# 교육-탐색-질문 / run 30

## Question

프로그래밍을 처음 배우는 성인 학습자에게 적합한 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 배우는 성인 학습자라면, “설명이 친절한지”, “실습 중심인지”, “한국어 지원이 되는지”를 기준으로 고르는 게 좋아요. 아래 강의들은 입문자 만족도가 높은 편입니다.

생활코딩

완전 초보도 이해하기 쉽게 설명해주는 무료 강의가 많아요.

HTML/CSS, JavaScript, Python, 데이터베이스까지 단계적으로 배울 수 있어요.

특히 “코딩이 처음인데 어디서 시작해야 할지 모르겠다”는 사람에게 추천합니다.

(생활코딩, https://opentutorials.org (https://opentutorials.org/?utm_source=chatgpt.com))

인프런

한국어 강의가 매우 많고, 입문자 대상 커리큘럼이 잘 정리돼 있어요.

웹 개발, Python, 앱 개발, AI 등 원하는 분야로 이어가기 좋습니다.

강사 스타일이 다양해서 자신에게 맞는 강의를 찾기 쉬워요.

(인프런, https://www.inflearn.com (https://www.inflearn.com/?utm_source=chatgpt.com))

코세라(Coursera)

해외 대학·기업 강의를 들을 수 있는 플랫폼이에요.

Google, Stanford 같은 기관의 입문 강의가 유명합니다.

영어가 부담될 수 있지만 자막 지원이 좋은 편이에요.

(Coursera, https://www.coursera.org (https://www.coursera.org/?utm_source=chatgpt.com))

Udemy

실습 위주의 강의가 많고 할인도 자주 합니다.

“파이썬으로 자동화 만들기”, “웹사이트 따라 만들기” 같은 프로젝트형 강의가 많아요.

자기 속도로 천천히 배우기 좋습니다.

(Udemy, https://www.udemy.com (https://www.udemy.com/?utm_source=chatgpt.com))

Codecademy

브라우저에서 바로 코드를 입력하면서 배우는 방식이라 입문자가 재미를 느끼기 쉬워요.

설치 과정 없이 바로 연습 가능해서 진입장벽이 낮습니다.

(Codecademy, https://www.codecademy.com (https://www.codecademy.com/?utm_source=chatgpt.com))

처음 시작한다면 추천 순서는 보통 이렇게 많이 선택해요:

완전 초보 → 생활코딩

한국어 + 체계적인 강의 → 인프런

영어 가능 + 깊이 있는 강의 → Coursera

실습 위주 → Udemy / Codecademy

원하면 다음 단계로도 추천해줄 수 있어요:

“비전공자에게 가장 쉬운 Python 강의”

“취업까지 연결되는 웹개발 로드맵”

“40대/직장인에게 맞는 코딩 공부법”

“무료 강의만 모아서 추천”
