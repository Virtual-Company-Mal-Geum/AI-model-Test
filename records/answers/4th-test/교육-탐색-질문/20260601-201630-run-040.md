# 교육-탐색-질문 / run 40

## Question

프로그래밍을 처음 배우는 성인 학습자에게 적합한 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 배우는 성인 학습자라면, **“쉽게 시작할 수 있는지 + 실습이 많은지 + 한국어 지원 여부”**를 기준으로 고르는 게 좋아요. 아래 강좌들은 입문자에게 특히 평가가 좋은 편입니다.

1. 생활코딩 (완전 초보 추천)

한국어로 설명이 매우 쉽고, 무료 강좌가 많아요.

HTML/CSS → JavaScript → Python 순서로 배우기 좋습니다.

“프로그래밍이 뭔지”부터 차근차근 설명해줘서 부담이 적어요.

추천 대상: 컴퓨터 전공이 아닌 성인 입문자

(생활코딩, https://opentutorials.org/)

2. Codecademy (실습형 입문)

브라우저에서 바로 코드를 입력하면서 배울 수 있어요.

설치 과정이 거의 없어서 시작이 편합니다.

Python, JavaScript 입문 코스가 특히 유명해요.

추천 대상: “읽기보다 직접 해보면서 배우고 싶은 사람”

(Codecademy, https://www.codecademy.com/)

3. Coursera

해외 대학 강의를 온라인으로 들을 수 있어요.

초보자용 “Python for Everybody” 과정이 매우 유명합니다.

자막 지원이 좋은 강좌가 많아요.

추천 대상: 체계적으로 배우고 싶은 사람

(Coursera, https://www.coursera.org/)

4. 인프런

한국어 개발 강의 플랫폼이라 접근성이 좋아요.

실무형 강의가 많고 가격대도 다양합니다.

“파이썬 입문”, “웹 개발 입문” 강좌가 많아요.

추천 대상: 한국어로 실무 느낌까지 배우고 싶은 사람

(인프런, https://www.inflearn.com/)

5. freeCodeCamp

완전 무료

웹 개발 중심으로 단계별 프로젝트를 만들면서 배웁니다.

실제 포트폴리오를 만들 수 있다는 장점이 있어요.

추천 대상: 비용 없이 진지하게 공부해보고 싶은 사람

(freeCodeCamp, https://www.freecodecamp.org/)

처음 시작한다면 추천 순서

생활코딩

Codecademy 또는 인프런

freeCodeCamp

Coursera 심화 과정

특히 처음이라면 Python이나 웹 개발(HTML/CSS/JavaScript)부터 시작하는 걸 추천해요.

원하면 제가:

“비전공자 기준 3개월 공부 로드맵”

“무료 강좌만 모아서 추천”

“40대/직장인 기준 현실적인 학습 순서”

“취업까지 연결되는 코스”

같은 것도 이어서 정리해줄 수 있어요.
