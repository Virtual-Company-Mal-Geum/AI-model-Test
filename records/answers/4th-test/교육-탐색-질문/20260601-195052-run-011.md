# 교육-탐색-질문 / run 11

## Question

프로그래밍을 처음 배우는 성인 학습자에게 적합한 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

처음 프로그래밍을 배우는 성인 학습자라면, “재미를 느끼면서 꾸준히 완주할 수 있는지”가 가장 중요합니다. 아래는 입문 난이도, 설명 방식, 실습 중심 여부를 기준으로 추천한 온라인 강좌들입니다.

한국어로 시작하기 좋은 강좌

인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 매우 많고, 입문자를 위한 무료 강좌도 풍부합니다.

Python, 웹개발, 데이터분석, 앱개발까지 단계별로 배우기 좋습니다.

추천 대상: 완전 초보, 직장인, 천천히 배우고 싶은 사람

생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

무료 중심의 유명한 프로그래밍 교육 사이트입니다.

설명이 친절하고 부담이 적어 처음 시작하기 좋습니다.

특히 HTML/CSS/JavaScript 입문이 강점입니다.

패스트캠퍼스 (https://fastcampus.co.kr/?utm_source=chatgpt.com)

실무형 강좌가 많고 커리큘럼이 체계적입니다.

할인 이벤트가 자주 있어 장기 과정 수강에 유리합니다.

추천 대상: 취업·이직 목표가 있는 학습자

영어지만 초보 친화적인 글로벌 강좌

Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코딩 실습 가능

“읽기 → 바로 실습” 구조라 입문자가 따라가기 쉽습니다.

Python, JavaScript 입문 추천

freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료

웹개발과 JavaScript 학습에 특히 강함

프로젝트 기반 학습이라 포트폴리오 만들기 좋습니다.

Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학 수준 강의를 온라인으로 제공

University of Michigan, Stanford University 등의 강좌를 들을 수 있습니다.

기초 컴퓨터과학(CS) 입문에 좋습니다.

CS50 by Harvard (https://cs50.harvard.edu/x?utm_source=chatgpt.com)

세계적으로 유명한 입문 컴퓨터과학 강의

난이도는 조금 있지만 설명과 과제가 뛰어납니다.

“제대로 기초를 배우고 싶다”면 강력 추천

처음 시작할 때 추천 학습 순서

“코딩이 뭔지 맛보기” → 생활코딩 / Codecademy

“Python 배우기” → 인프런 / Coursera

“웹사이트 만들기” → freeCodeCamp

“기초 CS까지 탄탄하게” → CS50
