# 교육-탐색-질문 / run 5

## Question

프로그래밍을 처음 배우는 성인 학습자에게 적합한 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 배우는 성인 학습자라면 “쉬운 설명 + 실습 중심 + 학습 커뮤니티”가 있는 강좌를 선택하는 것이 좋습니다.

1. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

완전 초보자를 위한 무료 프로그래밍 강의로 유명

HTML, CSS, JavaScript, Python, 데이터베이스 등을 기초부터 설명

비전공자와 성인 학습자에게 특히 추천

강의가 짧고 부담 없이 시작할 수 있음

2. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 매우 다양함

“파이썬 입문”, “웹 개발 입문”, “앱 개발 입문” 등 초보자 과정이 많음

강사에게 질문할 수 있는 기능 제공

실무형 강의를 찾기 좋음

3. 코드카데미 (https://www.codecademy.com/?utm_source=chatgpt.com)

직접 코드를 입력하며 배우는 인터랙티브 학습 방식

영어 기반이지만 초보자 친화적

Python, JavaScript, SQL 등을 체계적으로 배울 수 있음

4. 코세라 (https://www.coursera.org/?utm_source=chatgpt.com)

해외 대학과 기업이 제공하는 강의 수강 가능

초보자를 위한 "Python for Everybody" 같은 인기 강좌 제공

수료증 취득 가능

학습 로드맵이 잘 구성되어 있음

5. Udemy (https://www.udemy.com/?utm_source=chatgpt.com)

할인 기간에 저렴하게 구매 가능

초보자 대상 강의가 매우 많음

한 번 구매하면 평생 수강 가능

개발뿐 아니라 데이터 분석, AI 분야 입문도 가능

처음 시작한다면?

생활코딩으로 프로그래밍 개념 익히기

Python 기초 배우기

간단한 프로젝트 만들어보기

인프런 또는 코세라에서 심화 학습

마지막으로 요청하신 형식으로 정리하면:

(인프런, https://www.inflearn.com/)

(코드카데미, https://www.codecademy.com/)

(코세라, https://www.coursera.org/)

(Udemy, https://www.udemy.com/)
