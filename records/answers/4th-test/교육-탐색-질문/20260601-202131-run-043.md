# 교육-탐색-질문 / run 43

## Question

프로그래밍을 처음 배우는 성인 학습자에게 적합한 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 배우는 성인 학습자라면 **“쉬운 설명 + 실습 중심 + 입문 커리큘럼”**이 있는 플랫폼부터 시작하는 것이 좋아요.

1. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 매우 많고 입문자용 무료 강의도 풍부

파이썬, 웹 개발, 앱 개발, 데이터 분석 등 분야별 로드맵 제공

강사에게 질문할 수 있는 Q&A 기능이 잘 되어 있음

비전공자 입문자에게 특히 추천 슬기로운 정보 생활 , smartman78 님의 블로그+1 (https://smartman78.tistory.com/entry/%EC%98%A8%EB%9D%BC%EC%9D%B8-%EA%B0%95%EC%9D%98-%ED%94%8C%EB%9E%AB%ED%8F%BC-%EC%99%84%EB%B2%BD-%EA%B0%80%EC%9D%B4%EB%93%9C-%EB%AA%A9%EC%A0%81%EB%B3%84-%EC%84%A0%ED%83%9D-%EB%B0%A9%EB%B2%95%EA%B3%BC-%EC%B6%94%EC%B2%9C?utm_source=chatgpt.com)

2. 코세라(Coursera) (https://www.coursera.org/?utm_source=chatgpt.com)

스탠퍼드, 미시간대 등 유명 대학 강의를 수강 가능

기초 컴퓨터 과학부터 AI까지 체계적인 커리큘럼

영어 강의가 많지만 한국어 자막을 제공하는 경우도 많음 부동산 (https://all-the-t1me.tistory.com/40?utm_source=chatgpt.com)

3. 패스트캠퍼스 (https://fastcampus.co.kr/?utm_source=chatgpt.com)

실무 중심 강의가 강점

프로그래밍 입문부터 취업 준비 과정까지 다양

파이썬, 데이터 분석, 웹 개발 입문 강좌가 많음 부동산+1 (https://all-the-t1me.tistory.com/40?utm_source=chatgpt.com)

4. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

완전 초보자를 위한 무료 프로그래밍 교육 사이트

HTML, CSS, JavaScript, Python 등을 쉽게 설명

“코딩이 무엇인지”부터 배우고 싶은 사람에게 적합

5. Udemy(유데미) (https://www.udemy.com/?utm_source=chatgpt.com)

전 세계 강의를 저렴하게 구매 가능

할인 기간에는 강의를 매우 저렴하게 수강 가능

실습 프로젝트 중심 강의가 많음
