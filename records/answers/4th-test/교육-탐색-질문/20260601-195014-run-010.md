# 교육-탐색-질문 / run 10

## Question

프로그래밍을 처음 배우는 성인 학습자에게 적합한 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 배우는 성인 학습자라면, 너무 이론 중심보다는 실습 위주 + 쉬운 설명 + 커뮤니티 지원이 좋은 강의를 선택하는 게 중요해요. 아래는 입문자에게 특히 평가가 좋은 온라인 강좌 플랫폼들이에요.

1. 생활코딩

한국어로 배우기 가장 쉬운 프로그래밍 입문 강의 중 하나

HTML/CSS, JavaScript, Python, 데이터베이스까지 기초를 매우 친절하게 설명

무료 강의가 많아서 부담 없이 시작 가능

“프로그래밍이 뭔지” 감을 잡기에 최고 수준

(생활코딩, https://opentutorials.org/)

2. 인프런

한국 개발자들이 많이 사용하는 온라인 강의 플랫폼

“왕초보용” 강의가 매우 다양함

Python, 웹개발, 앱개발, AI까지 단계별 학습 가능

할인 이벤트가 자주 있어서 가성비 좋음

(인프런, https://www.inflearn.com/)

3. 패스트캠퍼스

취업·실무 중심 강의가 강점

입문부터 프로젝트 제작까지 이어지는 커리큘럼이 많음

“비전공자 개발자 입문” 패키지가 잘 구성되어 있음

(패스트캠퍼스, https://fastcampus.co.kr/)

4. Codecademy

영어 기반이지만 인터랙티브 학습이 매우 뛰어남

브라우저 안에서 바로 코드를 실행하며 배울 수 있음

“코딩을 손으로 익히는 느낌”이 강함

영어 부담이 크지 않다면 최고의 입문 플랫폼 중 하나

(Codecademy, https://www.codecademy.com/)

5. Coursera

해외 대학 수준 강의를 들을 수 있는 플랫폼

구글, 스탠퍼드 등의 입문 코스가 유명

체계적으로 공부하고 싶은 성인 학습자에게 추천

일부 강의는 무료 청강 가능

(Coursera, https://www.coursera.org/)

6. Udemy

전 세계 최대 규모 온라인 강의 플랫폼 중 하나

실습 중심 강의가 많고 가격 할인 폭이 큼

“Python for Beginners” 같은 초보 강의가 특히 유명

(Udemy, https://www.udemy.com/)

처음 시작한다면 추천 순서

완전 처음 → 생활코딩

한국어 실습 중심 → 인프런

취업·포트폴리오 목표 → 패스트캠퍼스

영어 가능 + 직접 코딩하며 배우기 → Codecademy

그리고 처음 언어는 보통:

웹에 관심 있으면 → JavaScript

범용성과 쉬운 문법 → Python

으로 시작하는 경우가 많아요.
