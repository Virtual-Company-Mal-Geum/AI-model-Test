# 교육-탐색-질문 / run 20

## Question

프로그래밍을 처음 배우는 성인 학습자에게 적합한 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 배우는 성인이라면 파이썬(Python) 으로 시작하는 것을 추천합니다. 문법이 비교적 쉽고, 데이터 분석·웹 개발·AI까지 확장할 수 있기 때문입니다.

1. 인프런 (국내 입문자에게 가장 추천)

한국어 강의가 많고 설명이 친절함

비전공자·직장인 대상 입문 강의가 풍부

실습 위주로 따라 하며 배우기 좋음 인프런+1 (https://www.inflearn.com/ko/courses/it-programming/programming-lang?levels=level-1&utm_source=chatgpt.com)

2. 생활코딩

무료 강의 중심

HTML, CSS, JavaScript, Python 등 기초를 쉽게 설명

프로그래밍이 처음인 사람도 부담 없이 시작 가능 공기업 통신직 & 공부 방법 가이드 (https://baekchwijun.tistory.com/347?utm_source=chatgpt.com)

3. 코드잇

체계적인 커리큘럼

퀴즈와 실습이 많아 독학하기 편함

꾸준히 학습할 수 있도록 설계되어 있음 공기업 통신직 & 공부 방법 가이드 (https://baekchwijun.tistory.com/347?utm_source=chatgpt.com)

4. Coursera

해외 유명 대학·기업 강의 수강 가능

영어 강의가 많지만 자막 지원이 잘 되어 있음

기초 컴퓨터 과학부터 전문 과정까지 다양함 Reddit (https://www.reddit.com/r/u_redsunjin/comments/1qp266e/opencoursettshelper%EB%8A%94_%EC%BD%94%EC%84%B8%EB%9D%BCcoursera_%EA%B0%95%EC%9D%98_%EC%9E%90%EB%A7%89%EA%B3%BC_%EC%9D%BD%EA%B8%B0_%EC%9E%90%EB%A3%8C%EB%A5%BC/?utm_source=chatgpt.com)
