# 교육-탐색-질문 / run 37

## Question

프로그래밍을 처음 배우는 성인 학습자에게 적합한 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 배우는 성인 학습자라면, **“설명이 친절한지 + 실습이 많은지 + 포기하지 않게 구성됐는지”**가 가장 중요해요. 아래 순서대로 시작하면 비교적 부담 없이 배울 수 있습니다.

생활코딩 — 한국어로 가장 유명한 입문 강의 중 하나. 완전 초보 기준으로 설명이 아주 쉬워요. 웹 개발, Python, 데이터 등 다양하게 배울 수 있어요.

(생활코딩, https://opentutorials.org/)

인프런 — 한국어 강의 플랫폼. “입문”, “비전공자”, “왕초보” 강좌가 많고 실무형 강의도 풍부해요.

(인프런, https://www.inflearn.com/)

Codecademy — 영어 기반이지만, 브라우저에서 바로 코딩하면서 배우는 방식이라 초보자에게 매우 직관적이에요.

(Codecademy, https://www.codecademy.com/)

CS50 (하버드) — 전 세계적으로 유명한 컴퓨터공학 입문 강의. 난이도는 약간 있지만 재미있고 동기부여가 잘 돼요.

(CS50, https://cs50.harvard.edu/x/)

Coursera — 대학 수준 강의를 체계적으로 들을 수 있어요. Python, 웹 개발, 데이터 분석 입문 과정이 많습니다.

(Coursera, https://www.coursera.org/)

freeCodeCamp — 무료로 웹 개발을 단계별 실습 중심으로 배울 수 있어요. 프로젝트 중심 학습이 강점입니다.

(freeCodeCamp, https://www.freecodecamp.org/)

Udemy — 할인 폭이 커서 저렴하게 강의를 구매할 수 있어요. 강사별 퀄리티 차이는 있으니 평점 높은 입문 강의를 고르는 게 중요해요.

(Udemy, https://www.udemy.com/)

처음 시작이라면 추천 순서는 보통 이렇게 많이 갑니다:

한국어 선호 → 생활코딩 → 인프런

영어 괜찮음 → Codecademy → freeCodeCamp → CS50

목표가 취업/실무 → Python + 웹 개발부터 시작 추천

그리고 첫 언어는 대부분 아래 중 하나를 추천해요:

Python: 가장 배우기 쉽고 활용 범위 넓음

JavaScript: 웹사이트/앱 만들기에 좋음

원하면 다음 단계로:

“비전공 성인 기준 3개월 공부 로드맵”

“완전 초보용 Python 강의 TOP 5”

“무료 강의만 골라서 추천”

“국비지원 포함 추천”

도 정리해줄 수 있어요.
