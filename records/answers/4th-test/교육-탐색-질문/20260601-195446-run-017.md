# 교육-탐색-질문 / run 17

## Question

프로그래밍을 처음 배우는 성인 학습자에게 적합한 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 배우는 성인 학습자라면, “쉽게 시작할 수 있는지”, “실습 중심인지”, “한글 지원 여부”, “학습 동기 유지”가 중요합니다. 아래 강좌/플랫폼들은 입문자에게 특히 평가가 좋은 편입니다.

생활코딩

한국어 기반이라 진입장벽이 낮고, HTML/CSS/JavaScript/Python 등을 아주 쉽게 설명해줘요.

“코딩이 뭔지”부터 시작하고 싶은 완전 초보에게 특히 추천합니다.

(생활코딩, https://opentutorials.org (https://opentutorials.org/?utm_source=chatgpt.com))

Codecademy

브라우저에서 바로 코드를 작성하면서 배우는 방식이라 설치 부담이 적어요.

영어 기반이지만 인터랙티브 학습이 강점입니다.

(Codecademy, https://www.codecademy.com (https://www.codecademy.com/?utm_source=chatgpt.com))

Coursera

대학/기업 강의를 체계적으로 들을 수 있어요.

특히 Google의 IT Support나 Python 강좌가 초보자에게 유명합니다.

일부 강좌는 한국어 자막도 제공합니다.

(Coursera, https://www.coursera.org (https://www.coursera.org/?utm_source=chatgpt.com))

인프런

한국 개발자 강의가 많고, 실무형 입문 강좌가 풍부합니다.

질문 답변 문화가 잘 되어 있어서 독학 부담이 적어요.

(인프런, https://www.inflearn.com (https://www.inflearn.com/?utm_source=chatgpt.com))

Udemy

할인 폭이 커서 저렴하게 입문 강의를 구매할 수 있어요.

“Python 완전 입문”, “웹 개발 부트캠프” 같은 강좌가 인기입니다.

(Udemy, https://www.udemy.com (https://www.udemy.com/?utm_source=chatgpt.com))

freeCodeCamp

무료로 웹 개발과 Python 등을 체계적으로 배울 수 있는 플랫폼입니다.

프로젝트 기반이라 포트폴리오 만들기에도 좋아요.

(freeCodeCamp, https://www.freecodecamp.org (https://www.freecodecamp.org/?utm_source=chatgpt.com))

처음 시작한다면 추천 순서는 보통:

한국어 선호 → 생활코딩 → 인프런

영어 가능 + 실습 선호 → Codecademy

체계적인 커리큘럼 → Coursera

무료 중심 → freeCodeCamp

그리고 언어는 보통:

처음 프로그래밍 자체를 배우기 → Python

웹사이트 만들기 → HTML/CSS/JavaScript

취업·실무 범용성 → Python 또는 JavaScript

이렇게 시작하는 경우가 많습니다.
