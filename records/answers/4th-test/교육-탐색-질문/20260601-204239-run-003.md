# 교육-탐색-질문 / run 3

## Question

프로그래밍을 처음 배우는 성인 학습자에게 적합한 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 배우는 성인 학습자라면, “설명이 쉬운가”, “실습이 많은가”, “한국어 지원이 되는가”, “작은 성공 경험을 빨리 주는가”를 기준으로 고르는 게 좋아요. 아래 강의들은 입문자 만족도가 높은 편입니다.

가장 추천하는 입문 강좌/플랫폼

생활코딩

완전 초보자에게 가장 많이 추천되는 한국어 프로그래밍 강의예요.

웹 개발, Python, JavaScript 등을 아주 쉽게 설명해줘서 “코딩이 처음”인 사람에게 특히 좋아요.

(생활코딩, https://opentutorials.org (https://opentutorials.org/?utm_source=chatgpt.com))

인프런

한국어 강의가 많고, 입문용 무료 강좌도 풍부해요.

특히 “파이썬 입문”, “웹 개발 기초”, “앱 만들기” 같은 실무형 강의가 강점입니다.

(인프런, https://www.inflearn.com (https://www.inflearn.com/?utm_source=chatgpt.com))

Codecademy

영어 기반이지만, 직접 코드를 입력하면서 배우는 인터랙티브 방식이라 초보자가 빠르게 익히기 좋아요.

“Python”, “HTML/CSS”, “JavaScript” 입문 코스가 특히 유명합니다.

(Codecademy, https://www.codecademy.com (https://www.codecademy.com/?utm_source=chatgpt.com))

Coursera

대학 수준의 체계적인 강의를 들을 수 있어요.

특히 University of Michigan 의 “Python for Everybody” 과정은 세계적으로 유명한 입문 강좌예요.

(Coursera, https://www.coursera.org (https://www.coursera.org/?utm_source=chatgpt.com))

Udemy

할인 폭이 커서 저렴하게 강의를 구매할 수 있고, 실무 중심 강좌가 많아요.

“100 Days of Code: Python” 같은 초보자 인기 강의가 유명합니다.

(Udemy, https://www.udemy.com (https://www.udemy.com/?utm_source=chatgpt.com))

CS50 (하버드 무료 강의)

난이도는 약간 있지만, 컴퓨터공학 기초를 정말 재밌게 가르치는 강의예요.

“왜 프로그래밍이 이렇게 동작하는지” 이해하고 싶은 사람에게 추천해요.

(CS50, https://cs50.harvard.edu (https://cs50.harvard.edu/?utm_source=chatgpt.com))

처음 시작한다면 추천 순서

완전 초보 + 한국어 선호 → 생활코딩 → 인프런

게임처럼 실습하며 배우고 싶음 → Codecademy

체계적인 대학식 강의 → Coursera / CS50

실무 프로젝트 빠르게 만들고 싶음 → Udemy
