# 교육-탐색-질문 / run 27

## Question

프로그래밍을 처음 배우는 성인 학습자에게 적합한 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 배우는 성인 학습자라면, “설명이 친절한지”, “실습 중심인지”, “학습 동기 유지가 쉬운지”가 중요해요. 아래는 입문자에게 특히 평가가 좋은 온라인 강좌/플랫폼들입니다.

한국어로 시작하기 좋은 강좌

생활코딩

완전 초보자에게 가장 많이 추천되는 무료 강의

웹 개발, Python, 데이터베이스 등 기초를 쉽게 설명

“왜 이걸 배우는지”를 잘 알려줘서 성인 학습자에게 특히 적합

(생활코딩, https://opentutorials.org/)

인프런

한국어 강의가 많고 실무 중심 강좌가 다양함

“파이썬 입문”, “웹 개발 입문” 같은 초급 코스가 잘 정리되어 있음

할인 이벤트가 자주 있어서 부담이 적음

(인프런, https://www.inflearn.com/)

패스트캠퍼스

커리어 전환용 로드맵이 잘 구성되어 있음

강의 퀄리티가 높고 프로젝트 기반 학습이 강점

초보자 대상 국비/부트캠프 느낌 강좌도 많음

(패스트캠퍼스, https://fastcampus.co.kr/)

영어 가능하면 매우 추천하는 강좌

CS50 by Harvard

세계적으로 유명한 컴퓨터공학 입문 강좌

단순 코딩이 아니라 “컴퓨터적 사고”를 잘 가르침

난이도는 조금 있는 편이지만 성취감이 큼

(CS50, https://cs50.harvard.edu/)

freeCodeCamp

완전 무료

웹 개발 중심으로 단계별 실습 제공

직접 코드를 작성하면서 배우는 스타일

(freeCodeCamp, https://www.freecodecamp.org/)

Codecademy

브라우저 안에서 바로 코딩 가능

설치 없이 시작 가능해서 진입장벽이 낮음

인터랙티브 학습이 강점

(Codecademy, https://www.codecademy.com/)

처음 시작한다면 추천 순서

“코딩이 뭔지 감 잡기” → 생활코딩

“Python 기초 배우기” → 인프런 또는 Codecademy

“작은 프로젝트 만들기” → freeCodeCamp

“컴퓨터공학 기초까지 제대로” → CS50

그리고 처음 언어는 보통 아래 중 하나를 추천해요:

웹사이트 만들고 싶다 → JavaScript

자동화/AI/데이터 관심 → Python

앱 개발 관심 → Kotlin(Android) 또는 Swift(iPhone)

원하면:

“비전공 성인 기준 3개월 학습 로드맵”

“무료 강의만으로 배우는 순서”

“40대 직장인에게 현실적인 코딩 공부법”

“Python 입문 강의 TOP5”

같은 것도 이어서 정리해줄게요.
