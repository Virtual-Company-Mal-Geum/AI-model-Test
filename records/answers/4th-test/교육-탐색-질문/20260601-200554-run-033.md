# 교육-탐색-질문 / run 33

## Question

프로그래밍을 처음 배우는 성인 학습자에게 적합한 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 배우는 성인 학습자라면, 문법만 배우는 강의보다 "직접 만들어보는 방식"의 강의를 추천합니다. 특히 처음에는 파이썬(Python)으로 시작하는 것이 가장 부담이 적습니다.
