# 교육-탐색-질문 / run 2

## Question

프로그래밍을 처음 배우는 성인 학습자에게 적합한 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

처음 프로그래밍을 배우는 성인 학습자라면 “재미 → 작은 성공 경험 → 꾸준한 실습” 순서로 배우는 게 중요해요. 아래 강좌들은 비전공자도 부담 없이 시작하기 좋습니다.

1. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

완전 초보자를 위한 대표적인 무료 강의

컴퓨터 기초, 웹 개발, Python, JavaScript 등을 쉽게 설명

영상 길이가 짧아 부담 없이 학습 가능

특히 “WEB1” 시리즈가 입문용으로 유명함 명랑한 햄토리의 하루+1 (https://luv-stars.tistory.com/entry/%EC%9E%85%EB%AC%B8%EC%9E%90%EB%A5%BC-%EC%9C%84%ED%95%9C-%EC%B6%94%EC%B2%9C-%ED%8C%8C%EC%9D%B4%EC%8D%AC-%EA%B0%95%EC%9D%98-%EB%AA%A8%EC%9D%8C?utm_source=chatgpt.com)

2. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 많고 실습 중심

무료 입문 강의도 다양함

Python, 웹 개발, 데이터 분석, AI 등으로 확장 가능

질문 게시판이 활발해서 혼자 공부하기 좋음 인프런 (https://www.inflearn.com/challenge/%ED%96%A5%EB%A1%9C%EC%99%80-%ED%95%A8%EA%BB%98%ED%95%98%EB%8A%94-x27%ED%96%A5%EB%A1%9C%EC%9C%88x27-%EC%99%84?cid=339353&utm_source=chatgpt.com)

3. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코드를 작성하며 학습

설치 과정 없이 시작 가능

영어 기반이지만 인터랙티브 학습이 뛰어남

Python, JavaScript 입문에 특히 추천 Keep going (https://keeeepgoing.tistory.com/1?utm_source=chatgpt.com)

4. Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

스탠퍼드, 미시간대 등 유명 대학 강의 제공

자막 지원 강의가 많음

체계적으로 공부하고 싶은 성인 학습자에게 적합 부동산 (https://all-the-t1me.tistory.com/40?utm_source=chatgpt.com)

5. K-MOOC (https://www.kmooc.kr/?utm_source=chatgpt.com)

국내 대학들의 온라인 공개 강좌

무료로 수강 가능

컴퓨터 과학 기초부터 프로그래밍 입문 과정까지 제공 부동산 (https://all-the-t1me.tistory.com/40?utm_source=chatgpt.com)

추천 학습 순서

생활코딩(Web 또는 Python 입문)

인프런 무료 Python 강의

간단한 프로젝트 만들기

Coursera 또는 K-MOOC로 CS 기초 학습

원하는 분야(웹 개발, 앱 개발, AI 등) 선택
