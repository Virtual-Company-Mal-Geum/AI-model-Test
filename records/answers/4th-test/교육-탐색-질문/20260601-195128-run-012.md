# 교육-탐색-질문 / run 12

## Question

프로그래밍을 처음 배우는 성인 학습자에게 적합한 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 배우는 성인 학습자라면, “설명이 친절한지”, “실습 중심인지”, “한국어 지원이 되는지”를 기준으로 고르는 게 좋아요. 아래 강좌들은 입문자 만족도가 높은 편입니다.

인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 많고, 완전 초보 대상 강좌가 잘 정리되어 있어요.

Python, 웹개발, 앱개발, 데이터분석까지 단계별 학습 가능.

추천 대상: 한국어로 천천히 배우고 싶은 성인 입문자.

(인프런, https://www.inflearn.com/)

생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

무료 강의 중심.

“코딩이 왜 필요한지”부터 쉽게 설명해줘서 부담이 적어요.

웹 개발(HTML/CSS/JavaScript) 입문에 특히 유명.

(생활코딩, https://opentutorials.org/)

Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코딩 실습 가능.

영어 기반이지만 인터랙티브 학습이 강점.

“따라 치면서 배우는 스타일”이라 초보자 진입장벽이 낮아요.

(Codecademy, https://www.codecademy.com/)

Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학 수준의 체계적인 강좌 제공.

University of Michigan, Stanford University 같은 학교 강의도 들을 수 있어요.

수료증 과정도 많음.

(Coursera, https://www.coursera.org/)

Udemy (https://www.udemy.com/?utm_source=chatgpt.com)

할인 폭이 커서 저렴하게 구매 가능.

실무형 강좌가 많고 선택 폭이 넓어요.

다만 강의 품질 편차가 있으니 평점·리뷰 확인 추천.

(Udemy, https://www.udemy.com/)

CS50 by Harvard (https://cs50.harvard.edu/?utm_source=chatgpt.com)

세계적으로 유명한 컴퓨터공학 입문 강좌.

난이도는 약간 높지만, 기초를 제대로 배우고 싶다면 매우 좋음.

무료 제공.

(CS50, https://cs50.harvard.edu/)

처음 시작한다면 추천 순서는 보통 이렇게 많이 갑니다:

완전 처음: 생활코딩 → 인프런

재미있게 실습: Codecademy

체계적으로 깊게: Coursera / CS50

빠르게 실무 체험: Udemy

그리고 첫 언어는 대부분:

웹에 관심 있으면 → JavaScript

자동화·데이터·AI 관심 있으면 → Python

으로 시작하는 걸 추천해요.
