# 교육-탐색-질문 / run 4

## Question

프로그래밍을 처음 배우는 성인 학습자에게 적합한 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 배우는 성인 학습자라면, “문법 암기”보다 작게 만들면서 배우는 강좌가 훨씬 오래 갑니다. 아래 순서대로 시작하면 부담이 적어요.

Python으로 기초 문법 익히기

간단한 프로젝트 만들기

웹/앱/데이터 등 관심 분야로 확장하기

추천 강좌는 난이도와 설명 친절함 기준으로 골랐어요.

입문자에게 특히 추천

생활코딩 (HTML/CSS/JavaScript/Python 입문 강력 추천) (https://opentutorials.org/?utm_source=chatgpt.com)

한국어 설명이 매우 쉬움

“왜 배우는지”를 함께 설명해줘서 비전공 성인 학습자에게 좋음

무료 강좌가 많음

Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코딩 가능

설치 없이 시작 가능해서 초보자 진입장벽이 낮음

영어 기반이지만 인터랙티브 학습이 강점

Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학 수준 입문 강의가 많음

“Python for Everybody” 같은 초보자 인기 강좌 추천

일정 관리형 학습에 적합

인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 많고 실무형 강좌가 강점

웹 개발, Python, 앱 개발 등 다양함

입문 → 프로젝트 흐름 강의가 많음

freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료

웹 개발 입문에 매우 강함

프로젝트 중심 학습 가능

Udemy (https://www.udemy.com/?utm_source=chatgpt.com)

할인할 때 저렴하게 구매 가능

“Complete Beginner” 스타일 강의가 많음

강사 스타일 차이가 커서 평점 확인 중요

목적별 추천

웹사이트 만들고 싶다 → 생활코딩, freeCodeCamp

데이터 분석/AI 해보고 싶다 → Coursera, 인프런(Python)

영어 부담 없이 배우고 싶다 → 생활코딩, 인프런

게임처럼 직접 해보며 배우고 싶다 → Codecademy

저렴하게 이것저것 찍먹하고 싶다 → Udemy

요청한 형식으로 정리하면:

(생활코딩, https://opentutorials.org/)

(Codecademy, https://www.codecademy.com/)

(Coursera, https://www.coursera.org/)

(인프런, https://www.inflearn.com/)

(freeCodeCamp, https://www.freecodecamp.org/)

(Udemy, https://www.udemy.com/)
