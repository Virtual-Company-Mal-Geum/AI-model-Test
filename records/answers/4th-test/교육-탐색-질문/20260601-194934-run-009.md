# 교육-탐색-질문 / run 9

## Question

프로그래밍을 처음 배우는 성인 학습자에게 적합한 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 배우는 성인 학습자라면 "쉬운 설명 + 실습 중심 + 학습 커뮤니티"가 있는 강좌를 선택하는 것이 좋습니다.

1. 인프런 (국내 입문자에게 가장 추천)

한국어 강의가 매우 많음

파이썬, 웹 개발, 앱 개발 등 다양한 분야

무료 입문 강의도 풍부

개발자 커뮤니티가 활발해 질문하기 쉬움 Eloan+1 (https://www.eloan.kr/picks/study?utm_source=chatgpt.com)

추천 대상:

코딩을 처음 접하는 성인

한국어로 차근차근 배우고 싶은 사람

2. 코세라 (Coursera)

세계 유명 대학과 기업의 강의 제공

초보자용 프로그래밍 과정이 잘 구성됨

일부 강의는 한국어 자막 지원

컴퓨터공학 기초를 체계적으로 배우기 좋음 금여사의 다이어트 (https://write82303.tistory.com/entry/%F0%9F%8E%93-2025%EB%85%84-%EB%AC%B4%EB%A3%8C-%EC%98%A8%EB%9D%BC%EC%9D%B8-%EA%B0%95%EC%9D%98-%ED%94%8C%EB%9E%AB%ED%8F%BC-%EB%B9%84%EA%B5%90-BEST-5?utm_source=chatgpt.com)

추천 대상:

기초 이론부터 제대로 배우고 싶은 사람

영어 자료 활용에 거부감이 없는 사람

3. Udemy

저렴한 가격에 입문 강의를 구매 가능

실습 위주의 강의가 많음

파이썬, 웹 개발, 데이터 분석 입문 과정이 풍부

추천 대상:

가성비를 중요하게 생각하는 사람

실습 중심 학습을 선호하는 사람

4. K-MOOC

국내 대학들이 제공하는 무료 공개 강좌

컴퓨터 프로그래밍 기초, 파이썬 입문 등 제공

비용 부담 없이 시작 가능 Eloan (https://www.eloan.kr/picks/study?utm_source=chatgpt.com)

추천 대상:

무료로 체계적인 학습을 원하는 사람

5. 패스트캠퍼스

직무·취업 연계형 강의가 많음

개발 입문부터 실무 프로젝트까지 연결 가능

강의 분량이 비교적 많고 체계적임 주어스 정보레터 이야기+1 (https://zooearth.tistory.com/entry/%EC%98%A8%EB%9D%BC%EC%9D%B8-%EA%B0%95%EC%9D%98-%ED%94%8C%EB%9E%AB%ED%8F%BC-%EC%99%84%EB%B2%BD-%EB%B9%84%EA%B5%90-%ED%81%B4%EB%9E%98%EC%8A%A4101%C2%B7%ED%8C%A8%EC%8A%A4%ED%8A%B8%EC%BA%A0%ED%8D%BC%EC%8A%A4%C2%B7%EC%9D%B8%ED%94%84%EB%9F%B0-%EC%B0%A8%EC%9D%B4-%F0%9F%93%9A?utm_source=chatgpt.com)

추천 대상:

개발자로 취업·이직까지 고려하는 사람

처음 시작한다면 추천 순서

인프런 무료 파이썬 입문

파이썬 기초 문법 완성

웹 개발 또는 데이터 분석 중 관심 분야 선택

프로젝트 실습

심화 강좌 수강
