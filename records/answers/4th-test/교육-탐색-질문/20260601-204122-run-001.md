# 교육-탐색-질문 / run 1

## Question

프로그래밍을 처음 배우는 성인 학습자에게 적합한 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

처음 프로그래밍을 배우는 성인 학습자라면, 아래 기준으로 고르는 게 좋아요:

설명이 쉬운가 (비전공자 대상)

실습이 많은가

한국어 지원 여부

무료로 시작 가능한가

진도를 스스로 조절할 수 있는가

입문자에게 특히 추천하는 온라인 강좌
1. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

한국어로 배우기 가장 쉬운 프로그래밍 입문 플랫폼 중 하나

HTML/CSS, JavaScript, Python, 데이터베이스 등 기초를 차근차근 설명

“왜 이걸 배우는지”를 잘 설명해줘서 성인 학습자에게 특히 인기

무료

추천 대상:

완전 처음 시작하는 사람

컴퓨터 용어가 아직 익숙하지 않은 사람

2. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저 안에서 바로 코딩 가능

따라 치면서 배우는 인터랙티브 방식

Python 입문 코스가 특히 유명

영어 기반이지만 설명이 직관적

추천 대상:

직접 손으로 해보면서 배우고 싶은 사람

짧게 자주 학습하는 스타일

3. Inflearn (인프런) (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 매우 많음

입문용부터 취업 대비까지 다양

“파이썬 입문”, “웹 개발 기초” 같은 실무형 강의가 강점

추천 대상:

한국어 강의를 선호하는 사람

나중에 실무·취업까지 연결하고 싶은 사람

4. Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학 수준 강의를 온라인으로 제공

Stanford University, University of Michigan 같은 학교 강의 수강 가능

무료 청강 가능한 과정도 많음

추천 대상:

체계적으로 깊게 배우고 싶은 사람

영어 강의에 부담이 적은 사람

5. CS50 by Harvard (https://cs50.harvard.edu/?utm_source=chatgpt.com)

세계적으로 유명한 컴퓨터과학 입문 강의

난이도는 약간 높은 편이지만 설명력이 뛰어남

문제 해결 능력을 제대로 길러줌

추천 대상:

“제대로 기초를 배우고 싶다”는 사람

시간 투자할 의지가 있는 사람

6. Udemy (https://www.udemy.com/?utm_source=chatgpt.com)

할인 기간이 많아서 저렴하게 구매 가능

Python, 웹 개발, 앱 개발 등 선택 폭이 넓음

강사 스타일 차이가 커서 평점 확인 중요

추천 대상:

특정 기술을 빠르게 배우고 싶은 사람

프로젝트 중심 학습을 좋아하는 사람

처음 시작한다면 추천 학습 순서

HTML/CSS (웹 기초)

Python 또는 JavaScript 중 하나 선택

간단한 프로젝트 만들기

Git/GitHub 익히기

원하는 분야로 확장

웹 개발

데이터 분석

앱 개발

게임 개발 등

성인 입문자 기준 추천 조합

가장 쉬운 시작:

생활코딩 → 인프런

영어 가능 + 실습 선호:

Codecademy → CS50

취업/실무 목표:

인프런 → Udemy → 프로젝트 제작

마지막으로 요청한 형식으로 정리하면:

(생활코딩, https://opentutorials.org/)

(Codecademy, https://www.codecademy.com/)

(인프런, https://www.inflearn.com/)

(Coursera, https://www.coursera.org/)

(CS50, https://cs50.harvard.edu/)

(Udemy, https://www.udemy.com/)
