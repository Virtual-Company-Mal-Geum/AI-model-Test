# 교육-탐색-질문 / run 31

## Question

프로그래밍을 처음 배우는 성인 학습자에게 적합한 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 배우는 성인 학습자라면 "쉬운 입문 → 작은 프로젝트 → 꾸준한 실습" 순서로 학습할 수 있는 플랫폼을 선택하는 것이 좋습니다.

1. Coursera

해외 유명 대학·기업의 강의를 수강할 수 있음

초보자를 위한 Python, 웹 개발, 데이터 분석 입문 과정이 풍부

영어 강의가 많지만 한글 자막을 제공하는 과정도 많음

체계적인 커리큘럼을 원하는 학습자에게 추천

2. Codecademy

브라우저에서 바로 코딩 가능

설치 없이 실습 중심으로 배울 수 있음

Python, JavaScript, HTML/CSS 입문에 특히 강점

"직접 따라 하면서 배우는" 스타일을 선호한다면 추천

3. freeCodeCamp

완전 무료

웹 개발 입문부터 프로젝트 제작까지 가능

실습 비중이 매우 높음

영어에 부담이 없다면 최고의 무료 선택지 중 하나

4. Udemy

입문 강의가 매우 많고 할인도 자주 진행

Python, Java, 웹 개발, 앱 개발 등 선택 폭이 넓음

한 번 구매하면 평생 수강 가능한 경우가 많음

5. Inflearn

국내 대표 IT 강의 플랫폼 중 하나

한국어 강의가 풍부하고 실무 중심 강좌가 많음

비전공자·직장인 대상 입문 강의가 다양함 재경일보+1 (https://news.jkn.co.kr/post/910257?utm_source=chatgpt.com)

6. K-MOOC

국내 대학 수준의 무료 공개 강좌 제공

컴퓨터공학·프로그래밍 기초 강의를 무료로 수강 가능

학습 비용을 최소화하고 싶은 경우 추천 궁굼한이야기 (https://curious40.com/entry/%EB%AC%B4%EB%A3%8C%EB%A1%9C-%ED%95%A0-%EC%88%98-%EC%9E%88%EB%8A%94-%EC%98%A8%EB%9D%BC%EC%9D%B8-%EC%9E%90%EA%B2%A9%EC%A6%9D-10%EA%B0%80%EC%A7%80-2025%EB%85%84-%EC%B6%94%EC%B2%9C?utm_source=chatgpt.com)

처음 시작한다면?

Python 기초

간단한 자동화 프로그램 만들기

웹 개발(HTML/CSS/JavaScript)

관심 분야(데이터 분석, AI, 앱 개발 등)로 확장

이 순서가 가장 부담이 적습니다.
