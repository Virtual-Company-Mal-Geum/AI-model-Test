# 교육-탐색-질문 / run 6

## Question

프로그래밍을 처음 배우는 성인 학습자에게 적합한 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 배우는 성인 학습자라면, 처음부터 어려운 컴퓨터공학 이론보다는 실습 위주로 배우면서 작은 프로젝트를 만들어보는 과정이 가장 효과적입니다.

1. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

브라우저에서 바로 코드를 작성하며 학습

초보자를 위한 Python, JavaScript, HTML/CSS 과정이 잘 구성됨

영어 기반이지만 인터랙티브 학습이라 진입장벽이 낮음 한국경제 플러스 (https://plus.hankyung.com/apps/newsinside.view?aid=201504207440A&category=&sns=y&utm_source=chatgpt.com)

2. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료

웹 개발, Python, 데이터 분석 등 체계적인 커리큘럼 제공

프로젝트 중심 학습이 강점

꾸준히 공부할 의지가 있는 성인 학습자에게 추천

3. Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

세계 유명 대학의 입문 강의를 수강 가능

초보자를 위한 Python, 컴퓨터과학 기초 강좌가 많음

수료증 취득 가능 (일부 유료) 인트라넷 (https://intranet.tistory.com/41?utm_source=chatgpt.com)

4. Khan Academy (https://www.khanacademy.org/?utm_source=chatgpt.com)

무료

프로그래밍 개념을 매우 쉽게 설명

코딩 경험이 전혀 없는 사람에게 적합 한국경제 플러스 (https://plus.hankyung.com/apps/newsinside.view?aid=201504207440A&category=&sns=y&utm_source=chatgpt.com)

5. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의

"파이썬 입문", "웹 개발 입문" 등 초보자 대상 강의가 많음

국내 개발자 취업 준비에도 유용

6. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

한국어 무료 강의

HTML, CSS, JavaScript, Python 등을 기초부터 설명

비전공 성인 학습자에게 특히 인기가 많음

처음 시작한다면?

생활코딩 또는 Codecademy로 기초 개념 익히기

Python 한 가지 언어에 집중하기

간단한 계산기, 메모장, 웹페이지 만들기 프로젝트 진행

이후 Coursera 또는 freeCodeCamp로 심화 학습

요청하신 형식으로 URL만 정리하면:

(Codecademy, https://www.codecademy.com/)

(freeCodeCamp, https://www.freecodecamp.org/)

(Coursera, https://www.coursera.org/)

(Khan Academy, https://www.khanacademy.org/)

(인프런, https://www.inflearn.com/)

(생활코딩, https://opentutorials.org/)
