# 교육-탐색-질문 / run 13

## Question

프로그래밍을 처음 배우는 성인 학습자에게 적합한 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 배우는 성인 학습자라면, “문법 암기”보다 실습 중심 + 쉬운 설명 + 꾸준히 따라갈 수 있는 구조가 있는 강좌가 좋아요. 아래 강의들은 입문자에게 특히 많이 추천되는 편입니다.

생활코딩

한국어로 아주 쉽게 설명해서 완전 초보에게 특히 좋아요.

웹 개발(HTML/CSS/JavaScript), Python, 데이터베이스 등 기초를 단계별로 배울 수 있어요.

(생활코딩, https://opentutorials.org (https://opentutorials.org/?utm_source=chatgpt.com))

인프런 (Inflearn)

한국어 강의가 많고, 입문자용 무료 강좌도 풍부해요.

Python, 웹 개발, 앱 개발, AI까지 폭넓게 배울 수 있어요.

(인프런, https://www.inflearn.com (https://www.inflearn.com/?utm_source=chatgpt.com))

Codecademy

브라우저에서 바로 코딩하면서 배우는 방식이라 초보자에게 매우 직관적이에요.

영어 기반이지만 인터랙티브해서 이해하기 쉬운 편입니다.

(Codecademy, https://www.codecademy.com (https://www.codecademy.com/?utm_source=chatgpt.com))

Coursera

대학 수준의 입문 강의를 들을 수 있어요.

특히 “Python for Everybody” 같은 강좌가 유명합니다.

(Coursera, https://www.coursera.org (https://www.coursera.org/?utm_source=chatgpt.com))

freeCodeCamp

완전 무료이며, 프로젝트를 직접 만들면서 배우는 스타일이에요.

웹 개발 입문용으로 세계적으로 유명합니다.

(freeCodeCamp, https://www.freecodecamp.org (https://www.freecodecamp.org/?utm_source=chatgpt.com))

Udemy

할인 기간이 많아서 저렴하게 강의를 구매할 수 있어요.

“Python 부트캠프”, “웹 개발 부트캠프” 같은 장기 커리큘럼이 강점입니다.

(Udemy, https://www.udemy.com (https://www.udemy.com/?utm_source=chatgpt.com))

처음 시작이라면 보통은:

완전 처음 + 한국어 선호 → 생활코딩 / 인프런

직접 따라치며 배우고 싶음 → Codecademy

체계적인 장기 학습 → Coursera / Udemy

무료 위주 → freeCodeCamp

이 조합이 가장 무난해요.
