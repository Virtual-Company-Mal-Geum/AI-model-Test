# 교육-탐색-질문 / run 21

## Question

프로그래밍을 처음 배우는 성인 학습자에게 적합한 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

처음 프로그래밍을 배우는 성인 학습자라면, “문법 암기”보다 작게 만들어보면서 배우는 방식이 훨씬 오래 갑니다. 아래 강의들은 입문자 친화적이고, 한국어 지원 또는 쉬운 영어 강의가 많아서 시작하기 좋습니다.

가장 추천하는 온라인 강좌 플랫폼

생활코딩

한국어로 매우 쉽게 설명해줘서 완전 초보자에게 특히 유명함

HTML/CSS → JavaScript → Python → 웹 개발까지 단계적으로 가능

무료 강의가 많음

“왜 이걸 배우는지” 설명을 잘해주는 스타일

(생활코딩, https://opentutorials.org/)

인프런

한국어 강의 플랫폼

입문용 Python, 웹 개발, 앱 개발 강의가 다양함

강사 스타일이 다양해서 자기에게 맞는 수업 찾기 좋음

실습 중심 강의가 많음

(인프런, https://www.inflearn.com/)

Codecademy

코드를 직접 입력하면서 배우는 인터랙티브 방식

영어가 아주 어렵지 않고, “따라 치며 배우기”에 최적화

프로그래밍이 처음인 성인 학습자에게 특히 편함

(Codecademy, https://www.codecademy.com/)

Coursera

대학 수준 강의를 온라인으로 들을 수 있음

Google, University of Michigan 같은 기관 강의가 유명

기초 컴퓨터과학을 체계적으로 배우고 싶은 사람에게 추천

(Coursera, https://www.coursera.org/)

Udemy

할인할 때 저렴하게 구매 가능

“실무 프로젝트 만들기” 스타일 강의가 많음

Python 자동화, 웹 개발, 게임 개발 등 분야 다양

(Udemy, https://www.udemy.com/)

처음 시작한다면 추천 학습 순서

HTML/CSS (웹 화면 만들기)

JavaScript 또는 Python 중 하나 선택

작은 프로젝트 만들기

Git/GitHub 익히기

원하는 분야 선택

웹 개발

데이터 분석

앱 개발

게임 개발 등

입문 언어 추천

“쉽고 활용도 높은 언어” → Python

“웹사이트 만들고 싶다” → JavaScript

개인적으로는 성인 입문자라면

생활코딩 + Python 조합이 가장 부담 없이 시작하기 좋습니다.
