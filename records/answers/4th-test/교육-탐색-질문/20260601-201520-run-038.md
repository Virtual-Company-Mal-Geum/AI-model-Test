# 교육-탐색-질문 / run 38

## Question

프로그래밍을 처음 배우는 성인 학습자에게 적합한 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 배우는 성인 학습자라면, “설명이 쉬운가”, “실습이 많은가”, “동기 유지가 쉬운가”를 기준으로 고르는 게 중요해요. 아래 강좌들은 입문자 평가가 좋고, 한국어 또는 영어 자막 지원이 잘 되어 있는 편입니다.

한국어 중심 추천

인프런 (Inflearn)

한국어 강의가 많고, 입문자 대상 강좌가 특히 강함

Python, 웹개발, 앱개발, 데이터분석까지 단계별 학습 가능

“따라 하면서 만드는” 스타일 강의가 많아서 초보자에게 적합

추천 대상: 완전 초보, 한국어 선호 학습자

(인프런, https://www.inflearn.com (https://www.inflearn.com/?utm_source=chatgpt.com))

생활코딩 (OpenTutorials)

무료 중심

“프로그래밍이 왜 필요한가”부터 매우 쉽게 설명

웹 개발(HTML/CSS/JavaScript) 입문용으로 특히 유명

추천 대상: 부담 없이 시작하고 싶은 사람

(생활코딩, https://opentutorials.org (https://opentutorials.org/?utm_source=chatgpt.com))

패스트캠퍼스 (FastCampus)

커리어 전환용 로드맵이 잘 되어 있음

프로젝트 중심 강의가 많음

프론트엔드·백엔드·AI 등 분야별 과정 체계적

추천 대상: 취업/이직 목표가 있는 성인 학습자

(패스트캠퍼스, https://fastcampus.co.kr (https://fastcampus.co.kr/?utm_source=chatgpt.com))

해외 플랫폼 추천

Codecademy

브라우저에서 바로 코딩 가능

설치 없이 실습 가능해서 입문 장벽이 낮음

인터랙티브 방식이라 지루하지 않음

추천 대상: “직접 해보면서” 배우는 스타일

(Codecademy, https://www.codecademy.com (https://www.codecademy.com/?utm_source=chatgpt.com))

Coursera

대학/기업 강의를 체계적으로 수강 가능

Google, IBM 등의 입문 과정 인기

수료증 과정도 많음

추천 대상: 체계적인 커리큘럼 선호자

(Coursera, https://www.coursera.org (https://www.coursera.org/?utm_source=chatgpt.com))

freeCodeCamp

완전 무료

웹개발·Python·데이터분석 등 전체 커리큘럼 제공

실습과 프로젝트 중심

추천 대상: 비용 없이 깊게 배우고 싶은 사람

(freeCodeCamp, https://www.freecodecamp.org (https://www.freecodecamp.org/?utm_source=chatgpt.com))

처음 시작한다면 추천 학습 순서

Python 또는 웹개발(HTML/CSS/JavaScript) 중 하나 선택

2~4주 동안 “작은 결과물 만들기”에 집중

계산기, 메모앱, 간단한 웹페이지 같은 미니 프로젝트 진행

이후 관심 분야 선택

웹서비스 → 프론트엔드/백엔드

데이터 → Python/AI

앱 → Android/iOS

원하면 다음 단계로:

“완전 비전공자 기준 추천 로드맵”

“취업 목표 기준 추천”

“Python 입문 강좌 TOP 5”

“무료만 모아서 추천”

같이 더 구체적으로 정리해줄게.
