# 교육-탐색-질문 / run 35

## Question

프로그래밍을 처음 배우는 성인 학습자에게 적합한 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 배우는 성인 학습자라면 "쉽게 시작 → 직접 실습 → 작은 프로젝트 만들기" 순서로 배우는 것이 가장 효과적입니다.

1. 생활코딩 (무료, 한국어)

완전 초보자를 위한 대표적인 입문 강좌

HTML, CSS, JavaScript, Python 등 기초부터 설명

비전공자도 이해하기 쉬운 설명

무료 콘텐츠가 매우 풍부함 인프런+1 (https://www.inflearn.com/courses?charge=FREE&skill=html-css&utm_source=chatgpt.com)

2. 인프런 (한국어)

국내 최대 규모의 개발 강의 플랫폼

초보자용 무료 강의부터 실무 강의까지 다양

특히 "김영한", "생활코딩", "얄팍한 코딩사전" 강의가 입문자에게 인기 인프런+1 (https://www.inflearn.com/ko/courses/it-programming/web-dev?charge=FREE&utm_source=chatgpt.com)

3. Coursera (영어, 자막 지원)

대학 수준의 체계적인 강의 제공

초급 Python, 웹 개발, 데이터 분석 강의가 유명

수료증 발급 가능

영어에 부담이 없다면 매우 추천 GGRS: Geoscience, GIS, & Remote Sensing (https://foss4g.tistory.com/828?utm_source=chatgpt.com)

4. freeCodeCamp (무료, 영어)

이론보다 실습 중심

브라우저에서 바로 코딩 가능

웹 개발, JavaScript, React 등을 단계적으로 학습 가능 mirabo01 님의 블로그 (https://mirabo01.tistory.com/m/entry/%F0%9F%92%BB-%EB%AC%B4%EB%A3%8C-%EC%BD%94%EB%94%A9-%EA%B3%B5%EB%B6%80-%EC%82%AC%EC%9D%B4%ED%8A%B8-%EC%B6%94%EC%B2%9C-TOP-7?utm_source=chatgpt.com)

5. Codecademy (영어)

코드를 직접 입력하면서 배우는 인터랙티브 학습 방식

설치 없이 바로 실습 가능

Python, JavaScript, SQL 등 입문 과정이 잘 구성됨 mirabo01 님의 블로그 (https://mirabo01.tistory.com/m/entry/%F0%9F%92%BB-%EB%AC%B4%EB%A3%8C-%EC%BD%94%EB%94%A9-%EA%B3%B5%EB%B6%80-%EC%82%AC%EC%9D%B4%ED%8A%B8-%EC%B6%94%EC%B2%9C-TOP-7?utm_source=chatgpt.com)

입문자 추천 학습 순서

생활코딩 → 프로그래밍 개념 익히기

인프런 → Python 또는 Java 선택

freeCodeCamp → 실습 강화

Coursera → 체계적 심화 학습

URL 목록 (요청 형식)

(생활코딩, https://opentutorials.org/ (https://opentutorials.org/?utm_source=chatgpt.com))

(인프런, https://www.inflearn.com/ (https://www.inflearn.com/?utm_source=chatgpt.com))

(Coursera, https://www.coursera.org/ (https://www.coursera.org/?utm_source=chatgpt.com))

(freeCodeCamp, https://www.freecodecamp.org/ (https://www.freecodecamp.org/?utm_source=chatgpt.com))

(Codecademy, https://www.codecademy.com/ (https://www.codecademy.com/?utm_source=chatgpt.com))

프로그래밍을 처음 시작하는 성인이라면 개인적으로는 생활코딩 → Python 입문(인프런) → 작은 프로젝트 만들기 코스를 가장 추천합니다. HTML/CSS보다 Python이 초반 성취감을 느끼기 쉽기 때문입니다.
