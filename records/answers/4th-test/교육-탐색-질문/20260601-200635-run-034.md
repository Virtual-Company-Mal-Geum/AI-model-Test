# 교육-탐색-질문 / run 34

## Question

프로그래밍을 처음 배우는 성인 학습자에게 적합한 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

처음 프로그래밍을 배우는 성인 학습자라면, 아래 기준이 중요해요:

설명이 쉬운가

실습 중심인가

한국어 지원이 되는가

무료/저렴하게 시작 가능한가

비전공자도 따라갈 수 있는가

아래는 입문자에게 특히 평이 좋은 온라인 강좌 플랫폼들이에요.

1. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

한국어 기준 최고의 입문 플랫폼 중 하나

프로그래밍 개념을 정말 쉽게 설명함

HTML/CSS, JavaScript, Python, 데이터베이스까지 폭넓음

무료

“코딩이 뭔지도 모르겠다” 수준에서 시작하기 좋음

추천 대상:

완전 초보

부담 없이 시작하고 싶은 사람

한국어 강의를 선호하는 사람

2. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국 개발자 강의 플랫폼

입문부터 실무까지 다양

질문 답변 문화가 좋아서 독학에 도움됨

무료 강의도 많음

추천 강좌 예시:

“파이썬 입문”

“웹 개발 입문”

“코딩테스트 기초”

추천 대상:

체계적으로 배우고 싶은 사람

한국어 환경 선호

취업/실무까지 생각하는 사람

3. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

해외에서 가장 유명한 인터랙티브 코딩 학습 사이트 중 하나

브라우저에서 바로 코딩 가능

“읽기”보다 “직접 입력” 중심

영어지만 초보 친화적

추천 대상:

직접 손으로 따라치며 배우는 스타일

영어 거부감이 크지 않은 사람

짧게 매일 학습하고 싶은 사람

4. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료

웹 개발 중심

프로젝트 기반 학습

전 세계적으로 유명한 무료 커리큘럼

추천 대상:

비용 없이 진지하게 배우고 싶은 사람

포트폴리오까지 만들고 싶은 사람

웹 개발 관심 있는 사람

5. Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학/기업 강의를 온라인으로 제공

Google, Stanford University 같은 기관 강의 수강 가능

체계적이고 품질이 높음

일부 강의 무료 청강 가능

추천 대상:

이론과 기초를 제대로 배우고 싶은 사람

자격증/수료증 관심 있는 사람

커리큘럼 중심 학습 선호

6. Udemy (https://www.udemy.com/?utm_source=chatgpt.com)

강의 수가 매우 많음

할인 자주 해서 저렴하게 구매 가능

특정 기술 빠르게 배우기 좋음

추천 대상:

필요한 기술만 빠르게 배우고 싶은 사람

실습 위주 선호

앱/웹/AI 등 특정 분야 관심

입문자에게 특히 추천하는 학습 순서

생활코딩
