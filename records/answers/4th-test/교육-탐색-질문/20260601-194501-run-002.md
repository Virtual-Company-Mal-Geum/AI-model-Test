# 교육-탐색-질문 / run 2

## Question

프로그래밍을 처음 배우는 성인 학습자에게 적합한 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

처음 프로그래밍을 배우는 성인 학습자라면, “문법만 설명하는 강의”보다 작은 프로젝트를 직접 만들어보는 방식이 훨씬 오래 기억에 남습니다. 아래는 입문자가 많이 선택하는 온라인 강좌 플랫폼과 특징입니다.

인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 많아서 진입장벽이 낮음

Python, 웹개발, 앱개발, AI 등 분야별 입문 강의가 풍부

“왕초보”, “비전공자” 대상 강의가 특히 많음

생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

완전 초보자에게 가장 유명한 무료 강의 중 하나

HTML/CSS/JavaScript, Python 등을 쉽게 설명

짧은 영상 중심이라 부담이 적음

Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

코드를 직접 입력하면서 배우는 인터랙티브 방식

영어 기반이지만 초보 친화적

“따라 치기”보다 실제 실습 비중이 큼

Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학 수준 강의를 온라인으로 제공

University of Michigan, Stanford University 같은 대학 강의를 들을 수 있음

체계적으로 공부하고 싶은 성인 학습자에게 추천

Udemy (https://www.udemy.com/?utm_source=chatgpt.com)

할인 폭이 커서 저렴하게 구매 가능

실무형 프로젝트 강의가 많음

Python 자동화, 웹개발 입문 강의가 인기

freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

무료로 웹개발과 JavaScript를 깊게 배울 수 있음

실습 중심 + 포트폴리오 제작 가능

해외 개발자 입문 루트로 유명

요약하면:

한국어 + 쉬운 시작 → 인프런, 생활코딩

직접 코딩하면서 배우기 → Codecademy

체계적인 커리큘럼 → Coursera

실무 프로젝트 중심 → Udemy

무료로 깊게 공부 → freeCodeCamp

마지막 요청 형식으로 정리하면:

(인프런, https://www.inflearn.com/)

(생활코딩, https://opentutorials.org/)

(Codecademy, https://www.codecademy.com/)

(Coursera, https://www.coursera.org/)

(Udemy, https://www.udemy.com/)

(freeCodeCamp, https://www.freecodecamp.org/)
