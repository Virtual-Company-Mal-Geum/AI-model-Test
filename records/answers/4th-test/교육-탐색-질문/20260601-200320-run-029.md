# 교육-탐색-질문 / run 29

## Question

프로그래밍을 처음 배우는 성인 학습자에게 적합한 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 배우는 성인이라면 "파이썬 → 간단한 프로젝트 → 웹 개발 또는 데이터 분석" 순서로 배우는 것이 가장 부담이 적습니다. 다음 강의 플랫폼들을 추천합니다.

1. 생활코딩

완전 초보자를 위한 무료 강의가 많음

프로그래밍 개념을 쉽게 설명

HTML, CSS, JavaScript, Python 등 입문 과정이 잘 구성됨

"코딩이 무엇인지"부터 배우고 싶은 분에게 추천 Keep going (https://keeeepgoing.tistory.com/1?utm_source=chatgpt.com)

2. 인프런

한국어 강의가 매우 다양함

초보자를 위한 파이썬, 웹 개발, 앱 개발 강의가 많음

실무형 강의도 많아 입문 후 계속 학습하기 좋음 devbnm+1 (https://devbnm.tistory.com/entry/%EC%BD%94%EB%94%A9-%EB%A7%89%EB%A7%89%ED%95%98%EB%8B%A4%EA%B3%A0-%EC%8B%9C%EC%9E%91%EC%9D%80-%EC%96%B8%EC%A0%9C%EB%82%98-%EC%89%AC%EC%9A%B4-%EB%B2%95?utm_source=chatgpt.com)

3. Codecademy

브라우저에서 바로 코드를 작성하며 학습 가능

영어에 거부감이 없다면 가장 인터랙티브한 입문 플랫폼 중 하나

따라 하기 방식이라 독학 초보자에게 적합 Keep going (https://keeeepgoing.tistory.com/1?utm_source=chatgpt.com)

4. Coursera

해외 대학 및 기업이 제공하는 강의 수강 가능

입문용으로는 Python for Everybody 과정이 유명

체계적인 커리큘럼을 선호하는 성인 학습자에게 추천 Reddit (https://www.reddit.com/r/u_redsunjin/comments/1qp35p3/%EC%BD%94%EC%84%B8%EB%9D%BC_%EB%93%A3%EB%8B%A4%EA%B0%80_%EC%82%AC%EC%9D%B4%EB%93%9C_%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8%EB%93%B1_%EB%AD%94%EA%B0%80_%EC%9D%B4%EA%B2%83%EC%A0%80%EA%B2%83_%EC%95%88%ED%95%B4%EB%B3%B8%EA%B2%83_%EB%93%A4%EC%9D%84_%ED%95%B4%EB%B3%B4%EA%B3%A0_%EC%9E%88%EC%9D%8C/?utm_source=chatgpt.com)

5. edX

대학 수준의 컴퓨터 과학 기초 강의 제공

하버드의 CS50 같은 명강의를 들을 수 있음

이론과 실습을 균형 있게 배우고 싶은 분에게 적합

처음 시작한다면?

생활코딩에서 프로그래밍 개념 익히기

인프런 또는 Codecademy에서 파이썬 입문

작은 프로젝트 만들기

Coursera·edX로 체계적인 심화 학습
