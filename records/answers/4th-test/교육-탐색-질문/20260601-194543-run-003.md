# 교육-탐색-질문 / run 3

## Question

프로그래밍을 처음 배우는 성인 학습자에게 적합한 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 배우는 성인 학습자라면, “쉬운 설명 + 실습 중심 + 너무 빠르지 않은 진행”이 중요해요. 아래 강의들은 입문자 만족도가 높고, 한국어 또는 쉬운 영어 기반으로 접근하기 좋은 편입니다.

생활코딩

완전 초보자에게 가장 많이 추천되는 무료 강의

HTML, CSS, JavaScript, Python 등 기초를 아주 쉽게 설명

“프로그래밍이 뭔지”부터 시작하기 좋아요

(생활코딩, https://opentutorials.org (https://opentutorials.org/?utm_source=chatgpt.com))

인프런 (Inflearn)

한국어 강의가 많고, 입문자용 로드맵이 잘 되어 있음

“파이썬 입문”, “웹 개발 입문” 같은 실전형 강좌 추천

질문 답변 문화가 활발한 편

(인프런, https://www.inflearn.com (https://www.inflearn.com/?utm_source=chatgpt.com))

코드잇 (Codeit)

비전공 성인 학습자 대상으로 구성된 인터랙티브 강의가 강점

영상만 보는 게 아니라 직접 코드를 실행하면서 배움

디자인/UI도 깔끔해서 진입장벽이 낮음

(코드잇, https://www.codeit.kr (https://www.codeit.kr/?utm_source=chatgpt.com))

Coursera

해외 대학 강의를 들을 수 있는 플랫폼

영어가 아주 어렵지는 않고, 한글 자막 지원 강의도 많음

특히 University of Michigan 의 Python 강좌가 유명

(Coursera, https://www.coursera.org (https://www.coursera.org/?utm_source=chatgpt.com))

Udemy

할인할 때 저렴하게 구매 가능

“Python for Beginners”, “Web Development Bootcamp” 같은 강의가 인기

실습 중심이라 직장인 입문자에게 잘 맞음

(Udemy, https://www.udemy.com (https://www.udemy.com/?utm_source=chatgpt.com))

freeCodeCamp

완전 무료

웹 개발, Python, 데이터 분석 등을 프로젝트 기반으로 학습 가능

영어 기반이지만 설명이 비교적 쉬운 편

(freeCodeCamp, https://www.freecodecamp.org (https://www.freecodecamp.org/?utm_source=chatgpt.com))

처음 시작한다면 추천 순서는 보통 이렇게 많이 가요:

한국어 선호 → 생활코딩 → 인프런/코드잇

영어 가능 → freeCodeCamp → Coursera → Udemy

그리고 첫 언어는 대부분:

웹사이트 만들기 관심 → HTML/CSS/JavaScript

자동화·데이터·AI 관심 → Python

으로 시작하면 가장 무난합니다.
