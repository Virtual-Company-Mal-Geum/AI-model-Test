# 교육-탐색-질문 / run 1

## Question

프로그래밍을 처음 배우는 성인 학습자에게 적합한 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

프로그래밍을 처음 배우는 성인 학습자라면, **“설명이 쉬운지 + 실습이 많은지 + 한국어 지원 여부”**를 기준으로 고르는 게 좋아요. 아래 강의들은 입문자 만족도가 높고, 혼자 시작하기에도 부담이 적은 편입니다.

생활코딩

한국어로 매우 쉽게 설명해줘서 완전 초보에게 특히 좋아요.

HTML/CSS, JavaScript, Python, 데이터베이스 등 기초를 차근차근 배울 수 있어요.

무료 강의가 많습니다.

(생활코딩, https://opentutorials.org/)

인프런

한국어 강의 플랫폼이라 접근성이 좋고, “입문자를 위한 Python”, “웹 개발 기초” 같은 강좌가 다양해요.

강사 스타일이 다양해서 자신에게 맞는 수업을 찾기 쉽습니다.

(인프런, https://www.inflearn.com/)

Codecademy

코드를 직접 입력하면서 배우는 인터랙티브 방식이라 초보자가 재미를 느끼기 좋아요.

영어 기반이지만 UI가 직관적입니다.

Python, JavaScript 입문 강좌가 특히 유명해요.

(Codecademy, https://www.codecademy.com/)

Coursera

해외 대학 강의를 온라인으로 들을 수 있어요.

특히 “Python for Everybody”가 초보자용으로 유명합니다.

자막 지원이 잘 되는 편입니다.

(Coursera, https://www.coursera.org/)

Udemy

할인할 때 저렴하게 구매 가능하고, 실무형 강의가 많아요.

“Python 부트캠프”, “웹 개발 완전 입문” 같은 강좌가 인기입니다.

(Udemy, https://www.udemy.com/)

freeCodeCamp

완전 무료인데도 커리큘럼이 탄탄해요.

웹 개발 입문 → 프로젝트 제작까지 이어지는 구조입니다.

영어 기반이지만 초보자 추천이 많습니다.

(freeCodeCamp, https://www.freecodecamp.org/)

처음 시작한다면 추천 순서는 보통 이렇게 많이 합니다:

한국어 선호 → 생활코딩 → 인프런

실습 위주 선호 → Codecademy

체계적인 대학 스타일 → Coursera

프로젝트 중심 → freeCodeCamp

특히 어떤 분야(웹 개발, 앱 개발, 게임, 데이터 분석, AI 등)에 관심 있는지 알려주면 그 방향에 맞춰 더 구체적으로 추천해줄게요.
