# 교육-탐색-질문 / run 25

## Question

프로그래밍을 처음 배우는 성인 학습자에게 적합한 온라인 강좌 추천해줘. 마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

처음 프로그래밍을 배우는 성인 학습자라면, 아래 기준이 중요해요:

설명이 쉬운가

실습 중심인가

한국어 지원 여부

무료/저렴한 가격

초보자 로드맵이 잘 되어 있는가

아래는 입문자에게 특히 평가가 좋은 온라인 강좌 플랫폼들이에요.

한국어로 시작하기 좋은 강좌
1. 인프런 (https://www.inflearn.com/?utm_source=chatgpt.com)

한국어 강의가 매우 많음

“파이썬 입문”, “웹 개발 기초” 같은 초보 강좌가 잘 정리됨

실무 개발자 강의가 많아 성장 단계별로 이어가기 좋음

성인 비전공자 수강생도 많음

추천 분야:

Python

웹 개발

데이터 분석

앱 개발

2. 생활코딩 (https://opentutorials.org/?utm_source=chatgpt.com)

완전 초보자에게 특히 유명

무료

개념 설명이 친절하고 부담이 적음

HTML/CSS/JavaScript 입문에 강함

추천 대상:

“코드가 뭔지도 모르겠다” 수준의 완전 입문자

3. 프로그래머스 (https://programmers.co.kr/?utm_source=chatgpt.com)

코딩 테스트로 유명하지만 입문 강좌도 있음

실습 환경이 웹에서 바로 제공됨

학습 → 문제풀이 연결이 쉬움

추천 분야:

Python

JavaScript

SQL

영어 기반이지만 세계적으로 인기 많은 플랫폼
4. Codecademy (https://www.codecademy.com/?utm_source=chatgpt.com)

인터랙티브 실습이 강력함

설치 없이 브라우저에서 바로 코딩 가능

“따라 하면서 배우기”에 최적화

추천 대상:

게임처럼 배우고 싶은 사람

짧게 자주 학습하는 스타일

5. Coursera (https://www.coursera.org/?utm_source=chatgpt.com)

대학 수준 강의를 온라인으로 제공

Stanford University, University of Michigan 같은 대학 강의 수강 가능

체계적인 커리큘럼이 장점

추천 강좌:

Python for Everybody

Google IT Automation with Python

6. freeCodeCamp (https://www.freecodecamp.org/?utm_source=chatgpt.com)

완전 무료

웹 개발 입문에 매우 강함

프로젝트 기반 학습

실제 포트폴리오 만들기 가능

추천 대상:

비용 부담 없이 시작하고 싶은 사람

웹 개발 관심 있는 사람

어떤 언어부터 배우면 좋을까?
가장 무난한 추천: Python
이유:

문법이 쉬움

데이터 분석, AI, 자동화 등 활용 범위가 넓음

초보자가 좌절하기 비교적 적음

웹사이트 만들기에 관심 있다면

HTML → CSS → JavaScript 순서 추천

앱/게임에 관심 있다면

JavaScript 또는 Python부터 시작 후 확장

입문자에게 추천하는 현실적인 학습 순서

생활코딩으로 “프로그래밍이 뭔지” 감 잡기

인프런/Codecademy에서 Python 기초 실습

작은 프로젝트 만들기

프로그래머스에서 쉬운 문제 풀이 시작

관심 분야(웹/AI/앱)로 확장

마지막에 요청한 형식으로 정리하면:

(인프런, https://www.inflearn.com/)

(생활코딩, https://opentutorials.org/)

(프로그래머스, https://programmers.co.kr/)

(Codecademy, https://www.codecademy.com/)

(Coursera, https://www.coursera.org/)

(freeCodeCamp, https://www.freecodecamp.org/)
