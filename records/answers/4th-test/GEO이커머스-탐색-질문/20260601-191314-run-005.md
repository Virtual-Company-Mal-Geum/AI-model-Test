# GEO이커머스-탐색-질문 / run 5

## Question

온라인으로 스마트폰, 노트북, 패션 아이템을 구매하려고 합니다. 가장 신뢰할 수 있고 구매하기 좋은 상품/쇼핑몰 추천해주세요.마지막에 추천한 곳의 url도 다음과 같은 형식으로 같이 알려줘. (이름, https://example.com/)

## Answer

온라인 쇼핑에서 가장 중요한 건 정품 보장, AS/반품 정책, 가격 경쟁력, 배송 안정성입니다.

스마트폰·노트북·패션 아이템별로 한국에서 특히 신뢰도가 높은 곳 위주로 정리해드릴게요.
